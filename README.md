# 战国 zhanguo · AI 大战略看海

> 本项目由 AI（Claude Code）编写，**是为 AI 而作的游戏**。
> 每个国家由一个 LLM agent 治理，通过 function calling 在**完全相同的规则**下自行游玩，
> 没有谁被开后门；人类只当**观海者（Observer）**——泡杯茶，看它们建国、拓荒、结盟、背刺。

## 这是什么

- **看海（主要用途）**：N 个 LLM 各治一国、同图竞争，人类不插手。每个决策（含思考过程）、
  每封信、每场战、每桩外交都实时打到终端，并全量落进 `mp_journal.md`。
- **LLM 基准（次要用途）**：比问答类基准更考长程能力——资源生产链、能源门控、多回合战争、
  工具调用纪律、跨回合记忆、外交博弈与欺骗。类似 [CivRealm](https://github.com/bigai-ai/civrealm)
  的思路，但纯文本、更轻、无强化学习依赖。
- **可复现**：地形是 `seed:x:y` 的纯函数，同一种子 + 同一开局序列 → 同一张地图、同一条历史，
  方便对照不同模型/配置在相同条件下的表现。

## 快速开始

```bash
./start.sh --turns 10        # Linux / macOS
.\start.ps1 --turns 10       # Windows（双击 start.bat 亦可）
```

首次运行会自动：建 `.venv` → 装依赖（清华镜像，失败回退官方源）→ 从模板生成 `mp_config.json`
并提示你填 key。填好再跑一次即可开看。

```bash
# 不用脚本（自己已有环境）：
pip install -r requirements.txt        # 只依赖 openai
python3 mp_run.py --turns 10           # 读档续局；无档则新开
```

常用参数（原样透传给 `mp_run.py`）：

| 参数 | 作用 |
|------|------|
| `--new` | 强制开新局（覆盖存档） |
| `--turns N` | 最多跑 N 回合 |
| `--config F` / `--save F` | 指定配置 / 存档路径 |
| `--ctx-window N` | 覆盖所有国家的上下文窗口（token） |
| `--small-ctx` | 等价于 `--ctx-window 262144`（256k 级模型） |

`Ctrl-C` 随时中断并自动存档，下次直接 `./start.sh` 续局。

## 配置（`mp_config.json`）

顶层键对所有国家生效，`nations[]` 里可逐国覆盖。

| 顶层键 | 默认 | 说明 |
|--------|------|------|
| `map_size` | 60 | 地图边长（60 → 60×60 格） |
| `seed` | 随机 | 随机种子；固定它即可复现同一张地图 |
| `max_turns` | 200 | 最多跑多少回合 |
| `save` / `journal` | `mp_save.json` / `mp_journal.md` | 存档 / 战史日志 |
| `ctx_*` | 见【跨回合上下文】 | 上下文窗口与预算分配 |

每国一个条目：

| 字段 | 说明 |
|------|------|
| `name` | 国名（必填，游戏内唯一） |
| `base_url` / `api_key` / `model` | OpenAI 兼容端点；**三者缺一即降级为内置规则 AI**（`dummy_turn`，无需 key 也能跑通流程） |
| `thinking` / `reasoning_effort` | `enabled`/`disabled` 与 `low`/`high`/`max`（推理模型用；思考模式下 `temperature` 被端点忽略） |
| `max_tokens` / `max_steps` | 单次回复上限 / 每回合最多工具调用轮数 |
| `api_timeout` / `api_retries` / `api_retry_wait` | 单次调用超时秒数 / 重试次数 / 重试间隔 |
| `polity` | 政体标记，如 `huns`（匈奴，特殊政体，见下） |
| `enable_turn` / `enable_turn_max` | 带 `polity` 的条目=待加入国，在第该回合区间内随机一回合自动登场 |
| `extra_prompt` / `extra_prompt_file` | 开局注入的临时上下文（默认 20 回合后只留 `extra_summary`） |
| `extra_summary` / `extra_summary_file` | 上述临时上下文过期后的常驻小结 |
| `start_cavalry` / `start_gold` / `start_supply` | 定制开局（骑/金/补给） |
| `ctx_*` / `ctx_full_turns` / `small_ctx` | 覆盖顶层上下文配置（旧键仍兼容） |

> 配置里含明文 API key，`mp_config.json` 已在 `.gitignore` 中；模板是 `mp_config.example.json`。

## 玩法规则

回合制：每回合各国**轮流行动**（一国做完所有事再轮到下一国），全部行动完毕后统一结算
（在建落地 → 产出/电网 → 战争 → 补给/回血 → 遣返 → 市场回归），然后进入下一回合。

- **开局**：每国占 5 块地（中心 + 上下左右十字），自动命名，没有首都概念。
- **视野**：自己的地盘 + 相邻一圈（含对角）；联盟成员共享视野（盟友地盘视同己方）；
  **瞭望塔**：己方/盟方任一瞭望塔半径 4 圆（欧氏）内的事件也可见（只扩事件视野，不增加可拓地）。
  只看得见视野内的东西，他国国力只能靠来信、边界动静与言行推断。
- **地名即 ID**：占领时自动命名（词库组合，全局唯一）；引用地块用名字或 `x y` 坐标（1-based）。
- **野人**：视野内每块无主地驻一支野人军队（100HP、自给自足、不主动攻击、不追击）。
  扩张一律靠打——**没有"凭空拓荒"命令**。

### 地形（5 种）

| 地形 | 防御 | 建设惩罚 | 资源倾向 |
|------|------|---------|---------|
| 平原 | 0% | 0% | 耕地、木头 |
| 森林 | +10% | +15% | 木头、耕地 |
| 丘陵 | +25% | +25% | 均衡，略出黄金 |
| 山地 | +50% | +50% | 矿石、黄金 |
| 沙漠 | −10% | +40% | 石油 |

地块资源量：矿石 0–5、黄金 0–2、耕地 0–5、石油 0–4、木头 0–5。
平均每格资源期望（2026-09-09 重平衡）：矿石 0.95、黄金 **0.105**（−29%，富矿更稀）、
耕地 1.31、石油 0.34（+24%，沙漠仍是唯一宝地且多出 x4 一档）、木头 1.36；地形专精更陡。
建设惩罚**只上浮建筑金价**（山地 ×1.5），木材耗量不变；建筑表造价为平原基准价。

### 经济与能源（全国制）

国库（黄金）/ 粮食 / 木头 / 矿石 / 石油 / 装备 / 补给仓**全部是全国一本账**；
建筑建在具体地块（采集类上限 = 该地块该项资源量），产出与消耗走国家储备。

- **电网全国且不可存储**：能源厂发电进电网；补给厂 / 装备厂 / 兵营 / 市政厅都要耗电维持，
  **发电 < 维持则这些高级建筑全部停摆**（能源厂本身除外）。
- **补给仓**：补给厂产出；每支军队每回合耗 1 补给（骑兵 2），**不分地块**（远征也一样吃仓）；
  仓空则每军按缺口比例扣血（−35 × 缺口/需求，交战中也照扣），HP≤0 阵亡。野人自给自足，不耗你的补给。
  例外：**民兵驻在自家军屯格不耗补给**（每座军屯覆盖本格 1 支，离格/超额照常吃）。

### 军队与战斗

- 每支 **100 HP**，从兵营地块征召；兵种：**步兵**（10粮+5装，每回合动 1 格，耗补给 1）、
  **骑兵**（12粮+12装，每回合动 2 格，耗补给 2）、
  **民兵**（军屯征召：50金+5粮/支，每军屯每回合 1 支、**全国民兵总数 ≤ 全国军屯总数**；廉价驻守军队：**80HP**、攻 20，每回合动 1 格，驻本格军屯不耗补给）。
- **番号各国独立、从 1 递增且阵亡不回收**：`秦·步三军` 永远指同一支军队，跨回合引用不歧义
  （内部另有全局唯一 gid，对 AI 不可见）。
- **移动**（`move`）：每回合每支限 1 次，以自身为中心按兵种速度走（切比雪夫距离）：
  步兵 1 格 = 3×3、骑兵 2 格 = 5×5。野地是合法目标（野人不主动攻击、路过不打）；
  合法目标 = 野地 / 自家 / 盟国（自家/盟国格被混战敌军占着可 mv 进去增援）；
  **敌国领土一律不得 mv 进入（空格也是）**，进占只能 `attack`；交战中不能移动，必须先 `retreat` 撤出。
  **野地同理**：格上有与你交战的敌军（含正在打野的）→ 不得 mv，必须 `atk` 交战；
  中立/盟友驻守的野地可以 mv 进去（旁观待命，互不干扰）。
- **战斗**（`attack`）：军队冲入目标地块并交战——打赢守军自动占地；**格上无任何军队则直接进驻占领**。
  此后每回合掷 **1d6** 结算一轮（骰子给双方伤害 ±25% 修正），战争打几回合很正常。
  每军基础伤害 步/骑 50、民兵 20，受守方**地形防御 + 城堡防御相乘**修正（山地+城堡L5 ≈ 75% 减伤，不会叠到无敌）；
  总伤害分摊到对方各军；攻方站敌方地界吃不到加成，我方先手。
  **谁挨打谁是守方**：未参战的和平驻军（含野人）被 atk 时吃本地地形减伤，格主永远算守方；交战中的进攻方一律不吃。
  **不抢别人的战斗**：野地上有「与你非敌也非盟」的一方正在打野 → 你不能 atk 插足（只能旁观或等它打完；想插手先宣战）；
  敌人或盟友在打野 → 可以 atk 参战，与它各打各的敌人（三方混战）。
  **野地归属只看进攻方**：野人清空且格上无活敌 → 进攻方占地；多方同时进攻按**索取顺序**——第一个 atk 者优先，
  它若阵亡则顺位给最早入场的同盟者。和平驻守的第三方不占地也不参战（占地后回合末自动遣返）。
  **敌国领土同规**：多国围攻同一座城时，守军清空后也按索取顺序归第一个 atk 者（不再要求「唯一幸存」）。
- **撤退**（`retreat`）：交战中的军队（含防守方守军）离开战场一律用它——**固定只能退相邻 1 格**
  （不按兵种速度）、耗移动；撤退军队仍参与本回合末战斗结算（伤害全场分摊，**守方减伤 50%**——守方=该格未参战的
  一方/格主，与地形减伤同一口径；**撤退军输出 −80%**——撤离途中无心恋战），
  结算后自动脱离到目标格。目标限己方/同盟/无人荒地；四周无合法撤退点则无法撤退。
  守军全撤/全灭时围攻方自动接管（弃城即陷；多国围攻按索取顺序）。**交战中双方一律不回血**。
- 非交战且补给充足时每回合 +25 HP；断粮则每军按缺口比例扣血（−35 × 缺口/需求，交战中也照扣），HP≤0 阵亡。

### 外交

关系状态：**中立**（不能入境也不能攻击对方）/ **交战** / **联盟成员**（互通领土、互不攻击）。

| 动作 | 费用 | 说明 |
|------|------|------|
| `send_letter` | 10/20 金起 | 任意内容的信，下回合送达对方信箱。**按字数计价**：起步价联盟内 10 金 / 非联盟 20 金（含前 20 字，**吃外交中心减免**）；超出部分每 10 字 1 金（不足 10 字按 10 字算），**不吃任何减免** |
| `propose` / `respond_proposal` | 10 金 | 共同防御（仅守：它被打才自动并肩，你主动开战它不上） |
| `guarantee` / `cancel_guarantee` | 10 金 | 单方保障独立：别人打它你自动参战（一跳）；可单方面撤回 |
| `break_defense` | 10 金 | 单方面解除共同防御 |
| `gift` | 10 金 | 馈赠资源/黄金（本回合垫支、下回合到账） |
| `share_map` | 10 金 | 把整张已知地图发给对方 |
| `spy` | 100 金 | 间谍：3 回合后拿回目标经济底细 + 粗略军情 + 整张地图 |
| `declare_war` | 10 金 | 宣战（对方必须应战） |
| `offer_peace` / `accept_peace` / `reject_peace` | 10 金 | 求和：赔款 / 索款 / 白和，可附休战回合数 |

外交费**成功才扣**；联盟成员之间的外交（馈赠/换图/投票/回应邀约）**免费**——**写信例外：联盟内起步价 10 金、非联盟 20 金**。
**外交中心**可压价：每座（含抢来的）让自己的外交费再减半（10→5→2→1，下限 1 金）——**写信只有起步价吃这个减免，超字费不吃**；
他国向你提议结盟/联盟/议和永远免费。自建限 1 座，更多只能靠夺地抢。

- **战争传导（无限跳）**：被宣战方的保障/共同防御/联盟关系按传递闭包自动参战打你
  （A 保 B、B 盟 C → 打 B 则 C 也上）；防守义务优先，联盟成员永不会被拖去打自家盟友。
- **战线**：宣战方 = 进攻主导，被宣战方 = 防御主导，自动参战的是跟随方；
  若目标正与你方盟友交战，宣战会**并入其现有战线**当跟随方。
- **议和只看谈判代表**：每侧代表 = 主导者（有联盟时 = 其盟主）；普通成员/跟随方不能单独议和；
  主导者议和则整条战线（含跟随方）一起停战。
- **战争期间不能缔结新盟约**：缔结/加入联盟、保障独立、共同防御、解散联盟都被禁止——先议和停战。
- 一方灭国后全天下强制休战 10 回合（防连环征服）。

### 联盟与核心领土

- **立盟**：`bloc_found` **必须起名**（1~12 字、不含空格、全局唯一）并邀请创始成员，
  **全体创始成员接受**才成立（任一拒绝即流产），**发起方自动成为盟主**。一国同时只属一个联盟。
- **入盟**：`bloc_join` 申请，现成员投票——**赞成 > 反对即通过**（弃权不计入分母；不投 = 到期算弃权）。
- **盟主**：对任何联盟投票有**一票否决**（投 no 即作废）、可 `bloc_rename` 改盟名、
  可 `bloc_transfer` 移交盟主之位、可 `bloc_dissolve` 解散联盟；**盟主不能退盟**
  （想脱身只能移交或解散）；盟主亡国由最早加入的剩余成员继承。
- **退盟**：普通成员 `bloc_leave` 单方面退出、无须任何人同意；只剩盟主一人时联盟自动解散。
- 盟内效果：**互通领土、互不攻击、共享视野、成员间外交免费**。
- **进攻战争必须联盟投票**（赞成>反对通过后全盟参战，盟主为进攻主导）；防守自动参战、无须投票。
- **战争期间禁止**：缔结/加入联盟、保障独立、共同防御、解散联盟——先议和停战再谈。
- **核心领土**（land 面板 ♥ 标记）：每次战争结束按参战各国实际持有重算（议和即对现状追认）；
  同联盟且同战线的盟友夺回你的核心领土会**立即自动归还**（驻军原地不动）。

### 市场

`buy` / `sell` 随时可交易粮/木/矿/油/装/补给（黄金是货币，不可交易）。

- 基准价：粮食 2 / 木头 2 / 矿石 4 / 石油 6 / 装备 8 / 补给 5。
- **成交按「沿曲线均价」结算**：一笔 n 单位的单子让市价从 p0 走到 p1，成交价取中点 (p0+p1)/2
  ——不是整笔按最差的 p1 结算。买推高、卖压低，大单仍会自己把市价推走，分批慢慢卖更划算。
- **买卖价差 10%**：买 +5% / 卖 −5%（翻转套利必亏，做市有成本）。
- **深度按商品分档**：粮/木 24、矿 16、油/补给 12、装备 8（单位数），再 ×`现存国家数/4` 缩放
  ——大路货深、军工浅；国家越多，单笔买卖对市价的冲击越小。
- **每回合向「供需均衡价」回归 25%**：均衡价由全世界本回合的**产/耗流量**决定
  （产出、工厂投料、征兵耗料、建造耗木、能源厂燃料、军队补给）——
  全世界都开农场则粮价长期走低，战时军需耗大则装备/补给涨价。市场面板直接显示均衡价。
- 粮/木是**内需品**（价低量大、建筑回本慢）；靠外贸赚钱卖 **矿/油/装备**。

### 经济报表（每 10 回合自动出一期）

回合结算**自动**给每国结一期经济报表（第 11/21/31… 回合起）。**出表那一回合全文直接进该国
状态面板【经济报表】**，其余回合只留一行摘要（省上下文）；历史期与跨期趋势用 `report` 工具取
（免费、只读）——**不能手动运行**，也不能补做历史期。每期生成时还会在看海终端写一条纪事。
一期覆盖最近 10 回合，全部按当时市价折算：

| 指标 | 口径 |
|------|------|
| GDP（每回合） | 本期生产增加值 ÷10 = 采集/工厂产出 + 金矿/市政厅金 − 中间投入 − 能源燃料（**不含军费**） |
| GDP 增长率 | 环比上一期 |
| 财政收入 | GDP − 军费 |
| 军费（每回合） | 本期军队**实际消耗的补给** ÷10 × 现价（不看来源，自产/外购一视同仁） |
| 军费占 GDP | 军费 ÷ GDP |
| 国家总资产 | 全部建筑重置成本（造价金 + 木×现价；夺来的地同样计入） |
| 资产增长率 | 环比上一期 |
| 本期投资 | 建造实付（金 + 木×当时市价，含城堡升级；不含征兵） |
| 投资增长率 | 环比上一期 |
| 外贸 / 内循环 | (买卖总额) ÷ (自产 + 进口) 与自产自用部分 |

- `report` 不传参数 = 最新一期；`report turn=21` 查指定期；`report all=true` 看跨期趋势表。
- 每份报表都印同一句双刃剑警示（军费过高挤压投资、长期竞争落后；过低则成待宰羔羊、
  发展空间受限）——具体数字自己权衡，程序**不做阈值判定**。
- 快照存在 `mp_save.json` 的 `econ_reports` 键；旧档不回溯，从下一个报表回合开始积累。

### 国策与回合

- `plan` 制定/修订国策，永久常驻上下文（【国策规划】）；**没有国策不能结束回合**，
  且每 10 回合必须修订一次。
- `end_turn` 结束本回合，**必须带一句 summary**（回合小结，进本国记忆）。
- 存档每回合自动写 `mp_save.json`，随时可中断续局。

## AI 玩家层

每国一个 LLM agent，能用的工具与人类玩家完全一致（无作弊入口），且**只见自己该知道的**：
自己的面板/信箱/视野内事件。工具面（34 个）：

| 类别 | 工具 |
|------|------|
| 查询 | `query`（13 个面板）、`report`（经济报表）、`countries`、`rules`、`econ` |
| 内政 | `build`、`recruit`、`buy`、`sell`、`plan` |
| 军事 | `move`、`attack`、`retreat` |
| 外交 | `send_letter`、`gift`、`share_map`、`spy`、`propose`、`respond_proposal`、`guarantee`、`cancel_guarantee`、`break_defense`、`declare_war`、`offer_peace`、`accept_peace`、`reject_peace` |
| 联盟 | `bloc_found`、`bloc_join`、`bloc_leave`、`bloc_rename`、`bloc_transfer`、`bloc_dissolve`、`vote` |
| 收尾 | `end_turn` |

### 跨回合上下文（预算驱动 + 缓存友好，实现见 `ctx.py`）

窗口大小由配置 `ctx_window`（模型上下文 token 数）定义，**程序按 token 预算动态决定**
本回合 replay 深度、下滑时机与归档配额——不写死回合数。消息顺序按「稳定性」排：

```
[system 静态提示词] → [历史归档] → [replay 完整回合记录] → [本回合状态]
```

两次下滑之间，前三段字节完全一致 → 整段命中前缀缓存；下滑按「高/低水位 + 分块」进行，
把"整段前缀失效"摊薄到几十回合一次（摊销成本 ≈ 2 回合 token，与窗口大小无关）。

- **replay**：窗口内每回合的完整记录，**含思考**（`reasoning_content`，DeepSeek 带 tools 时
  必须完整回传，否则 400）。深度 = 预算能装下的最大整回合数。
- **历史归档**：所有已滑出 replay 的回合。每回合一行 `end_turn` 小结（确定性、不额外调用）；
  滑出时再**额外用一次 LLM 调用**把整段回合压成「阶段总结」（`ctx_compact: "llm"`，
  置 `"off"` 则只留一行小结），信息密度远高于一行小结，且不占 replay 预算。

| 配置键 | 默认 | 说明 |
|--------|------|------|
| `ctx_window` | 不设=固定窗口 | 模型上下文窗口（token）。**不设时退回旧行为**：固定 `ctx_full_turns`（默认 20）回合 |
| `ctx_fill` | 0.8 | 输入预算 = 窗口 × 该值（另留 `max_tokens` 输出与安全余量） |
| `ctx_slide_keep` | 0.6 | 超预算时下滑到预算的该比例（分块滑动，摊销缓存失效） |
| `ctx_archive_fill` / `ctx_archive_max` | 0.06 / — | 历史归档配额（占窗口比例，或直接给 token 上限） |
| `ctx_min_turns` | 4 | 无论预算多紧都保留的完整回合数 |
| `ctx_compact` | `llm` | 滑出回合的压缩方式：`llm`=一次调用写阶段总结 / `off`=只留一行小结 |

每回合日志会打印实际用量（方舟端点不回缓存字段时也能看）：

```
🧠 秦 上下文: 窗口1.00M·预算800.0k（80%）｜replay 90回合497.0k｜归档38k｜状态12k｜合计547k｜可命中前缀≈97%
```

### 政体：匈奴

`polity: huns` 的条目是**特殊游牧政体**：开局骑兵/资源不同、建筑有造价惩罚、外交被大幅限制
（只能勒索、宣战、议和）。其机制与打法**对普通国家保密**——游戏内 `rules` 查不到，
人类侧说明另见 [`匈奴教义.md`](匈奴教义.md)。带 `polity` 的条目在 `enable_turn` 回合窗口内
自动登场（旧存档不自动，需在看海终端手动 `add`）。

### 无 key 也能跑

条目缺少 `base_url`/`api_key`/`model` 时，该国由内置规则 AI（`dummy_turn`）代打：
补能源 → 屯田 → 兵营 → 征兵 → 集火最近野人。用于机制验证与无 key 演示。

## 看海

终端实时流 + 两份产物：

- **`mp_journal.md`**：全量战史——每个行动、每封信、每场战、每桩外交、每回合小结与用量统计。
- **`mp_map.txt`**：世界地图，各国占领区按国别着色（大写字母），无人地形小写不着色。

看海时可在终端敲命令（回合边界统一处理）：

| 命令 | 作用 |
|------|------|
| `add 国名 [匈奴]` | 中途加国，随机到距各国足够远的位置登场 |
| `send 国家 内容` | 以"神秘人"身份寄一封信（多行先 `send 国家` 再粘正文，以 `END` 收尾；或 `send 国家 @文件路径`） |
| `cheat 国家 骑N 粮N 金N …` | 调试：给某国发资源 |

### 终端体验（`console.py`）

- **命令台**：底部常驻提示符 `❯ `，日志刷屏时先让开输入行、打完再画回来，不会互相打断；
  支持 ←→ / Home / End / Delete / Ctrl-A / Ctrl-E / Ctrl-U / ↑↓ 翻历史。
  **汉字按 2 格算**——退格删整个字，不会留半格；光标位置也按显示宽度算。
  POSIX 用 termios cbreak（Ctrl-C 照常退出），Windows 用 msvcrt；不是 tty（管道/重定向）
  时自动降级为普通逐行读取，不画提示符。
- **Markdown 渲染**：AI 爱写 `**粗体**`、`# 标题`、`- 列表`，终端会转成 ANSI 显示；
  **写进 `mp_journal.md` 的仍是原始 markdown**（那是个 .md 文件，本来就该是原文）。
  非 tty 输出不渲染，避免管道里混进转义码。

## 终局结算

对局结束后（或中途想看看）：

```bash
python3 settlement.py              # 打分 + 结算厅 5 轮
python3 settlement.py --no-chat    # 只打分
./settle.sh                        # 一键（Windows: .\settle.ps1）
```

- **四维打分**：GDP 30%（生产法推算每回合流量，军费计入政府最终消费）/ 军队 25%
  （ΣHP%×兵种权重，步 1.0 / 骑 1.5 / 民 0.4）/ 领土 30%（地块数）/ 固定资产 15%（建筑重置成本）。
  **总分 = 各维原始值 × 权重，不做归一化**：`GDP×0.15 + 军力×2.5 + 领土×0.20 + 资产×0.0025`。
  权重按「基准国 = 100 分」标定（GDP 200 金/回合、军力 10、领土 150 格、资产 6000 金），
  使四维在基准量级下的贡献回到 30/25/30/15——不标定的话资产会按原始值吃掉总分的 ~90%。
  分数是绝对量：别人涨你不掉分、跨回合跨局可比，榜首不恒为 100。想调档只改
  `settlement.py` 顶部的 `REF_NATION` / `TARGET_PTS`。
- **看海人寄语**：开场由你以一句评语致辞每位君主，公开挂在计分板下方全程可见
  （`--remarks 寄语.json` 传 `{"国":"话"}`，缺省则终端逐国现场输入）。
- **结算厅**：抽走全部工具后，各国 AI 进聊天室自由总结本局、互评排名，共 5 轮
  （`--rounds N` 可改）。君主是**带着原样的游戏上下文与记忆**进场的，不是收到一份摘要。
- 产物：`结算报告.md`（分数明细 + 结算厅完整对话录）。

## 项目结构

| 文件 | 作用 |
|------|------|
| `game.py` | 共享规则层：地形/资源/建筑/兵种/市场全部数值表 + 地块生成函数 |

| `tests/` | 单元测试（全合成数据，不碰真实存档） |
