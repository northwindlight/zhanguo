# EU4-like 地块小游戏（Python）

类 EU4 的地块经营小游戏。默认 **100x100 网格**，初始全迷雾。核心为
「视野扩张 + 资源生产链 + 能源门控 + 军队」。
设计目标：**全部状态可序列化为纯文本面板，供 LLM 游玩**。

## 核心规则

- **开局即占 5 地块：中心 + 上下左右（十字形）**，自动命名，没有首都概念。
- **视野 = 自己的地块 + 相邻一圈（含对角线）**。只能占领视野内地块（拓荒式扩张）。
  地图：亮色=己方、暗色=视野内未占领（可见地形）、`?`=视野外。
- **地块没有数字 ID，名字就是 ID**：占领时自动命名（词库组合，全局唯一），
  可用 `name 老名 新名` 改名。引用地块：名字 或 `x y` 坐标。
- **野人**：每个视野内未占领地块驻一支野人军队（正常军队，100HP，自给自足不需补给）；
  占领该地块即清剿野人。

## 地形（5 种）

| 地形 | 防御 | 建设惩罚 | 资源倾向 |
|------|------|---------|---------|
| 平原 | 0% | 0% | 耕地、木头 |
| 森林 | +10% | +15% | 木头、耕地 |
| 丘陵 | +25% | +25% | 均衡，略出黄金 |
| 山地 | +50% | +50% | 矿石、黄金 |
| 沙漠 | -10% | +40% | 石油 |

资源量：矿石 x0-5、黄金 x0-2、耕地 x0-5、石油 x0-3、木头 x0-5。
地形为纯函数（种子+坐标决定），视野预览与占领结果一致。

## 经济模型（全国制）

**全部资源全局存储**：粮食/矿石/石油/装备（国家储备）、木头、补给（补给仓）、黄金（国库）。
建筑建在具体地块（建造数受该地块资源量上限），但产出与消耗都走国家储备。

- **电力（能源）也是全局的，但不可存储**：全国能源厂发电进全国电网，供全部高级建筑
  （补给厂/装备厂/兵营/市政厅）维持；**发电 < 维持则高级建筑全部停摆**（能源厂除外）。
- **补给仓**：补给厂（粮+矿）产出入仓；军队每支每回合耗 1 补给（不分地块）。
- **世界市场**：黄金是货币。可交易 = 全部可存储物资（粮食/木头/矿石/石油/装备/补给），
  无需建筑随时可买卖（`market`/`buy`/`sell`）。价格受简单供需影响、随时间回归基准：
  - 买入=需求 → 推高市价；卖出=供给 → 压低市价；**整笔按成交后的清仓价结算**（大单自己
    把市价推走，越急买越贵、越急卖越贱）。
  - 每过一回合，市价相对基准价的偏离收窄 15%（回归基准价）。
  - 基准价：粮食2 / 木头2 / 矿石4 / 石油6 / 装备8 / 补给5（黄金1:10 仅作黄金矿场兑换额）。
    能源不可存储，不在市场内。
  - 产金路：黄金矿场 +10 金/回合/座；市政厅（高密度城，见建筑表）每座每回合 = 5 金 + 该地块每座建筑 ×1 金；
    卖物资也能换黄金，但价随量大跌。

### 建筑表（造价金·耗木·上限）

| 建筑 | 造价 | 耗木 | 上限 | 每回合行为 |
|------|------|------|------|-----------|
| 城堡 | 100/200/400/800/1600 | 10/级 | 5 级 | 每级 +10% 防御 |
| 林场 | 50 | 5 | =本地木头 | +1 木头 |
| 农场 | 60 | 5 | =本地耕地 | +1 粮食 |
| 矿场 | 80 | 5 | =本地矿石 | +1 矿石 |
| 石油厂 | 150 | 8 | =本地石油 | +1 石油 |
| 黄金矿场 | 200 | 10 | =本地黄金 | +1 黄金（直接入国库） |
| 木材能源厂 | 120 | 15 | =本地木头 | 耗 1 木头 → 2 能源 |
| 石油能源厂 | 300 | 15 | =本地石油 | 耗 1 石油 → 5 能源 |
| 补给厂 | 200 | 12 | =本地耕地 | 粮1+矿1 → 补给2 入**全局补给仓**（维持 1 能源） |
| 装备厂 | 240 | 12 | =本地石油 | 矿1+油1 → 装备2（维持 1 能源） |
| 兵营 | 350 | 20 | 不限地（受建筑位限制） | 维持 1 能源；每兵营每回合可征 **1 支军队**（耗 10 粮食+5 装备） |
| 市政厅 | 500 | 40 | 每地块限 1 座 | 需本地已用建筑位 **>5** 才可建；维持 1 能源；每座每回合 **5 金 + 该地块每座建筑 ×1 金**（不含市政厅）入国库 |

每地块 20 建筑位（城堡级数也占位）；**每地块每回合限建 1 座**（过一回合可再建）。

## 军队与战斗

- 每支 **100 HP**，手动征兵（`r`），从兵营地块集结，按兵种自动编番号：
  单机 步一军/骑一军…，多国 秦·步一军、楚·骑一军…。兵种：步兵(10粮+5装·动1格·补1/回合)；
  **骑兵(12粮+12装·每回合动 2 格·耗补给 2/回合)**。atk/mv/retreat 共用每回合一次移动额度。
- **移动**：`mv 军队id 地块`，每回合限 1 次、只能相邻一格（含对角线）、不能越界。
- **维持（全局补给仓）**：每支军队每回合从全局补给仓扣 1 补给，**不分地块**（远征/驻野外一样
  吃仓）；补给仓空则全国军队 -10 HP/回合，HP≤0 阵亡。
- **回血**：非战斗且未断供 → +25 HP/回合；交战中不回血。野人自给自足，不需补给、正常回血。
- **战斗（回合制战争）**：野人无 AI，不主动攻击、不追击，军队平时可**路过不打**。
  - `atk 军队id[,id...] 地块`：军队（1 格内）**冲入目标地块并与野人交战**（atk 已含移动）。
  - 此后**每过一回合**（`n`）掷战斗骰 **1d6** 结算一个战斗回合（骰子决定本回合双方
    伤害修正 ±25%），**战争打几回合很正常**。
  - 每军 **50 基础伤害**，按野人地块**地形×城堡防御%（相乘叠加，不会相加到 100% 无敌）**修正，总伤害**分摊**到各野人；
    野人防守反击**全额**（攻方站敌方地界吃不到加成）分摊到我军；我方先手。
  - `retreat 军队id 目标格`：**撤出**——当回合只挨野人一击（不还手），移到目标格脱离交战
    （交战中的军队不能直接 `mv`）。
  - **打赢自动占领**（atk 含占领逻辑），新地块自动命名；已击败地块野人不重生。
  - 扩张基本全是征服：每个视野内地块都驻野人，初始 5 块即家，之后全靠 atk 打赢自动占地。

## 面板（纯文本，喂 LLM 用）

| 命令 | 面板 | 内容 |
|------|------|------|
| `land` / 地皮 | 地皮管理面板 | 全部地块：名字/地形/防御/城堡/建筑/驻军 + 可扩张地块（含野人） |
| `res` / 资源 | 资源管理面板 | 国库/木材/补给仓/回合/电网 + 国家储备总量 + 军队 + 市场现价 |
| `market` / `mkt` | 世界市场面板 | 各物基准价/现价/相对基准/持有量（`buy`/`sell` 交易） |
| `army` / 军队 | 军队面板 | 每支军队的名字/阵营/血量/位置/移动状态 |

## 运行与命令

```bash
python3 main.py             # 读档 / 新局（默认 100x100）
python3 main.py --new --seed 42   # 指定种子新局
```

```
a [x y]            占领无野人的视野内地块（开局5块已占；扩张主要靠打赢自动占领）
b 建筑 [地块]        建造（地块=名字或坐标）
r [N] [地块] [步|骑]  征 N 支军队（步:10粮+5装·动1格·补1/回合；骑:12粮+12装·动2格·补2/回合）
mv 军队id 地块       调遣（相邻一格/回合，不越界，可路过野人不打）
atk 军队id[,id...] 地块  冲入并与该地野人交战（atk 含移动；战争随回合推进）
retreat 军队id 目标格   撤出：当回合挨一击、移到目标格脱离交战
name 老名 新名      改名（唯一、非空）
army / land / res   三个面板
n                  过一回合
m / d [地块] / s    地图 / 详情 / 统计
buy 物品 N          从世界市场购入（如 buy 木头 10，花国库黄金）
sell 物品 N         向世界市场售出（如 sell 矿石 5，赚国库黄金）
market / mkt        世界市场面板
gold|wood [N]      调试
demo N             视野内随机扩张 N 块
q                  退出（自动存档）
```

存档 `save.json`：地块（地形/资源/建筑/名字）+ 国家储备 + 世界市场现价 + 军队 + 种子 + RNG 状态。

## 多国·AI 对战（mp.py / mp_ai.py / mp_run.py）

单机之上是**多国共图**：每国一个 LLM agent，通过 OpenAI function tool-call 玩，
机制与玩家完全一致、无作弊入口；你当 **Observer（看海）**，看得见每个国家每个行动 + 全部通信。

- `mp.py`  多国引擎：各国独立国库/储备/电网/军队/国土/信箱；野人守无人区；关系约束
  （中立禁入境禁打、同盟互通、交战可打）；**打赢即夺地、空城踏入即陷**；结盟/断盟(军队
  全部撤出)/保障独立/共同防御/宣战(对方必须接受，被保障与共同防御方作为**跟随方**参战)/
  **求和只看主导者**（宣战方/被宣战方各为一边主导，跟随方不能单谈；主导者议和则**整条战线含跟随方一起停战**）
  (pay 赔款/demand 索款/white 白和)；信箱下回合到信；灭国清场；**建设施工 1 回合：下单即在建，回合末
  落地，下回合起才发电/收获/征兵**。**撤出攻守对等**：交战中的军队（含防守方守军）离开战场一律用 `retreat`——
  挨敌方一击（约半回合战损）+ 耗移动；`mv` 不能从交战地撤离。守军全撤/全灭时进攻方自动占领（守军弃城即陷）。
  但**交战中的军队（含守军）一律不回血**。
- `mp_ai.py` 把全部功能注册成 tools（`query` 随时取回国库/地皮/军队/市场面板、build/recruit/
  move/attack/retreat/buy/sell/expand/写信/外交全套）；每国只见自己该知道的；支持
  deepseek-v4-flash 之类**推理模型**（reasoning_content 多轮思考、思考不截断）；另有 `dummy_turn`
  规则 AI 供无 key 验证。
- `mp_run.py` 无人值守自动一局 + 看海（每回合轮流唤醒各国→结算→投信→存档）；`Ctrl-C` 存档续局。
  看海时可在终端**中途加国**：输入 `add 国名 [匈奴]`（如 `add 匈奴` / `add 秦`），
  随机到距各国足够远的位置登场。
- **匈奴政体**：**特殊游牧政体**，其开局资源、机制与教义（策略）全部保密——
  详见独立文档 `匈奴教义.md`；游戏内普通国家查不到其参数与打法。
  登场：新局在配置的 `enable_turn` 回合自动加入（如 120–150 窗口）；旧存档不自动，看海终端 `add 匈奴`/`add 林胡` 手动中途加入。

```bash
# 配置文件 mp_config.json：map_size/seed + 每国 base_url/api_key/model（直连 deepseek 等）
~/.venv/bin/python mp_run.py --turns 10     # 跑 10 回合；--new 重开；Ctrl-C 存档退出
```
看海产物：终端实时流 + `mp_journal.md`（每封信/每个行动/战报/外交全记录）。
