# 战国 zhanguo · AI 大战略看海

> 本项目由 AI（Claude Code）编写，**是为 AI 而作的游戏**。
> 每个国家由一个 LLM agent 治理，通过 function calling 在**完全相同的规则**下自行游玩，
> 没有谁被开后门；人类只当**观海者（Observer）**——泡杯茶，看它们建国、拓荒、结盟、背刺。
>
> **本文档以代码为准**：全部硬数字（造价/产出/费率/默认值）逐条对照引擎核实，
> 并由 `tests/test_readme_sync.py` 盯着——改引擎不改文档，测试会红。

## 这是什么

- **看海（主要用途）**：N 个 LLM 各治一国、同图竞争，人类不插手。每个决策（含思考过程）、
  每封信、每场战、每桩外交都实时打到终端，并全量落进 `mp_journal.md`。
- **LLM 基准（次要用途）**：比问答类基准更考长程能力——资源生产链、能源门控、多回合战争、
  工具调用纪律、跨回合记忆、外交博弈与欺骗。类似 [CivRealm](https://github.com/bigai-ai/civrealm)
  的思路，但纯文本、更轻、无强化学习依赖。
- **可复现**：地形与资源由 **`(seed, size)` 决定的一整张图**（蓝噪声 + 密度图调制，
  `mapgen.py`；同 seed 换尺寸会是另一张图），地名仍是 `seed:x:y` 的纯函数；
  同一种子 + 同一开局序列 → 同一张地图、同一条历史，方便对照不同模型/配置在相同条件下的表现。
  跨进程复现由 `tests/test_determinism.py`（不同 `PYTHONHASHSEED` 子进程存档哈希对拍）看门。

## 快速开始

```bash
./start.sh --turns 10        # Linux / macOS
.\start.ps1 --turns 10       # Windows（双击 start.bat 亦可）
```

首次运行会自动：建 `.venv` → 装依赖（清华镜像，失败回退官方源）→ 从模板生成 `mp_config.json`
并提示你填 key。填好再跑一次即可开看。

```bash
# 不用脚本（自己已有环境）：
pip install -r requirements.txt        # 只依赖 openai
python3 mp_run.py --turns 10           # 读档续局；无档则新开
```

常用参数（原样透传给 `mp_run.py`）：

| 参数 | 作用 |
|------|------|
| `--new` | 强制开新局（覆盖旧存档）。不带 `--new` 时若旧档版本不符会停下让人决定，不静默覆盖 |
| `--turns N` | 最多跑 N 回合 |
| `--config F` / `--save F` | 指定配置 / 存档路径 |
| `--ctx-window N` | 覆盖所有国家的上下文窗口（token） |
| `--small-ctx` | 等价于 `--ctx-window 262144`（256k 级模型） |

`Ctrl-C` 随时中断并自动存档（存档永远落在回合边界），下次直接 `./start.sh` 续局。

## 配置（`mp_config.json`）

顶层键对所有国家生效，`nations[]` 里可逐国覆盖。

| 顶层键 | 默认 | 说明 |
|--------|------|------|
| `map_size` | 60 | 地图边长（60 → 60×60 格） |
| `seed` | 随机 | 随机种子；固定它即可复现同一张地图 |
| `max_turns` | 200 | 最多跑多少回合 |
| `rule_ai` | `v10` | **无 key 国家的代打规则 AI 版本**（`v10`/`v9`/`v6`/`v5`/`v4`/`ai`，见 `rule_ai.py` 的历代表）；`nations[]` 里可**逐国覆盖**。未知版本当场报错，不静默退回 |
| `save` / `journal` | `mp_save.json` / `mp_journal.md` | 存档 / 战史日志 |
| `ctx_*` | 见【跨回合上下文】 | 上下文窗口与预算分配 |

每国一个条目：

| 字段 | 默认 | 说明 |
|------|------|------|
| `name` | — | 国名（必填，游戏内唯一） |
| `base_url` / `api_key` / `model` | — | OpenAI 兼容端点；**三者缺一即降级为内置规则 AI**（`dummy_turn`，无需 key 也能跑通流程） |
| `provider` | **必填** | 显式声明提供方（**不按 base_url 猜**）：`openai` / `openai-compat` / `deepseek` / `ark` 走 OpenAI 兼容端点实现；`anthropic` 为**预留位**——`llm_provider.AnthropicCompat` 已占位，接线配方在其 docstring，回合循环与上下文层无需改动。走 LLM 的条目（配了 `base_url`/`api_key`/`model`）必须声明，缺失会在运行时直接报错提示 |
| `thinking` / `reasoning_effort` | — | `enabled`/`disabled` 与 `low`/`high`/`max`（推理模型用；思考模式下 `temperature` 被端点忽略） |
| `temperature` | 0.3 | 采样温度 |
| `max_tokens` | 4000 | 单次回复上限 |
| `max_steps` | 24 | 每回合最多工具调用轮数 |
| `max_actions` | 12 | 规则 AI 代打时每回合动作上限（仅无 key 条目生效） |
| `api_timeout` | 180 | 单次调用超时秒数（POSIX 另有 SIGALRM 硬超时兜底；Windows 只靠 SDK 超时） |
| `api_retries` / `api_retry_wait` | 3 / 2.0 | 重试次数 / 重试间隔秒数（线性退避；只重试网络/限流/5xx，4xx 直接抛） |
| `polity` | — | 政体标记，如 `huns`（匈奴，特殊政体，见下） |
| `enable_turn` / `enable_turn_max` | — | 带 `polity` 的条目=待加入国，在该回合区间内自动登场。**登场回合每次读配置现算**（由 seed+国名决定，重启不变）；改窗口/新增待登场国**立刻生效**、**删掉条目即不再登场**，不依赖存档里的旧计划 |
| `extra_prompt` / `extra_prompt_file` | — | 开局注入的临时上下文（默认 20 回合后只留 `extra_summary`） |
| `extra_summary` / `extra_summary_file` | — | 上述临时上下文过期后的常驻小结 |
| `start_cavalry` / `start_gold` / `start_supply` | — | 定制开局（骑/金/补给），**仅对 `polity: huns` 条目生效**（匈奴缺省 6 骑 / 1000 金 / 200 补给） |
| `ctx_*` / `ctx_full_turns` / `small_ctx` | — | 覆盖顶层上下文配置（旧键仍兼容） |

> 配置里含明文 API key，`mp_config.json` 已在 `.gitignore` 中；模板是 `mp_config.example.json`。

## 玩法规则

回合制：每回合各国**轮流行动**（一国做完所有事再轮到下一国；先手按回合轮转——
第 N 回合从第 `(N-1) mod 存活国数` 个国家起，无人被永久排最后），全部行动完毕后统一结算，
然后进入下一回合。

**回合结算的固定顺序**（`World.resolve_turn`）：

1. **采集**：林场/农场/矿场/石油厂/军屯产出入储备，黄金矿场产金入国库；
2. **电网**：能源厂烧燃料发电 → 发电 < 维持则本回合高级建筑全部停摆；够电则工厂投料产出、市政厅产金；
3. **战争结算**：每个交战格掷 1d6 打一轮（含撤退军，见下）；
4. **撤退落地**：标记撤退的军队结算后脱离到目标格；
5. **补给与回血**：每军吃补给（步 1 / 骑 2 / 民兵驻自家军屯格免费），缺口按比例扣血甚至饿毙；非交战且满补给的军队 +25 HP；
6. **脱离清扫与弃城即陷**：格上已无活敌的军队解除交战；本回合打过仗、守军全撤/全灭的格子由围攻方按索取顺序接管；
7. **遣返与投票到期**：断盟/停战后滞留他国中立领土的军队自动向本国方向撤；逾期未决的联盟投票按已投部分定论；
8. **市场**：按本回合全世界产/耗流量重算均衡价，市价向均衡价回归 25%；
9. **在建落地**：本回合下单的建筑此刻才落成——**下回合起**才发电/收获/征兵（落地在市场之后，故新建筑不影响本期均衡价）；
10. **经济报表**：每 10 回合自动结一期（见下）。

- **开局**：每国占 5 块地（中心 + 上下左右十字），自动命名，没有首都概念。
  开局资源全国一致：黄金 1500、粮 20、木 60、矿 10、油 0、装备 5、补给 10。
- **视野**：自己的地盘 + 相邻一圈（含对角）；联盟成员共享视野（盟友地盘视同己方）；
  **瞭望塔**：己方/盟方任一瞭望塔半径 4 圆（欧氏）内的事件也可见（只扩事件视野，不增加可拓地）。
  只看得见视野内的东西，他国国力只能靠来信、边界动静与言行推断。
  **迷雾限眼不限手**：可对视野外的格下 mv/atk——撞上隐藏的规则墙（中立领土/暗藏敌军/别人的战场）时
  报错如实（斥候情报），但该军本回合移动额度作废；看得见的格撞墙不罚。侦察有料，但不白给。
- **地名即 ID**：占领时自动命名（词库组合，全局唯一；命名走 `seed:x:y` 独立随机流，
  不碰战斗骰）；引用地块用名字或 `x y` 坐标（1-based）。
- **野人**：**开局全图每块无主地都驻一支野人军队**（100HP、自给自足、不主动攻击、不追击）
  ——野人是地图的静态属性，不随谁看见、谁扩张而出现（同一 seed 布局永远相同）；
  守卫被杀后该格永久清空、不再重生。扩张一律靠打——**没有"凭空拓荒"命令**。

### 地形（5 种）

| 地形 | 防御 | 建设惩罚 |
|------|------|---------|
| 平原 | 0% | 0% |
| 森林 | +10% | +15% |
| 丘陵 | +25% | +25% |
| 山地 | +50% | +50% |
| 沙漠 | −10% | +40% |

建设惩罚**只上浮建筑金价**（山地 ×1.5），木材耗量不变；建筑表造价为平原基准价。
**地形也管走路**：多格移动逐格判定、按地形扣移动力——见下面的【移动】。
地图生成（蓝噪声 + 密度图调制）与资源分布详见
[`docs/地图生成与资源分布.md`](docs/地图生成与资源分布.md)（人类侧资料，由权重表现场算出）。
采集建筑上限 = 该地块该项资源量，这一条是游戏规则。

### 经济与能源（全国制）

国库（黄金）/ 粮食 / 木头 / 矿石 / 石油 / 装备 / 补给仓**全部是全国一本账**；
建筑建在具体地块（采集类上限 = 该地块该项资源量），产出与消耗走国家储备。

- **电网全国且不可存储**：能源厂发电进电网；补给厂 / 装备厂 / 兵营 / 市政厅都要耗电维持，
  **发电 < 维持则这些高级建筑全部停摆**（能源厂本身除外）。
- **补给仓**：补给厂产出；每支军队每回合耗 1 补给（骑兵 2），**不分地块**（远征也一样吃仓）；
  仓空则每军按缺口比例扣血（−35 × 缺口/需求，交战中也照扣），HP≤0 阵亡。野人自给自足，不耗你的补给。
  例外：**民兵驻在自家军屯格不耗补给**（每座军屯覆盖本格 1 支，离格/超额照常吃）。

### 军队与战斗

- 每支 **100 HP**，从兵营地块征召；兵种：**步兵**（10粮+5装，动 1 格/回合，耗补给 1）、
  **骑兵**（12粮+12装，平地动 2 格、崎岖 1 格，耗补给 2）、
  **民兵**（军屯征召：50金+5粮/支，每军屯每回合 1 支、**全国民兵总数 ≤ 全国军屯总数**；
  廉价驻守军队：**80HP**、攻 20，动 1 格/回合，驻本格军屯不耗补给）。
- **番号各国独立、从 1 递增且阵亡不回收**：`秦·步三军` 永远指同一支军队，跨回合引用不歧义
  （内部另有全局唯一 gid，对 AI 不可见）。
- **移动**（`move`）：每回合每支限 1 次，**逐格走、按地形扣移动力**
  （移动力 = 兵种 "动 N 格" 的那个 N；一步的代价 = **出发格与目标格取更贵的那个**）：
  **平原/丘陵/沙漠每格 1、森林/山地每格 2**（顺序同 `TERRAIN_STATS`，守卫按代码现算对账）。所以骑兵在平地能走 2 格，
  一旦涉森林/山地就只能走 1 格，而且**穿不过去**（走一步就把移动力花光）；
  步兵/民兵任何地形每格 1（仍是 1 格）。**多格移动逐格判定**：隔着一道山、或借道别人的地界，都过不去。
  野地是合法目标（野人不主动攻击、路过不打）；
  合法目标 = 野地 / 自家 / 盟国（自家/盟国格被混战敌军占着可 mv 进去增援）；
  **敌国领土一律不得 mv 进入（空格也是）**，进占只能 `attack`；交战中不能移动，必须先 `retreat` 撤出。
  **野地同理**：格上有与你交战的敌军（含正在打野的）→ 不得 mv，必须 `atk` 交战；
  中立/盟友驻守的野地可以 mv 进去（旁观待命，互不干扰）。
- **战斗**（`attack`）：军队冲入目标地块并交战——打赢守军自动占地；**格上无任何军队则直接进驻占领**。
  `attack` 与 `move` **同一套逐格判定**（同样的移动力与地形代价）⇒ 隔着一道山地/森林打不到，
  借道别人的地界也冲不进去（没有"跳过去直取纵深"这回事）。
  此后每回合掷 **1d6** 结算一轮（骰面 1~6 → 双方伤害修正 −25%/−15%/−5%/+5%/+15%/+25%，每方各掷各的），
  战争打几回合很正常。
  每军基础伤害 步/骑 50、民兵 20，受守方**地形防御 + 城堡防御相乘**修正（山地+城堡L5 = 75% 减伤，
  不会叠到无敌）；总伤害分摊到对方各军；攻方站敌方地界吃不到加成，我方先手。
  **谁挨打谁是守方**：未参战的和平驻军（含野人）被 atk 时吃本地地形减伤，格主永远算守方；交战中的进攻方一律不吃。
  **不抢别人的战斗**：野地上有「与你非敌也非盟」的一方正在打野 → 你不能 atk 插足（只能旁观或等它打完；想插手先宣战）；
  敌人或盟友在打野 → 可以 atk 参战，与它各打各的敌人（三方混战）。
  **野地归属只看进攻方**：野人清空且格上无活敌 → 进攻方占地；多方同时进攻按**索取顺序**——第一个 atk 者优先，
  它若阵亡则顺位给最早入场的同盟者。和平驻守的第三方不占地也不参战（占地后回合末自动遣返）。
  **敌国领土同规**：多国围攻同一座城时，守军清空后也按索取顺序归第一个 atk 者（不再要求「唯一幸存」）。
  **已下令撤退的军队不索取地块**——留下的人才配拿。
- **撤退**（`retreat`）：交战中的军队（含防守方守军）离开战场一律用它——**固定只能退相邻 1 格**
  （不按兵种速度）、耗移动；撤退军队仍参与本回合末战斗结算（伤害全场分摊，**守方减伤 50%**——守方=该格未参战的
  一方/格主，与地形减伤同一口径；**撤退军输出 −80%**——撤离途中无心恋战），
  结算后自动脱离到目标格。目标限己方/同盟/无人荒地（荒地上有与你交战的敌军也不行）；
  四周无合法撤退点则无法撤退。
  守军全撤/全灭时围攻方自动接管（弃城即陷；多国围攻按索取顺序）。**交战中双方一律不回血**。
- 非交战且补给充足时每回合 +25 HP；断粮则每军按缺口比例扣血（−35 × 缺口/需求，交战中也照扣），HP≤0 阵亡。

### 外交

关系状态：**中立**（不能入境也不能攻击对方）/ **交战** / **联盟成员**（互通领土、互不攻击）。

| 动作 | 费用 | 说明 |
|------|------|------|
| `send_letter` | 10/20 金起 | 任意内容的信，下回合送达对方信箱。**按字数计价**：起步价联盟内 10 金 / 非联盟 20 金（含前 20 字，**吃外交中心减免**：每座 −5、下限 5）；超出部分每 10 字 1 金（不足 10 字按 10 字算），**不吃任何减免** |
| `propose` / `respond_proposal` | 10 金 | 共同防御（仅守：它被打才自动并肩，你主动开战它不上）；向建有外交中心的国家发起提议免费 |
| `guarantee` / `cancel_guarantee` | 10 金 | 单方保障独立：别人打它你自动参战（一跳）；可单方面撤回。联盟/共同防御/保障两两互斥 |
| `break_defense` | 10 金 | 单方面解除共同防御 |
| `gift` | 10 金 | 馈赠资源/黄金（本回合垫支、下回合到账；收方亡国则退回） |
| `share_map` | 10 金 | 把整张已知地图发给对方 |
| `spy` | 100 金 | 间谍：3 回合后拿回目标经济底细 + 粗略军情（仅各兵种数量）+ 整张地图。**固定价，不吃外交中心减免** |
| `declare_war` | 10 金 | 宣战（对方必须应战） |
| `offer_peace` / `accept_peace` / `reject_peace` | 10 金 | 求和：赔款 / 索款 / 白和，可附休战回合数；向建有外交中心的国家发起求和提议免费 |

外交基础费 10 金可被**自己的**外交中心压价：每座（含抢来的）减半（10→5→2→1，下限 1 金）。
外交费**成功才扣**（合法失败不烧金）；联盟成员之间的外交（馈赠/换图/提议/回应邀约）免费——
**写信例外：联盟内起步价 10 金、非联盟 20 金**。盟内操作（投票/改盟名/移交盟主/解散联盟）一律免费。
**战争传导（无限跳）**：被宣战方的保障/共同防御/联盟关系按传递闭包自动参战打你
（A 保 B、B 盟 C → 打 B 则 C 也上）；防守义务优先，联盟成员永不会被拖去打自家盟友；
已与攻方或守方交战的第三方不会被重复收编。
**战线**：宣战方 = 进攻主导，被宣战方 = 防御主导，自动参战的是跟随方；
若目标正与你方盟友交战，宣战会**并入其现有战线**当跟随方（不开平行战争）。
**议和只看谈判代表**：每侧代表 = 主导者（有联盟时 = 其盟主）；普通成员/跟随方不能单独议和；
主导者议和则整条战线（含跟随方）一起停战。议和赔款在接受时校验国库。
**战争期间不能缔结新盟约**：缔结/加入联盟、保障独立、共同防御、解散联盟都被禁止——先议和停战。
一方灭国后全天下强制休战 10 回合（防连环征服）；休战期内不得宣战。

### 联盟与核心领土

- **立盟**：`bloc_found` **必须起名**（1~12 字、不含空格、全局唯一）并邀请创始成员，
  **全体创始成员接受**才成立（任一拒绝即流产），**发起方自动成为盟主**。一国同时只属一个联盟。
- **入盟**：`bloc_join` 申请，现成员投票——**赞成 > 反对即通过**（弃权不计入分母；不投 = 到期算弃权；
  票数已无悬念时提前定论）。
- **盟主**：对任何联盟投票有**一票否决**（投 no 即作废）、可 `bloc_rename` 改盟名、
  可 `bloc_transfer` 移交盟主之位、可 `bloc_dissolve` 解散联盟；**盟主不能退盟**
  （想脱身只能移交或解散）；盟主亡国由最早加入的剩余成员继承。
- **退盟**：普通成员 `bloc_leave` 单方面退出、无须任何人同意；只剩盟主一人时联盟自动解散。
- 盟内效果：**互通领土、互不攻击、共享视野、成员间外交免费**。
- **进攻战争必须联盟投票**（赞成>反对通过后全盟参战，盟主为进攻主导）；防守自动参战、无须投票。
  盟主发起/接受议和也须联盟投票。
- **战争期间禁止**：缔结/加入联盟、保障独立、共同防御、解散联盟——先议和停战再谈。
- **核心领土**（land 面板 ♥ 标记）：每次战争结束按参战各国实际持有重算（议和即对现状追认）；
  同联盟且同战线的盟友夺回你的核心领土会**立即自动归还**（驻军原地不动）。

### 市场

`buy` / `sell` 随时可交易粮/木/矿/油/装/补给（黄金是货币，不可交易；馈赠可赠黄金）。

- 基准价：粮食 2 / 木头 2 / 矿石 4 / 石油 6 / 装备 8 / 补给 5。
- **成交按「沿曲线均价」结算**：每单位推动市价 = 基准价 × 0.02 ÷ 深度；一笔 n 单位的单子
  让市价从 p0 走到 p1，成交价取中点 (p0+p1)/2——不是整笔按最差的 p1 结算。
  买推高、卖压低，大单仍会自己把市价推走，分批慢慢卖更划算。
- **买卖价差 10%**：买 +5% / 卖 −5%（翻转套利必亏，做市有成本）。
- **深度按商品分档**：粮/木 24、矿 16、油/补给 12、装备 8（单位数），再 ×`现存国家数/4` 缩放
  ——大路货深、军工浅；国家越多，单笔买卖对市价的冲击越小。
- **市价夹在基准价的 0.2×~3× 之间**；**每回合向「供需均衡价」回归 25%**：均衡价由全世界本回合的
  **产/耗流量**决定（产出、工厂投料、征兵耗料、建造耗木、能源厂燃料、军队补给；市场买卖本身是
  纯流通、不进流量），夹在基准价 0.5×~1.5×——全世界都开农场则粮价长期走低，战时军需耗大则
  装备/补给涨价。市场面板直接显示均衡价。
- 粮/木是**内需品**（价低量大、建筑回本慢）；靠外贸赚钱卖 **矿/油/装备**。

### 经济报表（每 10 回合自动出一期）

回合结算**自动**给每国结一期经济报表（第 11/21/31… 回合起）。**出表那一回合全文直接进该国
状态面板【经济报表】**，其余回合只留一行摘要（省上下文）；历史期与跨期趋势用 `report` 工具取
（免费、只读）——**不能手动运行**，也不能补做历史期。每期生成时还会在看海终端写一条纪事。
一期覆盖最近 10 回合；GDP 与军费是**结报那一回合**的 run-rate 值，投资/贸易/资产是整期值，
全部按当时市价折算：

| 指标 | 口径 |
|------|------|
| GDP（**本回合**） | 结报那一回合的生产增加值（市价，**不含军费**：采集/工厂/军屯产出 + 金矿/市政厅金 − 中间投入 − 能源燃料）——run-rate，不除天数、不攒期累计 |
| GDP 增长率 | 环比上一期的期末值（两个 run-rate 直接比，不受首期覆盖长短影响） |
| 财政收入 | GDP − 军费（为负会标注"靠卖库存/吃老本维持"） |
| 军费（**本回合**） | 结报那一回合军队**实际吃掉的补给** × 现价（不看来源，自产/外购一视同仁） |
| 军费占 GDP | 军费 ÷ GDP（同为期末回合值，比值不受跨度影响） |
| 国家总资产 | 全部建筑重置成本（造价金 + 木×现价；城堡逐级累计；夺来的地同样计入） |
| 资产增长率 | 环比上一期 |
| 本期投资 | 整期累计：建造实付（金 + 木×当时市价，含城堡升级与地形/工程院/匈奴修正后的真价；不含征兵） |
| 投资增长率 | 环比上一期 |
| 外贸 / 内循环 | 整期口径：外贸 = (买卖总额) ÷ (自产 + 进口)，内循环 = 1 − 外贸 |

- `report` 不传参数 = 最新一期；`report turn=21` 查指定期；`report all=true` 看跨期趋势表。
- 每份报表都印同一句双刃剑警示（军费过高挤压投资、长期竞争落后；过低则成待宰羔羊、
  发展空间受限）——具体数字自己权衡，程序**不做阈值判定**。
- 快照存在 `mp_save.json` 的 `econ_reports` 键；旧档不回溯，从下一个报表回合开始积累。
- 报表生成有兜底：出岔子只跳过本期并记进纪事，绝不拖垮回合结算。

### 国策与回合

- `plan` 制定/修订国策，永久常驻上下文（【国策规划】）；**没有国策不能结束回合**，
  且每 10 回合必须修订一次。
- `end_turn` 结束本回合，**必须带一句 summary**（回合小结，进本国记忆）；
  引擎回执（✅）才算真结束——递了小结但没国策/国策过期会被拒绝并催办。
- 存档每回合自动写 `mp_save.json`，随时可中断续局。存档**版本锁死、零旧档兼容**：
  版本或键集合不符直接拒载（不迁移、不猜），键集合由 `SAVE_KEYS` 契约断言盯着。

每国一个 LLM agent，能用的工具与人类玩家完全一致（无作弊入口），且**只见自己该知道的**：
自己的面板/信箱/视野内事件。工具面（34 个）：

| 类别 | 工具 |
|------|------|
| 查询 | `query`（13 个面板：res/land/army/market/mail/diplomacy/countries/news/threats/econ/intel/spy/plan，缺省 all=全集）、`report`（经济报表）、`countries`、`rules`（按主题查规则，识别不了就回全文）、`econ`（建筑回本核算） |
| 内政 | `build`、`recruit`、`buy`、`sell`、`plan` |
| 军事 | `move`、`attack`、`retreat` |
| 外交 | `send_letter`、`gift`、`share_map`、`spy`、`propose`、`respond_proposal`、`guarantee`、`cancel_guarantee`、`break_defense`、`declare_war`、`offer_peace`、`accept_peace`、`reject_peace` |
| 联盟 | `bloc_found`、`bloc_join`、`bloc_leave`、`bloc_rename`、`bloc_transfer`、`bloc_dissolve`、`vote` |
| 收尾 | `end_turn` |

工具接受中英文别名（`build`/`建造`、`attack`/`atk`/`进攻`…）；单次工具调用的参数非法或内部
异常只记为一次失败返回给模型，绝不炸掉整局。事件按**落盘时刻**的视野快照过滤——
你后来夺下的地上发生的旧战报不会事后凭空显形。

### 跨回合上下文（预算驱动 + 缓存友好，实现见 `ctx.py`）

窗口大小由配置 `ctx_window`（模型上下文 token 数）定义，**程序按 token 预算动态决定**
本回合 replay 深度、下滑时机与归档配额——不写死回合数。消息顺序按「稳定性」排：

```
[system 静态提示词] → [历史归档] → [replay 完整回合记录] → [本回合状态]
```

两次下滑之间，前三段字节完全一致 → 整段命中前缀缓存；下滑按「高/低水位 + 分块」进行，
把"整段前缀失效"摊薄到几十回合一次（摊销成本 ≈ 2 回合 token，与窗口大小无关）。
token 估算系数（CJK 1.05/字、其余 0.32/字）用 298 回合真实存档最小二乘校准过。

- **replay**：窗口内每回合的完整记录，**含思考**（`reasoning_content`，DeepSeek 带 tools 时
  必须完整回传，否则 400）。深度 = 预算能装下的最大整回合数。
- **历史归档**：所有已滑出 replay 的回合。每回合一行 `end_turn` 小结（确定性、不额外调用）；
  滑出时再**额外用一次 LLM 调用**把整段回合压成「阶段总结」（`ctx_compact: "llm"`，
  置 `"off"` 则只留一行小结），信息密度远高于一行小结，且不占 replay 预算。
  压缩失败不影响主流程（归档退回一行小结）。

| 配置键 | 默认 | 说明 |
|--------|------|------|
| `ctx_window` | 不设=固定窗口 | 模型上下文窗口（token）。**不设时退回旧行为**：固定 `ctx_full_turns`（默认 20）回合 |
| `ctx_fill` | 0.8 | 输入预算 = 窗口 × 该值（另留 `max_tokens` 输出与安全余量） |
| `ctx_slide_keep` | 0.6 | 超预算时下滑到预算的该比例（分块滑动，摊销缓存失效） |
| `ctx_archive_fill` / `ctx_archive_max` | 0.06 / — | 历史归档配额（占窗口比例，或直接给 token 上限） |
| `ctx_min_turns` | 4 | 无论预算多紧都保留的完整回合数 |
| `ctx_compact` | `llm` | 滑出回合的压缩方式：`llm`=一次调用写阶段总结 / `off`=只留一行小结 |

每回合日志会打印实际用量（方舟端点不回缓存字段时也能看）：

```
🧠 秦 上下文: 窗口1.00M·预算800.0k（80%）｜replay 90回合497.0k｜归档38.0k｜状态12.0k｜system20.0k｜合计567.0k｜可命中前缀≈96%
```

### 政体：匈奴

`polity: huns` 的条目是**特殊游牧政体**：开局骑兵/资源不同（缺省 6 骑 / 1000 金 / 200 补给，
可用 `start_*` 定制）、建筑造价 ×1.3、骑兵征召只要 8 粮 8 装、外交被大幅限制
（只剩勒索送信、宣战、议和与间谍 spy——提议/馈赠/换图/保障/联盟/投票全禁）。
其机制与打法**对普通国家保密**——游戏内 `rules` 查不到，人类侧说明另见
[`匈奴教义.md`](匈奴教义.md)。带 `polity` 的条目在 `enable_turn` 回合窗口内自动登场
（登场回合 = `seed+国名` 的纯函数，每次读配置现算，与存档无关）。

### 无 key 也能跑

条目缺少 `base_url`/`api_key`/`model` 时，该国由内置规则 AI（`dummy_turn`）代打：
一张账 ROI 驱动的扩张流（复利建设 → 能源/编制闸门 → 串行判定打地）。
**用哪一版由配置决定**（`rule_ai`，顶层或逐国，见上表）——代码里不写死版本，
历代表与各版差异见 `rule_ai.py`。缺省 `v10` 带**视野门控**——信息集严格等于引擎给玩家的
`visible_to`，不开图偷看未探明格资源，与 LLM 玩家在同一层信息下竞争；且**引擎数值一律
现读/现算**（不写死造价与兵种属性），所以平衡表（`balance.py`）一改，代打的水准跟着变、
不会按旧值决策。`v10` 同时是 RL 线的 BC 老师基线（`feat/rl` 的 `--teacher v10`）。
★ 换版本要**重量基线**：各版成绩不可混用（v8 之前有偷看，v10 改了山地与征召口径）。

### 终端体验（`console.py`）

- **命令台**：底部常驻提示符 `❯ `，日志刷屏时先让开输入行、打完再画回来，不会互相打断；
  支持 ←→ / Home / End / Delete / Ctrl-A / Ctrl-E / Ctrl-U / ↑↓ 翻历史。
  **汉字按 2 格算**——退格删整个字，不会留半格；光标位置也按显示宽度算。
  POSIX 用 termios cbreak（Ctrl-C 照常退出），Windows 用 msvcrt；不是 tty（管道/重定向）
  时自动降级为普通逐行读取，不画提示符。
- **Markdown 渲染**：AI 爱写 `**粗体**`、`# 标题`、`- 列表`，终端会转成 ANSI 显示；
  **写进 `mp_journal.md` 的仍是原始 markdown**（那是个 .md 文件，本来就该是原文）。
  非 tty 输出不渲染，避免管道里混进转义码。

## 终局结算

对局结束后（或中途想看看）：

```bash
python3 settlement.py              # 打分 + 结算厅 5 轮
python3 settlement.py --no-chat    # 只打分
python3 settlement.py --table      # 只看成绩单
./settle.sh                        # 一键（Windows: .\settle.ps1）
```

- **按「总消费」排名**：总消费 = 累计建造 + 征兵 + 军费（军队吃掉的补给），全部按**当时市价**
  折金——本质是支出法 GDP 的骨架（投资 + 政府消费；本游戏无居民部门，故无 C）。
  只算「真正花掉的」：市场买卖与馈赠不计（买来的物资在被消耗时才入账），**存货也不计**
  ——所以囤而不用的国家在这张榜上垫底。成绩单另列 GDP/军力/领土/资产 四维现状
  （生产法推算 / ΣHP%×兵种权重（步1.0/骑1.5/民0.4） / 地块数 / 重置成本），仅供对照，
  **不参与排名**。**已亡国同样上榜**（按累计消费排名，四维现状记 0）——活着不是及格线，
  参与到底也算数。
- **看海人寄语**：开场由你以一句评语致辞每位君主，公开挂在计分板下方全程可见
  （`--remarks 寄语.json` 传 `{"国":"话"}`，缺省则终端逐国现场输入）。
- **结算厅**：抽走全部工具后，各国 AI 进聊天室自由总结本局、互评排名，共 5 轮
  （`--rounds N` 可改）。君主是**带着原样的游戏上下文与记忆**进场的，不是收到一份摘要。
  已亡国的上下文随亡国清空，只进成绩单、不进聊天室。
- 产物：`结算报告.md`（分数明细 + 结算厅完整对话录）。
- **为什么是这个指标（完整论证）**：[`docs/消费总量评测指标论证.md`](docs/消费总量评测指标论证.md)
  —— 从「价值实现」的第一性原理推出六条推论，再用三组确定性对照实验逐条验证，
  含一组专门设计的**对抗性实验**（四种刷分策略全部失败）与全部局限说明。
  实验脚本随代码在 `experiments/spend_metric_probes.py`，`--exp all` 可复现全部数字
  （E1/E2 各 8 seed、E3 20 seed，全组几分钟内跑完）。

## 项目结构

| 文件 | 作用 |
|------|------|
| `balance.py` | **数值表 · 唯一调参入口**：建筑/地形/兵种/军队/市场价与价格曲线/外交费。**调平衡只改这个文件**——引擎、报表、规则 AI 读的都是这里的**同一份对象**（`game.py`/`mp.py` 原样转口，不是副本；守卫 `tests/test_balance.py`） |
| `game.py` | 共享规则层：转口 `balance.py` 的数值表 + 规则函数（兵种属性/移动代价查询、写信计费、地名词生成）（无状态；复合建筑的效果是数据：`BUILDINGS[*].effects`） |
| `mapgen.py` | 地图生成（蓝噪声 + 密度图调制）：`(seed, size)` → 整张地形/资源图，惰性构建。算法、不变量与参数见其 docstring 与 `docs/地图生成与资源分布.md` |
| `mp.py` | 多国引擎 `World`：回合结算、战斗、外交、联盟、信箱、视野、存档 |
| `mp_ai.py` | AI 层：34 个工具（schema + 执行）、system prompt、各面板文本、回合循环（提供方无关） |
| `llm_provider.py` | LLM 提供方兼容层：OpenAI 兼容端点实现 + Anthropic 预留桩；重试/流式聚合/平台超时全收口于此 |
| `ctx.py` | 上下文窗口管理：token 估算、预算分配、缓存友好组装、下滑与归档 |
| `mp_run.py` | 编排器：无人值守自动一局 + 看海终端 + 中途加国 |
| `console.py` | 终端体验层：Markdown→ANSI 渲染 + 汉字宽度感知的命令台（无第三方依赖） |
| `settlement.py` | 终局结算：按**总消费**排名（支出法 GDP 骨架）+ 结算厅 |
| `spend_rules.py` | 规则 AI 的账房：刚性支出 / 60% 闸门 / 满补给三条判据 |
| `rule_ai.py` | **规则 AI 注册表**：版本名 → 入口函数（懒加载）。「哪一版当代打」是**配置项**（`rule_ai`），不写在代码里；历代表与加新版本的步骤都在它的 docstring |
| `expand_rule_v10.py` / `v9` / `v6` / `v5` / `v4` / `expand_rule_ai.py` | 各代扩张流规则 AI（无 key 的国家按配置选一版代打）：`v10`=v9+抗抖+不绕山地（缺省，也是 RL 的 BC 老师基线）、`v9`=v8+视野门控、`v6`=`experiments/` 探针的论文基线 |
| `mp.py` 顶部 `good_value` / `build_econ` | 游戏层 ROI 原语：LLM 经济面板与规则 AI **共用**的一份回本计算——不存在第二套口径 |
| `experiments/spend_metric_probes.py` | 消费总量指标的对照实验（E1 攻击性 / E2 归属 / E3 朝贡），配 [`docs/`](docs/) 的论证 |
| `docs/消费总量评测指标论证.md` | 指标的第一性论证 + 对抗性实验 + 局限 |
| `docs/地图生成与资源分布.md` | 地图生成分布明细（人类侧资料，**勿搬回 README**，原因见该文件头部警示） |
| `mp_config.example.json` | 配置模板（复制为 `mp_config.json` 填 key） |
| `匈奴教义.md` | 匈奴政体的保密策略说明（人类侧） |
| `tests/` | 单元测试（全合成数据，不碰真实存档）+ 跨进程确定性看门狗 + README 数字同步守卫 |

```bash
python3 -m unittest discover -s tests    # 跑测试（pytest 亦可）
```
