战国 · Windows 美术与音乐体验包

1. 完整解压 ZIP 到桌面等可写文件夹；不要在压缩包里直接运行。
2. 双击 Zhanguo.exe。无需安装 Python、Godot 或 .NET SDK。
3. 想亲自玩：选“玩家模式”，先填自己的国名、颜色及下方地图／种子，再设置其他 AI 国家。
   想看 AI 对局：选“看海模式”，保留八国规则 AI，点“开始对局”，再点右上角“继续”。
   规则 AI 完全离线，不需要 API key；单机只控制一个国家。

玩家点自己的地块后，可直接打开建设／征兵图标格。亮的可以执行，变暗的悬停可看缺项。
短悬停显示本格价格、价格变化和条件，停留约一秒展开作用和预计收益。
每回合每地块只能下一次建设指令；面板显示本格在建状态及剩余次数，切地块会重新计算。
军屯或兵营落成后才能征召相应兵种。普通建筑没有等级，只有城堡分级。

空格：暂停/继续。Esc：菜单，自动暂停，可保存或保存并退出。
滚轮：缩放。右键拖动：移动镜头。F：总览。
近景能看到居民劳动、施工、部队交锋；每批调用结束后演出操作与行军，回合末有生产和伤亡演出。
保存以完整回合为边界，中途会提示排队；玩家完成本回合或看海继续至回合结束后写入。
右上角可以调速度、开关镜头跟随。建议先用1×，需要找战斗时再加速。
左下抽屉可看国家、地块、市场和事件。大模型为可选玩法，需自行配置。

存档和 API 设置：userdata 文件夹。转发给别人时使用原始 ZIP，
自己玩过后的 userdata 可能含个人 API 设置，不要一起转发。

默认采用兼容性渲染。支持 Vulkan 的显卡可用“使用Vulkan启动.bat”。
音乐与画面建议见“给音乐和美术的说明.md”。美术预览/index.html 可直接用浏览器打开。
本包还没有正式音乐与音效；重点用于查看场景、动作和实际回合节奏。
