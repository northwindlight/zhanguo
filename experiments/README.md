# experiments/

游戏机制统计实验，独立目录，**不 import 游戏运行时（mp.py）、不改游戏任何文件**；
只复用 `game.py` 里的纯函数权重表抽法。

## gold_uniformity.py — 金矿均匀度

随机种子 + 随机地图边长（默认 30..100）生成 N 张图，统计每格黄金资源
（0/1/2，权重随地形，山地最富）的分布均匀度。

```bash
~/.venv/bin/python gold_uniformity.py                # 200 张图，约 20s
~/.venv/bin/python gold_uniformity.py --trials 500 --size-min 40 --size-max 80
```

明细写 `out/gold_uniformity.csv`，汇总打 stdout。指标：

| 指标 | 含义 |
|------|------|
| density | 有矿格占比（黄金≥1） |
| total | 全图金量（=可建黄金矿场上限之和） |
| sector_cv | 4×4 分区金量的变异系数，↓越小越均匀 |
| sector_max_ratio | 最富分区/平均分区（某角独肥程度），↓ |
| gini | 逐格基尼（绝大多数格为 0，天然≈0.9，看相对变化） |
| near_mean / near_max | 每格到最近金矿格的距离（8 邻域 BFS）：平均/最远，↓ |

与真实对局的差异：游戏里资源从世界 RNG 顺序抽（依赖占地顺序），实验改为
每格独立抽——分布相同，逐格具体值不对应某次对局，对均匀度统计无影响。

## gold_uniformity2.py — 生成方案对比（A 现状 iid / B 分区配额 / C 蓝噪声）

回答两个问题：①"MT19937 理论很均匀，为什么还一地金子？"②"能不能更均匀？"

① 数列均匀 ≠ 空间均匀。逐格独立抽样是泊松点过程，天然成簇——实测分区 CV
恰等于泊松预测 1/√λ（大图 0.128 vs 0.124），随机数没毛病。12% 密度下开荒
几十格见到连片金矿是 iid 的正常表现。

② 同种子同图三方案对比（100 张，边长 50..100）：

| 指标 | A 现状 iid | B 4×4配额 | C 蓝噪声(间距≥2) |
|------|-----------|----------|----------------|
| 分区CV↓ | 0.152 | **0.093** | 0.102 |
| 最富/均↓ | 1.285 | **1.177** | 1.195 |
| 距矿最远↓ | 4.5 | **3.0** | 3.2 |
| 矿贴矿比↓ | 0.638 | 0.547 | **0.000** |
| 最大矿簇↓ | 10.6 | 5.9 | **1.0** |

- **B（分区配额）**：区域公平最好——每 4×4 块金点数只差 ±1，"最富分区"
  p90 从 1.45 降到 1.30；但块内随机落点仍 55% 贴矿，"一地金子"减而不除。
- **C（蓝噪声，任意两矿间距≥2）**：直接消灭连片金矿（矿簇恒为 1 格），
  距矿均值也最低；区域公平略逊 B。
- 两者都需把金矿与地形解耦（游戏里黄金矿场只看资源值不看地形，解耦不影响玩法）。
- 落地改法（若要做）：World 初始化时按 B/C 铺一张金矿表，`_new_tile` 查表
  代替 `roll_resources` 抽黄金（其余资源照旧）；改动集中在 mp.py 一处。

## 一次 200 张的结果（2026-09-09，种子 1486468087）

- 有矿格占比稳定在 **12%** 左右（几乎不随地图大小变）。
- 分区 CV 随边长增大而降（小图 0.28 → 大图 0.13），主要是分区期望金量变大的
  泊松效应（CV≈1/√λ），并非"大图机制上更公平"。
- 最富分区平均是均值的 1.37 倍（p90≈1.6）——开局选边时可能碰到明显的肥角。
- 全图任意格距最近金矿平均 1.26 格，最远 rarely 超过 5 格——金矿在可达性上
  相当均匀，不存在"大片无矿区"。
