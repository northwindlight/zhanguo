“停电”和“缺料”分别使用真实建筑生产回执 `energy-shortage`、`missing-input`，不是根据市场价格或失败订单反推。累计次数受已建建筑数量影响，不能直接当作归一化生产率。失败动作保留具体类别和次数。价格会变化，策略也可能主动不补亏损原料；目标是避免单一策略集体依赖不可得的材料并反复失败，不是冻结价格或保证永不缺料。

v13 使用五种持久经营偏好，但一次八国随机抽签不保证五种全出现；各局具体结果写在 JSON 的 `profiles`。观测模型不读取这些偏好，只使用本国玩家有权看到的市场事实。

验证：全量 849 项离线单元测试通过；市场回归 9 项通过（含真实燃料补货节奏、整单报价、状态续跑与不完整采购拒绝）；文档 API 参考同步检查与站内链接自检通过。实验版另外使用模拟议会验证工厂选择、国策协议、战斗概率注入，不能据此评价真实议会质量。
