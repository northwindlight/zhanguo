# 论消费总量作为大战略智能体的评测指标

### ——从价值实现的第一性原理出发，兼论其在 LLM 长程能力评测中的适用性

**项目**：`northwindlight/zhanguo`（AI 写的、为 AI 玩的 EU4 式回合制大战略游戏）
**日期**：2026-09-10

---

## 摘要

大战略游戏的智能体评测长期依赖多维加权评分（领土、军队、经济、科技按权重合成）。这类评分把设计者心中"什么是好战略"写进了计分板，因而是**有偏的**：它奖励被预设的打法，惩罚未被预见但同样有效的打法，且权重本身无从论证。

本文论证一个替代方案：**以累计消费总量（spend_total）作为唯一标量指标**。该指标定义为某主体累计真实消耗掉的价值总量，按当时市价折金，由建造、征兵、军费三项构成，市场买卖、馈赠与存货不计。

论证分两步。第一，从价值实现的角度做第一性演绎，得出六条推论——其中"指标对价值来源中立""消费流受产能约束因而不可刷""指标不编码任何战略观"三条是核心。第二，用三组对照实验逐条验证，包括一组专门设计的**攻击性实验**：四种从指标定义出发能想到的刷分策略（专挑最贵建筑建、低买高卖套利、囤积不消耗、征兵—饿死循环），全部失败，最成功者仅达诚实策略的 4.8%，而且**攻击最好的一次仍不及诚实基线最差一次的 13.3%**。

本文继而论证该指标为何对 LLM 评测特别有力：它测的是"实现"而非"意图"，不可单步攻破，零权重，无需裁判，且同 seed 可复现。最后讨论如何用 RL checkpoint 作为恒定对手，解决多智能体评测中"对手强度不可控"这一根本困境。

---

## 一、问题：现有评测测不出"让事情发生"的能力

### 1.1 问答类基准的天花板

当前主流 LLM 评测测的是"知道什么"。MMLU 考知识，GSM8K 考推理，HumanEval 考代码——三者共同的特征是**单步、有标准答案、无状态**。

而真实世界中的智能，很大一部分是另一种能力：**在开放局面里自己找到路径，并连续几十步维持下去，直到某件事真正发生**。这种能力——本文称之为**实现能力**——问答类基准完全测不到。一个模型可以在思维链里写出完美战略，却在第一步就调错工具；也可以每一步都合理，却始终连不成一条能回本的链。

### 1.2 游戏类基准的三个困境

用游戏评测 agent 是自然的选择（CivRealm、Diplomacy、StarCraft 等），但现有做法有三个未解的困难：

**困境一：权重主观。** EU4 的 score、Civ 的分数、本项目自己的终局四维结算（GDP / 军队 / 领土 / 资产），本质上都是设计者拍权重。为什么领土占 30% 而不是 25%？无从论证。权重一变，排名就变。

**困境二：对手强度不可控。** 多智能体互搏时，A 得 90 分，无法判断是 A 强还是 B 弱。换一批对手，分数全部失效，跨局不可比。这是多智能体评测的根本困境，几乎所有自对弈基准都受制于此。

**困境三：可刷。** 凡是"产出—累计"型指标，都存在刷分路径：反复买卖刷交易量、无脑铺建筑刷规模、堆数量刷账面。堵漏洞是打地鼠，堵不完。

### 1.3 一个理想指标应满足什么

| 性质 | 含义 |
|---|---|
| **无偏** | 不编码任何战略观；最优解由环境决定，不由指标决定 |
| **不可刷** | 短程投机无法提高长程累计值 |
| **无裁判** | 不依赖 LLM-as-judge 或人工评分 |
| **可复现** | 同 seed 同配置 → 同结果 |

下文论证：消费总量同时满足这四条，且不是靠设计补丁凑出来的，而是从一个会计恒等式里推出来的。

## 二、第一性演绎：为什么是消费

### 2.1 价值的双重环节：生产创造，消费实现

商品的价值不是在它被生产出来的那一刻确定的，而是在它被消费掉的那一刻确定的。

《大纲》导言关于生产与消费的同一性有一段常被引作辩证法俏皮话的论述：

> 生产直接是消费，消费直接是生产。每一方直接是它的对方。

在通常语境里这被读作哲学。但在一个有精确物质流规则的模拟世界中，它是**字面成立的会计事实**。关键在于区分两个环节：

- **生产**：创造使用价值与价值的物质过程；
- **实现**（realization）：价值被社会承认、被真正用掉的环节。

一件生产出来却永远没被使用的东西，其价值未实现。马克思在《资本论》第一卷把这个环节称为商品的"惊险的跳跃"——跳不过去，"摔坏的不是商品，但一定是商品所有者"。

因此：

> **公理 A**：价值的度量应落在实现环节，而非生产环节。

度量生产，得到的是"造出了多少"；度量消费，得到的是"实现了多少"。前者包含大量从未进入再生产循环的死价值，后者不包含。

### 2.2 恒等式

在"生产—消费同一性"下，消费不是价值的消灭，而是价值的**完成与转化**：消费生产出再生产的条件（被维持的军队、被建成的产能、被养活的劳动力）。于是有恒等式：

> **C ≡ P**：在闭合系统中，长期看，被实现的价值等于被创造的价值。

但注意这个恒等式的方向性：**是消费决定了多少生产有意义，而不是生产决定了消费能有多少**。用户对此的表述比任何教科书都简洁——

> 消费才是结果，生产无所谓。

"无所谓"不是说生产不重要，而是说**生产只是实现消费的诸手段之一**，不是唯一手段，更不是度量对象。

### 2.3 推论一：来源中立

既然度量的是"在哪里被实现"，那么被实现的价值**从哪来**就与度量无关。自产、外购、掠夺、勒索、朝贡——在指标面前一律平等。

这条推论直接给出一个反直觉的预测：**一个完全不事生产的国家，消费可以很高**。只要它能稳定取得外部价值并真实消耗它。

### 2.4 推论二：流通排除，但归属敏感

纯粹的形式变换（M–C–M′）不改变价值总量，其间的商品也未被消耗使用价值，故不计。

但一旦流通的终点是**某主体真实消耗了该使用价值**，则在该主体处完整计入。

于是流通不创造价值，但**流通决定价值在谁那里被实现**。这两件事必须分开说：排除的是未消耗的形式变换，计入的是跨主体的真实消耗。

### 2.5 推论三：不可刷（可持续性约束）

消费是**流量**，不是存量。任一时刻的消费速率受限于：

```
消费速率 ≤ f(自有产能, 可得外部输入)
```

而自有产能本身是过去投资的累积结果。因此，任何以提高即时消费额为目标的投机（放弃产能投资、专挑贵的东西建、无脑扩军），都会削弱产能基础，从而在后续回合降低消费流的上限。

**短程投机与长程累计之间存在结构性矛盾。** 这不是设计出来的防御机制，是从"消费流必须由产能或他国产能支撑"这个物理约束中长出来的。

### 2.6 推论四：不编码战略观

指标不规定价值应以何种方式取得，因此**不偏爱任何特定战略**。

这条推论有一个重要后果：**评测者不需要预先知道"好战略长什么样"**。闷头复利、贸易立国、军事掠夺、霸权朝贡，四条路在指标面前等价；哪条最优，由环境（地图资源、邻国强弱、政体约束）决定，而非由指标决定。

这是评测设计里极难达到的性质，几乎所有游戏基准都做不到。

### 2.7 推论五：总量非守恒

推论三的推论。既然不同主体的**即时消耗能力**不同，那么同一个价值池，在不同配置下的总实现量可以不同。

具体而言：盈余堆积在一个消耗能力弱（或投资机会已饱和）的主体手中，是**未实现**的；转移到一个能即时消耗的主体手中，则被真正实现。于是：

> 将盈余从低消耗能力主体转移到高消耗能力主体，可提高全系统的总实现量。

这预测了一件反常识的事：**剥削性转移可以是非零和的**。注意它同时预言了反面——反过来把盈余送到
**消费能力更弱**的主体手里，是净损失。实验三把这两个方向都测了：+16.7% 与 −73%。

## 三、指标的构造与会计口径

### 3.1 三项构成

```
spend_total(n) = build + recruit + supply
```

| 项 | 内容 | 折价 |
|---|---|---|
| `build` | 建造实付金 + 耗木 | 木按当时市价折金 |
| `recruit` | 征兵消耗（粮 / 装备 / 金） | 按当时市价折金 |
| `supply` | 军费：军队**实际吃掉**的补给 | 按当时市价折金 |

三项的共同特征：**都是使用价值被真实消耗的时刻**。建造把木料与劳动固化进地块，征兵把粮装转化为人力，军费是军队每回合真实咽下的补给。

### 3.2 排除项及其理论依据

| 排除 | 理由 |
|---|---|
| 市场买卖 | 形式变换，使用价值未被消耗（推论二） |
| 馈赠（gift） | 同上；贡品在受赠方**真实消耗时**计入受赠方 |
| 存货 | 未实现（公理 A） |

**关键澄清**：这些排除不是防作弊补丁。它们是从"只计被消耗掉的"这一条原则里推出来的必然结果。若某天规则新增了"消耗"方式（比如消耗石油发电），它应当自动进入指标——因为判定标准从来不是"哪些动作被列进白名单"，而是"使用价值是否被用掉"。

### 3.3 与支出法 GDP 的分野

项目 README 把该指标描述为"支出法 GDP 的骨架（投资 + 政府消费；本游戏无居民部门，故无 C）"。这个类比作为入门是准确的，但严格说，**spend_total 比支出法 GDP 更严格**，差别恰好在 GDP 最粗糙的那一处：

- 支出法 GDP：`GDP = C + I + G + NX`，其中 `I` 包含**存货投资**——生产出来但尚未出售的，照样计入。
- `spend_total`：**存货不计**。

也就是说，它砍掉的正是"已生产但未实现"的部分。GDP 测的是"生产了多少并流向何处"，`spend_total` 测的是"实现了多少"。前者是生产侧口径，后者是消费侧口径。

一个囤积居奇的国家，在 GDP 口径下账面漂亮，在 `spend_total` 下垫底——实验一中的 `hoard` 攻击将验证这一点。

## 四、实验

### 4.1 实验设计

所有实验由 `experiments/spend_metric_probes.py` 运行（确定性脚本对局，不含 LLM，理由见 §7）：
同 seed、同地图、同回合数，只改变策略。

**每个配置跑 8 个 seed（E3 跑 20 个），报中位数。** 早先版本只跑 3 个 seed，那是不够的——
实测规则 AI `v6` 在同一批 seed 上跨地图波动 13k~195k（20 seed，标准差 ≈ 均值的 45%），
3 个样本的均值标准误约 26%，足以把真实差异整个淹没。凡本文只给均值的表，都要按这个量级打折看。

| 实验 | 地图 | 回合 | 验证 |
|---|---|---|---|
| E1 攻击性验证 | 16×16 | 300 | 推论三（不可刷） |
| E2 归属实验 | 20×20 | 250 | 推论二（流通排除 / 归属敏感） |
| E3 朝贡实验 | 24×24 | 200 | 推论一 / 四 / 五 |

三组全部在 **`main`**（2026-09-10 合并后）上跑：`spend_total` 记账与外交（E3 的朝贡要用 `gift`）
都在 main 上。此前的 E1/E2 在 `feat/rl`、E3 在 `feat/total-spend`；`feat/total-spend` 已合入 main，
而 `feat/rl` 拆掉了外交，跑不了 E3。

对照组 `v6` 为项目内的规则 AI 脚本（扩张流复利策略），它是已知的强基线。

### 4.2 E1：四种刷分攻击全部失败

从指标定义出发，设计四种最可能成功的攻击：

| 攻击 | 策略 | 想刷的项 |
|---|---|---|
| `costly` | 合法建筑里永远挑造价最高的建 | `build` |
| `arbitrage` | 低买高卖，反复形式变换，不消耗任何东西 | 流通量 |
| `hoard` | 疯狂买入囤积，永不消耗 | 持有量 |
| `recruit_spam` | 疯狂征兵，养不起就饿死，死了再征 | `recruit` + `supply` |

**结果（16×16，300 回合，8 个 seed，报中位）：**

| 策略 | 消费·中位 | 领土 | 军队 | 相对诚实策略 |
|---|---|---|---|---|
| **v6（诚实复利）** | **24,024** | 51.0 | 11.5 | **100%** |
| `recruit_spam` | 1,157 | 5 | 0 | 4.8% |
| `costly` | 938 | 5 | 0 | 3.9% |
| `hoard` | **0** | 5 | 0 | 0.0% |
| `arbitrage` | **0** | 5 | 0 | **0.0%** |

四种攻击全部失败，最成功者不及诚实策略的 5%。它们的**死法高度一致**：全部卡死在 5 块初始地。

**一个不依赖误差棒的判据**：诚实基线**最差**的一次 run 是 9,991，而攻击**最好**的一次
（`recruit_spam` 的 1,330）也只有它的 **13.3%**。运气最好的攻击够不着运气最差的诚实策略——
这条结论不需要任何统计假设，也就不受 §4.1 那个 45% 跨图方差的影响。

`costly` 的死因最能说明问题。它专挑贵的建，但最有价值的建筑（市政厅、外交中心）有建筑位门槛，够不着；实际只能建城堡、瞭望塔这类不产出的东西 → 无产能 → 无收入 → 再也建不起 → 卡死。**它连花钱的资格都是自己断送的。**

`hoard` 与 `arbitrage` 的 0 分是定义性的：前者买入的物资一分未消耗，后者连买入卖回都不留下使用价值的痕迹——如理论所预测。

`recruit_spam` 是最费劲的一个：**它必须先在同一格连续建满 3 个建筑位才能开出兵营**（门槛按格累计），
而兵营还要 1 点电维持（能源厂每回合烧 1 木头，木头断了电力归零、兵营停摆）。这段引导本身就是
一条小小的复利链——**四种攻击的共同瓶颈恰好是"你得先有个经济"**。攻击者要么付这笔钱（于是它
不再是纯攻击），要么卡死在 5 块地。

这正是推论三的机制：消费流的上限由产能决定，而产能只能来自聪明的投资。投机在当回合得分，在后续回合被连本带利收回。

### 4.3 E2：外购消耗 vs 纯套利

构造一个**不事生产**的贸易国 B：只建到能开兵营的最低限，其余物资全部外购，然后真实消耗（征兵 + 军队吃补给）。对照组 B′ 完全相同，只是不买补给。第三个组是纯套利（买了立刻卖回）。

**结果（20×20，250 回合，8 个 seed，秦为生产国）：**

| 组 | 建造 | 征兵 | 军费 | 合计 |
|---|---|---|---|---|
| 买补给（真实消耗外购物资） | 1,052 | 56 | **533** | 1,640 |
| 不买补给（军队饿死） | 1,052 | 449 | **54** | 1,555 |
| 纯套利（买了立刻卖回） | 0 | 0 | 0 | **0** |

关键数字是军费：533 对 54，**差额 479 全部是商从市场买来、被自己军队真实吃掉的补给**。
而且这条在 **8 个 seed 上无一例外**：买补给那组落在 426~626，不买那组 8 个 seed 全是 54——
**两组完全不重叠**，比"合计"那一列干净得多（合计只有 6/8 更高，差异被跨图方差压住了）。

顺带一个反直觉的细节：买补给的那组**征兵只有 56，不买的那组是 449**。商不生产，只有一份开局
本钱；花在"让军队活着"上的每一分，都挤掉了"再征一支"的钱。**它用少一个数量级的兵力，换到了
略高的总消费**（1,640 对 1,555）——因为让军队活着本身，就是消费。

这两条把推论二精确地钉住了：

- 纯形式变换（买了卖回）→ **0 分**，流通不创造实现；
- 通过交换取得他国产品并真实消耗 → **完整计入**，来源中立。

**消费不要求自产。** 一个国家的消费能力可以完全建立在别国的生产之上——只要它有能力持续取得并即时消耗。

### 4.4 E3：朝贡体系与霸权国

这是最复杂也最有信息量的一组。构造一个霸权国 + 2 个生产型附庸，四种子场景
（24×24，200 回合，**20 个 seed**，报中位）：

| 场景 | 霸权是否生产 | 附庸是否朝贡 |
|---|---|---|
| `no_tribute` | 否（纯消费者） | 否 |
| `tribute` | 否（纯消费者） | 是（盈余 40%） |
| `autarky` | 是 | 否 |
| `heg_tribute` | 是 | 是 |

「不生产」的霸权用**纯消费者**策略：把到手的贡品**卖成金再花掉**。贡品是货物不是金，
所以它必须先过一道市场——这本身就是"价值要经过流通才能被实现"的字面演示。若让它只是
把贡品囤着，那测到的就不是推论一，而是"囤积无用"，所以这里必须让它花。

**结果：**

| 场景 | 霸权消费 | 附庸总消费 | 系统总量 |
|---|---|---|---|
| `no_tribute` | 1,320 | 30,482 | 31,801 |
| `tribute` | 5,708 | 2,930 | **8,638** |
| `autarky` | 14,387 | 24,988 | 39,375 |
| **`heg_tribute`** | **43,873** | 2,546 | **46,419** |

**发现一：来源中立——完全不生产的国家，消费翻了两番多（推论一验证）。**

`no_tribute` 与 `tribute` 的唯一差别是"附庸开始上缴"。霸权自己不建任何产能，消费从 1,320
涨到 **5,708（×4.3）**。这正是 §2.3 那条反直觉的预测：一个完全不事生产的国家，消费可以很高
——只要它能稳定取得外部价值并真实消耗它。四项指标里，**从哪来**与度量无关。

**发现二：霸权形态必然胜出。**

`heg_tribute`（自给 + 收贡）是纯自给的 **3.05 倍**（43,873 对 14,387），是纯朝贡的 **7.69 倍**
（对 5,708）。结构完全如理论所预测：

- **它确实是债务国。** 霸权消费 43,873，领土 83 格，自身产能撑不起这个消费量，差额靠贡品。消费 > 自产，净输入。
- **它是"可稳定"的。** 200 回合、20/20 全存活、消费仍在增长（军队中位 56 支）。这不是寅吃卯粮，是有稳定输入流支撑的持续逆差。
- **正反馈即霸权成因。** 收贡 → 养得起更多军队 → 更能胁迫 → 收更多贡。消费能力决定能吸收多少贡品，而吸收能力最强者吸收效率最高，资源必然向其集中。所以"最强国最终必然成为霸权国"不是偶然，而是**吸引子**。

**发现三：朝贡不是零和（推论五验证）。**

取最干净的对比——`autarky` 与 `heg_tribute` 的唯一差别是"有没有朝贡"。**逐 seed 配对**
（不是比两个独立的均值，那会被 45% 的跨图方差淹没）：

| | 附庸消费 | 霸权消费 | 系统总量 |
|---|---|---|---|
| `autarky` | 24,988 | 14,387 | 39,375 |
| `heg_tribute` | 2,546（−90%） | 43,873（+205%） | **46,419（+17.9%）** |

20 个 seed 里 **17 个为正**（均值 +17.9%），符号检验 **p ≈ 0.003**。

原因就在"消费才是结果"：附庸的盈余自己用不掉就是囤积，囤积 = 未实现；转移到能即时消耗的霸权
那里，反而被真正消费掉了。**价值在实现中才成为价值；换个主体实现，总量可以更大。**

**发现四：但这个转移是**有方向**的——送给弱消费者会毁掉价值。**

`no_tribute` → `tribute` 是同一套朝贡、同一个接收方，只是这次的霸权**消费能力弱**（只消费了
5,708）。系统总量从 31,801 **塌到 8,638**：附庸被抽干（30,482 → 2,930），而霸权吃不下那么多。

所以推论五要写完整：**非零和只在"盈余转移到更强的消费者手里"时成立**；转移给弱消费者是净损失，
因为货物在弱消费者手里重新变成囤积。朝贡本身不创造价值，**匹配**才创造价值。

**发现五：指标不偏爱任何一条路（推论四验证）。**

四条路径的消费分别是 1,320 / 5,708 / 14,387 / 43,873。指标不歧视任何一条，也不偏爱任何一条
——它只如实记录谁实现得多。在"有附庸可剥削且自己吃不下"的环境下朝贡最优，在"无附庸"的环境下
只能自给，在"自己消费能力弱"的环境下收贡反而有害。**是环境决定了哪条路好，不是指标。**

### 4.5 实验小结

| 推论 | 验证实验 | 关键证据 |
|---|---|---|
| 三、不可刷 | E1 | 四种攻击 ≤ 4.8%；**攻击最好的一次仅为基线最差一次的 13.3%**（不依赖误差棒） |
| 二、流通排除 / 归属敏感 | E2 | 纯套利 = 0（8/8 seed）；外购并被吃掉的补给 +479（两组 8/8 不重叠） |
| 一、来源中立 | E3 | 不生产只收贡：霸权消费 1,320 → 5,708（**×4.3**） |
| 四、不编码战略观 | E3 | 四条路径 1,320 / 5,708 / 14,387 / 43,873，环境决定最优 |
| 五、总量非守恒（**有方向**） | E3 | 转给强消费者 **+17.9%**（17/20，p≈0.003）；转给弱消费者 **−73%** |

## 五、为什么它对 LLM 评测特别强

### 5.1 它测实现，不测意图

模型可以在思维链里写出漂亮战略，但没执行成真实吞吐就是 0 分。这精准打击当前 agent 最典型的失败模式——**说得漂亮，落不了地**。

问答类基准恰恰测不出这个，因为它只要求产出文本，不要求产生后果。

### 5.2 不可单步攻破

复利链要几十回合才回本。任何单步投机都会被后续回合的反噬抹平。它考的是**跨回合一致性**，而长程一致性正是 LLM 最弱、也最值得测的能力。

E1 中四种攻击的失败方式都印证了这一点：它们在头几个回合看起来都在"花钱"，但因为没有形成产能回路，很快无以为继。

### 5.3 零权重、无裁判、可复现

- **零权重**：不需要拍 30/25/30/15。它是单一实物量的货币表现，不合成，天然跨模型可比。
- **无裁判**：不靠 LLM-as-judge，不受评分模型自身偏好污染。
- **可复现**：同 seed + 同规则 → 数字从物理规则里长出来。（注：2026-09-10 之前这条**并不成立**——
  地块的矿藏/耕地曾用世界共享 RNG 在拓疆那一刻摇，同一 seed 换个打法就得到另一张地图。已修复，
  详见 §7 局限第 6 条。）

### 5.4 密集的跨回合反馈信号

`spend_total` 已被暴露在状态面板中（"累计总消费"），模型每回合都能看到自己的累计消费在涨。

从本文的框架看，这一点比表面更巧妙：它给了模型一个**它看得见、每回合都在动、且无法伪造**的反馈信号。资本家看得见自己的周转，看不见"历史必然性"。给 agent 一个真实的、连续的、不可欺骗的仪表盘，比给它一个终局黑箱分数更接近真实的经营处境。

### 5.5 对 MoE 架构的压力：一个待验证的假设

项目实践中观察到：传统 MoE 模型在此类游戏中表现明显偏弱，推测原因是**路由在长序列上崩溃**——每个 token 只激活少数专家，而本游戏的决策要求同一决策内部的多域耦合（军事 / 经济 / 外交 / 时间维度同时生效），路由按表层语义切分，耦合即断裂。

本文无法验证此假设（需要真实模型实验），但指出它与本指标的一个可检验关联：

> 路由崩溃的典型症状是**局部合理、全局断裂**——每一步单独看都有理有据，连贯不起来。而消费流要求严格的连续性：任何一环没接上，后面全塌。**单看思维链看不出来，看累计消费曲线一眼可见**——它会阶梯状停滞，而非平滑复利。

若此假设成立，一个自然的推论是：开启 thinking / reasoning 能部分补偿路由问题，因为推理链让模型在时间维度上串行多次路由，等于把单次路由的分裂摊平了。这条可用对比实验检验（dense 与 MoE 在开/关 thinking 四格下的消费曲线）。

## 六、恒定对手：RL 作为标定砝码

### 6.1 多智能体评测的根本困境

§1.2 的困境二：LLM 互搏时，A 得 90 分，无法判断是 A 强还是 B 弱。换一批对手，分数全部失效。

这使得多智能体环境下的评测几乎无法跨局比较——而这恰恰是大战略游戏最有价值、也最难测的部分（外交、博弈、欺骗）。

### 6.2 checkpoint 作为标准砝码

RL 训练中的 checkpoint 提供了解决方案：

- **确定性**：同一 ckpt + 同 seed = 完全相同的对手。E1 中 v6 三 seed 跑出 30,384 / 25,694 / 25,920，方差极小。
- **强度可标定**：训练到不同阶段存不同 ckpt，即构成标准难度阶梯，类似 Elo 分级的 bot。
- **不受提示词影响**：不会因为 system prompt 改动而变强变弱，排除混杂变量。

于是 `spend_total` 终于有了一个固定参照系：**同一个对手、同一张图、同一回合数，换 LLM 上去跑，数字直接可比**。

这是把"LLM 基准"从口号变成可操作东西的最后一环。

### 6.3 蛮族外壳：把机制限制转化为世界观

RL 进入多国局有一个硬约束：**它做不了外交**（语言理解、谈判、欺骗均超出当前 RL 能力）。

项目的解法极其漂亮——告诉对面的 LLM：

> 这是一个讲外语的蛮族国家。

这不是掩盖缺陷，而是**把机制限制翻译成世界观**。其成立依赖于项目已有的基础设施：匈奴政体（`HUNS_BLOCKED`）本就禁用了 propose / gift / share_map / bloc_*，只留 `send_letter`（勒索）、`declare_war`、`offer_peace`。RL agent 在多国局中的行为形态，与匈奴**同构**。

而对面的 LLM **无法证伪**：它观察到这个国家从不回信、不结盟、不议和，只勒索和开打，但它无法区分"它不能"和"它不愿意"——而对一个讲外语的蛮族，"不愿意"本来就是合理设定。**限制被叙事完全吃掉，不留痕迹。**

更有意思的是 `HUNS_DOCTRINE` 中那条"拒绝谈判的国家，别再发第二次——打疼了再说"，它同时是对面 LLM 的行为补丁：对方试探几次没回应便会自行放弃，不会围着这个洞持续戳刺。

## 七、局限与开放问题

**1. 本文实验全部为脚本对局，不含 LLM。** 所有验证针对的是**指标的性质**（不可刷、来源中立、不编码战略观、总量非守恒），这些性质属于指标本身，与被测主体是 LLM 还是脚本无关。但"该指标能否有效区分不同 LLM"尚未验证，需要接入真实 API 后做跨模型对比。

**2. 跨地图方差极大，基准必须多图取中位。** 实测规则 AI `v6` 在 20 个 seed 上从 **12,647 到
194,686**（中位 127,860，标准差 ≈ 均值的 45%）——**地图抽签本身就贡献了分数差异的一大半**。
本文据此把每组样本量提到 8 个 seed（E3 提到 20 个）并报中位数；早先 3 个 seed 的版本，
均值标准误约 26%，不足以支撑任何小差异结论。模型侧的方差尚未标定（同一模型同 seed 多局之间的
差异），但它只会叠加在这之上，不会更小。

**3. 朝贡实验模拟的是"已建立的朝贡"，而非"如何建立"。** 代码中的 `gift` 是主动赠送，实验让附庸按 40% 盈余上缴；"强迫"那一环（宣战 → 索款 → 停战协定）未模拟。因此实验证明的是"朝贡体系一旦建立，霸权形态必然胜出"，**未证明"建立过程必然发生"**。后者涉及 LLM 的外交能力，是下一步工作。

**4. MoE 路由崩溃假设待验证**（§5.5）。

**5. 单一标量会丢失信息。** `spend_total` 不区分"通过建设消费"与"通过军费消费"。实践中建议同时报告三项分项（`build` / `recruit` / `supply`），它们构成免费的策略指纹：重建设的国家与重军费的国家，消费总量可能接近，但性质截然不同。

**6. 地图曾经不是种子的静态属性（2026-09-10 已修复，本文全部数字为重测值）。** 初稿实验跑在修复前：
地块的矿藏/耕地是用**世界共享 RNG** 在拓疆那一刻摇的，等价于"同一格摇出什么，取决于轮到它时
RNG 已经走了多远"——战斗掷骰、地块命名都在这条流上。于是**不同策略在同一 seed 上实际拿到的是
不同的地图**，§4.1 声称的"同 seed、同地图、只改变策略"当时并不严格成立。现已改为按 `(seed, x, y)`
定死（`World.tile_resources`），地形早就如此。**本文所有数字都在修复后的代码上重测**；作为参照，
修复前后各跑 20 个 seed，`v6` 的分布统计上分不出来（均值 111k 对 122k，中位 128k 对 128k），
即修复没有系统性改变地图的丰瘠，只是让"同一张图"这句话真正成立。

## 八、结论

消费总量之所以是一个强指标，不在于它把 GDP 换了个名字，而在于它**把"能不能让价值持续实现"变成了唯一的问题**。

它的四项关键性质——来源中立、不可刷、不编码战略观、总量非守恒——不是设计出来的，是从"只有被真实消耗的价值才被实现"这唯一一条原则里推出来的。四项同时成立，在现有游戏基准中未见第二例。

而"让价值持续实现"这件事，恰恰是 LLM 最不擅长、现有基准最难捕捉、却又最接近真实世界智能的能力。

一个指标能做到**评测者不需要预先知道好战略长什么样**，它就已经超越了一个计分板——它是一个可以让 agent 自由探索、而评价依然客观的空间。

最后一句留给工程：**这套指标已于 2026-09-10 合入 `main`**（合并提交 `c289d68`）。它的实现很小——
`SPEND_FIELDS` 定义 + 三处记账点（`build()` / `recruit()` / 回合末补给结算）+ 一个存档兼容兜底；
配套的 `World.spend_total(nation)` 与三项分项 `World._spend(nation)` 都在主线上。本文的实验脚本
随代码一起放在 `experiments/spend_metric_probes.py`，`--exp all` 可复现全部数字。

- **2026-09-12 重测**：下表全部数字在含修复的 `fix/hardening` 上重跑（民兵黄金按面值记账、

  绝对值因战斗随机流与上述规则微调有 ≤0.7% 漂移。§7 局限 2 的大图分布数字
  出自 bench（非本探针），未随本次重跑。
- 脚本：`experiments/spend_metric_probes.py` —— `--exp e1|e2|e3|all --seeds 0,1,...`
- 依赖：Python 3，无外部服务调用
- 所有对局均为确定性：同 seed → 同结果

**E1 攻击性验证**
```
地图 16×16 | 300 回合 | seed 0..7（8 个） | 单国
策略：v6（诚实复利基线） / costly / arbitrage / hoard / recruit_spam
```

**E2 归属实验**
```
地图 20×20 | 250 回合 | seed 0..7（8 个）
国家：秦（生产国，v6） + 商（贸易国，不建产能）
变量：商是否购买补给并真实消耗 / 是否纯套利
```

**E3 朝贡实验**
```
地图 24×24 | 200 回合 | seed 0..19（20 个）
国家：霸（霸权国） + 附1、附2（生产国，v6）
变量：霸权是否生产 × 附庸是否朝贡（2×2）
     霸权不生产时用「纯消费者」策略：把贡品卖成金再花掉，
     否则它只是把贡品囤起来，那就测不到推论一（来源中立）
朝贡率：盈余的 40%（保留 60% 自用，避免附庸饿死）
```

**关键 API**：`World.spend_total(nation)` 返回该国累计消费；`World._spend(nation)` 返回三项分项 `{"build", "recruit", "supply"}`。

**注意（对复现者）**：E2/E3 里构造贸易国/消费者要过三道连环门槛，本文的探针脚本已经把它们
逐一踩过一遍——复现时最容易在这里得到**假阴**（策略看起来"不行"，其实是卡在门槛上根本没法消费）：

1. **建筑位门槛按格累计**：兵营要求本地已用建筑位 ≥3，必须在**同一格连续建造**，分散建永远开不出来（每地块每回合还限建 1 座，所以这是个跨回合过程）。
2. **兵营要 1 点电**：没有能源厂则永久停摆，建了也征不了兵。
3. **能源厂每回合烧 1 木头**：木头断了电力归零、兵营跟着停摆；更阴的是**三座能源厂能把建兵营要的 20 木头烧光**，引导阶段就此死锁（实测 60 → 12，兵营永远建不起来）。凑建筑位要用瞭望塔这类不烧燃料的，木头不够就去市场买。

本文第一版探针就是在第 3 条上翻过车：`recruit_spam` 因为引导期先买粮、把搭兵营的本钱抽干，
一度跑出"0 征兵"的假阴结果——**那不是攻击失败，是我没让它攻击**。
