# 消费指标误注入与周国策偏差事故报告

日期：2026-10-19（Asia/Shanghai）。本文记录实际对局事故、源码来源、已知影响和修复证据。用户明确要求保留当前对局、仅对周做记忆手术，并要求形成报告。

## 1. 事故结论

开发过程把研究与离线结算使用的消费评测口径写进了 AI 可读的游戏规则和说明书。周在第18期读取该段后，将“累计总消费排名”理解为直接优化目标，形成“增产—尽耗”的国策，并推导出放弃自产补给、追求市购开支等错误安排。议会随后读取同一段规则审核该国策，进一步将这套叙述带入审核对话、历史快照和双方记忆。

这是一条有实际输入、模型发言、国策草案和审核记录相互印证的目标提示污染链。不能归结为模型凭空编造，也不能通过删除当前文档就宣称旧局恢复正常。

另一个同时发现的问题是财政报告的自动呈现：正式报表查询正常，回合简报却使用上一回合流量摘要，缺少已发布报表的覆盖期、跨期投资和增长率，并同样标为“经济报表”。这削弱了模型自动取得财政信息的完整性。

## 2. 消费指标的经济学依据与本次误解

本文依据[指标论文](../research/消费总量评测指标论证.md)的再生产、账户、跨期组织和需求价格分析理解事故。

论文中的生产是社会再生产整体：生产、交换、资源取得、配置和实际使用相互接通。出售使私人生产获得交换承认，消费使社会产品进入已经履行的用途，并继续形成再生产条件。国家消费还反映其通过贸易、联盟、贡赋和军事控制取得社会产品的能力，不能只拿本国产量衡量这一能力。

因此，长期维持更大实际消费，要求更大规模的社会生产及其取得、配置和实现。这与维持军队、建设设施和组织国家行动的能力直接相关，也与取得胜利的现实能力相联系。把消费解释成与胜利能力无关的装饰性成绩，同样割裂了论文的论证。

但“最大化现金支付”“故意采购更贵的物资”“因自产减少采购开支而放弃自产”并不是上述论证。论文明确要求同类实际使用对自产、购买、援助保持来源中立；付款与融资本身不能代替用途。周的推导将支付金额与实际实现混淆，反而可能削弱持续生产和活动能力。

### 2.1 形式化判断及其条件

**来源中立。** 在共同参考价格 `p⁰` 下，实际消费 `C⁰=Σ_e p⁰·q_e` 只依赖用途与用量。自产自用与市购后自用不因来源标签而不同；购买本身不是最终消费。现行动态估值下，交易可能改变市场行情和实际使用的金额，但这不等于“只有市购才计入”。周对两种来源计分资格的理解错误，可由经济事实的生成与归类直接核对。

**累计目标与当期支出。** 无贸易、无库存的简化资本模型为 `C_t+I_t=F(K_t)`、`K_{t+1}=(1−δ)K_t+I_t`。在全程零投资基准上，首期增加可行小投资 `ε` 的累计消费一阶变化为：

```
ΔA/ε → −1 + Σ_{t=1}^{T−1} F′(K_t)·(1−δ)^{t−1}
```

右侧大于0时，这种偏离改善累计消费，说明逐期尽耗不能替代跨期判断；小于或等于0时，不能据此声称投资有利。期限、资源来源与实际回报必须给定。这里不把零投资一概判为被支配，也不假定实际游戏有自动资本折旧。

**衰减的正确界限。** 资本几何衰减不等于一般凹生产函数的产出同率衰减。对 `F(K)=aK^α`，零投资路径的无限累计为 `aK₀^α/[1−(1−δ)^α]`，而非一般性的 `F(K₀)/δ`。例如 `F(K)=√K、δ=0.5、K₀=1` 时，前4期已为2.56066，大于线性形式给出的1.875；无限累计约3.414。仅有 `F′>0、F″<0` 也不足以保证累计有界。严格条件、反例和有限期最优递推见论文第五节及数学复算程序。

**需求、价格与读数。** 市场采购和销售改变有效需求、可售库存与行情。按当期价格 `p_t` 记录 `S_C=Σ_t p_t·q_t^C`，相同实际用量可能产生不同金额；这说明它是当期价消费，不是共同价格数量指数，不能由此直接否认动态价格的经济意义。同样，金额上升不能单独证明实际消费数量增加或战略效果改善。

三类消费成对检查采用六个相同初始世界，六期各消耗60补给、无投资；动态无交易、额外买入、额外卖出三组金额分别为360、551.991815、223.055993，固定报价三组均为360。详见[实现与复现附录](../research/消费指标实现与复现.md)。这组检查不读取真实对局，不能用于宣称周的经营结果已经恢复。

**事故判断的范围。** 可靠结论是：周误把研究口径当作游戏目标，并混淆采购付款与实际消费；“放弃自产即可提高真实消费”不由消费口径推出。判断具体投资、军事和采购安排是否改善长期结果，还需要给定期限、供给、价格与后续行动，不能用一个不适用的简化最优性结论替代。

事故发生时公开文字按四类支出叙述排名；现行离线结算将建造单列，不追溯改变当时输入、历史事实和模型已经接触的目标信息。

### 2.2 两点限定

论文也不允许把高开支、借贷或战争一概判为低效：实际征募、训练和维持已履行的活动可以形成真实消费（建造是投资，单列，不计入消费）；其战略代价须看后续结果。本次修复不改变消费账的分类、估值规则或既有实际消费记录，只改变排名取哪几类。

现行动态估值字段的可靠性是论文另外讨论的问题，当前稿 7.3 节已有价格通道反例；它不能代替或否定前述经济学依据。本事故处理不向模型补发计分公式、研究论证或操纵方法。
