# PPO参数消融（2026-11-03）

用户追问是否量过各个参数影响。此前只做了单环境训练前后成绩与固定状态漂移，
没有参数消融，不能确定哪项梯度/超参数导致退步。本轮执行显式对照，保留未测项。

## 固定实验条件

起点为保存的DAgger暖身权重（不替换原始BC保护基线），新价值头初始化种子31001。
所有实验共用完整150回合轨迹：260101/20地图/不换位，260102/24地图/换位，各8国。
采样在固定工作树139b95a进行，经济C路径开启，无资源赠送、硬合法掩码或战争规则变化。
轨迹以float32无损保存，缓存的相同观测共享保留；压缩文件SHA与回合/步数写manifest。
这些是新诊断世界，不是已丢失的昨晚轨迹，不能冒称精确重放历史更新。

每组都重新载入同一份含价值头的起点，随机顺序种子31002，共用原始BC锚与完整候选。
学习率3e-5、价值系数0.5、执行辅助0.1、开局BC约束0.05、熵0.001、裁剪0.2、
KL停止0.03、AdamW衰减0.01、batch8、2epoch为原默认；每组最多64次更新，
记录是否因预算或KL停止，避免不同停止原因混淆。奖励仍为ΔS，gamma=lambda=1。

## 测量和边界

- 更新0、1、9处分别量加权策略/价值/辅助/BC/熵项对共享编码器与各头的梯度范数、
  与策略梯度的夹角；逐批保留KL、裁剪率、分项损失、真实更新次数和停止原因。
- 在相同128个采样状态和128个教师验证状态上量完整候选分布KL、动作翻转、合法
  概率质量、熵；保存冻结轨迹的替代目标增益、价值MSE与解释方差。
- 单独保留此前第15回合伐木场/农场分歧状态，量各配置怎样改变这两个动作的概率。
- 固定状态统计只解释更新的直接影响；选出的配置仍须150期完整世界对照，不以
  KL/分类命中率代替S，也不通过这项诊断晋级模型。

代码入口rl/economy/ablation.py，默认训练逻辑仅增加参数入口和可选测量回调。
参数化前后的默认函数在固定轨迹8次更新后，逐张量最大差值0.0；35项相关检查通过。
价值梯度隔离/不改策略的单测也通过。T4正常申请返回Service Unavailable，未绕限额；
采样本机、参数更新计划ECS、长局验证本机。原始记录在archive/previews/
ppo-parameter-ablation-20261103/，本页后续记录实际结果，尚不宣称已找到主因。

## 测量缓存校验与修正

首轮关闭衰减组的训练中KL与更新后前向统计异常不一致，已追查到FastLinear克隆缓存：
父模型加载权重后版本计数2并缓存；deepcopy复制了缓存，新Parameter计数却从0开始。
无衰减的两次更新可让计数重新到2，旧缓存被误认有效。3输入2输出的数值复现中，
更新后的推理输出误差达12。已将Parameter身份纳入缓存键，并让每组评估冷加载刚保存
的权重，增加针对此版本碰撞和训练梯度路径的测试，两项通过；默认8次更新对照仍为0差。

此问题影响新消融的部分原位推理统计，训练的梯度路径直接使用权重，已保存的权重有效。
它尚未被证明与昨晚的PPO退步有关，不能拿它替代原因。本轮采用新v2输出完整重测，
首轮原始结果保留，不把失真的无衰减/分项统计拿来挑优。

两份150期冻结轨迹已完整保存：6278和4970次决策，总11248；奖励加总×1000与实际S
分别为19751.30768516951和18402.95863977351，逐项一致。真实采样动作可执行率19.13%，
11248行只含2195个不同观测；首两个batch的16次采样仅1次可执行。该诊断保留无硬掩码。
