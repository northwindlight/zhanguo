# 议会情报追踪与预算修复

本次修改解决三个相互影响的问题：情报渠道缺少持续提示与用途说明；议会批准后清空对话，无法持续追查未兑现事项；长审核轨迹降级时丢失状态差分，关闭图像后尤其容易缺少独立现状。另修复 experimental 未装配手册模块、议长把讲义当规则章节查询的接线缺口。

## 情报与可见范围

购报动作说明取当前银行的实际政策费用，说明立即返回的经济指标及覆盖日期；每期简报展示实际工具表中的报表与spy渠道。银行可以被其他模块替换，不能按固定模块ID取费用。没有这些能力的发行版不显示虚构入口。

native 的地图与军队标题明确：本国数据与他国当前可见子集不能混用。他国全国总量未知；旧谍报按采样日期使用。经济报告用于实力比较，但不替代当前军队位置或全国军力情报。君主和议长均可按需读现行讲义，文档不注册为规则章节。

## 追踪与证据

新增议长专用工具：

| 工具 | 用途 |
|---|---|
| `council_track` | 保存前提、承诺、风险和问题；记录期限、证据、完成或替代说明 |
| `council_search` | 按周期和关键词检索本国原始记录，返回稳定引用与续页游标 |
| `council_read` | 分页读当前/上一版快照、事项表或档案原文 |

批准仅清空审核对话，不清空未解决事项。否决原因自动登记；不会把“承认失误”或“换了一版”当成完成。每次审核的当前及前次快照都有固定档案引用；即使否决对话延续到下一期，旧证据引用也不会随current/previous别名指向新事实。动态快照用作追踪证据时同样固定，保存续载仍指向当时事实。关闭必须有说明，追踪状态与引用均验证。事项是议长判断，不是引擎已证实事实，未结风险也不构成批准或开战的机械否决。

工作集最多24条未结事项，每条正文和关闭说明各600字、8个证据引用；不静默驱逐未完成事项。已关闭事项仍存档，常驻仅最近4条；预算紧时只留未结事项编号、种类、期限及摘要，完整文本分页读取。满额导致自动否决事项无法新增时，否决本身仍保存于审核档案与下一轮基线。

## 输入预算

本次快照独立于历史轨迹，`vision=false` 也能得到当前事实。每次请求计算消息、工具、地图及安全余量，预留输出；固定回合记忆配置不能绕过窗口上限。未配置窗口时按200k估算，极小窗口在本地明确失败。

超限时逐步移出历史差分、事件与回执明细，转为快照摘要和区间统计。区间摘要保留动作次数、成功spy/购报数、失败数与现金极值，时间跨度很长时合并相邻周期，不截掉整段统计。最新谍报按目标列出并标采样日期，历史采样仍可读。材料缩减有明确提示，未附不代表未发生。

大量短反馈及归档通知也会合并成可追溯引用，避免累积失控。较早的完整assistant/工具回复组整体归档，避免悬空tool回复或拆开签名推理；当前独立事实、未结事项清单和新草案受保护。原始记录保存在独立服务状态中，缩减提示不删除证据。新草案或必要规则本身大到无法容纳时明确失败，不向提供者发送超限请求。

## 审查与行动意愿

先检查必要内容是否完整，再审核事实、承诺与执行；君主不写承诺、删去敌情评估或缩短国策，不能降低审查责任。不能以“没有反证”批准无依据的关键前提，但拒绝须指出实质缺项、证据和下一期可执行纠正。

审核明确允许信息不完整但收益、部署、后勤和受挫调整经过论证的进攻、机会战、有限试探和主动干预。无需完整全国情报、固定兵力倍数或保证胜利，补情报可与备战并行。对守势、种田和等待执行同样的目标推进要求：有阶段收益、期限、触发条件与实际步骤，不能借审核无限等待或放弃游戏目标；也不强制打一场不服务于目标的战争。

两阶段仍共用10轮、第五轮后催办。未完成裁决会打回并要求解释后下期重提，计入连续否决；保留第十轮有效裁决，取消超时自动批准。首次国策建立基线而免审的既定规则保持不变。

## 验收与适用范围

测试使用合成国家与模拟后端，覆盖真实experimental手册接线、追踪跨批准及保存续载、稳定快照引用及跨期别名隔离、强制关闭说明、分页无损、他国隔离、1000期区间统计、小窗口长轨迹与签名工具往返、24条长事项同时存在、极小窗口调用前失败、未结风险不机械否决，以及中英动态费用和替换银行。

项目虚拟环境全量离线回归837项通过（151.197秒），API参考页同步检查及文档站28页生成与链接自检通过；`git diff --check`通过。测试证明机制、权限和预算行为；提示词对真实模型战争意愿的影响仍需后续行为观察，不能以模拟裁决声称已得到实战提升。

发行版升级至experimental 0.15.0，议会服务格式为`council/2`，新增手册模块依赖。旧档不能直接混载，本次未迁移真实存档、重启运行局或新增付费模型调用。
