# 经济 RL 改进计划（2026-11-11）

对象：[经济RL二十轮失败归因审计-20261111](经济RL二十轮失败归因审计-20261111.md)（下称**审计**）与[经济RL二十轮综合报告-20261111](经济RL二十轮综合报告-20261111.md)（下称**报告**）。本文主体是**计划**：只读复算了审计的固定状态基线、读了现行代码与评测/成本日志，**没有改奖励/网络/验收、没有改任何训练目录**；唯一已执行的收尾动作是 §3 P0-1 的**停链与归档**（2026-11-11 11:30 放 STOP，12:44 R24 落盘后退出），记录在 P0-1、§0 与附录，其余条目仍未执行。数据截止：审计/报告冻结在 R1—R20；R21—R24 只作补记，不改变 R1—R20 结论。

结论先行：这二十轮不是"训歪了"，是"基本没训动"。三条病根，按可修性排序：

1. **动作空间没有可执行性约束，且训练与部署对失败的定义相反**——`projects` 模式只掩 padding、不掩 `legal`（`model.py:137-138`）；训练里选到不可执行项目是免费的（失败后复用同一分布继续抽，`online.py:158-165`），部署里则是**一次失败打空整回合 96 次预算**（`projects.py:186-198`）。于是 74% 的样本是废动作；部署时约一半的国家回合（74.4/150 ≈ 49.6%）被一次错误选择打空整回合预算（`truncated` 74.4、`failures` 7,138）。
2. **信用分配退化成"回合常数"**——整回合 ΔS 只记到最后一条决策（`online.py:194-198`），`monte_carlo` 再累加（`online.py:242-249`），同（国家,回合）的 return **恒等**（实测组内极差 0）；优势里 51.2% 是"这一局是谁"，加上回合趋势共 69.7%。`policy` 项符号 43%—51% 为负，单轮标准误 0.0055 已经大于均值 0.0039。
3. **起点与目标同向错，更新机制又没有任何选择压力**——BC15 建设准确率 12.19%（教师标签 43.85%），PPO 的奖励口径 S 不含建设（成功建设与 ΔS 同回合相关 −0.209，征兵 +0.741），熵奖励正把策略推平（熵 1.58→1.88），KL 的 β 在 68%—85% 窗口触底、等于没有，链上 `accepted=False` 从不选择。

排序原则：**先冻结口径、固化不可再生的离线资产 → 用离线门判定机制改动 → 一次只动一个机制 → 只有过门的改动才允许进训练链**。P0 不花训练轮；P1 前四项筛选档合计约 **8.6 ECS 小时 + 3.5 Pi 小时**。

## 2. 计划原则（先定规则，再动代码）

1. **口径先冻结**：S 定义、验收门槛、种子、每项实验的判据都写在跑之前（预注册），跑完按判据报"成立/不成立"，不换分母。
2. **离线门优先**：能在固定 192 状态或 R20 轨迹上判定的，绝不花训练轮。真需要长局的才进 ECS。
3. **一次只动一个机制**：每项改动默认关、单独 `--out`、可单独回滚；不覆盖现链产物。
4. **没有晋级门就不开新链**：否则每一轮只是往随机游走里再加一个样本（20 轮 best-of-N 的选择偏差约 +16.2%）。
5. **失败如实记录**：连续两次不过门就停下重定假设，不叠加改动、不靠"再训 N 轮"碰运气。

## 8. 实验矩阵与预算（实测口径）

计量：**ECS h** = 2.36 h/轮（R20/R21 实测：采集 0.98—1.14 h + 更新 1.24—1.35 h，更新占 52%—58%）；**Pi h** = 一次 2 环境评测 0.36 h（8101 522 s、8102 766 s）。

| 实验 | 训练轮 | 墙钟 | 算力 | 可离线验证 | 说明 |
| --- | --- | --- | --- | --- | --- |
| P0-3 离线门 G-A/G-B/G-C/G-D | 0 | <1 Pi h | Pi | ✅ 本身就是离线 | 唯一"不花训练"的判定层 |
| P1-1 软先验扫描 | 0 | 2—5 min | Pi | ✅ | 直接给 `legal_argmax` |
| P1-2 三臂评测（掩码/retry） | 0（只评测） | 3×21.5 min | Pi | ◐ | 测截断/失败/建筑/army 变化 |
| P1-6 S1 | 1 轮/臂 ×2 | 4.7 ECS h | ECS | ❌ | 筛选档只能测 ≥+20% |
| P1-6 S2 | 1 轮/臂 ×2 | 3.8 ECS h | ECS | ❌ | 去重后单轮更便宜 |
| P2 各项 | 1 轮/臂 | 2.4 ECS h/轮 | ECS | ◐ | 需配对评测 |
| P4 晋级门 | 0 | 3.2 Pi h/次 | Pi | ✅（先用 rounds.csv 模拟） | 不花训练钱 |

**预算结论**：P0 全做完 ≈1 天人工 + <1 Pi h；P1 前四项筛选档 ≈**8.6 ECS h + 3.5 Pi h**（≈一夜）；判定档（每项 2 轮）≈**17—34 ECS h**；正式晋级每次 ≈3.2 Pi h。Kaggle 一周约 17—20 轮、Colab 不可排期、TPU 20 h 从未跑通前向，**排期不得依赖它们**。

**统计纪律**（决定"多少算真改善"）：σ≈0.095、r=0.289 ⇒ 单次 2 环境筛 95% CI **±10.6%**，两个策略各筛一次比较 **±14.9%**；检测 +20%/+10%/+5% 分别需每臂 **2/5/19** 次独立评测（合计约 1.4/3.6/13.6 Pi h）。20 轮 best-of-N 的选择偏差约 **+16.2%** —— "第 10 轮 104%/114%"与 R20 的 95%/96% 之间的差距可以完全由噪声解释。
