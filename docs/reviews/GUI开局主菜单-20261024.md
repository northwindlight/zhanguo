# GUI 开局主菜单：新对局 / 加载存档 / 设置

2026-10-24。按"加开局 UI：新游戏、加载存档、设置；新开局选剧本、自定国家数量与种子、
国家和 API 档案可配置、UI 具备配置文件同等表达力"实现。改动仅 `mods/ui/desktop`
的 Godot C# 与启动器参数；宿主与引擎未动——菜单只产出 mp_config 形状的 JSON，
沿用已有的 `ZHANGUO_DESKTOP_CONFIG`/`ZHANGUO_RESUME` 通道，宿主仍是唯一解释者。

## 主菜单（`Scripts/MainMenu.cs`）

- 首页：像素大标题「战国 · 观天下」、八色国色条纹、四个入口
  （新的对局 / 加载存档 / 设置 · API 档案 / 退出）。默认启动进入菜单；
  `--smoke-output` 自动验收跳过菜单保持原路径。

## 新的对局

- 基本项：种子（可随机）、地图边长 12–96（默认 24，八国图尺寸）、
  回合上限、上下文窗口。
- 参战国家 2–10 行，行序即行动顺序：剧本国下拉（秦魏韩赵燕齐楚周 + 林胡/楼烦，
  后两者自动带 polity/appearance 字段）、国名可改、客户端三选
  （规则AI / 简易策略 / 大模型）、删除与添加。这就是"自定国家数量"——
  从 10 个剧本国里任取子集；任意字段补齐走附加 JSON。
- 规则AI 行：版本、经营风格、独立种子。大模型行：API 档案下拉（来自设置）、
  模型（留空用档案默认）、思考档位。
- 表达力对等：每国"附加 JSON"合并进该国条目、API 档案自带附加 JSON、
  全局"附加 JSON"合并进配置顶层（ctx_fill/mods/save 等任何字段）；
  附加字段后写覆盖表单值。生成文件落 `archive/menu-config-<时间>.json`。
- 表单校验：≥2 国、剧本国不重复、种子合法、各 JSON 可解析，错误显示在菜单内。

## 加载存档

- 列出 `archive/desktop/*/` 最近 30 个存档（按保存时间倒序），显示目录名、
  国家数与国名清单，"续看"以该目录 config.json + session.json 启动宿主。

## 设置 · API 档案

- 档案列表（增删）：名称、provider（openai/anthropic/google）、base_url、
  api_key（密文输入）、默认模型、附加 JSON；保存到
  `archive/desktop-settings.json`（本地文件，不入库），新对局的大模型国家按档案注入
  provider/base_url/api_key，附加 JSON 一并合并。

## 验证

- `desktop.py --menu-output <png>`：实窗自检——截图首页/新对局/设置/加载四屏，
  并断言生成的配置（8 国、seed、map_size、max_turns 与表单一致）后退出：
  `MENU_SMOKE_OK`。无引导视觉核验确认像素标题、按钮与条纹实际渲染。
- 端到端：用菜单生成的 8 国配置直接 `GameHost.new(cfg)` 实跑一个完整周期
  （`CYCLE_OK period 1 actors 8`）。
- 完整对局 smoke（跳过菜单路径）复验 `DESKTOP_SMOKE_OK`。
- 局限：任意 id 的"全新自定义国"未验证（引擎 spawn 事实是剧本 id 子集 +
  位置回退），菜单因此用剧本国子集表达国家数量；全新国走附加 JSON 自担。
