# DeepSeek 改造与 T4 实测

复核基线 5873219（ECS 当时为 9d40ba5），主线未修改。

- C 快路径覆盖 v13/v13plus 经济算术，并以源哈希拒绝过期二进制、失败回退 Python；规划查询去重有助于采样。已本地编译，C 一致性、训练与在线相关 26 项通过。
- 完整候选语义默认保留。可选截断会改变候选自注意力及分类分母，不能把截断后的 loss/accuracy 和完整候选直接相比。
- 目标已改为论文 S：征召、军需、行政的累计当期价消费，建设单列。与之前运营盈余目标不同，不能把两套分数连为同一学习曲线。
- 新 S2 数据已是 150 回合八国世界：8838 训练、3110 验证示范；ECS 只完成 2 epoch，约 1352–1355 秒/epoch。第 2 轮验证动作准确率 36.56%、征兵标签 76.92%，尚无该检查点的完整长局能力证明。
- 旧长训的两个 DAgger 候选均被回归门槛拒绝；150 回合旧基线累计运营盈余约教师 37.6%，末 50 期约 14.1%。这是旧目标、旧模型的历史对照，不能冒充 DeepSeek 新 S 模型成绩。

T4 实机为 Tesla T4，torch 2.11.0+cu130。原 CUDA BC 在 curriculum_weights 中创建 CPU 权重，实际报设备混用错误；修复索引和权重的设备位置后完成真实反向传播。新增 CUDA 回归测试，CPU 环境跳过，T4 上应运行。

合成基准：完整候选、batch 24、width 160、2 层，预热后测 10 次前向+交叉熵+反向+AdamW 更新并同步 CUDA：

| 候选数 | 每批更新 | 显存峰值 |
| --- | ---: | ---: |
| 685 | 38.13 ms | 307.67 MiB |
| 2000 | 177.74 ms | 702.23 MiB |

基准上下文为 8 token，用来确认 CUDA 可用和候选算子开销，不能当成真实全数据 epoch 加速倍数。真实数据实测：三个 150 回合训练世界（123/124/126）、一个独立验证世界（222），4305/1542 条示范；全部候选、batch24，epoch 含验证 24.81 秒，含进程启动和数据加载共 32.33 秒。这是四世界子集，不能直接和 ECS 八世界的 1352 秒作整轮倍数比较。该单轮从头训练模型只用于测速，不晋级。

提供 [Colab T4 Notebook](../../rl/economy/colab_t4.ipynb)，保持至少 150 回合数据、独立世界验证和完整候选，支持 last.pt 续训、best/last 与日志导出。ECS 可继续负责 CPU 采样和长局验证。

优先 T4：当前已有 CUDA 路径且完成实机验证。TPU 尚需独立后端适配和基准，不能将 CUDA 标志直接用于 TPU。免费 Colab 资源与运行时长会变，检查点需要及时取回，见 [Google 官方 FAQ](https://research.google.com/colaboratory/faq.html)。

CUDA 回归测试已在 T4 实机通过（1 项）；本地 26 项相关检查通过，最终训练设备测试 8 项通过（其中 CUDA 用例在 CPU 本机跳过）。真实子集 epoch 含验证 24.81 秒、端到端 32.33 秒；模型与日志已导出。完整八世界及 ECS 第 2 epoch 检查点已取回，准备同数据哈希续训至 20 epoch，保留全部候选。单轮子集模型不作正式晋级。
