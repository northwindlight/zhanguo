## 故障事实

Kaggle version16 在第 14 轮遇到种子 800115（20×20、换位）初始化失败：
正式宿主抛出 `ValueError: Start overlaps existing territory`。旧程序对同一个
无法开局的种子重复三次，随后整个轮次失败；监控又反复报告同一失败，GPU 已停止。
该任务失败不是 PPO 收敛或验收结论。

已完整保存三局：800112、800113、800114，共 17,638 条决策，三份轨迹 SHA
保持；轮次状态里的 completed_worlds=2 早于第三个子进程落盘，不能据此丢第三局。
