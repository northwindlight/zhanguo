# 旧局与模块化新局的结盟选择差异

2026-10-16，只读核对公开 258/158 档、最新正式局存档和日志，以及对应工具说明。没有加载存档运行、没有修改对局、没有调用模型。以下区分可验证事实与因果推断。

`/tmp/zhanguo-zg-current` 仍指向初始目录（period=0），已过时；实际最新正式局从保存时间和 recovery 日志核对，未改动这个指针。

## 已证实的直接决策机制

新局七国均显式接受，不是周的一次邀请绕过了其他国家的同意。存档 audit 保留了七个独立的接受动作；联盟成员顺序和七国 ID 与邀请一致。

新局日志给出了选择理由：

- 周第3期把尊王称为最便宜的获胜路线，认为尝试只需约10金；无人接壤，短期失去保障的危险不大，因此直接邀请七国。日志约12450–12466行。
- 燕第4期曾考虑拒绝以保留自主权，最后选择以10金取得次要胜利的保险、继续安全拓荒。约13734–13768行。
- 齐第4期知道全员入盟会挡住兼并路线，但认为一兵、146金的自己很难独自兼并七国；加入后可以先拿次要胜利、扩大经济，再考虑退盟。约14120–14180行。
- 秦第4期小结明确称“走尊王保底路线”；其余接受方也把共同安全、继续吃野地与次要胜利作为理由。约14824–15694行。

这些判断说明：模型把“加入周天下得到次要胜利”当作确定、便宜、可与未来兼并选择并存的收益。因此新局形成的是七国同时选择保底路线，而不是后台自动结盟。

## 为什么不能把原因说成新增了尊王目标

逐字比较存档中的剧本之志：旧158档与新局经换行转义还原后完全相同，均为787字；旧258档也已有相同的“次要胜利——尊王 / 终极胜利——兼并天下”两条路径。

尊王目标是此前用户明确的剧本设定。`scenarios/eight_nations.py` 注释还记载“写成目标、不写条件，观察者手动结束”的要求。新模型把入盟说成程序立即判胜/自动结束，属于对叙事目标的额外推断；代码没有“八国同盟自动终局”的判断。

## 确认存在的提示缺口

旧 v0.1 的 `mp_ai.py` 中，bloc_found 工具说明直接、醒目地交代：

1. 联盟是完整外交实体，保障、共同防御、宣战、议和须联盟表决，成员不能个人签约。
2. 入盟即放弃个人保障/共同防御。
3. 盟内互不攻击、共享视野、互通领土。
4. bloc_leave 明确“任一成员交战就锁死，先议和才能退出”，以及盟主不能直接退出。

模块化版本的 `mods/native/diplomacy/mod.py` 将 bloc_found 缩成独立和平国家、ID、名称、邀请列表、全体接受；bloc_join 只说申请与投票。公开外交规则仅概括实体、队列、计票和义务一跳，现行指南也未完整补回入盟的政治后果。

旧日志确实反复用“丧失独立条约权、战时锁死、会拖入别人的战争”解释早期观望。新日志虽然部分猜到了代价，但也反复出现“机制不清楚”“加入以后再离开”“离盟后攻击周不再自动召来别人”等不完整理解。最后一点尤其忽略了周天下本身仍是完整的防守外交实体。

因此，移植后对联盟后果的说明缩水是可定位的缺口。此前实现审计修复未把这一段完整补回，不能因为工具能调用就认定说明已齐全。

## 可成立的结论与限制

确定的近因是新局模型一致采用尊王保底策略；确定的实现差异是联盟政治代价的工具说明缩水。说明缺口很可能让“便宜胜利、以后还能自由改选”的判断更容易成立，但不能仅凭三局断言它解释了全部行为差异。

三局种子、经济轨迹、上下文、运行版本不同；258档还有模型切换，新局额外采用议会审核。没有做同一初始状态、同一模型参数下仅替换提示的成对实验，因此不能量化提示、经济压力或采样差异各占多少。第4期七国接受之后的议会修订批准不能倒推为议会强迫它们结盟。

复核后用户明确了新的规则：发行版挂载剧本程序，程序访问 world，经唯一的胜利钩子提交任意胜利事件；八国中周为盟主、「周天下」覆盖全部存续国家且总成员至少5国（包含周）时，周胜利，其他成员次要胜利。本次按该指令加入实际终局，覆盖此前“只写目标、手动结束”的安排；联盟利益和退出约束继续按原实现。

同时补齐创盟/入盟/接受邀约的直接工具说明、公开规则、战略/战争手册、君主持续剧本上下文和议长审核依据。修复的是已定位的信息缺口及明确授权的终局判定，未进行付费模型成对实验，不能据此宣称实际模型结盟率下降。新的胜利条件仍允许各国自愿选择尊王而形成全员联盟，成立后将正确结束并记录主次胜利。
