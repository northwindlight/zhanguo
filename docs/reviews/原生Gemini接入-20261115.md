# 原生Gemini SDK接入验收

日期：2026-11-15。

## 变更

- 增加 `provider=gemini`，使用固定版本 `google-genai==3.3.0`，直接发送Gemini `generateContent`，不经过Anthropic消息转换。
- 工具由战国玩家API执行；SDK自动函数执行和自动续写均关闭。保留原生响应Part、每个Part签名、并行调用ID及结果顺序，沿用既有客户端存档格式。
- 缺完成帧、异常结束、纯空响应和不完整工具调用明确报错，复用原有429／5xx重试及4xx停止规则；失败不会被计作一次正常行动。
- `ctx_old_reasoning=strip`移除旧思考摘要时保留函数调用Part本身的签名；携带原生Part的相邻assistant记录不合并。
- 主菜单增加Gemini与已有Responses协议选项。Windows便携包增加26个固定版本、固定SHA-256的SDK依赖wheel及许可证，并在内置Python验收中检查SDK导入与原生请求构造。

## 已完成验证

- 本机全量离线1241项，2项可选跳过，零失败／错误。
- 真实SDK通过本地HTTP模拟服务验证JSON路径、API key头、完整工具schema、并行结果顺序、签名原样存读与续接；覆盖空响应、断流和429／400分类。
- 26个Windows依赖wheel逐个对照PyPI官方元数据核对SHA-256；跨平台暂存、原生扩展文件及许可证收集通过。
- API参考同步、29页站点构建与链接自检通过。

## 实际边界

提交前的Google线上探针遇到导入Cookie失效，上游返回UNAUTHENTICATED；浏览器刷新也确认账户已退出。不能据此宣称原生协议已解决特定真实长局的malformed_response，必须重新登录后用同一保存边界验证。

真实游戏存档与接入配置均留在独立私有数据目录，不随源码或便携包发布。原局保持停止，不把缺失的模型回复当作完成行动跳过。
