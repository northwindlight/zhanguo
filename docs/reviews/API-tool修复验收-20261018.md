## 耦合收口

- API 的 `Methods / ReadOnly / ContentParameters / Actions` 归模块声明。移除工具表不会把查询变成写动作，工具声明读写不一致时装载拒绝。
- query 的参数和必填约束直接来自面板工具；新增天气参数的合成面板无需修改 query，全局 schema 和实际调用立即可用。
- 固定 State、Needs、Optional、Provides 回到 TOML，删除 native / experimental / UI 重复的常量方法。资源按内容注册动态追加能力的入口保留。旧扩展仍可覆写方法，但声明冲突直接报错。
- Buildings.demand_preview 使用建筑真实 cycle 配方；Military 的补员选兵与装备计算由预演和结算共用。EconomicQueries 汇总为公开 econ.preview，UI 不再重算电力、免供与补员。

对应回归：`test_api_read_contract_does_not_depend_on_tool_table`、`test_tool_cannot_reclassify_a_read_api_as_write`、`test_query_derives_new_parameters_and_required_constraints`、`test_fixed_declarations_come_from_toml_and_drift_is_rejected`、`test_ui_uses_domain_previews_and_preview_does_not_mutate_world`。
