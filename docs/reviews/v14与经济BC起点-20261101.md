# v14 复核与经济 BC 起点

本轮用户先要求解释 v14 比 v13 慢及效果差，随后明确多国多样市场、经济与军事
解耦、ECS 训练、本地验证，并选长期增长与复利。最新顺序是先用改进 v13 做 BC，
工作独立在 `codex/rl-economy-bc`，不更改主线默认策略。

## v14 当前源码证据

基线 main `2668ee8`，规则核心与 `9378e3f` 相同。八国、种子 73、固定土地、
保留征兵、十期：v13 8.02 秒，v14 238.68 秒，约 29.8 倍；v14 的 388 次 MILP
调用耗时 224.39 秒，占经济层 95.1%。每国每期常有两次运营求解和三次长期求解，
各自有节点／时间上限；不是整期共用五秒预算。最大样本 1213 个变量、716 个整数、
1739 条约束；重新求解没有复用上次整数解。

按用户提出的动态市场问题，另做四个八国混合世界：种子 73／42，各自交换 v13
与 v14 席位；每局 2 个 v11plus、3 个 v13、3 个 v14，五种偏好，十二期。
固定土地但保留真实征兵与市场成交。十二个国家样本合计：

| 指标 | v13 | v14 |
| --- | ---: | ---: |
| 初始价累计净生产 | 5861.5 | 7861.5 |
| 期末现金 | 2083 | 650 |
| 建筑 | 283 | 278 |
| 军队 | 24 | 29 |
| 缺料建筑期 | 0 | 29 |

v14 此项净生产高 34.1%，十二个换位样本中十一个较高。因此当前证据不支持
“v14 普遍更烂”。净生产不扣投资、军需和交易成本；短程固定土地也不能证明利润、
长期增长或战胜率更优。此前二十期负 17.2% 是不同历史源码的同质世界结果。

慢和脆弱性的可复核原因：

- MILP 限额逐层叠加；经济层无可行解时可能采用只完成军事优先目标的解，
  长期模型无整数解时仅做一期运营。扩大预算的两个实际状态重放并不总能修复。
- 价格路径按旧产能基线外推，没有把选中新建产能及未来订单回写到市场路径；
  正式游戏市场本身仍然动态。第四期流量又按 0.99 折现作长尾，放大预测误差。
- v14 只消费偏好的 horizon／reserve。相同观察中 merchant 与 liquid 的完整
  矩阵和目标哈希一致，其余偏好字段不产生差异，削弱多样性。
- 先服务、再最大征兵、最后经济，固定的军事优先级不等于经济机会成本优化。

144 个 v14 计划的 1008 项当期资源预测与实际相符（金只保守少估），无正式动作
失败；这支持当前物理执行接线，不证明远期估值正确。个别经济解实际 gap 达
1.3138，不能把配置的 2% 当作每次已达到。

本机原始合成审计保留在 `~/zhanguo/archive/previews/v14-audit-20261101/`，包含
逐层计时、成交回执、换位配置、重放状态和摘要。没有操作真实运行局。

## BC 实施边界

现成 `feat/rl` 是旧经济／军事联合环境，默认单国且引擎接口过期；最新
`feat/rl-tactics` 的环境专训战术，赠大量资源并自动补兵。复用注意力层及训练
经验，同时对当前正式经济重新建立观察、动作、标签和多国数据。旧权重不静默沿用。

教师优先修已确认的 v13 材料出售冲突，不宣称启发式到达全局最优。完整执行和
复现口径见 [经济 BC](../../rl/economy/README.md)，后续实测结果另记，不能用计划
规模充作训练完成。

首轮教师验证：八国混合 v11plus／v13／v13plus、种子 73／42、交换 v13 两版席位，
保留实际军事扩张，每局 40 期。双方各 14 个国家样本，改进版固定初始价净生产
34929 对 32604.5（+7.1%），期末 GDP 合计 1392.50 对 1230.51（+13.2%）；
领土 316 对 146、军队 49 对 16、建筑 441 对 443、现金 2415 对 8335。
两版均无失败动作、缺料和军需短缺。原始累计消费未在这一早期 runner 中单列，
新采集／评估代码已补正式账本口径，不能把这些数字替代长期主指标。
分世界结果及规则源码指纹见 [教师初测](v13plus-teacher-20261101.json)。
