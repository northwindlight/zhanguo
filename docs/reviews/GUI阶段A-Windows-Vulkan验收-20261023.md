## 输入与结果

两个固定输入与第三批样板一致：主样板 19 设施、286 树、19 人物，邻接样板 9 设施、259 树、10 人物。
报告中的两个 SHA-256 均可由仓库对应输入文件转换为 CRLF 后精确重算；
差异来自 Windows 换行符，布局、资源、对象数量及岩壁计数均与 Linux 基线一致。
