# 鼠标军令与持续路线阶段验收

本次落实[第二版计划第3组](../plans/GUI两版实施-20261028.md)及[军令设计](../design/军队选择与鼠标军令.md)，继续单机一位真人。完整v0.7.0仍有发行版开关、地图筛选、指南和银行报表等待办，本阶段不改VERSION或已公开附件。

## 实际行为

- 右侧按驻地或逐支勾选，可跨地块保留；滚动、筛选与切格不清空。固定摘要列已选数量、驻地及完整名单入口；可仅显示已选、清空、逐项取消。军队阵亡／不再属于本国时移除选择并提示。
- 右侧每军显示持续军令标记：正常为“路线”及剩余节点数，低血暂停为“回血”；悬停显示下一目标和正式原因。驻地汇总带路线的军队数量，未勾选也显示，取消／完成后随正式状态移除。
- 左键浏览地图，右键移动，Ctrl右键攻击；选军后立即显示当前移动候选，按住／松开Ctrl切攻击／移动。旧按钮保留。目标只执行合法子集，悬停显示参与数量与未参与原因，完整名单可在已选清单核对。控件区域不向底下地图下令；中键仍拖动地图。
- 选中光环绑定本国军队编号，跟随原行军位置；同格同兵种的已选和未选军队分组绘制，标“已选k/n”，未选部队不一起高亮。迷雾中的己方编队也标出部分选择。
- Shift右键追加移动，Shift Ctrl右键追加攻击；每军最多64个节点，可删节点、重画或取消。地图显示序号、路径线和攻击方向；未知段仅画虚线示意，不返回隐藏格路径。
- 路线与回血锁定属于军队域，随存档保存。用户确定低于绝对30生命暂停，正常补给恢复满血再继续；各军队独立，不额外治疗或强制撤退。暂停原因复用正式补给预演，区分同格交战、补给不足与装备不足。新兵、额度、地形、交战和外交仍由正式规则核算。

## 规则复用与执行时机

已有`move / attack / retreat`与批量接口支持跨驻地，不另创GUI移动公式。短期候选和长距规划共用`army/navigation.py`，规划使用绑定玩家观察；长距攻击可规划后续敌地，但实际先停在第一个进攻地块，等待战斗。目的地归己方／盟方后使用普通移动。直接军令替换该批部队剩余路线，验证失败不清掉原路线。

引擎只增加通用`Session.before_actor`扩展点，native在轮到该国时推进军令。行动先手仍按原规则轮换，原18个结算阶段声明完全保留；不会把后行动国家的移动提前到整轮开头。每支实际动作后马上记录快照，再执行下一支，回放能展示中间位置；一次真人批量规划的当期动作统一演出。

公共API为`native:army.queue_orders / orders / cancel_orders`；模型动作经military伞入口，查询`march_orders`全国面板，不增加按地图坐标的查询。真人状态新增`army_orders`；GUI只提交军令并绘制正式候选／公开路线。
