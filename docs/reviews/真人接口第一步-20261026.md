# 单机真人接口第一步验收

2026-10-26。依据用户“分两步，先做人类侧的接口”“做完了再汇报，然后做 GUI”“目前只做单机单人”的最新范围。

本批完成宿主与玩家接口；**没有改 Godot C# 界面，没有宣称真人窗口或 SVG 已接线**。第二步复用已提供的 human-ui-v1 素材。接口说明见[单机真人玩家接口](../真人玩家接口.md)，完整目标见[计划](../../plan.md)。

## 已完成行为

- native 与 experimental 支持一位开局真人混合 AI。真人等待实际输入，不能跳过或自动代结束；正式免国策、小结和议会流程，没有占位文本，AI 要求保持。
- 37 类默认操作经绑定玩家 API 进入原领域规则、审计与回执。结束回合仍自动处理外交提议及开放投票。
- 外部写请求验证当前席位、期数、控制代次、随机回合令牌和唯一请求号；重复点击返回同一回执，不再扣款。演出未确认时拒绝新写操作，查询继续响应。
- 单一宿主线程访问 Session；等待真人不持锁。回合中保存排队，中途退出需要继续本回合或明确放弃，标准输入断开保留最近完整存档。
- 真人数据通道固定本国视角，过滤外国思考、后台操作回执和私有账户；失败不能退到观察者全图。亡国后停止推进并保留最后合法观察。
- 地图区分实时、历史、未知；历史逐字段保留日期、稳定顺序与来源，清理收件箱和存读档不会刷新成实时世界。外国部分公开建筑缺省不等于其他建筑被拆除。
- 军令候选完全由玩家事实计算，移动与攻击独立，多选取并集，提交只使用该目标可执行的子集；不利用隐藏障碍预验，未知区域仍可尝试。保留新兵、已行动、交战、原地攻击及原有整批裁决。
- 正式 `map_offers / buy_map / knowledge` 对真人和 AI 共用。供图为开局及完整边界冻结的全国测绘，基础 20 金加每格 2 金，行政费用入账；同一版本只能购买一次，取得历史而非实时视野。共享及间谍图按实际送达合并。

**原有 18 个规则结算阶段及顺序保持。** 地图知识由发行版 Session 在完整结算后采样，没有新增结算阶段。
