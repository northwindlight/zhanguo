# 行动事件播报与内容别名修复

2026-11-14。针对本体八国看海局：即时占领混入期末动态、连续军令回执延迟，以及交易标题出现 `equip`。

## 发生时点

移动和进攻抵达仍在行动期即时执行；无守军占领也保持即时生效。有守军的战斗、战后占领、撤退落地和遣返仍按原结算阶段执行。本次不改军队规则、资源消耗或阶段顺序。

此前无守军占领已经写入领土，但军事事件队列一直等到期末才汇入情报事件，因此“领土变更”会插在军需前面。现在会话在行动成功后、回执回调前发布这些既成事件，沿用事件生成时保存的接收者和归属快照，并标记行动期。

终端在对应调用批次后播报行动事件。自动连续军令在该国行动开始时就刷新回执，无须等待模型响应；提交路线时已经执行的首段也显示实际移动或进攻结果。普通移动、手动进攻、脚本／规则客户端仍走既有行动回执。

提前显示的事件用独立编号集合去重，不推进期末事件游标。这样既不会在期末重复占领，也不会吞掉编号较早、仍应等待期末播报的公告。真实结算产生的事件继续归入结算动态。

## 内容别名

`equip` 已是正式内容别名，成交回执返回 `native:equipment`，但标题原来直接拿原始输入查翻译。工具层现在按所选动作声明的内容参数，复用内容注册表解析别名后生成标题；原始参数和审计记录保留，无法识别的失败输入仍原样显示。装备交易因此显示一次“售出 装备×2”，与成交正文一致。

## 验证

新增回归覆盖别名标题、普通移动、即时占领、较早公告不丢失、期末不重复、续档不重播、自动军令、首段军令，以及战后占领和撤退仍在实际结算时点发生。测试使用离线合成局；未开启或测试动态回合。

固定回合回归共 1112 项，零失败、零错误，2 项可选跳过；排除并发行动、桌面并发和无关 stock 测试。API 参考同步与 29 页文档站链接自检通过。第 23 回合真实存档直接读回、状态一致，无需转换。

存档格式、模块依赖和公开动作接口不变，现有局直接续载。
