# 经济模型跨环境验收

用户要求以各个环境接近并超越教师为验收标准。完成20轮训练或动作分类准确率
均不视为模型验收。初始模型为T4完整数据第20轮S模型，原权重保留。

选模环境是种子8101/8102/8103，对应20/24/28地图、150/200/250回合，分别交换
两组模型席位，共六个环境、24个模型席位。各环境使用同种子同席位的v13plus
教师对照，其他国家保持v13与v11plus，真实市场、五种经营偏好、无资源补贴。

接近：每个环境、每个席位的累计S和末50回合S均至少达到教师95%；开局按要求
征兵与扩张；项目/API失败、触顶和军需短缺另列为诊断。超越：在接近条件上每个席位
累计S不低于教师。汇总成绩不能弥补任何落后环境/席位，遗漏席位直接拒绝。
通过后须使用9901/9902/9903的独立世界确认；咨询后的确认种子不再当未见样本。

正式判定对每个环境跑完整150–250期，不以12期开局排查提前替代长期S比较。
此前12期排查结果仅作开发诊断，不纳入正式通过或拒绝。
贪心Policy对无账本变更的拒绝会重复96次；现仅折叠重复计算，失败数、触顶数、
尝试计数和整个世界结果均与原循环相同。没有删候选、硬合法掩码或教师代操作。
该等价性已通过世界状态和计数一致测试。

未接近时自动采两个新世界的学生状态做DAgger，每次6个训练epoch；验证与新种子
确认均接近后用PPO争取超越。候选在逐环境/逐席位对照中退化就回退。只有完整
新种子确认均超越才生成accepted.pt。预算/轮数/截止先到时状态为not_accepted，
不谎报成功。保持最近4个在线回放、1GiB目录预算、128MiB单文件限制和系统磁盘余量。
