# 正式生产队列阶段验收

本次完成[第二版计划](../plans/GUI两版实施-20261028.md)中的生产队列一步。v0.7.0其他项目仍待实施，当前不递增VERSION、不改v0.6.3已发布附件；完成整版后由CI验收并预发布。

## 实际行为

- 建筑与军队领域各自持有正式队列，入队扣全部资源并锁价，后续开工不再扣款。原直接操作、规则AI与原18阶段结算保留。
- 建筑预占共享资源位、同格限制和全国自建限额，按地块FIFO、每格每期一次动工。征兵按兵营／军屯原额度分批生成，待征民兵预占编制，新兵规则保留。
- 用户确认：未开始条目取消100%退款；在建拆除50%，完工0%；分批征兵只退未生成部分。失地／亡国取消未开始部分，退原付款国。城堡避免中间缺级，设施／前提变化明确等待。
- 新行动期开工，通过已有审计与演出回调记录真实开工／生成结果；只读规划、状态、队列面板不推进生产。
- 可花库存不含预付款；`econ.prepaid_stocks/prepaid`单列尚未消耗材料，计入总资产；消费只在实际开工／生成时记一次，经济报表包含预付资产，避免重复记账。
- 真人与LLM均可使用正式排队和取消工具，全国查询不需要地块参数。桌面默认队列模式，也可切回直接建造／征召；全国生产面板显示进度、定位、等待与退款确认。尚未提交的输入队列明确标注未扣款。
