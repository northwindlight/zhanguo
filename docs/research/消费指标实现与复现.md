# 消费指标：实现映射与独立复现

核对日期：2026-10-19。理论定义与证明见[研究论文](消费总量评测指标论证.md)。本附录只说明程序实际计算什么、哪些性质已检查，以及证据的适用边界。

## 一、实现映射

核对基准为提交 `e5ceceb` 的运行代码。研究文档与本附录配套程序另有变更；成对检查结果保存实际加载源码的 SHA-256，不能只凭基准提交号识别全部材料。

| 对象 | 程序行为 | 与理论定义的关系 |
| --- | --- | --- |
| `world.economy.spending(actor)` | 返回 construction、recruit、military、administration 四类历史估值 | 四类总和是现行最终用途支出代理，不全是消费 |
| `settlement.settle` 的 consumption | 征召、军需、行政三类的 `known` 小计之和 | 当期行情估值的消费代理 `S_C`，不是固定价数量指数 |
| `settlement.settle` 的 investment | construction 的 `known` 小计 | 建造投入代理，单列显示，不参与消费排序 |
| `cumulative_spending` | 四类金额累计，包含建造 | 不是三类消费合计；不能因名字或历史文案而混用 |
| 估值时点 | 经济报告阶段，对当期事实按行情估值后保存 | 后续不按终局行情改写，不表示跨路径使用共同价格 |
| GDP | 建筑产出估值减生产投入估值 | 属于游戏的增加值代理；不能未经完整账户核对便断言等于消费加投资 |
| 军事事实 | 实际补给和回血装备耗用进入 military | 反映实际资源使用，不直接标识军事任务成败 |
| 征召和行政 | 依领域事件计入相应费用 | 长期装备、纯金融费用与服务边界仍需分别审视，类别名不能自动证明严格经济分类 |

本文没有修改运行代码、发行版声明、计分规则、模型输入或存档。源码中的现行计分仍为按历史当期价格记录的三类消费代理。

研究论文以当期价实际消费 `S` 为主要评价对象，以固定参考价数量指数 `A` 为辅助分析。式（27）的跨局比较采用共同协议下的 `S` 期望差，包含主体与其他参与者共同形成的价格反应；没有要求各局形成相同相对价格。因此，程序采用当期价这一事实本身，不构成相对于论文主指标的缺陷；事件分类、估值记录、市场条件和能力解释仍须各自核验。

## 二、价格机制与测量对象

默认市场采用有限库存报价，期末价格形式为：

```
p = base × exp(elasticity × (reference − inventory) / reference)
```

另有绝对价格边界，参考库存按声明的流量规则更新。买入压低可售库存，卖出增加库存，因而交易需求与供给共同影响报价。该机制是库存反馈的做市规则，不能未经推导便等同于一个由需求函数与供给函数同时出清的竞争均衡，也不能把价格变化视为没有经济含义的随机噪声。

额外库存采购不属于本期最终消费，却属于真实市场需求。因此，“最终消费数量相同”不等于“完整经济活动相同”。成对检查隔离的是：这种市场需求变化是否改变同量最终消费的名义金额。

如果研究对象是按当期供需条件估值的消费，价格效应应当分解并解释；如果协议声称测量共同尺度的使用量，价格效应就与该数量规格不符。二者不能混为一个笼统的“指标正确性”。实际成交价测采购成本，也不能自动替代共同参考价。

## 三、三类消费的成对价格检查

### 3.1 设计

脚本为 [strict_consumption_probe.py](../../experiments/consumption_metric/strict_consumption_probe.py)。全部世界仅在内存中创建，不读取或写入对局存档，不调用模型服务。

六个世界的初始条件完全相同：秦有 20000 金、2000 单位补给、十支预置满血步兵和一块无建筑的本国领土。预置军队属于共同初始条件，不计为当期征募。观察六期；没有建设、征募、战斗或回血。

每种报价机制分别设置三个处理：无交易；每期额外买入100补给并留存；每期额外卖出100补给。动态报价使用默认模块，固定报价替换为仓库提供的固定定价示例。各世界均调用正式军需结算与经济报告；最终分数直接取 `settlement.settle` 的 consumption。

脚本逐期独立核对：

1. 交易前后库存差额与买卖量一致；
2. 交易后到军需结算后的库存恰好减少10；
3. 十支步兵均保持满血，不存在断供、战损或装备回血；
4. 当期三类消费事实只有一条 military，输入恰为10补给；
5. 没有 construction，investment 为0；
6. 最终消费与六期军需估值合计在浮点容差内一致。

这样既没有将建造代入消费，也没有仅用累计消费字段自身证明实际用量。

### 3.2 结果

| 报价机制 | 交易处理 | 实际消费补给 | 投资 | 结算消费金额 | 相对动态无交易组 |
| --- | --- | ---: | ---: | ---: | ---: |
| 动态 | 无交易 | 60 | 0 | 360.000000 | 0 |
| 动态 | 每期买入100 | 60 | 0 | 551.991815 | +53.3311% |
| 动态 | 每期卖出100 | 60 | 0 | 223.055993 | −38.0400% |
| 固定 | 无交易 | 60 | 0 | 360.000000 | 0 |
| 固定 | 每期买入100 | 60 | 0 | 360.000000 | 0 |
| 固定 | 每期卖出100 | 60 | 0 | 360.000000 | 0 |

逐期数据、完整初始条件和源码指纹见 [strict_consumption_results.json](../../experiments/consumption_metric/strict_consumption_results.json)。

**能够确认的结论**：现行三类消费金额不是交易路径不变的数量指数；固定报价下本组差额消失。买卖确实改变了需求、供给和库存，动态金额包含其价格影响。这是一个测量对象的辨别，不能单独证明动态价格失去经济意义，也不能证明买卖策略在完整战略任务中有利。

**证据边界**：没有测试军需以外的全部消费、所有模块替换、完整成本收益或长期模型能力。处理组有真实资金和资源机会成本，期末库存也不同；不能把同量消费解释为所有经济条件和最终状态都相同。

该实验有效控制的是最终消费数量，操纵的是额外市场交易，观察的是金额响应。它没有保持现金、库存分布和完整需求结构不变，也未验证这些不同状态应具有相同的社会机会成本。固定报价组将价格通道关闭，适合辨别机械通道，但未提供一个在完整市场中证成的“正确价值”。53.3311%的金额差可以精确报告，未经额外价值基准论证则不应改称53.3311%的计量误差。

把一份既有对局按参考价重算，得到的是该样本对两种估值的敏感性；把固定定价模块接入自主对局重新运行，得到的是制度干预的反事实。前者没有重新产生行为，后者可能改变行为，两者都不能只凭名次是否一致证明某种理论必然有效或无效。本批不为裁定这一理论问题新增对局或重算真实存档。

### 3.3 建造与四类支出的独立材料

[price_channel_probe.py](../../experiments/consumption_metric/price_channel_probe.py) 及其 [price_channel_results.json](../../experiments/consumption_metric/price_channel_results.json) 使用相同数量的建设，记录四类支出字段。其动态买入组相对无交易组高42.9%，卖出组低25.9%。

这组材料说明建造估值的价格效应，不能直接作为三类消费排名的数值证据。两组脚本的使用类别、交易资源与处理规模不同，百分比不能混报；复现一种结果也不构成复现另一种结果。

## 四、数学公式复算

### 4.1 资本积累与需求价格

[theory_checks.py](../../experiments/consumption_metric/theory_checks.py) 只使用 Python 标准库，不加载游戏。结果保存在 [theory_check_results.json](../../experiments/consumption_metric/theory_check_results.json)。

已完成33项常数投资率及跨期平衡公式数值核对、30项有限期价值递推与全部全投/全消费路径的穷举对照，并核对首期小量投资偏离、平方根技术衰减和逐资源平衡实例。对数凹函数例子检查其导数符号及序列表示；无穷级数的发散仍由正文的调和级数论证，不以有限运行证明。

这些是对公式与实例的一致性复算，不是新增的一般定理证明，也不是对实际游戏最优战略的推断。

### 4.2 消费金额的宏观价值证明

论文第七节以社会用途及再生产机会成本为价值含义，证明竞争价格的宏观支持性质，以及竞争性投入产出经济中的 `pᵀc=wᵀG(Id−H)^{-1}c`。前者给出边际价值根据，后者说明消费总额对应其直接与间接资源需求的价值。劳动价值仅在明确的附加条件下作联系，不把一般均衡价格与劳动量无条件等同。

[market_value_checks.py](../../experiments/consumption_metric/market_value_checks.py) 为独立标准库复算，不加载游戏。结果见 [market_value_results.json](../../experiments/consumption_metric/market_value_results.json)：

- 两个异质用途主体的预算最优、市场出清、固定分配权重与共同支持价格；两个资源的价值函数导数及15组资源变动的全局支持不等式。
- 一个带中间投入产业链的完整例子：由最终用途评价与资源上限先求稀缺价值，再核对需求端边际评价、生产端单位成本、消费金额与完整初级资源使用。
- 五种产业技术、四种消费构成，共20个模型：用精确有理数核对投入产出价格、完整资源成本、国家合并和消费/投资分解。
- 同20个模型的非均衡价格残差、宏观误差恒等式与范数上界。
- 单一劳动要素下的价格比例，以及正资本报酬下不再普遍同比例的两部门例子。

这些结果核对一般证明的数值实例，**没有验证当前游戏已达到充分市场条件**。游戏中的整数动作、库存报价、政治军事外部影响和资本服务映射仍须分别考察；价格成对实验也不承担这一证明。

## 五、评价口径与待核验的实现边界

1. **主评价对象。** 现行当期价三类消费与论文主指标方向一致；共同价格数量排名是另一种分析口径，尚未实现并不自动意味着主指标缺失。使用哪一种结果必须明确标注。
2. **未估值消费的完整总额。** 结算按 `known` 小计排序，未定价项目合并提示；尚未按消费、投资分别处理不完整估值，也未拒绝不完整总额排名。
3. **严格最终服务分类。** 征召和行政类别仍是游戏抽象，长期装备、金融服务与纯转移需要按具体事件逐项对应。
4. **完整产出—支出恒等。** 现有GDP代理、市场货币规则、库存和服务并非一套已通过完整核对的国民账户，不能直接套用 `Y=C+I`。
5. **长期能力效度。** 合成记账对照没有证明消费排名与模型综合战略能力、胜率或长期可持续性之间的经验关系。

这些边界应在研究报告中保留。本附录不会因论文选择某种理论对象而追溯改写历史账目。

## 六、复现

在仓库根目录执行：

```bash
.venv/bin/python experiments/consumption_metric/theory_checks.py
.venv/bin/python experiments/consumption_metric/market_value_checks.py
.venv/bin/python experiments/consumption_metric/strict_consumption_probe.py
```

前两个程序分别覆盖资本/需求公式与市场价值公式的复算结果，第三个覆盖三类消费成对结果。三者均为离线检查。数学程序不读引擎；消费程序加载当前声明和运行代码，并将实际源码哈希写入结果，因此在代码变化后重新运行可能得到不同的程序事实。

2026-10-15 的[静态核对快照](消费指标实现核对.json)与[短程账本记录](../../experiments/consumption_metric/implementation_record.md)保留其各自日期、指纹与口径，不代表本文所列实现已经在这些材料中被验证。
