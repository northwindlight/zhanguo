# 消费总量作为 4X 大战略智能体评测口径的经济学根据

**版本**：2026-10-19

---

## 摘要

4X 大战略的玩法由四个动词构成：探索、扩张、开发、征服。玩家探索地图、扩张疆域、开发资源、征服对手。这四件事本身就是目的；工厂、道路、要塞只是做这四件事的能力。

**消费是目的，投资是手段。** 投资形成未来行动的能力，不在当期被用掉；消费是把产出真正变成行动：远征的粮食、军队的补给与装备、开拓的物资、治理的行政服务。消费不是“吃掉”，是“做成”。

由此，本文论证：以**累计消费总量**作为唯一标量，有经济学根据。

这不是游戏设定里的偏好，是经济学的两条老结论。马克思的再生产说明消费完成生产：没有被消费的产品只是潜在的使用价值；凯恩斯的有效需求说明没有消费生产会停：产能存在，不等于产出会发生。两条合起来，消费既是目的，也是生产继续的条件。

口径先卡死。**消费不是总支出：消费 = 总支出 − 投资。** 两者合起来是支出，也等于产出：

```
E = C + I = Y
```

第一条等号是支出构成，第二条等号是恒等：**生产 ≡ 支出**。消费是支出减去投资之后的部分。

为什么不用支出？因为支出里包含投资——它是手段，不是已经实现的行动。固定资本的价值不在建成时实现，而在未来逐期服务中实现；按形成时计入，等于把“将来能被用来做”提前算成“现在已经做到”。

由此得到六条性质：有经济含义、单一可复现、只计实现、来源中立、不编码战略观、可审计。也划出三条边界：不测投资与产能；不测融资；不测构成。

消费没有固定上界，只要增长为正就可以无限增长；但增长率由投资决定，消费的水平与增长率随投资率改变。长期比较落在增长率上，不在“谁有界”上。

口径的正确性不等于度量的正确性：若按报告期行情估值，同一批消费会因交易路径不同得到不同读数；度量必须路径无关。修法是固定参考价或实际成交价，不是放弃口径。

评测协议还有一条：口径不得进入被测者可读的文本。一旦被测者读到目标，测量就变成任务。

**关键词**　大语言模型；多智能体；4X；大战略；消费总量；有效需求

## 一、问题：为什么需要一个单一口径

### 1.1 加权评分的三处困难

设一份计分板按领土 30%、军队 25%、经济 30%、科技 15% 合成。三个问题随之而来。

**权重不可论证。** 为什么领土是 30% 而不是 25%？权重一变，名次就变；而权重本身没有可检验的依据。它不是从规则里长出来的，是从设计者的偏好里长出来的。

**跨局不可比。** 同一套权重下，换一张地图、换一批对手，分数的基础就变了。A 得 90 分，无法判断是 A 强还是对手弱。

**编码了战略观。** 权重高的项，模型会优先做。于是计分板不只是测量，它还在指定“什么是好战略”。

### 1.2 单一口径的要求

一个好的评测口径应当满足五条：

1. **有经济含义**：不是若干项的加权和，而是一个有名字、可解释的总量；
2. **可观测**：每条计分都能追到具体事实，不依赖主观评分；
3. **可复现**：同一初始条件、同一行动序列，得到同一结果；
4. **不编码战略观**：不预设哪条路线更好，最优由环境决定；
5. **只计实现**：生产出来但没有进入用途的，不算。

### 1.3 本文的任务与界限

本文论证**口径**：严格口径的消费总量满足上述五条，可以承担 4X 大战略的评测。本文不论证**度量**：任何具体的记账程序是否忠实计算了这个口径，是另一层问题，见第七节。

口径是经济学问题，度量是工程问题；前者错了要换口径，后者错了改度量。后文只作一般论证，不依赖具体对局数据。

## 二、目的与手段：4X 与消费

### 2.1 4X 是目的

4X 大战略的四个动词是：探索（explore）、扩张（expand）、开发（exploit，含资源利用与治理）、征服（exterminate）。玩家探索地图、扩张疆域、开发资源、征服对手。

这四件事本身就是目的。玩家不是为了建厂而建厂，而是为了能做这四件事：没有粮食，远征走不出去；没有补给，军队打不了仗；没有开发，疆域守不住。工厂与道路是能力的来源，但能力不是成就；成就是行动真的发生了。

评价一个国家，要问的是它做了多少行动，不是它有多少能力。

### 2.2 投资是手段

投资是形成未来行动能力的产出：工厂、农场、道路、要塞。它不在当期被用掉；它的价值在于未来能支持多少行动。

所以投资是手段，不是目的。把投资当成绩，等于奖励“准备”而不是“行动”：一座永远不投产的工厂，在投资口径下也是成绩；但在 4X 的目的下，它什么行动也没有支持。

### 2.3 消费是 4X 的实现

消费是被 4X 行动真实消耗掉的产出：远征的粮食、军队的补给与装备、开拓的物资、治理的行政服务。它不再回到生产，而是变成了行动本身。

所以消费是 4X 的实现。这里的“消费”不是“吃掉”，是“做成”：粮食被远征队吃掉，远征就发生了；补给被军队吃掉，征服就发生了；行政服务被支付，疆域就治理起来了。

这也解释了为什么消费是目的：4X 的每一件事，都要以资源被真实用掉为标志。没有被用掉的资源，只是能力；被用掉的，才是行动。

### 2.4 再生产：消费完成生产（马克思）

马克思在《导言》里把生产与消费看作同一过程的两个环节：生产生产出消费的对象、方式与需要；消费使产品成为产品——没有被消费的产品，只是潜在的使用价值。

这不是说消费比生产重要，而是说两者是同一件事的两面。生产是起点，消费是完成；没有完成，起点悬在空中。

社会总资本的再生产要求两大部类平衡：部类 I 生产生产资料，部类 II 生产消费资料。简单再生产的条件是 `I(v+m) = II(c)`；扩大再生产的条件是 `I(v+m) > II(c)`——生产资料部类必须有剩余，才能积累。

投资是部类 I 的积累，消费是部类 II 的实现。投资领先，是为了未来更多的消费，不是为了投资本身。这就是“消费是目的、投资是手段”的再生产版本。

（本模型没有工资与剩余价值，`v`、`m` 只作类比；能直接观测的是 `I` 与 `C`。）

### 2.5 有效需求：没有消费，生产会停（凯恩斯）

凯恩斯的问题是：产能存在，不等于产出会发生。设需求为 `D_t`，产出为 `Y_t = min(F(K_t), D_t)`。若需求不足，产能闲置，投入照付、收入实现不了，账面亏本。

十座消费品工厂而没有军队，就是这个状态：产出没有吸收者，库存堆积，最后停产。工厂不是财富，能被吸收的产出才是。

消费是最终需求的主要部分。投资也是需求，但它是为了未来的消费；没有消费吸收，投资的回报无法实现。所以消费既是生产的目的，也是生产能够继续的条件。

### 2.6 生产 ≡ 支出：消费是已实现的部分

记全部最终消费为 `C`、投资为 `I`，在闭合、无对外贸易、无存货变动的经济中：

```
E = C + I = Y
```

第一条等号是支出构成；第二条等号是恒等，即**生产 ≡ 支出**。消费不是产出的全部，它是支出减去投资之后的部分：

```
C = E − I
```

**建厂是投资，不是消费。** 这是本文的口径起点：`C` 里不含建造。把建造算进消费，等于把“为未来行动做准备”与“行动本身”混在一起，增长分析会直接失效。

存货变动不计入支出，也不计入消费；囤积的部分留在账外，作为未实现残差。

支出 `E` 里包含投资，而投资是手段，不是已经实现的行动。固定资本的价值不在建成时实现，而在未来逐期服务中实现；按形成时计入支出，等于把“将来能被用来做”提前算成“现在已经做到”。所以支出总是高估实现，高估的额度就是 `I`。消费 `C` 恰好是已实现的那一部分。

### 2.7 指标的定义

设 `p⁰` 为一组固定的参考价格，`C_t` 为第 `t` 期的消费，则指标是

```
A(T) = Σ_{t≤T} p⁰·C_t
```

即消费的积分。在闭合、一致口径的期间内，

```
C_t = Y_t − I_t
```

所以 `A(T)` 同时也是“产出减去投资”的积分。

## 三、为什么是消费

### 3.1 有经济含义

消费总量不是若干项的加权和，它在国民账户里有名字：最终消费。评价者不需要先回答“领土值多少分”，只需要回答“这一局实现了多少 4X 行动”。

### 3.2 单一、零权重、可复现

一个标量，没有权重可拍。同一初始世界、同一行动序列，数字由规则决定；离线脚本可以从对局记录重算，不依赖模型或裁判。

### 3.3 只计实现

这是它与“产出总量”“支出总量”的关键区别。堆在仓库里的东西不计；卖不掉、用不掉的，不计；建造不计（它是投资，是能力）。指标只记录已经变成行动的部分。

这一条同时是凯恩斯式的：没有被需求吸收的产出，不构成已实现的消费。库存是“未实现”，不是“已生产所以算数”。

### 3.4 来源中立

口径只问“谁用掉了多少”，不问“从哪来”。自产、外购、贡赋、掠夺，在指标面前一律平等。一个完全不事生产的国家，只要持续取得并真实消耗，消费就可以很高。

这条性质否定了“只有市购才计入、自产不计”这类误读：口径对来源中立，自产自用与市购等价。

### 3.5 不编码战略观

指标不规定行动应以何种方式取得。种田、贸易、朝贡、军事扩张，四条路在指标面前等价；哪条最优，由地图、资源、邻国与政体决定，不由指标决定。

这在评测设计里是稀缺性质：**评价者不需要预先知道好战略长什么样。**

### 3.6 可审计

每一笔计入都有记录：消费了什么、被谁用掉、发生在哪一期。离线可以逐项重算，可以与对局记录对账，可以复现同一局。

### 3.7 与其他口径的对比

| 口径 | 单一 | 有经济含义 | 不编码战略 | 只计实现 | 主要问题 |
|---|---|---|---|---|---|
| 加权评分 | 是 | 否 | 否 | 视权重 | 权重不可论证 |
| 领土 / 军队规模 | 是 | 部分 | 否 | 否 | 只测存量，不测行动 |
| 毛产量 | 是 | 部分 | 否 | 否 | 含未实现，鼓励囤积 |
| 支出总量 | 是 | 是 | 是 | 是 | 把准备当成绩，高估实现 |
| **消费总量** | **是** | **是** | **是** | **是** | 不测投资与产能（见第四节） |

## 四、它测什么，不测什么

### 4.1 测：已实现的 4X

由 2.7 的定义，消费总量是“产出减去投资”的积分。它回答的问题是：**这一局，这个国家把多少社会产品真正变成了行动。**

### 4.2 不测：投资与产能、融资、构成

- **不测投资与产能。** 建造不在 `C` 里；它记录的是已经发生的行动，不是下一期能准备多少行动。同样的消费总量，可以来自扩大的产能，也可以来自吃老本。
- **不测融资。** 它只记“花了多少”，不记“钱是挣的还是卖的”。卖资产、借债、收贡赋，都能撑起消费，指标照单全收。
- **不测构成。** 它不分消费的内部构成；不同构成对国力的含义不同。

### 4.3 恒等成立的层面

恒等式在**系统**层面成立：全世界的支出（消费加投资）等于全世界的生产，即“生产 ≡ 支出”。在**国家**层面，只有当市场不创造价值时才成立——本文假定市场只做固定比例的转换（一单位产品换另一单位产品，按固定比价，无价值增殖）。行情会随库存变动，但那是比价的变动，不是价值的增殖；按固定参考价 `p⁰` 折算时，恒等在价值口径上成立。

### 4.4 因此必须并报什么

因为 4.2 的三条边界，消费总量不能单独使用。正式的评测报告至少并报：

- `I` 与 `C` 的分项（能力与行动）；
- 期末产能 `K` 与资源存量（还能不能继续行动）；
- 债务与可售资产（融资来源是否可持续）。

单看消费总量，分不清“靠增长支撑的行动”与“靠吃老本支撑的行动”。

## 五、增长：消费无界，增长率有别

### 5.1 当期约束

每一期，消费不能超过“产出减去投资”：`C_t = Y_t − I_t ≤ Y_t`。这是当期约束，不是时间上的上限。

需求不足时，产出会低于产能（见 2.5）；需求满足后，产出由产能与投资决定。

### 5.2 增长率由投资决定

设产能为 `K_t`，折旧率为 `δ`，投资率为 `s = I/Y`，资本产出比为 `ν = K/Y`，则

```
K_{t+1} = (1−δ)·K_t + I_t
g ≈ s/ν − δ
```

`s = 0` 时 `g = −δ`：资本衰减，产出衰减，消费衰减。`s > 0` 时 `g` 为正，`s` 越大增长率越高（在 `ν` 不变的范围里）。

**只有 `I` 进入这个式子。** `C` 提供当期需求，不改变增长率。

### 5.3 消费无界，增长率不同

消费没有水平上限。只要增长为正，它可以无限增长；有界的只是份额 `C_t/Y_t = 1 − s ≤ 1`，不是水平。

不同的投资率不改变“有没有上限”，只改变水平与增长率：

- 投资率高：当期消费份额低（`C/Y = 1 − s`），但 `g` 高，未来消费增长快；
- 投资率为零：当期消费份额为 1（`C = Y`），但 `g = −δ`，未来消费下降。

繁荣与衰退不体现在“撞到上限”，体现在增长率上。比较两条路径，不能比“谁有界”，只能比增长率，或比有限期内的积分。

### 5.4 军队的双重角色

军队在当期是 `C` 的一部分：它吃掉补给，是行动。军队在跨期是条件：它开疆，抬高 `K` 的可达水平。

所以军队不是纯消耗。没有军队，产能会被别人摧毁；只有军队没有生产，军队会被饿死。两者互为条件。

### 5.5 有限期与长期

评测在有限期 `T` 内进行，比较 `A(T) = ∫₀^T C_t dt`。若 `C` 近似按 `g` 增长，

```
A(T) ≈ C_0·(e^{gT} − 1)/g
```

`T` 越大，`g` 的差别越占主导。长期比较就是增长率比较；短期比较才看水平。

### 5.6 零投资的路径

若一条路径长期取 `I = 0`，则 `C = Y`，当期消费达到最高水平，但 `g = −δ`，消费逐年下降。它在短期积分上可能领先，在长期积分上必然落后——因为它的增长率是负的。

这不是“被上限挡住”，是增长率输掉了。

## 六、口径细则

### 6.1 判据

唯一判据：**使用价值是否被该主体真实用掉，且属于最终消费。** 计入规则是这条判据的推论，不是白名单。将来若新增一种消耗方式，它应当自动进入指标，因为判定标准不是“是否列在表里”，而是“是否被用掉”。

### 6.2 计入项

| 项目 | 类别 | 对应 4X | 时点 |
|---|---|---|---|
| 远征的粮食 | `C` | 探索 / 扩张 | 结算时 |
| 军队的补给与装备 | `C` | 征服 | 征募/补给时 |
| 开拓的物资 | `C` | 扩张 / 开发 | 结算时 |
| 行政服务 | `C` | 开发 / 治理 | 服务结算时 |
| 建造 | `I`（不计入消费） | 能力（非行动） | 单独报告 |

### 6.3 排除项

| 排除 | 理由 |
|---|---|
| 建造 | 投资，是手段，不是行动；单列 |
| 市场买卖 | 形式变换，使用价值未被消耗 |
| 馈赠 | 同上；贡品在受赠方真实消耗时计入受赠方 |
| 存货 | 未实现；既不进支出，也不进消费 |

### 6.4 归属与时点

按**使用者**归属，不按支付者或生产者。A 把粮食卖给 B，B 的军队吃掉，计 B 的消费；A 的销售不再计一次。时点按事实发生期；跨期与在途费用单列。

### 6.5 价格

用固定参考价 `p⁰` 折算。`p⁰` 必须是公开的、可复核的、预先给定的；它的选择是规范性输入，不是经济学唯一给定，因此必须做敏感性分析。

替代方案是实际成交价。两者都比“报告期动态行情”更适合比较：前者稳定，后者真实。实践中常采用第三种，见第七节。

### 6.6 未定价项

存在未估值资源时，总额返回 `None`，不得用已知小计冒充全额。

### 6.7 防重复

- 中间投入不重复计：若最终装备的估值已含矿石与金属，不再把三段销售额相加；
- 同一资产不二次计：建造计入 `I` 一次，之后不逐期把同一资产价值再加入消费；
- 取消与回收须冲回：这是扩展建筑动作时的规则约束，不宣称现行实现已经具备。

### 6.8 口径卡点清单

1. 消费、投资、支出三分（`C`、`I`、`E = I + C`）；
2. 价值、使用价值、价格三分；
3. 实现与出售的区别；
4. 归属：使用者而非支付者；
5. 期界：结算前后、在途费用；
6. 价格：`p⁰`、成交价、行情，三者不可混用；
7. 未定价项：`None` 不得当零；
8. 主体退出后的计量（结算保留）；
9. 存量变现算不算实现（算，但不可持续，见第五节）；
10. 转移与援助的归属（在受赠方的使用处计）。

## 七、度量要求：路径无关

### 7.1 命题

设两条合法路径保持逐期用途与用量逐项相同，只改变交易或融资路径。记两条路径的读数为 `S₀`、`S₁`，容差为 `ε = 10⁻⁷·max(1,|S₀|,|S₁|)`。要求是：

> **H**：`|S₁ − S₀| ≤ ε`。

`H₁` 指固定估值下的不变性；`H₂` 指按报告期行情估值的做法也满足同一不变性。

### 7.2 固定价格下成立

固定参考价下，金额只依赖逐项用量：`A = Σ p⁰·q`。路径只改变成交方式，不改变 `q`，故 `A` 不变。这是加总规则的构造性质，不需要实验。

### 7.3 报告期行情下不成立

设行情随库存下降：

```
p = p̄·exp(η·(R − M)/R)
```

其中 `M` 是市场库存，`R` 是参考库存。买入使 `M` 下降，`p` 上升；卖出使 `M` 上升，`p` 下降。于是同一批用量 `q`，只因为交易方向不同，就被估成不同的金额：

```
S = Σ p(M_t)·q_t ，  M_t 依赖交易路径  ⇒  S 不是路径不变量
```

这不是实现细节，而是“用报告期行情给历史事实估值”这一做法的性质：估值发生在事实之后，行情却可以被事实之前的交易改变。任何这样的度量都不能用于跨策略比较。

### 7.4 修法

三条候选，任选其一：

1. **固定参考估值**：用公开的 `p⁰` 折算，行情只作参考；
2. **实际成交价**：在事实发生时保存价格凭据；
3. **协议禁止影响库存的交易**：改变合法行为空间，代价最大。

选定后仍须重跑成对检查。**修的是度量，不是口径。**

### 7.5 三个量

| 记号 | 含义 | 用途 |
|---|---|---|
| `A` | 严格消费按 `p⁰` 折算 | 口径本身 |
| `S` | 按报告期行情估值的支出（含投资） | 不能用于排名 |
| `S_C` | 同上的消费分项 | 严格口径的近似读数，仍受同一估值规则影响 |

三者不可互相替代。选择报告期行情作为度量，`S_C` 与 `A` 的差就是度量的误差。

## 八、评测协议

### 8.1 测量不得成为目标

一个只用于离线统计的量，和被写进规则、被模型读到、被当作优化目标的量，是两种东西。前者是测量，后者是任务。测量可以错，改口径即可；任务一旦错置，模型会认真地去完成它。

所以：**评测口径不得进入被测者可读的文本。** 给模型的任务信息里，不应出现排名、计分公式或结算命令。

### 8.2 研究与运行分离

研究用脚本读对局记录，离线计算；对局只给玩家任务信息。两者共用同一份事实数据，但不共用同一套叙述。

这不是工程细节，是实验设计：被测者知道自己在被测什么，行为就变了。

---

## 九、边界与局限

1. **本文不论证最优战略。** 指标不编码战略观，最优由环境决定。
2. **本文不比较不同模型。** 跨模型比较需要真实对局；本文是理论论证，不含模型实验。
3. **环境方差很大。** 跨地图、跨种子的分数差异可能很大；任何小差异结论都必须多种子、多地图取中位。
4. **消费总量不测投资与产能。** 它必须与投资率、产能、资产负债表并报（第四节）。
5. **路径无关是度量要求，不是自动成立的事实。** 采用报告期行情估值的做法，必须先修，再用于比较。

---

## 十、结论

**消费是目的，投资是手段。** 4X 的目的是探索、扩张、开发、征服；投资形成能力，消费把产出变成行动。评价应测行动实现了多少，不是能力准备了多少。

**口径成立。** 严格消费总量是“总支出减去投资”的积分；在闭合、固定比例转换的前提下，它等于“产出减去投资”的积分。它有经济含义、来源中立、不编码战略观、只计实现、可复现、可审计。消费没有固定上界；不同路径的差别在增长率。

**度量需修。** 按报告期行情估值会让同一批消费随交易路径变动；修法是固定参考价或实际成交价，不是放弃口径。

**协议隔离。** 评测口径不得进入被测者可读的文本。
