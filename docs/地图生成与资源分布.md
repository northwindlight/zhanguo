## 生成机制

- 地形：`tile_terrain(x,y)` = `random.Random(f"{seed}:{x}:{y}")` 按先验权重抽——**纯函数**，
  同 seed 同坐标永远同地形，与占领顺序/战斗无关。
- 资源：`tile_resources(x,y)` = `random.Random(f"{seed}:{x}:{y}:res")` 按该地形的权重表抽五项。
- 地名：`random.Random(f"{seed}:{x}:{y}:name")`（撞名重试只影响名字本身，不碰战斗随机流）。
- 野人守卫：开局全图无主格每格一支（100HP），是地图静态属性；死后永久清空。

## 空间均匀度

逐格独立抽样是泊松点过程，天然成簇：**数列均匀 ≠ 空间均匀**。实测分区变异系数恰等于
泊松预测 1/√λ（大图 0.128 vs 理论 0.124）——12% 密度下开荒几十格见到连片金矿是正常表现，
不是 RNG 的毛病。三种生成方案（iid / 4×4 分区配额 / 蓝噪声）的对比实验与指标定义见
`experiments/gold_uniformity.py`、`experiments/gold_uniformity2.py` 及 `experiments/README.md`。

## 采集建筑上限

地块某项资源量 = 该地该类采集建筑的可建座数上限（如金矿 x2 的地最多建 2 座黄金矿场）。
建筑造价/产出属于**游戏规则**（局内 `rules` 可查），在 README 建筑表；本文件只管分布。
