## GPT 与本机 Antigravity 的出图方式

这里使用内置 image_gen 工具，不另写付费 API 批量脚本。GPT 图像工具接受文字描述、
参考图和编辑要求，也可请求透明背景；导出 PNG 后检查真实 alpha，放进 Godot 看实际缩小效果。
见 [OpenAI 官方图像生成说明](https://developers.openai.com/api/docs/guides/tools-image-generation)。

本机已有可用的 Antigravity 网关。CLI 的 `agy models` 当次只列出文字模型，
网关的独立生图路由经过一次真实调用，约 92 秒返回一张 1200×896 JPEG。
请求模型名由现有路由源码指定为 `gemini-3.1-flash-image`；原图及提示词保留，
实测数据见 [agy-image-probe-20261023.json](../reviews/agy-image-probe-20261023.json)。

返回图画了灰色棋盘背景，没有 alpha；本批随后用内置 image_gen 做背景提取，
得到具有真实 alpha 的 1451×1084 PNG，与第一张 GPT 山岩交替试用。
这条工作流是“Antigravity 生成主体 → 透明处理 → 游戏内检查”。
原图、去底提示词与衍生图都在项目中保存，来源在生成清单中明确区分。
去底工具可能重绘边缘，不能当作像素逐点不变的处理。

Gemini Pro 网页/App 出图也可以沿用下面的规格。应下载原始文件并检查格式和 alpha，
图片中画出的棋盘不代表文件透明；正式拼块与动画仍需逐项校对。

## 统一规格

- 视角：正交的高角度俯视，略能看到正面，保持与既有房舍相同的方向；不使用等距菱形底座。
- 比例：人物身体 6×8、普通房舍 16×16、专门设施约 24×24、山岩组合 64×48；这些是显示尺寸。
- 画法：粗像素、有限色板、左上光源、边缘清楚；灰绿岩石、低饱和橄榄苔藓，与现有草木搭配。
- 背景：单个对象、完整轮廓、四周留透明空间；PNG 真透明，不画棋盘格、地块底座、文字或阴影背景。
- 产出：每张一个对象、一个方向。初期分别出山岩、矿场、油井等，不把不同设施和动作塞进一张难以切分的图。
- 验证：原图好看不代表小尺寸可用；在 Godot 中缩到目标尺寸检查轮廓、颗粒感、遮挡和重复拼接。

AI 生成图不保证像素网格、无缝边缘或动画帧一致。当前两张山岩最终 PNG 有真透明，
颗粒与 Mini World 仍有差异，多处复用轮廓仍可识别；当前是放进实际地图的素材试用，山体拼块继续完善。

## 可直接用于 Gemini 的提示词

本批山岩的完整英文提示词已保存为
[mountain-outcrop-v1.prompt.txt](../../mods/ui/desktop/assets/generated/mountain-outcrop-v1.prompt.txt)，
可先用同一提示词比较；参数不随提示词假定为所有工具都支持。

下一张矿场可用：

```text
为一款小比例2D大战略游戏绘制一个独立矿洞入口素材。高角度俯视、略见正面，
非等距视角，没有菱形地块底座。低矮灰绿色岩壁中嵌入木架入口，旁边一小堆矿石。
粗像素、有限色板、左上光源，逻辑像素约24×24，轮廓需在小尺寸下可辨。
只画一个矿洞设施，完整轮廓，四周留空。背景必须真实透明，PNG输出；
不要人物、金币、界面、文字、地面方块、照片质感、模糊或柔化边缘。
```

下一张油井可用：

```text
为同一款小比例2D战略游戏绘制一台磕头机的静态素材。高角度俯视、略见正面，
与16×16房舍搭配，显示尺寸约24×24。主体为深灰色金属，少量木色支架与低饱和暖色点缀。
粗像素、有限色板、左上光源、清楚的机械轮廓。只画一台设备，不添加烟雾、油流或运行特效。
完整轮廓、四周透明留空、真实透明PNG；不要地块底座、文字、人物或照片质感。
```

上述矿场/油井提示词是后续用的规格，本批未声称已经生成或接入这些图。

## 2026-10-24 视觉增强批：角色表与建筑预留位

桌面端本批接入了自动素材管线：`mods/ui/desktop/assets/actors/` 下的 PNG
按文件名查找，缺失时继续使用代码绘制的小人与 Mini World 贴图，放入即生效，
无需改代码。行列布局、单元格尺寸和逐文件提示词见
[assets/actors/README.md](../../mods/ui/desktop/assets/actors/README.md)，

预留位一览：

| 文件 | 单元格/尺寸 | 内容 |
| --- | --- | --- |
| `resident-walk.png` | 16×16，6帧×4行 | 村民行走/攻击循环 |
| `soldier-infantry.png` | 16×16，6帧×4行 | 步兵行走/攻击循环 |
| `soldier-cavalry.png` | 24×18，6帧×4行 | 骑兵与马整体循环 |
| `worker.png` | 16×16，4帧×2行 | 工人挥锤 |
| `townhall/farm/mine/oilwell/factory/barracks.png` | 24×24 左右 | 六类建筑单帧 |
| `tree-round/tree-pine.png` | 16×16 | 两种树单帧 |

四行的含义固定：0 右行、1 左行、2 右攻、3 左攻；只有两行时攻击行回退到行走行。
程序按国家颜色对角色做 42% 混合染色，服装主体保持素色才能看清国别。
建筑图烟囱画在右上角，程序在该位置生成炊烟粒子。
生成与去底流程沿用本页前述“Antigravity/Gemini 生成 → 透明检查 → 游戏内缩小核对”，
放入后运行 `python desktop.py` 直接看缩放效果，删除文件即回退代码绘制版本。
