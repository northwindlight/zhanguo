# 漆金界面重设计（第一版）

2026-11-24，分支 `ui/redesign`。承接[GUI 体验打磨](../plans/GUI体验打磨-20261029.md)与试玩反馈：现有界面“像 2000 年代的像素游戏”“过于简陋，缺乏装饰”。

**状态：第一版视觉语言与部分交互已接入真人界面，已在 Linux 软件渲染的离线验收中截图；尚未经过 Windows 便携包验收和实际试玩。** 地块大面板、军队四组折叠面板等结构性改动仍按原 UX 计划分步推进，本轮没有改规则、存档或玩家 API。

## 视觉语言

| 层次 | 做法 | 位置 |
| --- | --- | --- |
| 色板 | 漆黑底 `#18110b`、青铜 `#b48d4e`／亮铜 `#e2c27e`、朱漆 `#8e2b1e`／`#b63c27`、纸色正文 `#efe2c4` | `Scripts/UiSkin.cs`，与 `scripts/build_lacquer_ui.py` 同步 |
| 字体 | 正文思源宋体（可变字重，取 520／720），标题马善政毛笔字；毛笔子集不含数字和拉丁字母，回退到宋体粗体 | `assets/fonts/*-zhanguo.woff2`，来源见 `assets/CREDITS.md` |
| 面板 | 九宫格：双青铜线框，四角回纹与铆钉；内层卡片只留细线，数据区不加纹样 | `assets/ui-lacquer/panel*.svg`、`card.svg` |
| 标题 | 抽屉与菜单用朱漆燕尾题签；小节标题为毛笔字 + 朱漆菱形与渐隐铜线 | `title.svg`、`heading.svg` |
| 按钮 | 切角漆面；悬停亮铜、选中加铜底线；主操作朱漆；结束回合为朱印式大按钮 | `button-*.svg`、`seal-button*.svg` |
| 图标 | 38 个原创 48×48 图标，取材战国器物：版筑（建设）、戈（军队）、布币（市场）、方孔圆钱（银行）、使节之旄（外交）、交叉旌旗（联盟）、竹简（邮箱）、鼎（国家）、朱印（结束回合） | `icon-*.svg` |
| 主菜单 | 原创山水落日背景，毛笔标题；进入子页面时压暗保证表单可读 | `menu-landscape.svg` |
| 地图迷雾 | 去掉棋盘格抖动边缘，改为暖墨实底与向未知一侧渐隐的雾边 | `WorldMap.Human.cs` |

素材全部由脚本生成（`python3 scripts/build_lacquer_ui.py`），只用路径与渐变，Godot 的 ThorVG 直接导入；脚本同时生成 `docs/design/ui-lacquer/catalog.svg` 图录。像素字体保留为 Esc 菜单中的可选字体；地图上的像素地貌、人物和建筑本轮未改。

## 交互调整

- **底部政务栏**：9 个等宽文字按钮改为四组图标导航（经营：建设、军队｜财政：市场、银行｜邦交：外交、联盟、邮箱｜国务：国家），每个按钮带说明悬浮和数字快捷键 1–8；当前打开的页面高亮；待处理提议、投票和未读邮件以朱漆角标显示，不再把数量拼进按钮文字。
- **结束回合**：与导航分开放在右下，朱印样式、毛笔字，是画面上唯一的红色大按钮。
- **地块页**：地名所在的标题行直接给出“建设／征兵”主按钮（缺兵营时征兵按钮禁用并说明原因），地形图标与归属同行；驻军仍在首屏，原文末的“在这里建设／征兵”按钮移除。
- **建设页**：当前分页用青铜高亮框而不是灰显；前后地块切换改为图标按钮。
- **总览与切换按钮**：已选中的条目与标签页显示青铜选中框。
- 确认框“确认”为朱漆主按钮；地图工具、顶部暂停／菜单按钮加图标。

## 验证

`.github/workflows/ui-review.yml` 在 `ui/**` 分支推送时于 Linux（Xvfb + Mesa）运行菜单、真人与财务三组离线验收并上传截图；脚本 `scripts/review_desktop_linux.py`。这些验收与 Windows 便携包共用 Godot 内部检查（按钮在窗口内、抽屉不横向溢出、驻军首屏可见等）。软件渲染只核对布局与流程，不代表实体显卡表现。
