# 地图尺度与看海演出

2026-10-23 设计讨论记录。用户已在 Windows 跑通首版，指出其地图比例与静态面板有管理软件观感，要求先暂停实现、讨论设计。本文记录目标，不表示下述内容已经实现。

后续完整方案见[上帝视角演出系统详细设计](上帝视角演出系统详细设计.md)，包括战斗演出、事实与展示时点、速度控制、素材缺口和验收。

## 地图尺度与布局

- 一个规则地块表现为一片大地区，由多个素材组成有层次的地貌；建筑与角色相对于地区要小，放大后才能看清人物。
- 用户提出地块内部展示 16×16。目前将其理解为每个规则格内的 16×16 视觉小格，沿用 16 像素素材时为 256×256 基础像素；这是当前解释，最终以视觉样板确认。
- 视觉小格不增加规则上的领土、资源、人口、路径或可独立操作单位。地貌跨视觉小格组合，相邻规则地块自然衔接。
- 山地格以山体为主，内部保留谷地、缓坡、空地，建筑错落安置在这些位置；不把建筑直接叠在山峰上。这不表示把规则地图的大多数地块改为山地。
- 未建市政厅时，以数量最多的建筑类型决定地区主题，例如农业、林业、采矿和生产区；不把每一栋真实建筑都直接堆到地图上。具体设施和数量仍可查详情。
- 一旦有市政厅，采用城市地形，并按实际建筑数量显示三级城市规模。以聚落布局、街区密度与覆盖面积体现发展；城堡在地区内部独立设计、选址。
- 军队采用 WorldBox 式迷你人物，同国同格按真实军队数量归并显示三级军团样式，以队形、密度与占地表达规模，人物比例保持一致。
- 野人在所属地块内部的可活动区域随机游走，避开山体和建筑。视觉游走不跨规则地块、不自行触发规则移动、交战或占领。

三级城市、三级军团的数量阈值、并列主导建筑的处理以及城市和专门设施的布局比例尚待样板确定。现成素材帧覆盖与缺口须同步核对，不以缩放一个图标代替三级设计。

## 观察节奏

用户要求回合显著放慢，尤其 Rule AI 必须提供速度挡位，让人能看到变化。

建议设置慢速、常速、快进、瞬时及单步；具体秒数尚未确定。默认给出可观察的行动与结果展示时间，不能让规则 AI 在一帧之间连续跳过数个回合。

- 需要可展示的逐国/逐动作事实与阶段更新，不能只在完整周期后换一次最终快照，再用空等待冒充行动演出。
- 下一段推进应顾及当前片段是否播完、用户选择的停留时间，以及暂停/聚焦请求；快进可以压缩或合并普通事件，重大变化仍须可定位、可回看。
- 当前规则存取仍按合法边界执行；界面要明确区分正在展示的时点、宿主最新时点与真正保存的回合。
- LLM 等待时不增加虚构回合；镜头、选择、环境待机与城镇活动保持响应。演出速度不增加模型请求或自动重试次数。

## 君主气泡

LLM 行动期间，从本国市政厅位置冒出气泡，让观察者看到君主正在想什么。

- 使用已有的君主思考/发言输出；未收到内容时显示等待状态，不编造“正在权衡”的具体理由。
- 气泡先显示短片段，点击查看完整内容；过长内容不遮住整个城市。流式展示只跟随实际收到的内容，不为气泡额外调用模型。
- 随镜头缩放控制密度：近看气泡，远看可辨认的活动提示；多国提示避免彼此遮挡。
- 失去市政厅、多座市政厅时的锚点选择需要另定，不能凭空画一座市政厅作锚点。

## 环境、设施与资源细节

用户明确要求地图持续有细微活动：树木摇晃、人流穿梭、驻军训练、石油设施的磕头机抽油。

| 对象 | 表现目标 | 数据与状态依据 |
| --- | --- | --- |
| 树木 | 轻摆、不同相位、疏密成片 | 地块木材资源丰度决定森林丰富程度，叠加固定的布局变化 |
| 聚落 | 小人在街巷、设施之间穿梭 | 装饰居民不宣称为真实可操作人口，不额外产生交易或生产 |
| 驻军 | 小范围训练、队列整理、休息 | 根据驻扎/交战等实际状态选择表现，训练待机不改变战力 |
| 石油设施 | 磕头机起伏，形成明确的机械节奏 | 区分建设、运行、停工；先核对素材是否具备此类机械和动画 |
| 金矿地块 | 地表岩石带裸露金色矿脉 | 依据地块黄金资源，丰度影响覆盖和显露程度 |
| 林地/耕地等 | 同类型地块有可辨认的贫富与自然变化 | 用地块资源、地形与固定布局种子驱动，不根据国家库存随意改变地貌 |

布局在刷新、缩放与续看时保持稳定；动画各有节奏，不能所有树木和机械同步摆动。远景保留植被、山势、聚落和军团的主要轮廓，近景再逐渐加入人物与设施动画；只精细更新可见地区，避免大地图所有装饰同时成为活跃对象。

## 下一次视觉样板

先在少量相邻大地块中核对比例和节奏，再铺完整地图：贫木/富木森林、带谷地的山地聚落、裸露金矿、石油设施、三级城市和三级军团，以及市政厅气泡和速度挡位。样板应同时展示远景与近景，检查人物是否足够小、地貌是否连续、设施是否合理落位，以及慢速时是否看得见变化。
