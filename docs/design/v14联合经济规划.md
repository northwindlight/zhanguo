# v14：联合经济规划模型

用户2026-10-29明确纠正：不要继续对逐项评分补局部优先级，采用运筹学联合规划。此前v14原型仍是顺序策略，未提交发布，不能作为本设计的实现或最终验收。

## 目标与范围

v14以可选候选合并，综合验证通过后再切默认。每次国家行动，在同一个有限时域混合整数规划中决定各格建设、交易、原料／燃料库存、生产、电网、征募与军需资金，执行本期方案后按正式回执滚动重算。默认显式时域4期、各层8个节点／5秒、经济层2%相对间隙。采用SciPy的`milp`（HiGHS），不是另写一个评分表冒充求解器。未来价格与军事需求属于策略输入；不声称找到完整博弈、无限时域或真实未来的全局最优。

未来买卖价格使用现价与公开净流量预测的保守区间；预测涨价不作为确定的融资收益。目标包含期末现金、按整单深度计算的库存可变现价值和可持续产能的延续价值；已有军需／供电损失作为优先目标；本期服务优先于所有未来预测短缺，权重取未来全部短缺的可证上界加一，不允许为减轻远期预测损失主动牺牲本期。军队扩张需求保存绝对期限；军费沿用30%上限，但以模型实际可运行净产出、增长后的总军需为准。成本、设施、供电和补给与经济一起核算，不能先无条件征兵再让建设承受剩余预算。必要周转量受统一预算约束；不以囤钱或花光钱本身为绩效。

## 主要变量与约束

| 部分 | 变量与耦合 |
| --- | --- |
| 建设 | `x[s,k,t]`为格s在期t开工类型k的0/1变量；每格每期至多一次，读取本期剩余额度、建筑位、共享资源位、同类／全国限额及前置建筑数。落成后下一期才生产 |
| 工程院 | 工程院在期t是否已落成；与后续开工变量的乘积用标准0/1线性化，选用正式领域给出的当前报价／工程院后报价，不在策略层复制取整公式 |
| 买卖 | 每资源每期的买入量、卖出量和方向0/1变量。买卖互斥；当前市场可买库存为硬约束，不能把不存在的货当作流动资金 |
| 交易成本 | 本期用正式账户整单试算构造分段线性成本／收入，买价弦线向上、卖价弦线向下估计并计金币尾差边界；执行前再按正式整单报价验资。未来价格是公开观察的场景预测 |
| 库存与现金 | 逐期、逐生产阶段守恒，采购、建设和征募都发生在本期生产之前，不能提前花掉尚未收到的产金；各阶段实物非负。预付队列已扣款／预占位置不再重复支用 |
| 自动生产 | 按原采集→发电→工业→厅金的顺序。相同格／同类型可聚合；多种工厂共享原料时保持正式顺序。生产量为设施数与可用完整配方的最小值，不能虚构玩家能逐厂关闭 |
| 电网 | 发电取决于实际可用燃料；供电不足时全部耗电建筑停摆，使用一个全网0/1状态及对应线性约束；新电厂本期不供电。初始无电厂导致的首期停产保留 |
| 军需 | 已有军队和计划新兵的补给、恢复资源进入库存流；不可避免的短缺显式记录，不能让求解器通过假定部队不吃补给提高收益 |
| 贡赋／其他义务 | 使用绑定玩家可读的贡赋比例和累计小数，扣取时点与资源流一致；不读他国私有未来产出补充来贡。已知债务／到期支付进入现金约束 |

当前行动使用正式规划做最后校验，未来状态用公开规则的数学模型表达。目录新增生产阶段、规划新增只读的工程院后价格，均由领域原函数派生，不改变世界规则、结算顺序或存档字段。待建项目不可被新计划取消或覆盖；不确定的自动开工／外国变化只能保守预测并在下次行动重算。

## 求解与执行

- 明确记录时域、价格假设、变量／约束数量、求解状态、原始目标、最优界、间隙和节点数；只有已证明最优才标最优。触及上限仅执行通过独立可行性检查的整数解，不悄悄退回旧评分策略。
- 只执行第一期。统一按交易、建设／征募及领域允许的顺序提交，逐次处理真实回执；意外回执失败时停止剩余提交，下次行动重新规划，不重复支付，不为模型预期修改引擎结果。
- 将经济职责与军事需求输入分离，为后续真人托管提供复用入口；当前不实现真人托管界面或联机。

## 验收

小规模可枚举实例核对联合最优解：两个项目共同受资金／木材／燃料约束、共享原料、前置电厂、工程院跨期折扣、买卖与库存联动。核对模型生产量与独立正式结算一致，包括缺料、电网、贡赋和施工时点。验证限制求解时不冒称最优、无可行解时不提交损坏方案、旧策略存档仍按原版本继续。

之后再做相同种子固定土地、完整战斗和混合策略市场对照。同时报告固定价格实际净产出、军需、产能／现金与失败，保留此前顺序原型数据为被替代基线，不将其39%的样本提升当成联合规划的效果。

求解器接口与状态含义见[SciPy 1.15.3官方MILP文档](https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.optimize.milp.html)。
