# 山河与人间 · 新素材第一批

2026-10-24。原生桌面 GUI 的独立素材制作批次，暂未接入游戏。

[交互预览](index.html) · [组合场景](scene-2x.png) · [完整图录](catalog.png) · [动作 GIF](motion.gif)

![第一批素材](overview.png)

用户确认的方向：地形按视觉格子组成、存在明确高度层级与岩壁；普通建筑约 2×2 小格；
居民和军队统一人物比例；用原创 SVG 组件拼装，并让树干固定、叶簇运动。

第一批交付 107 个素材条目，包括 32 个山体连接块、3 个岩壁部件、16 个岸线连接块、
地表与三档水面、12 种建筑/施工素材、树木与资源，以及 6 类人物四方向动作图集。
清单与完整规格见[素材说明](../../../mods/ui/desktop/assets/unified-v1/README.md)。

`scene.svg` 和 `scene.png` 使用同一组导出的素材拼接，展示 1:1 的人物/建筑关系；
`scene-2x.png` 仅为最近邻放大。场景为合成美术样板，不是运行中的游戏截图。
`index.html` 是本地预览文件，所有图片从本目录加载。

本批没有修改游戏渲染接线、地图规则、对局存档或模型调用。尚需后续覆盖更多建筑等级、
环境变体、野人、受击/阵亡与特效，并在游戏窗口中验证缩放、遮挡和性能。
