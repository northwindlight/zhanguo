## 已落地的边界

| 问题 | 实现与行为 |
|---|---|
| 野地驻军查询崩溃 | 玩家事实通过 `owned_by` 查询土地归属；未物化地块返回 `None`。查询不创建地块，不使驻军占地。决策总览与工具查询共用此事实。 |
| 工具与直接调动的阶段裁决不同 | `World.move` 进入规则前调用既有 `runtime.require_tool(..., 'move')`。工具入口（含移动别名）与直接调用共用行动者、政体、作用域、阶段校验。非行动阶段均抛出同一类错误，部队状态不变。坐标仍由工具将 1-based 转成领域 0-based。 |
| 调动后查询版本不更新 | 一次 move 改变位置或行动额度时，`state_version` 增加一次；成功原地调动消耗额度也算变化。失败若因迷雾撞墙消耗额度则增加；无位置/额度变化则不增加。工具与直接调用都在军事回执包装中完成更新。 |
| 多字段行为留下部分修改 | `Unit.update` 先构造并校验候选记录，再一次提交字段；`move_to` 使用该路径。非法回合、未知字段、不可改的身份或位置错误都不改坐标、额度、显式字段顺序与守卫索引。创建前先检查参数及序号容量，失败不消耗编号。 |
| 存档身份错配可被加载 | 国家码唯一；野人码必须是 0，其他码必须为正；现存部队拥有编码，`gid = 国家码 × ARMY_GID_BASE + 番号`；番号在编码区间内，计数器不落后、不溢出，计数器的国家有编码。世界加载还核对部队所属国家存在。损坏数据明确拒载，失败 restore 不替换现场对象。已移除部队的计数器保留，续建不复用番号。 |

番号区间检查封住编码区间溢出；没有增加兵种、改变移动力、通行、战斗或占领规则。亡国后保留的编码和计数器允许继续存在，不要求它们全部对应现存国家。

## 状态版本的实际契约与限制

当前 `state_version` 是已接入操作的失效序号，表示客户端应重查当前事实；它不是事件条数，也不是所有世界字段的全局修订号。既有更新来源是开回合、外交提交、外交结果和正式投票；本批增加 move 的实际位置/额度变化。只读查询不增加版本，存读档保留版本。

征兵、进攻、撤退、市场、内政及直接修改内部字段尚未全部接入版本更新，不能凭版本相同推断全部面板未变。本批只验证 move 的完整路径。阶段 B 需逐动作迁移并完成统一的失效契约；不在这里加全世界深拷贝比较或通用事务框架来掩盖未迁移入口。

`require_tool` 的复用仅覆盖 move。其余动作入口、初始化权限、结构化结果与客户端迁移清单仍在阶段 B。
