# 用百点 GDP 国家快照训练市场大亨

大亨是第五个决策者。四个国家共用一份已经能稳定经营的冻结策略，各自保有独立观测、历史、动作随机流和国库。另起一个小模型经营六种商品，只有大亨的参数参与市场 PPO。大亨改价以后，四国每次都按实际可见的新报价重新决策。训练所需的价格反馈来自这些交互。旧市场的成交数据可以帮助预测流量。[市场成交及经济约束](商品市场重写计划-20261128.md)

## 哪一份国家权重算过百

每局先对四席**第 100 回合名义 GDP**取均值，每张地图各有一票。候选条件是训练端最近 16 局的均值严格超过 100。当前训练每批先采样、后更新，所以若第 N 局报告触发，固定的是采这批时的父检查点，当前每批四局时为 N−4。按原训练谱系和 SHA-256 核对，并在备份轮换前单独保留。

同一份候选权重在原市场打 32 张未参与国家 PPO 的 24×24 地图。四席自对弈，100 回合，保留原采样策略和思考预算。将地图预先分为不重叠的两组各 16 张，两组均值都严格超过 100 才合格。种子按候选批号分配；每组首动国平衡。失败记录逐席结果，至少再积累 16 个训练世界才选下一候选。这是本次给“稳定”设的操作口径。阈值只用来选国家快照，大亨的盈利能力另行评估。

Pi 的监视器只读国家 PPO 备份。候选出现时固化权重，调度双卡分组复评，复评每两局落盘以便断线续跑。通过时输出 `qualified.json`，记录权重摘要、规则与评估源码指纹、32 组席位结果。市场训练从该清单解析国家权重；市场训练器与新市场引擎的联调属于下文的实施阶段。[选取与复评程序](../research/commodity-dealer/country_gate.py) · [冻结权重评估](../research/commodity-dealer/country_holdout.py)

## 大亨模型

**原型实数为 202,016 个可训练参数。** 每个交易窗口开盘前执行一次前向，100 回合、每回合两窗，共 200 次报价。仓库、成本、信用和成交回执以引擎账本为准。[PyTorch 模型与订单生成](../research/commodity-dealer/dealer_policy.py)

| 部分 | 设计 |
| --- | --- |
| 输入 | 12 个全局量描述回合、窗口、现金、剩余信用、负债、融资成本、盈利与风险。每种商品 22 个量覆盖公开价及新鲜度、存货及库龄、取得成本、本商人的买卖量、上窗封窗后可见的未成交汇总、买卖方数、上下游成本和预测置信度。数量按商品深度、价格按基价、金额按初始资本缩放；缺历史用统一开局值和置信度表示。 |
| 六商品之间 | 每种商品一个 96 维向量，共享编码权重，另加商品身份。一层四头自注意力允许油价和装备销路相互影响。均值汇总加全局账本，输入 128 维 GRU。每个世界独立持有隐藏状态，跨窗口延续，新局清零。 |
| 策略动作 | 全市场先选可用资金的 0%、25%、50% 或 100%。每种商品选参考价倍数、价差、档距、采购资金权重、可售库存比例。确定性地生成三档买、三档卖。采购档预留的最坏整币支出合计不超过获批资金；各卖档合计不超实物库存。价格刻度、预留、清算、成交优先级均由引擎执行。 |
| 训练头 | 一个整窗价值头；每种商品另预测未来 1、3、10 窗的实际买卖数量。辅助预测共享表示，未来标签只在训练时使用。当窗私单、他国隐藏国库、地图真值和未来事件均不能进入报价观测。 |
| PPO 回放 | 一份整窗报价是一个联合动作。保存抽样前的公开观测、历史前缀、总资金动作、六组原始动作、行为 logp、动作前价值以及订单与回执。用原始离散动作重算联合 logp；取整后相同的订单可能来自不同指令。按连续窗口回放 GRU，用整窗概率比裁剪并监控联合 KL。 |

用小模型是因为开盘只要看六种商品和一本总账。当前原型已经在 CPU 核对采样与回放的 logp、有限梯度，以及零现金、低库存、极低价格刻度下的订单边界；这项验证没有使用国家模型进行市场训练。[原型检查](../research/commodity-dealer/verify_dealer.py)

## 国家快照怎样进入新市场

旧国家策略会选“买木 20”“卖粮 5”，没有学过限价单、冻结货款或封窗。适配层必须保持原权重输入维度、候选动作编号和每个国家回合总共 60 次的预算。买卖动作按国家此刻看到的整单报价转换成有明确限价的订单，只能占用可支配资金和实物。提交后只显示真实可用余额；成交后再让国家看见实际到账的货和钱。没有学过的新指令不应由冻结国家网络凭空生成。

当国家在有待清算单时选择结束，适配层提交该窗。成交后的剩余决策机会由同一国家策略使用；新窗口沿用本回合剩余动作预算与记忆，随后才进入原世界的回合结算。无后续动作的国家可跳过窗口。用实际轨迹检查重复挂单耗尽预算、账上尚未到账就建厂、同一回合重复开启思考等偏差。

市场训练前先用**同一快照、同一新引擎、同一批地图**跑固定档大亨，验收卖矿换油、购木开工与真实交割，再把固定档替换成可学习的大亨。旧市场百点属于国家的入场资格；新市场对国家经济的影响用同版本固定档基线衡量。Python main 实验规则和 C++ 逐单校验通过后才能生成正式训练轨迹。

## 经营奖励和经济底线

- **利润按货卖给真实国家时确认。** 每窗奖励取已售货收入减已售货取得成本，再扣实际融资费、保管费和库存减值的净增加。初始仓库有取得成本。期末给滞销货做保守清算减值，按有资金、有数量的外部买盘估算残值，并限制自身循环成交的影响。自报高价和新增授信均不能创造利润，同一笔费用只扣一次。
- **考察能否周转，同时约束拒绝经营。** 分商品记录实际售出率、持货时间、滞销损失和坏局现金回撤。按根种子匹配固定档基线，约束必需品交付、断电、军需断供、出售盈余后的购买力以及固定价实际 GDP。补做有真实预算和实际用途的标准购货测试，以免大亨用劝退买家的报价抬高表面履约率。名义 GDP 用来观察市场；直接按名义 GDP 奖励大亨会给抬价带来好处。
- **按市场决策时间分配信用。** 一个窗口一个价值，回报累积到这批木材后来售出或减值。有限局先取折扣 1，用整条 200 窗轨迹估计优势，并同时看积压时长与盈亏发生的间隔。冻结四国的推理关闭梯度；大亨拥有独立优化器和随机流。

## 训练次序和放行条件

1. 拿到合格国家快照后，从旧市场已有记录为流量头提供初值。新引擎里对公开报价做整窗、可复现的扰动，允许四国真实改买量；记录被拒、未填、成交和库存。按世界拆训练、验证和最终留出集。可用固定档策略初始化报价头，比较其与随机初始化的稳定性。
2. 固定国家权重，对大亨做 PPO；每次更新使用其上一快照在完整游戏里刚采到的订单轨迹。与固定档大亨同图轮换席位，报告利润、风险及经济底线。基线阈值与配对统计沿用市场计划，状态版本、国家 SHA 和大亨 SHA 均写入轨迹。
3. 在没参与报价训练的地图和需求场景上测试集中抛售、真实燃料短缺，以及晚一窗入场。再用历史国家快照、规则国家或改变一席采购习惯测试泛化，防止大亨只会对付同一个开局。合格后才讨论让国家也适应新市场，避免两边同时更新导致无法判断收益来源。
