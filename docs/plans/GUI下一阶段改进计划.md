# GUI 下一阶段改进计划

记录日期：2026-10-26。来源：v0.5.1 发布后用户与朋友的试玩反馈。
状态：**需求已记录，以下项目均待实施与验收**；本次只整理计划，不修改运行代码或发布新版本。
后续 GUI 工作优先依据本计划；[第一阶段记录](GUI第一阶段.md)与[原详细设计](../design/上帝视角演出系统详细设计.md)保留历史，冲突处以本次反馈为准。

目标：缩短重复结算演出，让人看清一国怎样经营、交易和交战，同时提高地图与文字的辨识度。

## 1. 采集、生产和补给按国家汇总演出

- 回合末的采集、生产和补给不再逐个格子、逐个建筑或逐支军队轮播；按国家归并，每国每期一组汇总。
- 镜头移动到该国市政厅，在同一处集中显示一次收入、生产用料和军队补给消耗。多种资源合成同一张清单，绿色 `+x`、红色 `-x`，避免满地图飘字和反复切镜头。
- 汇总必须来自该期实际结算事实，保留收入与消耗明细，不能只报相抵后的净数，也不能把库存变化全部当成生产。缺料、停产或补给不足须能辨认。
- 一国有多座市政厅时，选定稳定的展示锚点，不逐城重复播全国总账；市政厅失守或该国亡国时使用明确的替代锚点，不聚焦空坐标。
- 战争继续按实际战场逐场演出。全国账目汇总只改变展示方式，不改变生产、补给、战斗和归属的规则结算顺序。

验收：同一国家有多处矿场、工厂和驻军时，镜头只为这组收支聚焦一次；逐项加总与原始事实一致，没有漏账或重复播报。

## 2. 左上角显示当前国家的资源与收支

- 为各国提供同一套单国面板，左上角同一时刻显示当前行动或结算聚焦的国家；切换国家自动切换内容，不把全体国家的大表常驻屏幕。
- 显示国名、国色、回合、当前各项资源库存，以及该国的收支变化；绿色 `+x`、红色 `-x`，同时保留正负号。
- 主面板沿用 CLI 看海的资源顺序与已结算流量口径：上一完整期的生产、军队消耗和贡赋转移净变化。明确标注对应期数，不把上一期实际值写成本期预测。
- 交易和赠礼不混入这条 CLI 净变化；交易实际付款、收款在集市演出中单列。结算汇总中的收入和消耗明细使用同一批事实。
- 参考行式为“粮食：库存 120，上期 +18”；具体数值仅作排版示例。字体、列宽、留白与新字体一起调整，不遮住主要地图目标或压住其他浮层。

验收：行动换国和结算切国时，国名、库存、期数和红绿变化同步切换；同一快照与 CLI 单国数据可逐项对账。

## 3. 道路重新设计

- 以真实建筑入口、市政厅广场和集市为起终点，形成可理解的主路、支路网络；移除无目的的随机线段和随意穿插。
- 道路沿合法地表绕开岩壁、高山、海洋、建筑本体与重要资源标识；相邻地区的道路连接一致，避免突然断头和错位。
- 转角、路宽、交叉口和贴图遵循统一像素尺度；镜头缩放或普通回合刷新时不随机重排。
- 本阶段道路是地图呈现，不新增道路建设规则、移动加成或穿越不可通行地形的能力。

验收：近景能看出道路通向哪里；密集生产区仍可辨认建筑和资源；远中近景及相邻地块连接有同种子对照。

## 4. 市政厅周围减负，增加集市作为交易舞台

- 删除市政厅旁自动生成的成片装饰房屋和零散假建筑，让真正的采集建筑、工厂等生产设施容易看清。这里删除的是视觉装饰，不删除对局中的真实建筑。
- 市政厅继续保持体量与高度辨识度，周围保留清楚、简洁的广场和必要道路。
- 市政厅旁集中放置一个容易辨认的集市，取代散乱摊位；集市是交易演出的视觉地点，不新增必须建市场才能交易的规则门槛。
- 买卖在该国集市演出：显示买入或卖出的资源、数量及实际金币支付或收入；同批可合并同类交易，失败交易明确显示失败，不伪造货物到账。
- 交易仍随对应调用批次播放，不推迟到回合末；多市政厅国家使用稳定锚点，避免重复播报同一笔成交。

验收：真实生产建筑数量与快照相符，装饰房屋不再冒充生产设施；实际成交可在集市看懂并与回执金额一致。

## 5. 缺失素材自行用 SVG 补绘

- 缺少的道路拼块、集市、资源图标、战争箭头、信件和其他 UI 素材，由后续实现时自行补绘 SVG，不再等待外部素材齐全。
- 保存可编辑 SVG 源文件，遵循现有世界的像素网格、比例和配色，保证导入后与人物、建筑和地貌协调。
- 若需要栅格化，记录导出尺寸与映射，保持 SVG 为母版；登记素材用途与来源，检查透明边缘、锚点和缩放清晰度。

验收：新增素材有源文件、明确用途和导入尺寸，在实际窗口中没有白底、错位或风格突变。

## 6. 修复放大后飞鸟消失

- 将“飞鸟随镜头放大突然消失”列为显示缺陷修复。当前 `WorldMap.Actors.cs` 的 `DrawBirds()` 在 `_scale > .9f` 时直接返回，不能继续用这个阈值硬隐藏。
- 同一鸟群在远景、过渡缩放和近景中保持位置与飞行连续性；调整尺寸、遮挡和可见范围时不突然跳变。

验收：连续放大、缩小并跨过原阈值，鸟群不凭空消失或重置；位于视口外时正常裁切。

## 7. 战争显示进攻方向箭头

- 从攻击部队或进攻出发地指向目标战场，使用有明确箭头的方向线，配合进攻方国色与双方国名。
- 箭头随对应进攻和战斗演出出现，支持多支部队与多个战场，避免整屏无差别拉线；该场结束后清理，下一场显示自己的方向。
- 方向和目标来自真实行动及战斗事实；不能画成反向、指向无关地块，或表示不存在的攻击。

验收：相邻、远距离及多国交战的演出都能一眼辨认“谁从哪里打向哪里”，与实际攻守方一致。

## 8. 同国军队统一穿国色服装

- 同一国家的全部军队，无论剑、矛、斧外观混编或骑兵，服装都使用该国颜色；不同国家能靠衣服区分，而非只靠旗帜或脚圈。
- 保留已接受的混编外观，兵种规则不增加；肤色、金属、武器和马匹保留自身材质颜色，避免整张图染色。
- 待机、行军、攻击等各方向和动画帧均使用一致的国色映射，并与国家面板和战争箭头对应。

验收：至少两国并排的近景、行军与交锋截图中，士兵服装归属清楚，换帧不跳色，HP 和步骑数量仍来自真实部队。

## 9. 写信在回合末播放传递动画

- 行动时展示“写信／已寄出待送达”；回合末实际投递时，再播放从发信国到收信国的信件传递动画。
- 使用市政厅等稳定锚点，显示发信国、收信国和送达状态；可用信封或信使沿路线移动，缺少的素材按 SVG 补绘。
- 动画跟随真正的通信投递事实，失败或未送达不能演成已收到；不提前展示尚未送达的正文，不改变通信生效时机。

验收：单信、多国互寄、失效收件方分别有正确表现；同一封信不重复送达，暂停恢复不漏播或重复播。

## 10. 开始游戏时允许选择剧本

- 在“开始游戏／新建对局”流程中提供剧本选择，显示剧本名称、简介、参与国家和特殊规则，再进入该局的玩家与参数配置。
- 选择项来自当前已提供的剧本，先接现有正式八国剧本及实际可用的其他开局方式，不虚列尚不存在的剧本。
- 所选剧本确实控制地图初始化、国家落位、初始外交和胜利条件；不能只换菜单名称，仍固定创建原默认局。发行版与剧本分别表达。
- 切换剧本后同步默认参数与校验结果；继续存档显示存档原剧本，不将其套用成另一个新局。

验收：从菜单选择不同可用开局，核对生成的世界及剧本钩子；Windows 便携包内无须手改配置即可操作。

## 11. 更换更容易读的中文像素字体

朋友反馈现有字体难读；下一轮以实际界面可读性为验收标准。现主题使用 Fusion Pixel 12px 字形，默认字号 18；先对比更大点阵的字形，并检查字号、缩放、行距与对比度，不能只替换字体文件。

2026-10-26 已查阅作者说明，先列以下候选；**尚未导入、截图比较或确定最终选型**：

| 候选 | 已核实的作者说明 | 后续比较重点 |
| --- | --- | --- |
| [寒蝉点阵体 16px](https://github.com/Warren2060/ChillBitmap) | 提供基于 Unifont 调整的 16px 字形；作者说明列出本体 OFL 与上游许可信息 | 常用与复杂汉字、数字和标点；正式引入时核对所选文件与完整许可 |
| [Z 工坊像素圆体 16px](https://github.com/Astro-2539/ZLabs-RoundPix-16px) | 16px 规格，支持 GB/T 2312 全部汉字；字型 OFL-1.1，仍在开发调整 | 圆体在账目和长正文中的辨识度、未覆盖字的回退与混排一致性 |
| [现有 Fusion Pixel 12px](https://github.com/TakWolf/fusion-pixel-font) | 作者提供 8／10／12px 字形 | 作为现状对照，比较匹配点阵的显示尺寸与当前 18px 显示，判断渲染设置的影响 |

验收：用同一份真实界面文字对比国家收支、工具回执、长篇模型正文、按钮和战斗标签，覆盖复杂汉字、正负号、小数及中英文混排。Windows 至少检查 1280×720、1920×1080 和 100%／125%／150% 系统缩放；字清楚、框不截字、行不重叠，并提供字号调整。候选最终是否更易读，以这些截图和试玩反馈定案。

## 分批顺序与共同验收

沿用原先两周至一个月分批推进的节奏，先记录顺序，不把本计划视为已启动的后台开发排期。

| 批次 | 内容 | 交付依据 |
| --- | --- | --- |
| 第一批 | 单国结算汇总、左上角单国收支面板；字体对比 | 原始结算事实对账、切国录像、字体同屏比较 |
| 第二批 | 市政厅周边减负、集市与交易演出、道路重做；补所需 SVG | 同种子前后远中近景、真实建筑清单与成交回执 |
| 第三批 | 飞鸟缺陷、战争箭头、同国服装、回合末信件 | 缩放连续录像、多国战斗与多信件送达片段 |
| 第四批 | 剧本选择、界面整体验收与 Windows 便携包复核 | 各可用剧本开局核对、实际窗口截图和完整观看短片 |

每批完成后再勾选对应需求，不以素材存在或编译通过代替演出接线验收。保留 v0.5.1 已确定的时序：每次模型响应中的工具全部执行后统一播放本批，播完再继续调用；行军随调用，战争仍在结算阶段。Esc 自动暂停、完整回合保存边界、LLM 行动始终 1×、规则 AI 与结算可调速继续回归检查。
