# 战国 Mod 开发文档

战国是回合制大战略游戏。每个国家由一个玩家控制，可以是大模型、规则 AI，也可以是坐在桌面版前的一位真人。所有玩家都通过同一套工具和同一套规则行动。

本站讲的是**怎么给战国加东西**：一种资源、一个兵种、一条结算规则，或者一整套新玩法。本站是 Mod 开发文档的唯一来源；仓库里的 `docs/Mod开发指南.md` 只是指向这里的入口。

## 三句话读懂架构

| 说法 | 含义 |
| --- | --- |
| 引擎不认游戏 | `engine/` 只管机制：依赖解析、状态所有权、能力调用裁决、工具通道、结算调度、存档核对 |
| 模块只做一件事 | 一个模块管一个领域：它独占的状态、它对外的能力、它的结算阶段、它的规则正文 |
| 发行版定义游戏 | 发行版是一份清单：装哪些模块、结算挂点怎么排、玩家看到哪些工具、谁来替玩家行动 |

依赖方向是单向的：**引擎 ← 模块 ← 发行版**。模块之间不互相 import，只通过声明过的能力调用对方。

## 三十秒版

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python mods/examples/tour.py                    # 离线跑一遍全部配方
.venv/bin/python -m unittest tests.test_example_mods -v   # 示例 Mod 的回归
```

想直接看一套完整的小游戏：`mods/examples/minigame` 是从零写的九模块规则，离线就能跑完整局，不需要 API key。
