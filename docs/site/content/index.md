# 战国 Mod 开发文档

战国是一个**为 AI 而生**的回合制大战略游戏：每个国家一个模型 agent，模型通过工具同规则玩，人类只当观海者。

这个站点讲的是**怎么给战国加东西**：加一种资源、一个兵种、一条结算规则、一整套新玩法。

## 三句话读懂架构

| 说法 | 含义 |
| --- | --- |
| 发行版定义游戏 | 一个「发行版」是一张清单：装哪些模块、挂点按什么顺序、给模型看哪些工具 |
| 模块只做一件事 | 一个模块管一个领域：它拥有的状态、它的工具、它的结算阶段、它的规则正文 |
| 引擎不认游戏 | 引擎只管机制：依赖解析、状态所有权、能力裁决、工具通道、存档 |

依赖方向单一：**引擎 ← 模块 ← 发行版**。模块之间不互相导入，只通过声明的能力对话。

## 三十秒版

```bash
# 装依赖（Python 3.13）
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# 跑离线回归：全仓库的验收测试
.venv/bin/python -m unittest discover -s tests

# 跑一遍所有示例 Mod
.venv/bin/python mods/examples/tour.py
```

想直接看一个完整的小游戏：`mods/examples/minigame` 是从零写的一套九模块规则，离线可跑完整局。
