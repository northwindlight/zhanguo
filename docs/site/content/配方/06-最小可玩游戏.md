# 最小可玩游戏

做最小局有两条路：**从零写一套小规则**，或者**在 native 上做减法**。前者规模可控、一眼能看完，适合作为起点；后者受既有模块的声明约束，能减掉的不多。

## 从零写：minigame

`mods/examples/minigame/` 是完整可玩的游戏，九个模块的规则都在 `game.py` 一份文件里：

| 内容 | 规模 |
| --- | --- |
| 资源 | 3 种：钱、粮、木 |
| 地形 | 1 种：平原 |
| 建筑 | 5 种：市政厅、林场、农场、金矿、兵营 |
| 兵种 | 1 种：步兵 |
| 外交 | 宣战、议和 |
| 规则 | 建筑每期产出；兵营所在格可征兵；向交战国的相邻格进攻，无守军即占领；失去全部市政厅即亡国 |

```
mini:resources   账户与原子兑换       mini:territory    地块归属
mini:buildings   五类建筑与产出       mini:army         部队、征兵、移动、进攻
mini:nations     身份与存亡           mini:diplomacy    交战关系
mini:government  回合推进             mini:succession   亡国判定
mini:intelligence  事件与可见性
```

入口是 `mods.minigame.toml`。发行版声明了 `mini` 客户端工厂，用自带的简易策略驱动，离线、不需要 API key 就能跑完整局：

```bash
.venv/bin/python -c "from host import GameHost; h=GameHost.new({'mods':'mods.minigame.toml','map_size':12,'seed':3,'nations':[{'name':'甲','client':'mini'}]}); h.cycle(); print(h.clock())"
```

开局规则归发行版所有：`[Distribution.Session] Entry` 指向 `MiniSession`，由它投放 `mini:gold`、`mini:food`、`mini:wood`、`mini:plain` 和 `mini:town-hall`，并定义落位、登场与管理 API。宿主不要求固定的领域对象名或 native 内容 ID，mini 也不需要占位市场。

## 做减法：playable_min

`mods/examples/playable_min/mod.toml` 从 native 的成员里去掉与核心链无关的 `polities/huns`、`bank`、`economy_queries`、`query`、`manuals`、表现层 `ui` 和剧本，剩下 15 个模块仍能开局、行动、结算、存档：

```bash
.venv/bin/python -c "
from engine.runtime import Runtime
runtime = Runtime.load('mods.playable.toml')
print(len(runtime.order), runtime.order)"
```

剩下的不能再减，原因有两类。一是 native 会话（`mods/native/session.py`）直接调用 territory、government、nations、buildings、succession、market、intelligence 的接口。二是模块之间的声明依赖，删掉一个会连带报错，例如：

| 去掉 | 报错 |
| --- | --- |
| `resources` | `state 无主：resources` |
| `buildings` | `native:economy 缺少依赖 native:buildings` |
| `market_pricing` | `native:market 所需能力无提供者：market:pricing` |
| `economy_reports` | `native:government.advance 挂点条件无人提供：economy.reported` |
| `map_generation` | `native:territory 缺少依赖 native:map-generation` |
| `succession` | `native:army.repatriate 挂点条件无人提供：actors.eliminated` |

要压得更小，只能**替换**声明链上的模块（参见[替换已有内容](配方/04-替换内容.html)），或者自己提供会话需要的那些接口。去掉模块后，`PlayerState` 也要同步删掉不再存在的工具，否则报 `玩家状态必须声明唯一的只读工具`。

规则 AI 客户端会读 `econ`、`market` 两项事实和若干报价工具，它们属于 `economy_queries`；要接规则 AI，就得把这个模块加回来。`playable_min` 用的是最小客户端，所以不需要。
