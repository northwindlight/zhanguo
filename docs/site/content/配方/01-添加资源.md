# 添加一种资源

示例：`mods/examples/tea/`（模块）与 `mods/examples/tea_dist/`（发行版）。`mods/examples/tour.py` 的「配方四」会离线跑一遍。

## 1. 注册资源

资源用**类**注册：继承 `Resource`，给出命名空间 ID 和展示名键，再从 `content_definitions()` 返回。

```python
from engine.resource import Resource
from engine.runtime import GameMod


class Tea(Resource):
    TYPE_ID = 'example:tea'
    NAME_KEY = 'resource.example:tea.name'


class TeaMod(GameMod):
    def mixins(self):
        return ()

    def content_definitions(self):
        return {Tea.TYPE_ID: Tea}
```

资源域会枚举内容表里所有 `Resource` 子类，自动为它建立账户、库存、只读接口和存档，`mods/native/resources/` 不用改。`NAME_KEY` 只是展示名的键，模块要另外提供对应语言的文案；资源注册不会自动装载本地化文件。`TRADEABLE = False` 的资源不能上市，账户和存档不受影响。

资源可以声明**角色**（`ROLES`）：`currency`（货币）、`supply`（补给）、`construction`（建材）。跨模块规则按角色取 ID（`native:resource-inspection` 的 `role_ids`、`currency`），不写死内容 ID，所以换一种货币只改资源模块。角色名必须小写，同一资源内不得重复。

## 2. 让它上市

**注册不等于上市。** 商品清单由市场模块自己的 `[[Listings]]` 决定，引擎不会合并别处的商品。要让新资源能买卖，就在发行版里换掉市场模块：

```toml
# mods/examples/tea/market.toml
Currency = "native:gold"

[[Listings]]
Resource = "example:tea"
BasePrice = 3
Depth = 10

[Mod]
Id = "native:market"          # 保持原 Id：别的模块在 Requires 里按 Id 引用它
Version = "1.1.0-tea"
Entry = "mods.examples.tea.market:TeaMarketMod"
```

```python
from mods.native.market.mod import MarketMod

class TeaMarketMod(MarketMod):
    """行为不变，只是多上市一种商品。"""
```

（真实文件里还列着 native 原有的全部商品，这里只写出新增的那一条。）

未上市的资源在结算时被忽略，但报价、买入、卖出会返回 `Resource is not listed: <id>`。声明了没注册的资源，则在世界初始化时报 `Market resource is not registered`。

## 3. 装进发行版

在 native 的成员表上改两处：把 `../../native/market/mod.toml` 换成 `../tea/market.toml`，再追加 `../tea/mod.toml`。完整清单见 `mods/examples/tea_dist/mod.toml`，写法说明见[制作发行版](开发流程/07-制作发行版.html)。

加了新内容，依赖清单就变了，旧档会被拒绝，这是预期行为。
