# 插入一个结算阶段

示例：`mods/examples/harvest/`，每个行动期在「秋收」挂点给存活国家发粮。

## 1. 发行版加挂点（已有合适的挂点就跳过）

结算骨架由**发行版**声明，模块只往上挂。在清单**顶层**（不是 `[Distribution]` 段里）加一条：

```toml
[[Hooks]]
Id = "example.harvest"
Name = "秋收"
```

挂点按声明顺序执行。`Id` 只能用 `[a-zA-Z0-9_.:-]`，全局唯一。

## 2. 模块声明阶段

```python
def stages(self):
    return (Stage('example:harvest.reap', self._reap,
                  hook='example.harvest', provides=('harvest.reaped',)),)
```

| 字段 | 含义 |
| --- | --- |
| `name` | 阶段 ID，全局唯一 |
| `handler` | 可调用对象，或世界上由某个 mixin 提供的方法名 |
| `hook` | 发行版挂点 ID；单模块运行、没有发行版时可以省略 |
| `needs` | 本阶段消费的条件；必须由同一或更早挂点上的阶段 `provides`，同一挂点内据此排序 |
| `provides` | 本阶段发布的条件，全局唯一 |
| `requires` | 必须存在的阶段 ID（只检查存在，不发布条件） |
| `after`／`before` | 相对其他阶段的顺序 |
| `scope` | `'world'`（缺省，收 `(world, context)`）或 `'actor'`（对每个行动者收 `(world, actor, context)`） |
| `title`／`description` | 结算顺序表里的显示文字 |

全部阶段共享一个 `context` 字典，这是阶段之间传数据的唯一途径，**处理函数的返回值会被忽略**。发行版的会话可以从 `context` 里取结果（`result` 键，没有则取整个 `context`）。

## 3. 跨域写入走对象接口

```python
actors = world.runtime.object_call(world, 'native:nation-inspection', 'ids')
world.runtime.object_call(world, 'native:resource-exchange', 'exchange_batch', operations)
```

两个能力都要写进 `[Capabilities] Needs`，方法都要列进 `[Interfaces]`，见[跨模块协作](开发流程/05-跨模块协作.html)。

## 4. 核对顺序

```python
runtime = Runtime.load('<你的发行版入口>')
print(runtime.stage_order)
```

规则正文里的 `{{SETTLEMENT_STAGES}}` 会渲染成同一张结算顺序表。
