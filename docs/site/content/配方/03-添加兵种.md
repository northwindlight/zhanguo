# 添加兵种与兵种阶段

示例：`mods/examples/elephants/`。`mods/examples/tour.py` 的「配方五／六」会离线跑一遍。

## 1. 注册兵种

兵种用**映射**注册（资源和建筑用类）：

```python
WAR_ELEPHANT = {
    'category': 'unit',
    'name_key': 'unit.example:war-elephant.name',
    'hp': 200,
    'speed': 1,
    'supply': 3,
    'atk': 90,
    'recruit': {'native:food': 20, 'native:equipment': 10, 'native:gold': 60},
    'move_cost': {'native:plain': 2, 'native:forest': 3, 'native:hill': 3,
                  'native:mountain': 4, 'native:desert': 2},
}


class ElephantsMod(GameMod):
    def mixins(self):
        return ()

    def content_definitions(self):
        return {'example:war-elephant': dict(WAR_ELEPHANT)}
```

| 字段 | 要求 |
| --- | --- |
| `category` | 必须是 `'unit'`，否则不被当作兵种 |
| `name_key` | 非空字符串 |
| `hp`／`speed` | 整数，均 `≥ 1` |
| `supply`／`atk` | 整数，`≥ 0` |
| `recruit` | 非空映射：资源 ID → 正整数（征兵消耗） |
| `move_cost` | 非空映射：**地形内容 ID** → 整数 `≥ 1`（进入该地形消耗的移动力） |
| `glyph` | 可选：地图上的单字字形，缺省取 ID 首字母 |

`move_cost` 的键是 `native:plain` 这样的地形 ID，不是中文地形名；运行时以 `territory.terrain(x, y).id` 查表。征兵配方里用到的资源必须已注册为 `Resource` 子类。

注册后，新兵种自动进入征兵工具的枚举、兵种目录、面板和存档依赖清单，`mods/native/army/` 不用改。军费、移动代价、战斗等既有规则对它同样生效，征兵仍受兵营配额和电网状态约束。

## 2. 给这个兵种加结算阶段

`scope='actor'` 的参与者是国家，不是兵种。“只对某个兵种生效”要写成 `scope='world'`，在处理函数里按 `unit.kind` 过滤。部队数据通过对象接口读：

```toml
[Capabilities]
Needs = ["native:army", "native:resource-exchange"]

[Interfaces]
"native:army" = ["snapshot"]
"native:resource-exchange" = ["exchange"]
```

```python
def stages(self):
    # 挂在已有挂点上，用 needs 排到 army 自己的补给阶段之后
    return (Stage('example:elephants.upkeep', self._upkeep,
                  hook='military.supply', needs=('military.supplied',),
                  provides=('elephants.fed',)),)

def _read_heads(self, world):
    heads = {}
    for unit in world.runtime.object_call(world, 'native:army', 'snapshot'):
        if unit.kind == 'example:war-elephant':
            heads[unit.owner] = heads.get(unit.owner, 0) + 1
    return heads
```

部队状态（`units`、`military`）归 army 所有，其他模块只能读。所以兵种专属阶段的常见形态是“读部队，写自己领域的状态”，或者通过资源兑换施加影响。确实要改部队，需在 `[State] Requests` 里申请，并由 army 的 `apply_state_change` 放行。
