# 报错速查

装载期的错误都是 `ModError`，由 `engine/runtime.py` 在 `Runtime.load()` 或世界构造时抛出；会话与存档的错误来自 `engine/session.py`。下表里的 `<…>` 是报错时填入的模块、能力或键名。

## 模块装不起来

| 报错 | 原因 | 怎么办 |
| --- | --- | --- |
| `重复的 Mod ID` | 两个模块用了同一个 `[Mod] Id` | 改 ID；替换实现时只保留一份 |
| `<模块> 缺少依赖 <模块>` | `Requires` 指向的模块没装 | 把依赖加进 `Members`，或去掉这条 `Requires` |
| `<模块> 所需能力无提供者：<能力>` | `Needs` 里的能力没人 `Provides` | 装上提供者，或改成 `Optional` |
| `state 无主：<键>` | 有人读写或 `RequiredState` 要求的键没有所有者 | 装上拥有它的模块 |
| `state 有多个写入所有者：<键>` | 两个模块 `Owns` 同一个键 | 换个键名，或只留一个模块 |
| `数值有多个所有者：<键>` | 两个模块的 `numbers()` 给出同一个键 | 加上模块前缀 |
| `依赖存在环` | `After`／`Before` 或阶段条件互相依赖 | 拆掉其中一条顺序约束 |
| `<阶段> 挂点条件无人提供：<条件>` | 阶段 `needs` 的条件没人 `provides`，或提供者在更晚的挂点 | 检查条件名与挂点顺序 |
| `<阶段> 缺少阶段依赖：<阶段>` | `requires`／`after`／`before` 指向不存在的阶段 | 核对阶段 ID |
| `<路径> 未实现 GameMod` | `Entry` 指向的类没继承 `GameMod` | 修正 `Entry` 或基类 |
| `模块声明缺失：<路径>` | `Members` 里的路径不存在 | 路径相对清单文件所在目录 |
| `<模块> 的 <段>.<键> 声明与实现漂移` | 声明里的能力、状态等与覆写的方法返回值不一致 | 让两边一致，或删掉多余的覆写 |

## 工具与玩家 API

| 报错 | 原因 |
| --- | --- |
| `工具名称/别名冲突：<名>` | 两个工具或别名同名 |
| `模块工具不能占用玩家 API 保留名称` | 工具名用了 `player_state`、`player_rules`、`player_events` 或 `memory_search` |
| `<模块> 声明了 [PlayerAPI] 但未实现 player_api` | 声明了方法却没返回玩家 API 对象 |
| `<模块> 声明了 [PlayerAPI] 但仍在 tools() 返回工具` | 两条接入路径混用；声明 `[PlayerAPI]` 后工具只能由工具层提供 |
| `<模块> 的 [PlayerAPI] 方法未封装：<方法>` | 工具层没有任何工具或动作封装这个方法 |
| `工具 <名> 引用了未声明的方法：<模块>.<方法>` | 工具的 `api` 不在 `[PlayerAPI] Methods` 里 |
| `只读工具 <名> 覆盖了写 API`／`写工具 <名> 覆盖了只读 API` | 工具的 `read_only` 与 `[PlayerAPI] ReadOnly` 不一致 |
| `工具 <名> 的 fact/panel 必须只读` | 事实或面板工具不是只读 |
| `玩家状态必须声明唯一的只读工具` | `PlayerState` 里有不存在、重复或非只读的工具 |
| `玩家事件必须引用只读工具` | `PlayerEvents` 写错 |
| `ReadOnlyPanel must reference a registered read-only tool` | `ReadOnlyPanel` 指向的工具没注册 |
| `Distribution.Tools 必须声明 Entry` 等 | 工具层入口缺失、不可调用，或返回的不是 `Tool`／`Action` |

## 跨模块调用

| 报错 | 原因 |
| --- | --- |
| `<模块> 未声明对象接口调用：<能力>.<方法>` | 能力不在 `Needs`／`Optional` 里，或方法没列进 `[Interfaces]` |
| `对象接口无提供者：<能力>` | 调用的能力没人提供（可选依赖不在时也会这样报） |
| `对象接口未注册：<能力>` | 提供方的 `objects()` 没返回这个能力 |
| `对象接口不能调用私有方法` | 方法名以下划线开头 |
| `<模块> 未声明向 <所有者> 请求写入 state：<键>` | 写别人的状态前没在 `[State] Requests` 里申请 |
| `内容注册者未加载：<模块>` | 注册内容或别名时用了没装载的模块 ID |

## 发行版与会话

| 报错 | 原因 |
| --- | --- |
| `同时加载多个发行版` | 一次装载里出现了两个 `[Distribution]` |
| `行动门声明缺少公共能力或方法` | `ActionGate` 的能力或方法不存在 |
| `玩家时钟必须引用公共能力和方法` | `PlayerClock` 写错 |
| `发行版须声明 PlayerClock 或实现 clock()` | 发行版既没声明时钟，会话也没实现 |
| `发行版须实现定时登场策略或采用 GridSession` | 会话缺少登场策略 |
| `Session.Observer 必须引用公共能力` | `Observer` 里的能力写错 |
| `Session.Observer.Records 必须返回包含 events / messages 的对象` | 观察者记录方法的返回形状不对 |
| `Scenario is not declared by this distribution` | 配置选了发行版没声明的剧本 |
| `Scenario Mod must be a loaded ScenarioMod` | 剧本声明指向的模块没装，或不是剧本模块 |

## 玩家提交动作时

这些不会中断对局，而是作为失败回执交给玩家：

| 报错 | 原因 |
| --- | --- |
| `该国当前不能行动：已亡国，或不在行动阶段` | 行动门拒绝（已结束本回合或已亡国） |
| `仅行动阶段可以提交动作` | 当前不在行动阶段 |
| `该工具不属于行动者的作用域`／`该动作不属于行动者的作用域` | 政体禁用，或模块不作用于该国 |
| `未知参数：…`／`缺少参数：…` | 参数与 schema 不符；回执的 `available` 列出可用参数 |
| `工具参数须为对象` | 参数不是 JSON 对象 |
| `未知内容键值：…` | 传了没注册的内容；注册内容或加别名 |
| `键值冲突，请指定命名空间` | 短键在多个命名空间里重名；用完整 ID |
| `query 只能查已注册的只读动作` | 用查询入口调了写动作 |

## 存档

| 报错 | 原因 |
| --- | --- |
| `存档 Mod 依赖/版本/工具契约与当前加载环境不相同，拒绝加载` | 存档的依赖清单与当前发行版不一致；用匹配的版本，或按[状态与存档](开发流程/06-状态与存档.html)升级为新副本 |
| `存档 Mod 状态清单与当前环境不相同` | 模块集合变了 |
| `Unsupported session format` | 存档格式号不认识（当前为 `zhanguo.session/5`） |
| `Save only at an action boundary` | 在回合中途存档 |
| `Scenario differs from saved scenario` | 存档的剧本与当前配置不同 |
| `<类名> 不支持这些存档状态` | 模块没实现 `load_state`，存档里却有它的状态 |

## 排查顺序

1. 看报错出在哪个阶段：装载期是声明问题；提交动作时是作用域、参数或内容问题；读档时是版本问题。
2. 对照声明与实现：多数问题是 `mod.toml` 与代码不一致。
3. 最小复现：用 `Runtime.load('<你的模块目录>')` 单独装它，或写一个只含必要成员的小发行版。
4. 跑 `python3 scripts/api_doc.py --check`，确认参考页与代码同步，再对照 [API 参考](reference/引擎.html) 核字段。
