# 工具表

每个发行版实际暴露给模型的工具。模型看到的工具表就是这里这份。


## native 发行版

| 工具 | 归属 | 只读 | 说明 |
|---|---|---|---|
| `build` | native:buildings | 否 | 在本国地块动工：site 传地名或 "x y" 坐标串，或直接传两个整数 x、y。直接返回实际扣款和施工回执；参数或材料不符时返回原因。每格每回合一次，结算落成。造价、门槛查 building_catalog，全部收益查 building_economics。 |
| `cancel_build_order` | native:buildings | 否 | 取消construction_queue中的未开工建筑id，预付材料全额退回。已开工条目拒绝此操作，须用demolish按50%拆除；城堡从最高一级取消。 |
| `demolish` | native:buildings | 否 | 按id拆除本国建筑或取消待建：未开工全额退回，施工中退回实际材料50%（可含半单位），完工0%。撤销不恢复本格当期施工额度。城堡从最高一级拆起；拆除最后市政厅可能导致亡国。编号查building_sites或construction_queue。 |
| `economy` | native:economy-queries | 否 | 经济命令：action 选动作，其余参数按该动作需要。行情用 query(panel=market)，库存与报表用 query(panel=econ/report)。经济行动 |
| `end_turn` | native:government | 否 | 结束本国行动。AI 的 summary 只用一两句概括本回合实际执行的结果与关键待结算事项；详细行动已有回执，不重复国策、逐格清单或下回合战略。AI 必须先有有效国策；正式绑定的真人可省略 summary、无需国策。结束成功后，未回应的已收到外交提议提交自动拒绝、回合末生效，开放的联盟投票未表态则自动反对。 |
| `intelligence` | native:intelligence | 否 | 对外通信与谍报：action 选动作，其余参数按该动作需要。各国 id 用 query(panel=foreign) 查，结果在 intel 面板。对外通信与谍报 |
| `military` | native:army | 否 | 军队命令：action 选动作，其余参数按该动作需要。征召材料、军队编号、路径与战斗信息用 query 查（army/unit_catalog/reachable/battle）。军队行动 |
| `plan` | native:government | 否 | 提交持久国策：写未来多回合的经济、军事、情报与外交战略，明确目标、优先级、资源约束和调整条件，依据事实而非编造。不是本回合流水账。到期或战略变化时修订，已有有效国策无需反复提交。 |
| `query` | native:query | 是 | 只读查询统一入口：panel 选面板，其余参数、必填项和说明见对应分支。已有资料无需重复查询；唯一按单格查询的是 tile。 |
| `queue_build` | native:buildings | 否 | 将建筑加入本国地块正式队列，立即按当时造价预付全部材料，空闲则马上动工，否则后续回合依次开工且不再扣款。预占建筑及资源位，每格每期仍只动工一次。未开工取消全退，已开工拆除50%，完工0%。查询construction_queue，取消用cancel_build_order。 |
| `relations` | native:diplomacy | 否 | 外交命令：action 选动作，其余参数按该动作需要。当前联盟、条约、战争、提议编号与投票用 query(panel=foreign) 查。外交行动 |

## minigame 开发模式

| 工具 | 归属 | 只读 | 说明 |
|---|---|---|---|
| `army` | mini:army | 是 | 只读部队：列出本国与各国现役部队（编号、兵种、HP、所在格），本国部队排在前面。 |
| `attack` | mini:army | 否 | 进攻：unit 是本国部队编号，x、y 是目标格。只能攻击交战国的地块，且目标格须与该部队相邻；守军被歼灭即占领该格。 |
| `build` | mini:buildings | 否 | 在本国地块上动工：x、y 是地块坐标，kind 是建筑种类（查 catalog）。只能建在本国地块上，材料不足会返回原因。 |
| `catalog` | mini:buildings | 是 | 只读图鉴：建筑种类与造价产出、兵种属性、地形种类。建造与征兵前先查这里。 |
| `declare_war` | mini:diplomacy | 否 | 向另一国宣战：target 是对方国家 id（查 nations）。只有交战国之间才能进攻对方地块，议和后方可再战。 |
| `diplomacy` | mini:diplomacy | 是 | 只读外交：当前与哪些国家交战。本作没有同盟、条约、提议与投票；wars 里 attackers 是宣战方，defenders 是被宣战方。 |
| `end_turn` | mini:government | 否 | 结束本国行动。summary 只用一两句概括本回合实际做了什么，不要重复逐条流水账；细节已有回执。 |
| `government` | mini:government | 是 | 只读回合状态：当前是第几期、本国本回合是否已经结束行动。 |
| `land` | mini:territory | 是 | 只读本国地块：本国每块地的位置、地形与已建建筑。 |
| `make_peace` | mini:diplomacy | 否 | 与另一国议和：target 是对方国家 id（查 nations）。议和立即生效。 |
| `move_army` | mini:army | 否 | 调动本国部队：unit 是部队编号，x、y 是目标格，只能移到相邻格。 |
| `nations` | mini:nations | 是 | 只读各国：所有国家的 id、名称与是否存续。宣战、议和的 target 用这里的 id。 |
| `news` | mini:intelligence | 是 | 只读近讯：按时间倒序的事件流（亡国、宣战、占地等），只含公开事件与涉己事件。 |
| `recruit` | mini:army | 否 | 在本国地块上征一个步兵：x、y 是地块坐标，该地块必须有兵营。征兵耗粮与金（查 catalog），资源不足会返回原因。 |
| `stock` | mini:resources | 是 | 只读资源存量：返回本国当前的钱、粮、木各有多少。建造与征兵都从这些存量里扣。 |
| `view` | mini:territory | 是 | 只读地图：逐格列出全图地块（坐标、归属、地形、建筑）。本作没有视野限制，全图皆可见；进攻只能落在交战国的地块上。 |
