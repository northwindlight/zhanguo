# 引擎 API

引擎是发行版之上的通用运行时：装 Mod、跑回合、存档、给模型发工具。

## GameMod：模块要实现的东西

`mixins` 必实现；其余按需覆写。说明取自源码里的行内注释。

| 方法 | 签名 | 说明 |
|---|---|---|
| after_tool | `after_tool(self, world, actor, name, result)` | 工具执行后的钩子：改写结果或记日志。 |
| apply_state_change | `apply_state_change(self, world, key, operation)` | 替换状态对象前的钩子；默认检查写入所有权。 |
| before_tool | `before_tool(self, world, actor, name, arguments)` | 工具执行前的钩子：校验参数、限流、记账。 |
| content_definitions | `content_definitions(self)` | 返回「内容 ID → 定义」的映射。注册过的内容才有短键与显示名。 |
| initialize_world | `initialize_world(self, world)` | 建世界对象：把状态挂到 world 上。 |
| load_state | `load_state(self, world, state)` | 读回本模块的存档状态。 |
| mixins | `mixins(self) -> 'tuple[type, ...]'` | 必实现。返回混入 World 的类（Mixin）；Mixin 的方法会变成世界对象的属性。 |
| needs | `needs(self)` | 本模块用到的其他能力名；能力名就是「模块ID:能力名」。 |
| numbers | `numbers(self)` | 本模块提供的数值；规则正文里的 {{number:…}} 从这里取，改参数规则正文就跟着变。 |
| objects | `objects(self, world)` | 返回「能力名 → 对象」的映射；能力方法就在这些对象上。 |
| optional | `optional(self)` | 可选依赖能力名：对方不在也不报错。 |
| player_api | `player_api(self, world)` | 返回玩家 API 对象；工具层通过它调用动作与只读事实。 |
| presentations | `presentations(self)` | 本模块提供的呈现部件（面板、回执渲染等）。 |
| provides | `provides(self)` | 本模块提供的能力名。 |
| rule_sections | `rule_sections(self, world=None)` | 返回规则正文节（RuleSection）；模型用 player_rules 按主题查。 |
| save_state | `save_state(self, world)` | 导出本模块的存档状态。 |
| schema_for_actor | `schema_for_actor(self, world, actor, schema)` | 按玩家改写工具 schema（比如按权限隐藏参数）。 |
| stages | `stages(self) -> 'tuple[Stage, ...]'` | 返回结算阶段（Stage）；阶段挂在发行版声明的挂点上。 |
| state_keys | `state_keys(self)` | 本模块独占的状态键；别人要写必须先在本模块的 State.Requests 里申请。 |
| tools | `tools(self) -> 'tuple[Tool, ...]'` | 返回本模块暴露给模型的工具（Tool）。工具要写清 description：模型只看得见它。 |


## Tool：暴露给模型的工具

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | str | None |  |
| `handler` | Callable | None |  |
| `aliases` | list | () |  |
| `description` | str |  |  |
| `adapter` | Callable \| None | None | adapter 是 Mod 自己的坐标/旧参数转换，不属于通用引擎。 |
| `normalizers` | dict | factory | normalizers 在 adapter 之后、schema 校验之前把显示词汇归一化成动作词汇。 |
| `parameters` | dict \| None | None |  |
| `argument_types` | dict | factory |  |
| `read_only` | bool | False |  |
| `hidden` | bool | False | 只读面板等内部工具不出现在模型工具表；脚本/规则 AI 不走工具名。 |
| `content_parameters` | list | () |  |
| `owner` | str \| None | None | tool 层字段：owner 是提供玩家 API 的能力名；None 表示沿用「哪个模块返回」。 |
| `api` | list | () |  |
| `covers` | tuple[tuple[str, str], ...] | () | 组合工具额外覆盖的其他能力方法（如 foreign 组合 intelligence/diplomacy）： 只用于装载期覆盖与读写一致性检查，工具仍由 owner 的上下文执行。 |
| `fact` | bool | False |  |
| `panel` | bool | False |  |
| `groups` | list | () |  |
| `schema_for_actor` | Callable \| None | None |  |

## 配置层

配置层（`engine/config.py`）声明每个字段的类型、取值范围与是否必填：

| 名字 | 说明 |
|---|---|
| `Field` | 一个配置字段：类型元组、choices、minimum/maximum、nullable |
| `Schema` | 一组字段的集合；`normalize` 会校验并保留未声明的键 |
| `component` | 调用发行版自己声明的归一化函数 |
| `prepare` | 把整份配置按发行版契约归一化 |
