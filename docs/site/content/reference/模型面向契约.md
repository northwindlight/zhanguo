# 模型面向契约

模型客户端不认识任何发行版：它只按这份契约办事。

发行版只要满足这份契约，同一个模型客户端就能玩它。

## 引擎内建工具

任何发行版都有，模型直接可调：

| 工具 | 说明 | 参数 |
|---|---|---|
| `memory_search` | 检索本客户端的历史行动与小结，不包含思考；query 为关键词，limit 默认3。 | limit、query |
| `player_state` | 本国当前可见事实，按权限过滤；等价于 observe() 的 facts。 | — |
| `player_rules` | 查询本国公开规则。缺省或未知 topic 返回目录；传目录标题或主题词查正文，all 查全部。 | topic |
| `player_events` | 按游标取本国可见事件；cursor 缺省取全部，返回值带新游标。 | cursor |


## 事实词汇

模型面向的简报与仪表盘按这些事实名取数；发行版给哪些，简报就出哪些节。

## 回合小结契约

`end_turn` 必须接收 `summary`，并在回执数据里返回 `text`：

```
end_turn(summary="本期建了兵营并宣战")
→ data.text = "本期建了兵营并宣战"
```


模型客户端会把这个 `text` 存进本回合小结，作为下一回合的记忆。


## 交战事实形状

战争事实可以有三种写法，模型面向层都认：

```
{"attackers": ["a"], "defenders": ["b"]}
{"parties": ["a", "b"]}
["a", "b"]
```


## 工具描述就是给模型看的说明书

工具的 `description` 直接进模型工具表：写清参数、约束与失败原因，模型才知道该传什么、什么时候会失败。
