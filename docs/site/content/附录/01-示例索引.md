# 示例索引

示例都在 `mods/examples/` 下，全部可以离线运行。拿不准某个东西怎么写，先找最接近的那个示例。

| 你要做的事 | 示例 | 配方 |
| --- | --- | --- |
| 写第一个模块：一个状态、一个工具、一个阶段、一段规则 | `hello` | [快速上手](开始/01-五分钟上手.html) |
| 加一种资源并让它上市 | `tea`（模块）、`tea_dist`（发行版） | [添加一种资源](配方/01-添加资源.html) |
| 新增挂点，插入一个结算阶段 | `harvest` | [插入一个结算阶段](配方/02-插入阶段.html) |
| 加一个兵种与它的专属阶段 | `elephants` | [添加兵种与兵种阶段](配方/03-添加兵种.html) |
| 替换已有内容：去掉电力系统 | `no_power`（模块）、`no_power_dist`（发行版） | [替换已有内容](配方/04-替换内容.html) |
| 换一个定价引擎：实现 `market:pricing` 的另一个提供者 | `fixed_market_pricing` | [跨模块协作](开发流程/05-跨模块协作.html) |
| 另写一个银行模块（固定授信），提供同一能力 `economy:bank` | `fixed_credit_bank` | [替换已有内容](配方/04-替换内容.html) |
| 只写清单：在 native 成员之后追加秋收与战象两个模块 | `recipes_dist` | [制作发行版](开发流程/07-制作发行版.html) |
| 写一个客户端 | `idle_client` | [提供一个客户端](配方/05-提供客户端.html) |
| 从零写一套完整小游戏 | `minigame`（入口 `mods.minigame.toml`） | [最小可玩游戏](配方/06-最小可玩游戏.html) |
| 在 native 上做减法 | `playable_min`（入口 `mods.playable.toml`） | [最小可玩游戏](配方/06-最小可玩游戏.html) |

想看规模更大的真实例子：`mods/native/` 是标准发行版，一个领域一个目录（`api.py` 玩家 API、`objects.py` 领域对象、`mod.py` 装配）；`mods/stock/` 是规则完全不同的模拟炒股发行版。

## 跑一遍全部

```bash
.venv/bin/python mods/examples/tour.py
```

巡礼脚本把各条配方都跑一遍，每步打印可核对的数字。不联网，不需要 API key，不读写真实存档。
