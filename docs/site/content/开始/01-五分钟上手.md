# 快速上手

## 环境

| 项 | 要求 |
| --- | --- |
| Python | 推荐 3.13，支持 3.11／3.12 |
| 依赖 | `requirements.txt`：模型接入用的官方 SDK 和 v14 规则 AI 的求解器；只写规则模块时不会用到它们 |
| 地图图片 | 另装 `requirements/vision.txt`（Pillow）；不装也能跑，只是不出地图 PNG |
| 平台 | Linux／macOS／Windows；引擎不依赖平台特性 |

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install -r requirements/vision.txt   # 需要地图 PNG 时再装
```

依赖一律装进项目虚拟环境，不要改系统 Python。

## 跑起来

```bash
# 离线跑一遍全部配方：每一步都打印可核对的数字，不联网、不读写真实存档
.venv/bin/python mods/examples/tour.py

# 示例 Mod 的回归测试
.venv/bin/python -m unittest tests.test_example_mods -v

# 全量离线回归（一千多项，机器慢时可以只交给 CI）
.venv/bin/python -m unittest discover -s tests -q
```

## 玩一局最小游戏

`mods/examples/minigame` 是**从零写**的九模块小规则：三种资源、一种地形、五种建筑、一个兵种，外交只有宣战与议和。配置写成这样：

```json
{
  "mods": "mods.minigame.toml",
  "map_size": 12,
  "seed": 3,
  "nations": [
    {"id": "scenario:qin", "name": "秦", "client": "mini", "position": [3, 3]},
    {"id": "scenario:chu", "name": "楚", "client": "mini", "position": [8, 8]}
  ]
}
```

```bash
.venv/bin/python mp_run.py --config mini.json --new --turns 5
```

`"client": "mini"` 用发行版自带的简易策略来下，**不需要 API key**。换成 `"client": "llm"` 并填好模型配置，就交给真实模型来玩：规则和工具面都不变，发行版也不用为模型做任何改动，原因见[模型面向契约](reference/模型面向契约.html)。

## 第一个模块

模块是一个目录，里面有一份声明和一份实现。完整代码见 `mods/examples/hello/`：

```
mods/examples/hello/
  mod.toml    声明：身份、状态、能力
  mod.py      实现：继承 GameMod 的类
```

```toml
[Mod]
Id = "example:hello"
Version = "1.0.0"
Entry = "mods.examples.hello.mod:HelloMod"

[State]
Owns = ["hello"]

[Capabilities]
Provides = ["example:hello"]
```

```python
from engine.runtime import GameMod, RuleSection, Stage, Tool


class HelloMod(GameMod):
    def mixins(self):
        return ()                                  # 必填；不给世界挂属性就返回空元组

    def initialize_world(self, world):
        world.hello = {}                           # 世界构造完成后调用一次

    def tools(self):
        return (Tool('hello_add', self._add, ('打招呼',)),       # 第三个参数是别名
                Tool('hello_total', self._total, read_only=True))

    @staticmethod
    def _add(world, actor, amount: int):
        if amount < 1:
            raise ValueError('amount 必须是正整数')
        world.hello[actor] = world.hello.get(actor, 0) + amount
        return {'actor': actor, 'count': world.hello[actor]}

    @staticmethod
    def _total(world, actor):
        return {'counts': dict(world.hello), 'total': sum(world.hello.values())}

    def stages(self):
        return (Stage('example:hello.settle', self._settle, title='打招呼结算'),)

    @staticmethod
    def _settle(world, context):
        context['hello_total'] = sum(world.hello.values())   # 阶段返回值会被忽略

    def rule_sections(self, world=None):
        return (RuleSection('打招呼', '用 hello_add 给自己记数，hello_total 查全场的数。',
                            ('hello', '打招呼')),)

    def save_state(self, world):
        return dict(world.hello)

    def load_state(self, world, state):
        world.hello = dict(state)                  # 真实模块要先校验再收下
```

`Entry` 里的包路径按**仓库根**解析，各层目录不需要 `__init__.py`。

装起来试，有两种方式：

```python
from engine.runtime import Runtime, Unit
from mods.examples.hello.mod import HelloMod

# ① 进程内装载，不落文件：适合单模块开发和测试
runtime = Runtime([Unit('example:hello', HelloMod(), version='1.0.0')])
world = runtime.world_class()()
runtime.call(world, 'demo', 'hello_add', {'amount': '4'})   # 字符串 "4" 按类型标注转成 4
runtime.call(world, 'demo', '打招呼', {'amount': 2})          # 别名同样可用

# ② 从目录装载：目录里只有模块声明、没有发行版清单也能装
runtime = Runtime.load('mods/examples/hello')
```
