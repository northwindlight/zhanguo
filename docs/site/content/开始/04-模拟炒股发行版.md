# 模拟炒股发行版

stock 2.0 使用 PAMS 0.3.0 的订单簿，有限做市资金、玩家订单和已公布消息共同形成价格。
每交易日20000逻辑tick，宿主尽快运行，无需等待现实20分钟。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt -r requirements-stock.txt
.venv/bin/python mp_run.py --config mp_config.stock.offline.example.json
```

盘前模型改策略、租资源、借贷、购买谍报，并可使用解锁的只读研究槽。
全体结束后锁定策略，沿共同tick运行；成交下一tick生效并立即进入账户，收盘结算。
普通源码每日一次；定义 `def on_tick():` 则默认每100tick回调，私人JSON字典 `state` 跨回调/跨日保留。
`sleep`只安排下次回调，不能用while等待。

默认每日400万计算单位、4000次API、1个交易槽。`compute(action=buy,kind=pool/slot/research)`
用游戏现金增购算力池、自动交易槽或行动内研究槽；所有槽共用每日预算。
最多4档算力、4个交易槽和1个独立研究槽。研究槽解锁500、日租50，
`script(action=run,slot=research,inputs={...})`可立即运行分析，只读已知数据，不交易、不推进行情。

交易 API 支持 buy/sell/short/cover、限价、撤单、部分成交、有限券源及保证金。
PAMS按同批统一清算价成交；市价意图有2%价格保护，Day委托收盘到期。

`intel(action=steal,target=玩家id)`花1000游戏现金取得对方现金、银行贷款和持仓规模快照；
报告标明获取时间且不自动刷新。普通查询仍仅能读本账户。

全部参数、规则、代码示例、第三方来源和存档边界见仓库 `mods/stock/README.md`。
这是2.0状态协议，不自动加载旧stock 1.0存档。尚未进行真实LLM排名实验。
