## 零、总则

1. **外交实体是外交与条约的最小单位**：独立国家、联盟各算一个实体。条约、宣战、议和、休战、
   通行、视野，全部**以实体为单位**结算；一个国家在盟内时，它**不是**外交主体。
2. **提交 ≠ 生效**。外交动作在行动阶段**提交**、在回合末的外交阶段**统一生效**。【待改】
   - 回执必须区分：**已提交（待生效）** / **已生效** / **失败** / **取消**。
   - 已提交不等于已成，**不得**把待执行的动作报告为成立的条约或既成战线。
3. **回合末结算顺序（钉死）**：
   > 计票 → 配额与采集 → 电网与工业 → 外交 → 补给与回血 → 战争 → 撤退落地 → 脱离清扫 → 弃城即陷 → 亡国与强制休战 →
   > 遣返 → 市场 → 在建落地 → 世界央行 → 摘要与经济报表
   - 外交排在**补给与战争之前**：本回合谈成的停战**能拦下本回合的仗**。
   - 补给排在战争之前：饿着的军队**先掉血、再上阵**；本回合补的血**能拿来打这一仗**。
   - 亡国排在战争之后：**厅被夺的当回合，抢回来就不算亡国**。
   - 逐步清单**只在说明书一处出现**（本次定稿后即第一章），别在两处各抄一份。
4. **状态查询与回执不解释规则**：面板只给事实（谁是谁、谁跟谁、当前值），
   不得自行推断、补写或解释规则；GUI、人类玩家、LLM、规则 AI 用同一套命令与查询语义。

## 一、回合、时间与提交点

- **一个回合＝一国行动一次**，全部国家行动完毕后才统一结算；先手按回合轮转，无人被永久排最后。【事实】
- **`end_turn` 只结束本国行动**，不触发世界结算；世界结算由引擎在全员行动完毕后统一跑。【事实】
- **投票**：发起后**下一回合**表决，全部国家行动结束后，**在世界结算首阶段统一计票**；通过议案按内容进入对应执行阶段。现有宣战、议和、缔约、入盟在本轮外交阶段执行。【待改；用户补充定案】
  - 现状是"赞成已不可能被超过即提前定论"、"盟主投反对当场作废"、"结束回合＝弃权"——三条都要改。
  - 定稿后：投票在**同一个计票时刻**结算（回合末），**未投票按弃权**，盟主反对只是反对票之一，
    **不额外拥有一票否决**（否决权若保留，须在新的表决时点同样生效，另立条目）。
- **编号与去重**：外交提交使用**稳定编号**，可序列化进存档；同一请求**不得重复执行**。【待改】
- **回合区间**：休战到期、投票截止、物资送达、贷款到期一律用**明确回合区间**表达，"至第 N 回合（含）"。【事实】
- **存档**：原子写、每回合结算后落盘；旧档只加字段不删字段，缺字段按默认补齐；破坏性变更才 bump 版本。【事实】
  - **待执行的外交队列必须进存档**（现在没有队列，也没有这部分）。【待改】

## 二、在地图上

- **八邻域**（含斜向）移动；一步的代价＝**出发格与目标格取更贵者**，多格移动逐格判定。【事实】
- **没有"禁止切角"**：斜向一步只要求目标格可入，不要求两个正交邻格为空。【选择】
- 三种军事命令**共用同一个行动额度**（`moved_turn`）：移动、进攻、撤退**一回合只能做其中一次**；
  **原地进攻不耗额度**。【事实】
- **新兵当回合不能行动**：刚征召的军队本回合只能站着，下一回合才能动。【事实】
- 失败是否烧额度：**看得见的格上撞墙不烧**（不罚）；**视野外撞墙照烧**（迷雾限眼不限手）。【事实】
- 撤退固定**一格**、不看兵种速度、不看地形代价；撤退有**撤退地合法性**判定，目标不合法则自动改撤或原地留守。【事实】
- 遣返（断盟/退盟/停战后滞留他国领土）：**回合末**按兵种速度逐回合往家走，必要时可走中立地。【事实】

### 军事命令的语义（2026-10-12 用户确认，与 PLAN 同步）

- **"调动不占地"是设计意图，必须保留**：调动的用途是**快速穿越野地**去支撑联盟战争、
  均势战争、围魏救赵这类跨区域行动；**不**要求军队把走过的路逐格征服，
  **也绝不把普通调动自动改成占领**。"能穿野地"仍受移动力、地形、通行关系、目标格、
  敌军与战场规则约束——不表示无视敌军、瞬移或额外额度。【选择】
- **五个状态各自独立表达，不许混**：军队**位置** / 地块**归属** / **交战身份** /
  **行动额度** / **待撤离状态**。"经过、驻留、参战、占领、准备撤离、已撤离"是**六件不同的事**，
  不得用名字相近的措辞混指。【待改：回执与面板按此拆开】
- **两条回执必须分开写**：夺取的"**已占领**"与"**已进入交战、尚未占领**"；
  脱战的"**已提交撤离**"与"**已撤离**"（提交之后它**仍在战场上**，不能说成安全了）。【待改】
- **移动力 ≠ 行动额度**：移动力是"**一次**行动能走多远"，行动额度是"**一回合**能执行几次"。
  骑兵移动力 2 **不等于**可以连续调动两次、或调动后再进攻——移动/进攻/撤退**共用同一个额度**
  （一回合只做其中一次，原地进攻不耗）。【事实】
- **失败要说清两件事**：是否消耗行动额度、位置是否改变（现行：看得见的格上撞墙不罚、
  视野外撞墙照烧）。【事实 + 待补齐回执措辞】
- **多军夺取要走整批校验**：部分不可达/部分失败要有明确结果与**索取顺序**，
  不能出现"回执说进攻失败、可部分军队已经动了"。【待改】
- **强制遣返 ≠ 主动脱战**：前者是回合末按兵种速度的强制回撤（断盟/退盟/停战后），
  **不是**一种免费撤退能力；两者分开定义。【事实】
- **改名/别名要有兼容策略**：工具别名与存档里对军队的引用不得因为改名而让
  **旧记忆里的命令无声变义**；兼容入口与正式入口走**同一条时序**。【待改】

## 三、领土、建筑与国祚

- **亡国的唯一条件＝一座市政厅都不剩**（不是丢光领土）。【事实】
- **厅只能被"占地"夺走，不能被"拆毁"**——本作**没有拆建筑这条命令**。【事实】
- 建筑**随地块易主**：`atk` 占下一格，地上的建筑（含市政厅/城堡/兵营）**原样归新主**。【事实】
- **在建未落成的厅不算国祚**：`has_townhall` 只认**已落成**的厅；在建厅在回合末的"在建落地"步才落成，
  **落成排在亡国判定之后**——所以"本回合动工的厅"救不了本回合的亡国。【事实】
- **抢回厅＝重新落成或夺回**：亡国判定在战斗之后，所以厅被夺的同回合把它（或另一座）抢回来就不亡国。
  "抢回已落成的厅"与"新盖一座厅"是两件事，不要混为一谈。【事实】
- 建筑**在建一期**：本回合动工，回合末落成，**下回合起**才发电/收获/征兵；落成排在市场之后，
  所以新建筑不影响本期均衡价。【事实】
- 建筑位与选址限制（`min_slots`、每地块上限、本地资源上限）以 `balance.py` 为准。【事实】

## 四、军队、战斗与补给

- 每军**吃补给**（按兵种），缺口按比例扣血甚至饿毙；**民兵驻自家军屯格免供**。【事实】
  - 免供覆盖到哪几支**取决于军队顺序**（按列表序取覆盖）；超编只是不让再征，**不强制遣散**。【事实】
- **回血**：不交战且未断粮的军队每回合回血，吃装备；民兵回血免费。【事实】
- 战斗（每交战格每回合掷一轮）：
  - 一方**输出基数＝Σ 各兵种攻击**，**与该方各军血量无关**【事实】——
    **伤兵照样满额输出**，所以削弱对方输出的唯一办法是**打掉它的编制**（把军打死），磨血没用。【选择】
  - 掷骰修正 ±25%；伤害下限 `max(1,…)`；**地形与城堡减伤相乘**（不是相加）。【事实】
  - 伤害**按人头均摊**；**有军被打死时，它吃不完的那部分转嫁给还活着的**（不浪费在尸体上）。
    例：一击造成 100，对面两支军分别 20 血与 90 血 ⇒ 结算为 **0 血与 10 血**。【事实】
    - **例外**：该方存在**撤退中（有减伤档）**的军队时走逐军减免、**不做溢出转嫁**。【事实】
      （这条要不要统一，留待下一轮；说明书须如实写出现行例外。）
  - **撤退减伤是"承受比例"**：防御方撤退只承受 `RETREAT_DEF_COVER`% 的伤害——
    `50` ＝只受一半、`100` ＝全额承受、`0` ＝免伤；进攻方撤退＝全额（但输出 −80%）。【事实】
- 多方混战：**进攻方不必是纯联合**；野人只打进攻方；一格的归属由**索取顺序**决定
  （`engage_seq`，撤退军不索取），本回合打过、守军全撤或全灭的格子由围攻方接管（弃城即陷）。【事实】

## 五、外交

- **权力上移到实体**：在盟国家**个人签不了任何条约**，一切对外承诺走**联盟投票**。【事实】
- **条约表按实体 id 存**（独立国＝国家实体，联盟＝联盟实体）。【事实】
- **休战（和约）也按实体存**，与条约同一口径：
  - 联盟的休战记在**联盟**身上：**换盟主、移交、继承都动不了它**。【事实】
  - **成员个人的和约在盟内自动冻结**（对盟外的也一样），**退盟/解散即自动恢复**，
    按**原到期回合**——表里那条一个字都不删。【事实】
  - **和约只许延长、不许缩短**（新增一条不能覆盖更长的旧约）。【事实】
  - 同一个实体内两国之间**不存在**独立和约（盟内互不攻击本来就更强）。【事实】
- **休战只拦"宣战"，不拦缔约、不拦结盟**【事实】；和约拦下的是**宣战**与"把签约方拖进战争的自动参战"。
- **战争传导＝一对实体只走一跳**：被宣战实体的**直接**保障国/共同防御伙伴参战，
  这些援军**自己身上的条约不再往下传**；**"无限跳"只指联盟**——打盟员＝打全盟，全盟一起上。【选择】
- **和约优先于盟约**：休战期内，已有的保障/共同防御**不触发**（该来的援军不来，且**双方都被通知**）。【事实】
- **开战即作废在途外交**：宣战那一刻，**战前未通过**的缔约/入盟投票与结盟提议一律作废并通知当事人；
  **宣战票与议和票保留**（那是战争本身的操作，清了等于把出口堵死）。【事实】
- **强制和平（亡国触发的全天下休战）**：
  - **所有战线当场终止**（不只与亡国者有关的那几条），并给**每一对实体**压上 10 回合休战。【事实】
  - 在途的**一切**外交事项当场作废（含求和提议、含全部投票），并通知当事人。【事实】
- **提议与回应**：缔约/结盟的提议、回应、拒绝都要**通知对面**；"怎么谈的"不广播，
  但**结果必须到达当事人**（盟内与盟外都算当事人）。【事实】
- **投票结局**：成功、未通过、逾期、被否决、被开战/强制和平作废——**每一结局都要通知
  盟内与盟外全部当事人**（申请人常在盟外）；但**票数不进通知**（票数属"商议过程"，不公开，
  只在发起人拿到的回执里给出）。【事实】
- **联盟锁死**：任一战线上有成员在交战 ⇒ **不退盟、不解散**（先议和）。【事实】
- **兼容别名**（如 `break_alliance`）**必须与正式入口同一条时序**，不得绕过队列与冻结。【待改】

## 六、联盟与投票

- 盟主＝实体的对外代表：**对外出面**签条约、议和、宣战，但**都要先过投票**。【事实】
- 入盟**即放弃个人条约**（保障/共同防御一并作废）；**个人和约只是冻结**（退盟恢复）。【事实】
- 联盟改名要**同步所有按实体 id 存的引用**（条约表、休战表、进行中的投票），漏一处即"改名即失约"。【事实】
- 投票表决议题（宣战/缔约/入盟/议和）的**通过票数规则**：以定稿后的统一计票时点为准（见 §一）。【待改】

## 七、情报、可见性与通讯

- **可见性有三套口径、互不相同**：地块可见（`visible_to`，本国地+邻接一圈+瞭望塔/联盟共享）、
  建筑可见（他国地块**只报城堡与市政厅**）、事件可见（落盘时抓一次视野快照，事后不回溯补发）。【事实】
- **厅与城堡只在视野内露出**：面板那行"视野内市政厅"**只含你视野内的**——
  拔掉看得见的那座**不等于**亡国，对方可能有你看不见的厅。【事实】
- **写信**：N 回合后送达；**馈赠**：下回合到账，收方亡国则退回；**分享地图**：单向、下回合到账；
  **间谍**：派出后第 3 回合回报（口径照抄引擎：厅 + 各兵种数量，**位置/番号不外泄**）。【事实】
- **双方皆亡时的在途馈赠会被静默丢弃**（物资凭空消失、手续费无说法）——**定稿：按"退回原主/或按失败
  处理并通知"择一**，不得静默。【待改】
- **经济报表的公开性**：说明书说"每期全世界都收到一行公告"，代码只公告给本国。
  **定稿＝只公告给本国**（报表是本国账本），说明书照此改。【选择】

## 八、市场、央行与经济指标

- 市场：均价结算 + 价差 + 深度 + 均衡价；**同回合同方向拆单与一次性下单逐分相同**（已有"攒零钱"）。【事实】
- 跨回合分批是**正常做法**，与"同回合倒手"不是一回事；空转检测按**回合区间**判定。【事实】
- 央行：只有一种贷款（额度＝当时 GDP×倍数、固定期数、不可自选）；储蓄结息、贷款计息与到期强制扣款
  都在**回合末的央行步**。【事实】
- **指标时点**：GDP 用**当期市价**的生产法；军费＝本回合实吃补给×**现价**；资产＝**现价**重置成本；
  排名＝**总消费**（累计建造+征兵+军费，按当时市价折金；买卖与馈赠不计，存货不计）。【事实】

## 九、终局与结算厅

- **终局条件**：只剩一国存活，或跑到回合上限。【事实】
- **结算厅＝全体国家入席（含已亡国）**；每位君主带着**自己那份上下文**进场（逐字回放 + 归档 +
  长期记忆重建），不是收到一份摘要。【事实】
- **亡国不清记忆**：亡国时只清**在局状态**（逐字回放、地图、国策、账本、信箱等），
  **长期记忆/回合小结/阶段块/政体身份一律保留**——就是为了让他们能进结算厅。【事实】
- **胜负口径分离**：终局原因（灭国 / 到回合上限）、剧本胜负、测评得分是**三件事**，
  各自定义，不混用。【待改：说明书需写明】

## 十、文档与 AI 侧的边界
