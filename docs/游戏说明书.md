# 游戏说明书 · native 4.1.0

由 `python -m docs.generate_manual` 从所选发行版声明生成。
此文档列出模块公开规则、实际结算顺序与声明数值；领域实现及玩家 API 以对应模块为准。

由已加载 Mod 提供规则内容；结算顺序由阶段依赖自动生成。

## 匈奴政体

匈奴模块以国家作用域加载。开局资源和骑兵、外交禁用项及建造/征召覆盖都由本模块声明；卸载本模块不影响普通国家。

## 视野

本国和同盟土地周围一格可见，哨塔扩展视野。他国可见地块只显示已落成的市政厅和城堡，不公开库存、资源容量或其他建筑。

## 国策与回合

end_turn 结束本国行动；世界结算仍由宿主统一调用。国策到期须更新，小结须满足清单声明长度。

## 领土

地块保存地形和核心，当前归属由建筑站点维护。查询未物化地块不改变世界；部队调动不改变土地归属。坐标使用 0-based。

## 军队

调动只改变位置。移动、异地进攻、撤退共用行动额度，新兵当期不能行动；原地进攻保留额度。外交先于补给与战斗，撤离提交后仍参加本期战斗。军队从资源域扣除征召、补给与回血材料，并发布经济事实。坐标接口使用 0-based。

## 外交实体与提交

独立国家、联盟是条约实体。外交在行动期提交并预留费用，在外交挂点重新校验后生效或退款。联盟表决在发起后下一周期末统一计票，未投票弃权，赞成票多于反对票通过；宣战仅传导原防守实体的直接保障与共同防御。
