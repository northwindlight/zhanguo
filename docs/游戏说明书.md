## 一、一局游戏

回合制。每回合各国**轮流行动**（一国把本回合要做的事做完，再轮到下一国），
**全部行动完毕后统一结算**，然后进入下一回合。先手按回合轮转——无人被永久排最后。

结算顺序固定（`World.resolve_turn`），一次结算跑完下列各步：

- **备料**：刷新每地块每回合的建造 / 征召配额。
- **采集**：林场/农场/矿场/石油厂产出入储备；黄金矿场产金入国库。（军屯不产粮，见下）
- **电网与工厂**：能源厂烧燃料发电；发电量够则工厂投料产出、市政厅产金；不够则高级建筑
  （补给厂/装备厂/兵营/市政厅）整回合停摆——能源厂自己不受影响。
- **战争**：每个交战格掷骰打一轮（含已下令撤退的军队）。
- **撤退落地**：结算后撤退军脱离到目标格（目标格战局生变则改撤或留守，战报如实记）。
- **补给与回血**：每军吃补给（数值见兵种表），缺口按比例扣血甚至饿毙；非交战且补给充足的军队回血。
- **脱离清扫**：所在格敌军已撤离或覆灭的军队，解除交战状态。
- **弃城即陷**：本回合打过、守军全撤或全灭的格子，由围攻方按索取顺序接管。
- **遣返与投票到期**：断盟/退盟/停战后滞留他国领土的军队自动往家走；逾期的联盟投票按已投部分定论。
- **市场**：按本回合全世界产/耗流量重算均衡价，市价向它回归。
- **在建落地**：本回合动工的建筑此刻才落成，**下回合起**才发电/收获/征兵（落地排在市场之后，
  所以新建筑不影响本期均衡价）。
- **结算摘要与经济报表**：每国得到本回合摘要；逢报表回合自动结一期。

**地块与开局**：每国开局占**中心 + 上下左右十字**共五块地，自动命名，没有首都概念。

- **地名即 ID**：占领时自动命名（词库组合、全局唯一），引用地块用名字或坐标；坐标从 `1` 数起。<!--lint-ok-->
- **视野**：自家地盘 + 相邻一圈（含对角）；联盟成员**共享视野**（盟友地盘视同己方）；
  **瞭望塔**把事件视野再往外推（半径见建筑表），只扩事件视野、不增加可拓地。
- **国土与视野是两张「地图」**：每回合的状态里常驻**带坐标轴的地形/国土图 + 军事图**（同框，
  每格 `2` 个字符，**只用半角 ASCII**——全角/歧义宽度的符号会让整张格子错位）。
  - **地形/国土图**：自家 = 大写地形字母；视野内的**他国领地** = 小写地形 + **该国字母**
    （地形与归属**都给**，各占一位，互不冲突）；`*` = 野人守军；`#` = 自家有建筑（含在建）；
    第 `2` 位是 `.` 表示无异物（无主空地可直接 `attack` 进驻）。
  - **军事图**：只标**能动的军队**——自家 `1..9` 再 `a..z`、他国 `A..Z`；**一格只画一个符号**
    （重叠时画优先级最高的那支，其余数量写进图注），番号/血量/坐标都在下方图注里；
    野人守军**不在**此图——它们驻在每一块无主地上（静态属性），地形图的 `*` 已经标了。
  - **视野内已经包含地形**（每格第一位就是）；视野外的格画成 `?`，其详情一律不答——
    与"迷雾"同一条纪律，**地形不会比视野更宽**。
  - 逐格明细走 `query panel=land`（`cap=` 列几块 / `offset=` 翻页 / `filter=` 只看含某**建筑**或
    某**资源**的格，如 `filter=兵营`、`filter=耕地`）；单格全明细走 `query panel=tile x= y=`
    （或 `at=地名`）。
- **迷雾限眼不限手**：可以对视野外的格下 `mv`/`attack`——撞上隐藏的规则墙（中立领土、暗藏敌军、
  别人的战场）时引擎**如实报错**（这本身就是侦察所得的情报），但该军本回合的移动额度照烧作废；
  对看得见的格撞墙则不罚。侦察有料，但不白给。
- **事件按落盘时刻的视野快照过滤**：你后来夺下的土地上发生的旧战报，不会事后凭空显形。
- **野人**：开局**全图每块无主地都驻一支野人**（自给自足、不主动攻击、不追击）——野人是地图的
  静态属性，不随谁看见、谁扩张而出现；守卫被杀后该格永久清空、不再重生。
- **没有「凭空拓荒」命令**：占地一律靠打（`attack`）；`mv` 只挪位置、不占地。

## 二、经济与能源

- **全国一本账**：国库（黄金）、粮食、木头、矿石、石油、装备、补给仓全部记在国家账上；
  建筑建在具体地块，但产出与消耗走国家储备。采集类建筑的建造上限 = 该地块该项资源的数值
  （资源分布与地形属性见 [`地图生成与资源分布.md`](地图生成与资源分布.md)）。
- **电网全国且不可存储**：能源厂发电；补给厂/装备厂/兵营/市政厅要耗电维持（数值见建筑表）。
  发电量 < 维持需求时，这些高级建筑**全部停摆**——工厂不投料、市政厅不产金、兵营不能征兵
  （军屯不耗电，民兵照征）。
- **补给仓**：军队的口粮，每军每回合按兵种消耗（数值见兵种表），**不分地块**（远征一样吃仓）；
  仓空则每军按缺口比例扣血，可能饿毙。例外：民兵驻在自家军屯格不耗补给（每座军屯覆盖本格一支）。
- **黄金**：货币。黄金矿场稳定产金；市政厅每回合按本格建筑密度产金（地越盖越值）；
  也可以在世界市场卖物资换金。

几条不便进表的补充：

- **外交中心**：自建有名额上限（见表），**叠加只能靠抢**——夺下他国外交中心所在的地块，它的
  减半效果就归你。

- **军屯**：**纯民兵编制，不产粮**（全国民兵总数 ≤ 全国军屯总数）；不耗电，
  电网停摆时仍能征民兵。
- **兵营**：占用建筑位有门槛（防裸地兵营），且征召要求电网正常。
- **在建**：在建期间不产出、不耗电，但已经占住建筑位。

- **番号**：各国独立编号、从 `1` 递增、阵亡不回收（`秦·步三军` 永远指同一支军队，跨回合引用
  不歧义）；引用时一律以最近一次查询到的军队面板为准。<!--lint-ok-->
- **征召**：步/骑从有兵营的地块征召，民兵只能在自己军屯征召（产量与耗材见上表）。
- **合法目标**：野地（含野人驻守格）/ 自家 / 盟国；**敌国领土一律不能 `mv` 进入（空格也不行）**，
  进占只能 `attack`；交战中不能移动，必须先 `retreat`。野地上有与你交战的敌军（含正在打野的
  敌军）时也不能 `mv`，只能 `attack`。
- **`attack` 与 `mv` 共用同一套逐格判定**（同样的移动力与地形代价）⇒ 隔着一道山地/森林打不到，
  借道别人的地界也冲不进去——没有"跳过去直取纵深"这回事。目标格上**没有任何守军时，
  `attack` 直接进驻占领**。
- **战斗**：冲入即交战；此后每个回合结算掷骰打一轮（骰面修正见下），战争打几回合很正常。
  每方各掷各的骰，伤害受守方**地形防御与城堡防御相乘**修正（叠不到无敌），总伤害分摊到对方各军；
  **攻方站在敌国地界上吃不到防御加成**。
- **谁挨打谁是守方**：未参战的和平驻军（含野人）被攻击时吃本地减伤，格主永远算守方；
  交战中的进攻方一律不吃。
- **不抢别人的战斗**：野地上有「与你非敌也非盟」的一方正在打野 → 你不能插足（只能旁观或等它
  打完；想插手先宣战）；敌人或盟友在打野 → 可以参战，各打各的敌人（三方混战）。
- **占地按索取顺序**：野人清空且格上无活敌后，**第一个** `attack` 的一方占地（它若阵亡，
  则顺位给最早入场的同盟者）；和平驻守的第三方不占地也不参战（占地后回合末自动遣返）。
  敌国领土同理：多国围攻同一座城，守军清空后也归第一个进攻方。
- **撤退**：交战中（含防守方守军）要离开战场一律用 `retreat`——耗移动、本回合末随战斗结算
  （伤害全场分摊；防御方撤退减伤、撤退军输出大幅削减，数值见下），结算后自动脱离。
  撤退固定只能退相邻格（不看兵种速度），目标限己方/同盟/无人荒地；四周无合法撤退点则撤不了。
- **弃城即陷**：守军全撤或全灭时，围攻方自动接管（不必再补一刀）。
- **不回血的情形**：交战中双方（含守军）一律不回血；断粮的军队也不回血。

## 五、外交

关系状态：**中立**（不能入境、也不能互相攻击）/ **交战** / **联盟成员**（互通领土、互不攻击）。

### 签约主体：外交实体

本作**只有两种外交实体**：

- **独立国家**——不在任何联盟里的国家，它自己就是实体；
- **联盟**——由成员组成的整体，以盟主为对外代表。

**在盟的国家不是实体。** 在**条约与战争**这两件事上，**联盟内部的国家不是参与对象**：

- 它签不了、也撤不了任何条约——`guarantee`（保障独立）、`propose`（共同防御）、`break_defense`、
  `declare_war`、`offer_peace` 调用后**一律转为联盟投票**，通过后由联盟以实体身份执行；
- 别人打它 = **打联盟**，全盟一起应战；
- 别人保障它 = 保障的是**整个联盟**（谁动它，面对的是全盟的兵锋）。

由此得到**联盟外交的必然一致性**：一个联盟对某个外部实体，只有"和平 / 交战 / 有某条约"
**一种**状态。不存在"盟主与王五开战、成员李四与王五议和"，也不存在"盟员甲与某国签了保障、
盟员乙不知道"。外交上，联盟是一个**不可分割的单元**。

（唯一例外是**非约束动作**：写信 `send_letter`、馈赠 `gift`、换图 `share_map`、间谍 `spy`
仍归国家自己——那是通信与物资，不是对外承诺，不会把全盟拖进任何义务。）

### 联盟是「星形」，不是「链条」

关系只挂在**实体 ↔ 实体**之间，形状是**星形**：

```
       外部实体 A          外部实体 B
            │                   │
        ┌───┴───────────────────┴───┐
        │         联  盟            │        ← 对外只有一个点
        │   盟主 ●                  │
        │   ／  │  ＼                │        ← 内部是"成员─联盟"，彼此无双边条约
        │ 成员 成员  成员            │
        └───────────────────────────┘
```

- **成员与成员之间没有双边条约**，联盟内部也不存在"我保障你"这种关系——盟内互通领土、互不攻击、
  互卫是联盟**自带效果**，不需要签、也没有对应的约可撤。
- 所以**传导不会在联盟内部形成链条**：传递闭包只在**实体之间**扩散
  （联盟甲保障独立实体 B、B 又与联盟乙有共同防御 → 打 B 时甲、乙都上）。
  联盟内部永远收成一个点，不会经由某个成员把盟外国家串成一串。
- 推论：**想改变联盟的对外关系，只能走联盟投票**，没有"私下和某个成员谈好"这条捷径。

### 条约 ≠ 盟友

三个概念必须分清，别混：

| 关系 | 是什么 | 不是什么 |
|---|---|---|
| **联盟成员**（同一实体） | 互通领土、互不攻击、共享视野、外交免费 | — |
| **共同防御** | 两个实体**互相**承诺：**谁被打，另一方就自动参战**（**双向互保**） | **不是盟友**：不互通领土、不共享视野、不共同行动；而且**你可以主动打它**——宣战即自动解除该条约 |
| **保障独立** | **单向**承诺：保障方承诺"别人打你，我就参战" | **不是盟友、也不是互保**：被保障方对保障方**没有任何义务**；保障方不因这条约获得通行权、视野或任何盟友待遇；条约可单方面撤回（在盟者须联盟投票） |

两条容易被误读的要点：

- **共同防御是双方互保行为**，不是"我保你"。签了之后 A 被打 B 上、B 被打 A 上，完全对等
  （实测：赵打秦则燕参战，赵打燕则秦参战）。
- **保障者不是盟友，只是保障者**。它只承担一个义务（你被打我参战），不获得任何权利，
  也不代表它站在你这一边打仗以外的事上。

缔约双方的**组合不限**：国↔国、国↔盟、盟↔盟都合法。联盟对联盟缔约要**两边各自过自己的
联盟投票**——一方通过只算发出邀约，另一方还要再投一次才生效。

### 宣战、传导与战线

- **宣战**：对方必须应战，即刻生效。**交战方是实体**：在盟国家调用宣战会自动转为联盟宣战投票。
- **战争传导（无限跳，以实体为单位）**：打某个实体，它的**保障国**与**共同防御伙伴**按传递闭包
  自动参战（A 保 B、B 与 C 共同防御 → 打 B 则 C 也上）；**打盟员 = 打联盟，全盟一起上**。
  防守义务优先；联盟成员永不会被拖去打自家盟友；已与攻方或守方交战的第三方不会被重复收编。
- **战线**：宣战方 = 进攻主导，被宣战方 = 防御主导，自动参战的是跟随方；若目标正与你方盟友
  交战，宣战会**并入其现有战线**当跟随方（不开平行战争）。
- **同战线是硬保证**：联盟全体成员**永远在同一条战线的同一侧**——不会出现"一半成员在这次战争里、
  另一半在对面"，也不会出现盟员之间互相开战。
- **议和只看谈判代表**：每侧代表 = 主导者（有联盟时 = 其盟主）；普通成员与跟随方不能单独议和；
  主导者议和则整条战线（含跟随方）一起停战。求和可以是赔款、索款或白和，休战回合数由双方约定；
  赔款在接受时校验国库。
- **战争期间条约冻结**：**既不能缔结、也不能解除**（保障独立 / 共同防御的缔结与撤回、
  加入或缔结联盟、退盟、解散联盟全禁）。连同下章的「战时锁死」，
  一旦开打就**没有"打不过就跑"的通道**——想脱身只有议和（或被灭）。
- **灭国**：一方亡国后全天下强制休战若干回合（见节奏表），休战期内不得宣战——防连环征服。

### 联盟投票与「弃权」

宣战、议和、保障独立、共同防御、入盟——**联盟的每一次对外承诺都要联盟投票通过**。

- **谁能提**：任何成员都能把议题提上桌（`declare_war` / `guarantee` / `propose` 等调用即发议题）。
- **怎么算**：**赞成 > 反对即通过**（弃权不计入分母）；**盟主投 no = 一票否决**，议案立即作废；
  票数已无悬念时（未投的全投反对也追不上）**提前定论**。
- **弃权是什么**：投票只发生在**你自己的回合**里（用 `vote` 表态）。
  **在你的回合里不投票、直接结束回合（`end_turn`），这次表决你就等于弃权**；
  也可以明投 `abstain` 表示弃权。到期末投的一律按弃权计。
  换句话说：**沉默不是反对**——但你放弃的这一票，会以"分母变小"的方式让赞成方更容易通过。

### 情报

- **间谍 `spy`**：花固定价派往某国，若干回合后拿回**那个国家的情报**——它的经济底细
  （国库 / 收入结算 / 全部地块建设）、粗略军情（**只给各兵种数量**，位置与血量不外泄），

  这是"我告诉你我掌握什么"，与间谍的"我去偷你的"正好相反；两者都进同一个 `intel` 池。

## 六、联盟与核心领土

联盟不是"一张条约网"，而是一个**整体**：成员之间的关系全部经由联盟本身（**星形**），
成员与成员之间不存在双边条约（见上一章）。

- **立盟**：`bloc_found` **必须起名**（长度与字符限制见表）并邀请创始成员，**全体创始成员接受**
  才成立（任一拒绝即流产），**发起方自动成为盟主**。一国同时只属一个联盟。
- **入盟**：`bloc_join` 申请，现成员投票——**赞成 > 反对即通过**（弃权不计入分母；不投 = 到期算
  弃权；票数已无悬念时提前定论）。**入盟即放弃个人条约**：该国原有的保障 / 共同防御一律作废
  ——入盟后它不再是签约主体，留着那份条约等于指向一个不再存在的实体。
- **盟主**：联盟的对外代表——对任何联盟投票**一票否决**、可改盟名、可移交盟主、可解散联盟；
  代表联盟提出 / 接受议和，接受或拒绝外部邀约；**盟主不能退盟**（想脱身只能移交或解散）；
  盟主亡国由最早加入的剩余成员继承。
- **退盟**：普通成员单方面退出，无须任何人同意（滞留在前盟友领土的军队回合末自动遣返）；
  只剩盟主一人时联盟自动解散。
- **⚠ 战时锁死**：只要有一名成员正在交战，全盟**不准退盟、不准解散**——锁到整盟停战为止
  （先议和）。盟主也不能借此脱身。这是**刻意**的：联盟是"同生共死"的承诺。
- **盟内效果**：互通领土（合法通行与撤退地）、互不攻击、共享视野、成员之间的外交动作免费
  （写信例外：起步价减半，仍按字数计价）。
- **外交一致性（硬保证）**——外交上联盟只有一个点、一种状态：
  - **同战线**：全体成员**永远在同一条战线的同一侧**，不存在"一半参战、另一半旁观或站对面"；
    一个实体在一条战线上只有一个身份。
  - **条约一致**：联盟对外签的每一份保障 / 共同防御，动用的都是**全盟**的义务；不存在
    "某个成员被条约排除在外"，也不存在成员私下另签一份。
  - **动作一致**：宣战、议和、缔约、入盟全部过**联盟投票**，通过后由联盟统一执行。
- **进攻战争必须联盟投票**（通过后全盟参战，盟主为进攻主导）；防守自动参战、无须投票；
  盟主发起或接受议和也须投票。
- **核心领土**（`land` 面板的 ♥ 标记）：每次战争结束按参战各国实际持有重算（议和即对现状追认）；
  同联盟且同战线的盟友夺回你的核心领土会**立即自动归还**（驻军原地不动）；不同战线时占领者
  可以留下。

- **成交按「沿曲线均价」结算**：一笔单子让市价从成交前的价格走到成交后的价格，成交价取两点
  中点——不是整笔按最差价结算。买推高、卖压低，大单会自己把市价推走，分批慢慢卖更划算。
- **买卖价差**让翻转套利必亏（做市有成本）；**深度随现存国家数缩放**——国家越多，
  单笔买卖对市价的冲击越小。
- **均衡价由全世界本回合的产/耗流量决定**（含产出、工厂投料、征兵耗料、建造耗木、能源厂燃料、
  军队补给；**市场买卖本身是纯流通、不进流量**），并夹在基准价的区间内。全世界都开农场则
  粮价长期走低；战事一起，装备与补给涨价。市场面板直接显示均衡价。
- 粮/木是**内需品**（价低量大、建筑回本慢）；靠外贸赚钱卖**矿/油/装备**。

## 八、经济报表

每国每 `REPORT_EVERY` 回合**自动**结一期（值见节奏表）。**出表那一回合，报表全文进该国状态
面板**，其余回合只留一行摘要（省上下文）；历史期与跨期趋势用 `report` 工具查（免费、只读）
——**不能手动运行**，也不能补做历史期。

一期覆盖最近若干回合；**GDP 与军费是结报那一回合的 run-rate 值**（不除天数、不攒期累计），
投资 / 贸易 / 资产是整期值，全部按当时市价折算：

- **GDP（本回合）**：生产增加值（市价，**不含军费**）＝ 采集/工厂产出 ＋ 金矿与市政厅的金
  − 中间投入 − 能源燃料。
- **军费（本回合）**：军队**实际吃掉的补给** × 现价（不看来源，自产与外购一视同仁）。
- **军费占 GDP**；**财政收入** = GDP − 军费（为负会标注"靠卖库存 / 吃老本维持"）。
- **国家总资产**：全部建筑的重置成本（造价金 ＋ 木×现价，含夺来的地）；**本期投资**：
  本期建造实付（含城堡升级与各类折扣修正后的真价，不含征兵）。
- **外贸 / 内循环**：买卖总额 ÷（自产 ＋ 进口），其余部分即内循环。
- 每期报表都印同一句双刃剑警示（军费过高挤压投资、过低则成待宰羔羊）——程序**不做阈值判定**，
  具体数字自己权衡。

## 九、国策、回合与存档

## 十二、终局结算

对局结束后（或中途想看看）：

```bash
python3 settlement.py              # 打分 + 结算厅
python3 settlement.py --no-chat    # 只打分
python3 settlement.py --table      # 只看成绩单
./settle.sh                        # 一键（Windows: .\\settle.ps1）
```

| 结算项 | 口径 |
|---|---|
| 排名依据 | **总消费 = 建造 + 征兵 + 军费**（全部按**当时市价**折金） |
| 不计入总消费 | 市场买卖、馈赠（买来的物资在被消耗时才入账）、**存货**——囤而不用的垫底 |
