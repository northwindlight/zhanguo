## 一、一局游戏

**第一条　适用。** 本规则适用于国家玩家。人类、LLM及规则AI使用相同的世界规则、命令权限和信息边界。观察者权限不属于玩家权限。

**第二条　术语。**

| 术语 | 定义 |
|---|---|
| 世界回合 | 全部现存国家各完成一次行动阶段，并完成一次统一结算 |
| 国家行动阶段 | 一国在本轮中提交命令的期间；各国轮流进行，先手按世界回合轮转 |
| 外交实体 | 独立国家或联盟；联盟成员不另作为外交实体 |
| 地块归属 | 地块的国家所有者；无所有者的地块为无主地 |
| 核心归属 | 领土归还规则使用的归属标记；不等于当前所有者 |
| 国祚 | 一国拥有的已落成市政厅；在建市政厅不计入 |
| 已提交 | 命令已登记，预定效果尚未生效 |
| 已生效 | 命令的实际结果已经写入世界状态 |

**第三条　收尾。** `end_turn`仅结束本国行动阶段。全部国家完成行动后，方进行世界结算。一次模型请求可以包含多条命令；模型请求上限不等于命令条数上限。

**第五条　开局投递。** 进入下一世界回合时，先递增回合号，再依次处理到期信件、馈赠、地图和间谍任务，随后开始国家行动。

**第六条　时间边界。** 休战记录须注明起止回合。标为“至第N回合（含）”的休战，在第N回合仍禁止宣战，下一回合解除。任务送达、投票截止及贷款到期均须注明对应回合与阶段。

**第八条　取得领土。** 调动不改变地块归属。夺取无敌且可占领的地块，立即进驻并取得归属；夺取有敌地块，先进入交战，胜出后判定归属。建筑随地块归属转移；不存在拆毁建筑命令。

**第九条　占领索取。** 归属候选须为仍在场、未下令撤退且与格上其他存活势力没有交战关系的进攻方。候选按进入战斗的索取顺序接管；先入场方无存活且不撤退的军队时，顺延至下一候选。和平驻军不因驻留获得领土。

**第十条　存亡看市政厅。** 在亡国阶段，一国没有任何已落成市政厅即亡国。此前夺回或取得已落成市政厅的，不亡国；本轮新建但尚未落成的市政厅不能阻止亡国。停电不改变已落成市政厅的国祚资格。

**第十一条　亡国清理。** 亡国者军队解散；剩余领地成为无主地，原建筑保留，原核心主张作废。清除其在局状态，保留终局重建所需的长期记忆、回合小结、阶段归档及政体身份。亡国事实公开。
