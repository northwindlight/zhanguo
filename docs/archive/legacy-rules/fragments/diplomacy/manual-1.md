## 五、外交

**第三十五条　提交与生效。** 国家间外交在行动阶段提交，在规定的回合末阶段处理。命令结果须为已提交、已生效、失败或取消之一；待执行请求不得显示为正式条约或战线。

**第三十六条　外交主体。** 宣战、议和、休战、保障和共同防御以外交实体为主体。对联盟成员的外交目标解释为该联盟。写信、馈赠、地图分享及间谍仍由具体国家执行。

**第三十七条　关系。**

| 关系 | 权利与义务 |
|---|---|
| 中立 | 不得入境，不得攻击 |
| 交战 | 可按军事规则进攻；调动仍不得进入敌方领土 |
| 同联盟 | 互通领土、共享视野、不得互攻；同战线核心地按归还规则处理 |
| 共同防御 | 任一签约实体被宣战，另一方承担参战义务；不附带通行或共享视野 |
| 保障独立 | 保障方承担被保障实体遭宣战时的参战义务；被保障方无对等义务 |

**第三十八条　宣战与传导。** 独立实体宣战无需对方同意。被宣战实体的直接保障方和共同防御伙伴自动参战；援军自身条约不继续传导。联盟整体计作一个实体，被攻击时全盟同侧参战。

**第三十九条　名单。** 参战名单在宣战生效时确定，后续推进、反击或夺地不重新触发条约。休战阻止宣战及把签约方拖入战争的自动参战；休战义务优先于保障和共同防御，并通知相关方。

**第四十条　战线。** 进攻与防御各有主导者，义务参战者为跟随方。目标与同阵营既有战线相匹配时，按既有战线规则并入，不建立重复战争。联盟成员不得分列同一战线两侧。

**第四十一条　议和。** 各侧仅由主导实体的代表提出或接受议和；联盟代表须经投票。跟随方不得单独议和。议和包括白和、付款或索款；接受时核验付款能力。议和生效后整条战线终止、参战军解除交战，并按实际占有重算核心。

**第四十二条　冻结。** 战争期间不得缔结或解除保障、共同防御，不得立盟、入盟、退盟或解散联盟。开战使战前未通过的缔约、入盟投票及立盟提议作废；宣战与议和议案不因此作废。

**第四十三条　强制休战。** 亡国触发全部现有国家战争终止，并为现存外交实体两两设置强制休战；无关战线亦终止。在途外交事项，包括求和及全部投票，取消并通知当事人。休战只禁止宣战及受其阻止的自动参战，不禁止和平缔约。

**第四十四条　和约归属。** 联盟和约属于联盟，移交或继承盟主不改变和约。成员个人和约在盟内暂停，退出或联盟解散后按原截止回合恢复；已过期的不恢复。新增和约只能延长有效截止，不得缩短。成员个人保障和共同防御在入盟时作废，不随退盟恢复。

**第四十五条　视野。** 可见地块由本实体领地、相邻一圈及本实体瞭望塔覆盖范围组成。联盟成员共享视野。可见不等于可达，可达不等于可占领；玩家可向视野外下令，但承担军事命令的盲探规则。

**第四十六条　建筑与军情。** 自有地块公开完整资源、建筑及在建情况；可见他国地块仅公开城堡和市政厅，不公开其余建筑和资源。可见无主废墟公开遗留建筑。可见军队与未知军队不得混为同一统计；看见的市政厅不代表对方全部国祚。

**第四十七条　事件。** 事件写入时确定知情国家，后来获得视野不补发旧事件。正式条约、宣战、议和、联盟变化及亡国公开；信件、情报、提议与表决过程只对有权当事人可见。当前状态只陈述事实，不把历史判断或策略解释写成规则。

**第四十八条　通信。** 信件、馈赠及地图在发出后的下一回合开局处理。馈赠发送方扣出物资，收方存活则到账，收方亡国且发送方存活则退回。送达或失败均须留存结果并通知当事人，不因双方亡国而静默丢弃。地图为单向发送，保存发出时快照，不自动要求对方回图。

**第四十九条　间谍与报表。** 间谍在到期回合取得目标当时的经济、外交、建筑及地图情报；军情仅给兵种数量，不给军队位置、HP或番号。目标已亡国则任务失败。经济报表摘要仅公告本国；别国明细须购买。购买报表不是获取当前实时状态。
