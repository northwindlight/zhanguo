# 战国 0.7.0 试玩版

两版单机改进的第二版，补齐正式生产队列、鼠标持续军令、地图规划和经济入口。仍为单机一位真人与AI混合，保持原18阶段结算；联机暂未加入。

- 建筑／征兵队列入队预付、锁价并预占容量，跨期推进、随档保存。未开工取消全退，在建拆除退50%，完工拆除不返还。
- 军队支持跨驻地勾选与脚底光环；右键移动、Ctrl右键攻击、Shift追加多个移动／攻击节点。持续路线与回血等待在右栏标记；低于30生命时暂停，正常补给恢复满血后继续。
- 明确选择原生版／实验版；议会、脚本沙盒和规则AI战斗推演分别实际启停。读档沿用原档规则，已知旧档可升级为新副本，保留原档及历史。
- 新增简易地形图／图例、真实空位组合筛选、紧凑地块状态图标和建设费用分项。支持右键返回上次操作，以及游戏内指南。
- 独立银行入口展示正式授信、手续费、现金、债务、当前利率和剩余期限；借款需确认，到期沿用正式自动扣款。
- 本国十期经济报表免费进入邮箱并提醒，可查看完整内容与历史。已读状态按对局保存；他国报表只在正式购买后进入邮箱，购图／派谍入口保留。
- 修复灭国后旧地图残留国色，保留历史日期和视野权限。防御显示与自动交易校验复用规则层，演出采集减少重复面板查询。

完整解压`zhanguo-0.7.0-windows-x64.zip`，双击`Zhanguo.exe`，无需安装Python、Godot或.NET。附同提交源码ZIP和`SHA256SUMS`；由CI完成离线与Windows实际窗口验收后公开为Pre-release，试玩确认后再转正式。

本版含生产队列／持续军令的状态与依赖变化，旧包存档不能直接混载。存档列表对已知v0.6.3及支持的开发版提供“升级为新副本”；未知依赖仍拒绝，请保留旧版程序和原档。邮箱已读记录保存在存档旁的`.desktop-mail.json`，不改世界状态；搬动存档时可一并复制此文件。
