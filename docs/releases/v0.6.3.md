# 战国 0.6.3 试玩版

本次是两版单机改进的第一批，先修正军令规则和交付流程。

- 修复敌国地块上另有中立国家参战时，真人界面误拦截合法攻击。
- 修复已移动部队的合法原地攻击被按钮置灰；行动资格由规则侧投影到界面。
- 修复本国土地正在受攻击时，候选错误阻止其他军队进入。
- 真人候选与正式军令共用加权寻路、夹角限制、目标与行动资格规则。已探明路线按逐格路径演出；未知路线仍是不确定尝试，不提供全图路径。
- 瞭望塔每格最多一座，包含施工中。旧存档原有多塔保留，新增受限，视野不叠加。
- 新版本由 CI 完成离线回归、文档、C#、Windows 实际窗口与便携包验证后直接发布预发布，附同提交源码和 SHA-256。

完整解压 `zhanguo-0.6.3-windows-x64.zip` 后双击 `Zhanguo.exe`。无需安装 Python、Godot 或 .NET。

生产队列、Shift 连续军令、跨驻地鼠标选军、选中光环及其他界面改进安排在第二版（0.7.0）；本版仍为单机单人，保持原18阶段结算。灭国旧国色反馈已加入合成局回归，但尚未复现全部实机情况，继续跟进。存档格式与模块版本未变，依赖检查保持。

这是试玩版，确认体验后再转正式发布。
