# 战国 0.7.1 试玩版：规则AI v14联合经济规划

新局可以选择v14候选经济层，用混合整数规划联合安排建设、交易、原料、电力、军需和已知还款。默认仍为v13，保留v11plus供对照，旧存档继续使用记录的策略版本；不把旧局自动升级成v14。v14是AI版本，游戏包版本为0.7.1。

- 每次行动同时规划多块土地与多个后续周期，只执行本期方案，再按实际库存和回执重算。工程院折扣、施工额度、资源共享位和预付队列占位使用正式规划。
- 生产、电厂燃料、全国缺电、工厂争用原料、自动供粮与恢复共用同一套数学约束，不能虚构提前投产、免费原料或自主少吃补给。
- 先求本期可达到的运营服务水平，再约束长期投资不得使它恶化。长规划未取得可行解时使用一期联合运营方案，并记录诊断。
- Windows便携包内置锁定版本的NumPy／SciPy及许可证，完整解压后双击即可；源码运行需在项目虚拟环境安装`requirements.txt`。

求解比v13慢。默认显式窗口4期，纳入原生贷款近期到期；每层最多8节点／5秒，经济层允许2%相对间隙，达到上限时使用经过检查的可行解。未来市场价格和产能延续价值是预测假设，不能将模型目标当作真实利润或全局最大复利；短局对照不等于长期胜率。纯经济样本已改善，但带扩军的综合开局尚未稳定超过v13；本次不将候选策略直接设为默认。

仍为单机一位真人与AI混合，保持原18阶段结算。地块大面板、军队面板重排和真人经济托管属于后续UX工作，本版没有接入托管开关。

本次规则模块状态与依赖版本不变，可继续读取匹配规则的v0.7.0存档；更旧的支持范围仍通过“升级为新副本”处理，未知依赖继续拒绝。下载包、源码ZIP与`SHA256SUMS`在同提交CI验收成功后自动发布为Pre-release，试玩确认后再转正式。实现与验证见[v14复核](https://github.com/northwindlight/zhanguo/blob/v0.7.1/docs/reviews/v14联合经济规划-20261029.md)。
