## 1. 未占领地块的地名向玩家暴露

### 口径

- 地名是**地图的属性**，不是地块的状态：由 `(seed, size, x, y)` 纯函数决定，未物化的格子也有一份，不进存档。这一点保留。
- **未占领的地块不向玩家暴露名字**：玩家侧的 `view` / `tile` / 状态地图 / 回执渲染，只在**已有主**的地块上给地名；无主（含未物化）一律只给坐标。名字可以存在，但不出现在玩家拿到的任何字段里。
- **名字不是句柄**：解析地名时按同一条口径收（见"要改的地方"），未占领之地只能用坐标指。

### 代码现状

**名字表**：`mods/native/map_generation/names.py` 的 `name_grid(seed, size)` 按规范扫描序给每一格一个唯一名字，前缀 98 × 后缀 82 = 8036 组合，撞名加序号；是 `(seed, size, x, y)` 的纯函数，不受 `PYTHONHASHSEED` 影响。

**没有默认铺地**：`Territory.initialize_world`（`mods/native/territory/mod.py:16`）只建 `Territory` 对象，不生成地块。未占领的格子由 `Territory.cell(x, y)`（`mods/native/territory/objects.py:74`）临时合成 `Tile('', x, y, terrain, None, cell.name)`——id 为空串，查完即弃；只有 `create` / `create_claim` / `transfer` 才落一块进 `_tiles` 与存档。

**名字不进存档**：`territory/objects.py` 的 `Tile` 带 `name`，但 `to_save()` 只写 `id / position / terrain / core`；读档用 `map:generation cell` 从地图读回。

**暴露面——视野内每一格都给名字，与是否占领无关**：

| 位置 | 现在 |
| --- | --- |
| `mods/native/vision/mod.py:41` | `VisibleTile((x,y), fact.tile.name, …)`：视野里本国/他国/无主/野人每一格都带名字 |
| `mods/native/army/mod.py:148` | `tile` 载荷 `{'position','name','terrain','owner',…}`，工具说明写的是"返回可见单格详情（**含地名**）" |
| `mods/ui/views.py:66` | 模型状态地图行 `if row.get('name'): out.append(row['name'])`，无主地归入【野人】段照样打名字 |
| `mods/ui/receipts.py` | 回执渲染经 `remember(observe)` 拿到同一批名字，`pos()` 打「名(x, y)」 |
| `mods/native/observer.py:35` | 观察者地图也带名字：旁观面，玩家提交不到（`observer_snapshot` 不是玩家动作），不算暴露 |

**同一个结构里两套口径**——资源与建筑明细按归属门控，名字没有门控：

```python
# mods/native/vision/mod.py:41
VisibleTile((x,y), fact.tile.name, fact.tile.terrain, fact.owner, tuple(kinds.items()),
            fact.resources if fact.owner==actor or fact.owner is None and fact.tile.id else ())
#                          ↑ 无条件                       ↑ 资源：本国，或无主且已物化
```

```python
# mods/native/army/mod.py:145（tile 工具）
full=fact.owner==actor or fact.owner is None and bool(fact.tile.id)
result={'position':(x,y),'name':fact.tile.name,'terrain':…,'owner':…}   # ← name 无条件
if full: result.update(resources=…, capacity=…)                          # ← 明细才门控
```

工具文案也按这个口径写过：「他国仅公开建筑和归属，不泄露迷雾或资源」（`view`）、「本国及物化无主遗址显示资源、容量、施工与建筑」（`tile`）——资源被点名保护，名字没被提到过。

**名字是全局句柄，解析不看视野**：`territory.resolve(text)`（`mods/native/territory/objects.py:65`）对非坐标串直接调 `map:generation where(seed, size, text)`——纯地图函数，不查视野、不查归属。同一段里坐标串只认「`x y`」与「`x,y`」两种写法。

### 0.1 语义

`git show v0.1:game.py`（第 187 行附近）：`"""随机生成一个不与现有地名重复的地块名。"""`——名字是**地块的属性**，**实例化时才起**，随地块进存档。未占领的野地没有名字：名字是"占下来的地方才有"的东西。

### 变更点

`8247946`（2026-10-14「恢复地名表，并修正征召报错与造价口径」）把名字改成地图属性并铺到未物化格子，同时把这件事写进了三处：

- `names.py` 模块注释：「未物化的格子同样有名字——"有名字没守军"这才是可读的侦查信号。」
- 该提交信息：「地名回到地图上……未物化的格子也有名字，所以"有名字没守军"这类侦查信号重新可读。」
- CHANGELOG 同款措辞。

要读的侦查信号应该是"**占领了才有名字**"（占没占一目了然），不是"未物化也有名字"；后者让野地在玩家面前变成有名有姓的实体，且与同结构里资源/建筑的门控口径自相矛盾。

### 不动的部分

- 名字表本身、名字不进存档、观察者地图带名字（旁观面）。
- 已占领的地块继续带名字——0.1 语义就是"占下来才有名"。
- `native:tile/{x}-{y}` 这种 id（占领来的格子，id 不随归属变）不额外处理：回执渲染认不出就照原样回显。
- 已修的显示问题（`pos()` 认坐标串，`0aab9a0`）与本文口径一致：未占领之地只剩坐标可显示，缺了它日志里那块地就空着。
