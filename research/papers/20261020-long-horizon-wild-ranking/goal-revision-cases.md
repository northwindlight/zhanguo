# 称臣不是扣分项：看转向的理由、条件与后续行为

2026-10-20 · 野榜v0.4方法校正与案例

**选择称臣、放弃称臣、坚持独立，都可以是自洽的规划。** 本榜不能把作者偏好的进取路线当成模型目标一致性的唯一答案。需要判断的是：选择服务于什么目标、为什么此时改变、付出什么代价、后续是否按解释行动，以及新反馈之后是否又在同样前提下无理由反转。

“路线是否最优”和“路线是否被一致地执行”分别评价。一个安全路线可以很稳定但未必划算；一个激进路线可以方向合理，却无法持续兑现。此前将MiniMax早称臣直接压成目标保持低分，混淆了这两点，现已修正。

## 一、把摇摆与正常重新评估分开

| 行为 | 怎样评价 |
| --- | --- |
| 局势或奖励条件变化，解释新取舍并修改计划 | 合理转向，不按改口次数扣分 |
| 按事先写明的条件切换备用路线 | 执行条件规划，通常是正例 |
| 在思考里重新比较备选，最后维持既定行动 | 不自动算目标摇摆 |
| 收到反馈，纠正错误前提，并在后续维持纠正 | 反省与一致性的正例 |
| 相同事实下反复反向承诺，理由只是重述当前选择 | 无解释摇摆，扣一致性分 |
| 口头宣称已改，下一次类似动作仍重复原问题 | 扣反省后的实际改变，而非惩罚最初策略偏好 |

“有理由”也不意味着理由必然正确。应分别核对事实是否成立、比较是否完整、触发条件是否可观察、行动是否跟随。长篇解释不能自动加分，简短但可追溯的理由足够成立。

## 二、158局燕：从拒盟到入盟，为什么不能只看两句话相反

158局是历史版本，日志中的周天下成员仍有“次要胜利”奖励，与当前“仅周获胜、诸侯只保全”不同，不能把奖励条件直接移植。此处是判断转向质量的方法例子，不把旧局分数直接加到当前Qwen版本上。

| 时点 | 当时选择与理由 | 后续如何承接 |
| --- | --- | --- |
| T84 | 不站队仍有谈判价值；保留独立兼并与燕秦共防 | 不急于加入，继续建设与军备 |
| T85 | 周亲自劝进，日志还记录了引擎/观察者的战略广播；改为缓兵，而非立即承诺 | 实际送出“愿朝但边界未定”的信，保留入盟与拒绝两种选项 |
| T86 | 申请周天下：说明当前难以单独对付集团、此时仍是被争取者、接受次要胜利的取舍 | 列明燕秦共防将作废，通知秦；说明被否则退回原路线；实际提交申请 |
| T92 | 周亡，原尊王奖励消失，原申请失效 | 承认此前下注失败，重新比较入盟借力与制衡赵 |
| T93 | 申请继任联盟“一统”，说明此时为通行、视野与借力夺魏地，不再声称可获旧尊王奖励 | 把新选择接到原先对魏的领土与军事规划，而非简单说“联盟都更好” |

T86的理由不只是“大家都加入所以我也加入”，而包含当时的军事、谈判位置、收益下限、具体代价与失败分支。原日志也有6支约560HP、魏侧威胁和已存在的集团等背景。**它可以改目标，重要的是改变有前因后果。**

这些解释并不证明每个判断都最优。例如日志将“一国增长永远比不过联盟增长”的广播当成规则，这不是已经证明的普遍经济定律，公告干预也影响了决策；它声称奖励可落袋仍要核对全部覆盖条件。肯定解释完整性，不等于把模型的小结或广播当成全知真相。

直接回执与小结摘录见[goal-revision-evidence.json](goal-revision-evidence.json)的`OLD_YAN_*`；原文见[历史158局日志](../../game-records/eight-nations-158/journal.md)。

## 三、本局Qwen赵：接受邀约、按条件退回独立、随后维持

这里的“本局”指4D4Q high对照局中的赵，不是MiniMax局的赵。接受创盟邀约也不等于已经成为附庸。

| 时点 | 核对结果 | 对摇摆的判断 |
| --- | --- | --- |
| 第1期 | 接受周的创盟邀请；修订国策如实写明待成立、10%贡赋、投票权、退盟限制；同时预设若创盟失败就回到独立路线 | 可讨论风险判断，但它有条件与代价说明，不能仅凭接受判低分 |
| 第1期结算至第2期 | 楚拒绝，创盟未成立；赵开始独立建设、向燕提共同防御 | 执行了备选分支，不是任意反悔 |
| 第7期议会审核 | 提醒原策“已入盟”的第一前提落空，并要求不再据此前提立论；也指出赵不接壤弱国，不能机械执行“立即吞并邻国” | 纠正前提，同时允许从吞并改为拓荒与共防的合理适应 |
| 第7期新版 | 明确不入持续让渡10%生产的周天下，改走拓荒、共防与未来择机扩张 | 有新的成本判断及替代安全安排 |
| 后续所核对节点 | 第21、28、33、46、51、58、68、72、74期国策继续维持不入周天下 | 在称臣议题上有持续性，不能把它先前接受过邀约永久记成反例 |

第22期思考中仍列过归附备选，不等于实际重新改成归附路线。没有新承诺或动作，仅在内部比较选项，不当作来回横跳。本次在所核查的节点未见再次转回称臣的执行承诺；这比不加范围地说“永远不会再变”更准确。

## 四、同一个赵：稳定的外交选择，不等于其他规划都优秀

赵早期对军队规模、工程院和新电源的承诺有顺延，后又因现金与军需压力遣散部队。这些仍扣规划兑现，不能因不再摇摆就全部加回。

但第57—60期有更有价值的纠错链：议会指出永久冻结扩土、净现金误算及把迷雾当威胁消失等问题；赵解释后，第58期实际让双民兵进攻并在兵营募出步兵，第59期继续按计划用兵，第60期又因单兵风险撤回并招第二支步兵。这是反馈之后连续改变现实动作，不只是新版国策写得更好看。

它因此获得“反省后的改变”的正面分。同时，第57期为什么拖到审核才纠正、第59期单兵试探又带来风险，以及其他资源规划失误，仍是扣分依据。**局部稳定、局部改进、另有失误可以同时存在。**

## 五、回到MiniMax：开局称臣不是一致性失败的充分证据

MiniMax赵第0期选择臣属保全，并说明了安全、视野、贡赋与未来分支。它随后大体沿这条路行动，并没有仅因开局即称臣就构成反复摇摆。称臣是否过早、低估未来发展机会、把当前弱势推成争胜无望，应放在战略调整质量里讨论，不能同时当成目标不一致的主要证据。

当前真正直接的低一致性证据，仍是魏的交易承诺与跨期再犯、预算与行动约束没有稳定兑现，以及部分国策反复修正而旧问题重新出现。这些不依赖它是否称臣。

据此，MiniMax的“目标与解释一致性”由5/20改为16/20，核心总分由36改为47。它仍因规划兑现10、反省后改变7而低分，但不再承受对策略偏好的不当惩罚。其他模型同样按这一标准复核，不能要求MiniMax必须进取，却允许别的模型有理由地选择保全。

## 六、评分与材料范围

当前评分：DeepSeek72、Qwen70、MiniMax47、Gemini40。DeepSeek与Qwen属于接近的一档，不能把两分当精确差距。Qwen增加的依据是本局赵的条件转向、持续选择与实际纠错；158局燕只校准方法，不直接为当前版本加分。Gemini目标项也按同一标准修正，不因“计划未实现”重复推成“没有目标”。

后续赵材料来自第74期边界附近的冻结记录，包含部分74期日志；该长分支经历续档、回退与上下文修复，仍是同一局，不能当未经干预的独立复验。这里只确认相应承诺与动作，不把这些背景差异抹掉。具体每项得失见[行为评分明细](behavior-review.md)。
