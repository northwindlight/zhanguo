# 野榜 v0.4：如何比较不同长度、不同终局的对局

2026-10-20，v0.4。本方案是本项目拟采用的评价约定，不是已验证的标准基准。它解决的是比较口径，不会把不同版本、地图和对手的真实对局变成控制实验。

## 行为看反馈链，经济看宏观尺度

目标调整不等于摇摆。称臣与独立都可以有合理理由，应核对前提变化、成本与备选、后续是否维持；按条件改走备用路线不扣分。参见[158局燕与本局赵](goal-revision-cases.md)。

长程行为一致性不能等同于必须运行50轮。14轮里已经发生多次规划、执行、反馈与后续同类行动，就可以判断反省是否改变了行为。持续违背自己已经明确的承诺，是有效的低分证据，不需要再运行100轮确认。一次局部受挫则不能直接推成整体不一致，要检查原因、应对及修正能否维持。

行为归一化按相近的决策责任与反馈机会看轨迹：是否有条件执行，是否遇到新信息，原计划是否仍适用，为什么改，以及后来怎样做。不按每轮固定扣分，也不让长局单因暴露错误更多而受罚。跨局不足影响信心，但不阻止主观野榜对现有行为直接判分，详见[核心行为评分](behavior-review.md)。

消费指标则要求宏观、长尺度。借款支持的提前消费、透支库存和减少投资，可以在短窗口内抬高累计使用量，把偿债、供给收缩及未来产能损失留在窗口之外。短尺度可以刷消费分，不能据短期C值推断宏观经营质量。贷款到账本身不算消费，实际用途才计入；记账真实不等于长期能力解释有效。

50轮是本项目宏观经济表的第一个经验观察节点，不是行为评分的准考证，也不是自动消除借贷与截止期效应的保证。仍应检查建设回报、贷款到期与再生产调整，报告滚动窗口和期末债务，不偷偷把消费分改成净资产分。

## 同一个指标，比较同一个时间窗口

宏观经济表预先登记50、100、150轮节点，分别记录，不把它们混成一个分数。行为榜随已经出现的规划与反馈链更新，不受这些节点限制。本文“完成14轮”指第0—13期均结算完，以第14期开局为状态截面；若写“完成50轮”，应对应第0—49期结算完、第50期开局。旧资料若用“第50期结算后”，实际含0—50共51期，必须注明这一个周期的差别。

| 评价对象 | 对齐方法 | 本次能否做 |
| --- | --- | --- |
| 早期执行、成本 | 双方同为0—13期，按完整国别行动统计 | 能；不含MiniMax未完成的第14期 |
| 中长期经济 | 同为完成50、100或150轮，分别比较 | MiniMax只有14轮，不能 |
| 阶段增长 | 同一段，例如完成25至50轮的增量 | 本次不能据MiniMax估计 |
| 战略事件 | 同样标明事件发生回合、当时条件和可选动作 | 能做个案，不当通用胜率 |
| 胜负、终局原因 | 按真实事件及结束回合记录 | MiniMax是人工停止，无正式终局 |
| 跨局一致性 | 多个独立初始世界、位置、对手，保留各局轨迹 | 三者均缺少充分审核样本 |

不能拿一个模型14轮时的资产对另一个69轮；不能把“每轮平均消费”当成50轮累计消费的替代品；也不能用“已玩回合/最终回合”的百分比对齐，因为一局20轮结束与另一局100轮结束，未必经过相同发展阶段。

## 经济：统一期限、用途分类与价值口径

正式经济结果采用同一结算定义下的实际消费。设国家i完成H轮的累计消费为C_i(H)，取第0至H−1期已记录的征募、军事与行政用途价值之和，建设投资I_i(H)另列。本文使用已冻结的事件估值，不用今天的价格重估过去。

**不能直接把存档的`cumulative_spending`字段叫消费。** 当前经济报表该字段累计的是包括construction在内的支出；正式[结算程序](../../../settlement.py)单独汇总recruit、military、administration，排除construction。还要核对旧版本是否采用同样分类、记录是否完整、是否存在未估值资源。

本次离线提取同为0—13期的事件，采用上述三类，另用逐期`spending − investment`交叉检查，结果一致。这个检查验证了随文算术与分类的一致性，不是对所有实物来源的独立经济审计。

每个节点同时保留四种信息：C_i(H)原值、最近窗口增量、同局份额、同局名次。原值有经济意义；份额和名次只辅助判断在共同世界里相对做得如何。建设、GDP、债务、存货、领土和供给能力另列，用来解释路径，不代替消费。

同局份额可以写为C_i(H)/ΣC_j(H)，分母为0时不计算。若把同局名次r映射到0—1，可用(N−r)/(N−1)，并列取平均名次，N为开局参与国家数，保留亡国者。这只是显示尺度，不是消除了地图、种族特权、朝贡、对手强弱和生态差异。一个弱对手世界里的第一，不自动强于另一个世界的第二。

跨局比较仍要注明版本、货币制度、市场规则、种子和初始资源。价格内生不等于价值指标失效，但名义消费增长与实物数量增长也不是同一概念；必要时另列固定篮子的数量敏感性分析，不能悄悄改掉正式计分定义。出生位置差异优先靠多种子、换席位和成对实验处理，不能随手除以国土或建筑数，就声称公平归一化了。

**同回合只是必要条件，还必须满足足够长的宏观评价尺度。当前14轮消费只作核账及用途构成展示，不作为能力领先的反证，不发经济分。** 早期行政与招募支出、贷款消费、过度消费、投资兑现时机和运营约束，都可能让14轮截面与长期排序很不一样。上述解释与[消费指标论文](../../../docs/research/消费总量评测指标论证.md)第五节跨期取舍、第六节金融账户及第八节效度边界及第九节比较协议保持一致；不以这次短局检验或否定论文的宏观主张。

## 早终局、晚终局和人工停止分别怎么处理

| 情况 | 正确记录 | 不该做的处理 |
| --- | --- | --- |
| 20轮真实获胜 | 胜利、路径、结束回合；同时给20轮实绩 | 伪造后30轮经营，或因消费少判成弱者 |
| 20轮真实战败 | 战败、原因、此前轨迹 | 只按存活回合求高平均分，掩盖提前出局 |
| 一国早亡，但世界继续到50轮 | 记录亡国及实际已实现累计用途，按真实世界的50轮截面说明 | 为了平均成绩删掉亡国者 |
| 100轮才终局 | 给50轮共同节点，再另列真实终局 | 用100轮积累金额压过别人的50轮 |
| 第14轮人工停局 | 记录观察截止及停止原因；只评已观察部分 | 当正式战败、当20轮周已获胜、或外推成50轮资产 |
| 网络或环境故障 | 单列故障与续局关系 | 当模型战略失败，或把续档当独立新局 |

早获胜不应受消费期限惩罚，因为胜负与经济是不同结果；早称臣也不能因缩短总耗时而得到效率奖励。周独占胜利时，其他成员的臣属保全依然不是获胜。

MiniMax因体验差而被停，不是随机缺失。直接删掉这局只保留能跑长的对局，会美化体验；反过来补零到50轮也不公。处理方式是保留停局、耗时、失败案例和未完成节点，在“完成覆盖情况”中单列，不把未知50轮经济质量伪装成已测低分。模型导致的运行中止、操作者体验止损和基础设施故障应分别计数。

## 速度、token与有效决策

按同一窗口的完整国别回合，给出总用时、P50、P90、最大值与调用批次；同一模型有四国、八国时不能只比模型总时长。实际使用体验包含接入延迟和议会，若想比较纯模型解码则需要独立测量，不能把流式阶段全当解码，也不能把慢全推给排队。

token必须统一计数口径，君主、议会、修错、压缩分别展示，思考若已含在输出用量中只能计一次。没有可比用量就留空，调用次数不是token数量。

不采用“动作数/token越大越聪明”的机械指标：重复查询、失败重试和无价值交易都能刷动作数。应结合可核对的决策任务，例如是否解决一个真实供给缺口、是否执行了已选应急动作、是否在新证据后有效更新方案。确认规则不需要无穷推演；但有价值的深入分析也不能因文字长自动扣分。

## 排行榜怎么展示

现行核心榜直接给100分主观行为分：规划兑现25、反省后改变25、目标与解释一致性20、战略调整20、执行控制10。前三项70分评价行为一致性。速度、token、宏观经济与战争另外展示，不拿局部指标替代计划是否兑现的判断。v0.2只排错误与速度的办法已经撤回。

Gemini自己的51期轨迹可以支持对停滞、执行失约、断供的评分，不需要同局其他玩家开high。它可以与MiniMax14轮的行为作主观比较：看模式、反馈与修正，而不是按观察回合数换算扣分。经济数字仍必须同窗、足够长尺度比较，这两种要求不能混用。

未来合并多局时，优先平衡独立游戏，再平衡席位；不能让一局靠更多回合主导全部证据，也不能平均掉持续失败的国家。跨独立对局的覆盖、典型表现与较差轨迹单列。评分可依据后续行为修订，保留版本与理由。
