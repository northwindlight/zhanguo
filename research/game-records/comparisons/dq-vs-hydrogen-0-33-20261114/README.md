## 口径与核对

- 回合 t 的 GDP、当期消费，配该回合结算后、边界 t+1 的领土和军队。没有混入下一回合行动，也不计中断后重试留下的重复播报。
- GDP 按生产事实的历史估值计算：生产产值减中间投入与能源燃料。Hydrogen 局魏在第17回合亡国前仍完成了8金GDP的生产，因亡国后不再生成该国期末报告，本表从已入账事实中纳入这8金。
- 当期消费统一为征兵 `recruit`、军需 `military`、行政 `administration` 三类；排除建造投资、市场购货和生产中间投入。累计消费从第0回合起累加，亡国不抹去历史消费。没有把旧 `spending` 的四类总支出直接当消费。
- 军队含正规军和民兵的存活支数，伤兵仍算一支，不含野人；不是按生命值加权的军力。
- 经济明细取自存档及相邻 `native_economy` 归档，按事实ID去重。全历史费用与存档消费检查点逐类一致，存续国家逐期GDP/支出与原报表一致，没有按现在的物价重算过去。
- 领土和军队取自动打印的完整回合边界全景，排除手动查询。旧局第1—34边界的八国数据与议会原始状态差分逐项一致；Hydrogen第34边界与正式存档的领土和军队对象一致。

旧局最终存档在边界120，Hydrogen本次取样在边界34；完整来源摘要和检查结果见 `metrics.json`。两局种子分别为20261018、20261114，规则版本和议会配置也不同；本表记录两场实际对局，不把所有差异归于模型。

## 复算

先解压旧局公开的存档和审计，让 `session.json.audit/` 与 `session.json` 同级。使用各自的原始日志；旧局压缩日志可直接作为输入。

```bash
python3 compare.py \
  --dq /path/to/dq/session.json \
  --dq-journal ../../eight-nations-dq-120/journal.md.gz \
  --dq-early-journal ../../eight-nations-dq-120/journal-before-rollback.md.gz \
  --hydrogen /path/to/hydrogen/session.json \
  --hydrogen-journal /path/to/hydrogen/journal.md \
  --output /tmp/dq-hydrogen-comparison
```

脚本只读取资料，不推进游戏或调用模型。CSV、JSON、Markdown只需标准库；Excel导出另外使用 `openpyxl`。Hydrogen原始私人存档和日志未包含在此目录，复算者需自行提供；其SHA-256留在指标文件中。
