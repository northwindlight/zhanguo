# 国家生命周期模块

`native:succession` 1.0.0 按 [正式发行版模板](../README.md) 装配。`Succession` 拥有已加入市政厅亡国规则的国家集合，公共接口 `enroll / settle`；无玩家管理工具。

宿主创建国家、领土及初始市政厅后调用 `world.succession.enroll(国家ID)`。未登记的纯经济夹具不会因缺少首都自动亡国。占领完成后、建造落成前检查已落成市政厅，尚在建设的市政厅不能救国；同周期战后收复的市政厅参与检查。

亡国依次解除名下站点归属（保留建筑作为废墟）、裁决外交强制和平、清理亡国部队及存活国家交战、登记国家灭亡、撤销引擎政体作用域。国家 ID、资源账户、债务和报表保留，后续账务仍由经济模块决定。

`succession` 挂点依赖 `claims.resolved`，发布 `actors.eliminated`，随后军队遣返。跨域写方法和引擎 `polity` 写权限均显式声明。只保存登记集合；恢复允许已归档国家引用。验收见 `tests.test_world_domains`。
