# 独立经济查询与工具

`native:economy-queries` 提供 `economy:queries`，查询由声明的资源、建筑、经济、估值和市场对象接口组成，没有自己的写状态，也不依赖银行。

| 工具 | 返回 |
|---|---|
| `econ` | 本账户当前库存、库存资产、建筑重置资产、总资产及最近关闭周期的经济记录 |
| `report` | 本账户已发布报表，包括 GDP、支出、资产、负债、净资产和增长率 |
| `building_economics(kind, level=1, other_slots=0, site="")` | 登记建筑的成本、投入、产出、能源与回本期估算 |
| `market` | 公开价格、均衡价、货币和周期，不返回账户零头或其他玩家的交易记录 |
| `market_quote(resource, quantity, side)` | 本账户零头下的纯报价，不改变状态 |
| `buy / sell` | 调用市场对象，以实际成交金额扣款并返回成交事实 |

银行模块另提供 `bank / borrow / buy_report`，其工具随模块加载。资源和建筑参数使用完整内容 ID；建筑 schema 从注册表枚举，新增茶园无需改查询代码。返回不可变结构化记录，显示层负责翻译名称；内部字段与资源键没有中文硬编码。

建筑估算取当前 `economy:valuation`，尊重具体建筑 `cycle` 与资源 `value_of`。假设满负荷、有足够原料及电力；每单位能源成本取登记发电建筑的最低燃料成本/产电量，明确返回这个假设。发电建筑的能源也按这一成本估值。被动建筑或收益非正时不提供回本期；资源未估值时保留未估值 ID，能源无可估值来源时收益和回本期均为 `None`。不是建筑资格裁决，也不包含战争、外交或土地价值。

`econ` 的资产按查询时库存和价格计算；最近周期记录和 `report` 是结算时观察，带各自周期。当前贷款余额通过 `bank` 查询，避免把当前负债混入历史报表。

完整发行包将 `ActorCollection` 指向只读 `economy_actors`（资源账户列表）；工具调用按照该列表核对行动者。写动作继续受引擎行动阶段限制，读查询可以在结算后调用。旧世界、面板、AI 和排行榜未接线。

2026-10-13：上述查询与工具已进入仓库 `mods.toml` 的正式 native 发行版，建筑模块另提供 `build(site, kind)`，当前共 11 个工具。正式入口与验收见 [native](../README.md)。

当前版本 1.1.0：site 参数可选择本国站点，估算调用建筑公共 quote 接口，以真实等级、槽位、折扣和政策计算成本；不指定站点也应用行动者政策。完整经济发行版现为 14 工具，LLM 和规则 AI 通过同一玩家接口使用查询。上文未接线描述为历史阶段。
