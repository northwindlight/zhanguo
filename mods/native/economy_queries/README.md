# 独立经济查询与工具

`native:economy-queries` 提供 `economy:queries`，查询由声明的资源、建筑、经济、估值和市场对象接口组成，没有自己的写状态，也不依赖银行。

| 工具 | 返回 |
|---|---|
| `econ` | 本账户当前库存、库存资产、建筑重置资产、总资产及最近关闭周期的经济记录 |
| `report` | 本账户已发布报表，包括 GDP、支出、资产、负债、净资产和增长率 |
| `building_economics(kind=None, level=1, other_slots=0)` | 一次列齐所有建筑的各级基础造价、原料与产出配方、能源、效果、建造门槛，以及按当前市价算的净收益与回本；kind 可选筛选，不接受地块或坐标。市政厅以 other_slots 再加 3 座作乐观估计，返回 projected_slots 和假设说明 |
| `market` | 公开价格、均衡价、货币和周期，不返回账户零头或其他玩家的交易记录 |
| `buy / sell` | 调用市场对象，以实际成交金额扣款并返回成交事实 |

银行模块另提供 `bank / borrow / buy_report`，其工具随模块加载。资源和建筑参数优先使用唯一短键值，同名冲突时使用命名空间 ID；建筑 schema 从注册表枚举，新增茶园无需改查询代码。返回不可变结构化记录，显示层负责翻译名称；内部字段与资源键没有中文硬编码。

建筑估算与实际经济报表分开：报表保持当期中间价增加值核算，建筑 ROI 恢复旧版建设决策口径。造价材料按中间价折金，采集产出按卖价、工业投入和自用替代产出按买价；工业同时返回外销产值。买卖价来自当前注册市场的单单位边际价，不受账户零头、整数结算或市场是否有货影响，也不伪装成可成交报价。金币按面值、未上市内容仍服从显式估值/未估值规则。

电耗基准为登记的木电厂买价燃料成本/产电量；该类型不存在时才选登记的可估值发电类型。电不能出售，发电厂净收益仅为负燃料开支，不虚构售电收入。市政厅按已有建筑数再加 3 座的乐观密度假设估算，返回 projected_slots，不改变实际结算产出。工程院把 25% 金币优惠按假设建筑密度、平均基础金价、30 周期摊销及厅密度联动估算，明确返回 assumptions；此值用于建设比较，不是已实现收入。

无参数查询返回全部建筑，不接受 site/x/y，不读取地块、施工资格或工程院优惠。level 和 other_slots 是显式的假设等级/建筑数量，不是站点查询；基础估算应用行动者国策，地形加价及工程院减免由实际建造确定。报告包含成本材料、各级基础造价、原料和产品配方、能源、效果及门槛，模型无需逐个查建筑。估算假设满负荷、原料和电力充足；收益非正或未估值时不提供回本期，耗电建筑没有可估值能源基准时净收益也为 None。城堡、军屯等军事/情报/外交价值不折成虚构现金收益。

`econ` 的资产按查询时库存和价格计算；最近周期记录和 `report` 是结算时观察，带各自周期。当前贷款余额通过 `bank` 查询，避免把当前负债混入历史报表。

完整发行包将 `ActorCollection` 指向只读 `economy_actors`（资源账户列表）；工具调用按照该列表核对行动者。写动作继续受引擎行动阶段限制，读查询可以在结算后调用。旧世界、面板、AI 和排行榜未接线。

2026-10-13：上述查询与工具已进入仓库 `mods.toml` 的正式 native 发行版，建筑模块另提供 `build(site, kind)`，当前共 11 个工具。正式入口与验收见 [native](../README.md)。

当前版本 1.2.0：LLM 和规则 AI 通过同一玩家接口查询。收益查询已移除地块参数，默认返回完整建筑报告；真实施工报价与建造仍由建筑模块裁决。

`report {}` 默认只返回最近已发布一期；`report {period:9}` 查询以第9周期结束的报表，`report {all:true}` 返回全部跨期。period 与 all 不能同时指定；指定尚未发布的周期会拒绝，不把未完成收益当作报表。


贡赋面板（1.8.0）：balance.preview.tribute 包含 carried_remainders、full_load_outgoing、retained_outputs 和 full_load_remainders，直接调用建筑域只读累计预演，查询不推进余额。宗主的 tribute_receivables 仅列当前附庸的历史应收小数，不暴露其当前产能或库存；应收未入库，不可用于生产或消费。工具 econ 与 AI 每回合国力简报使用同一视图；满负荷是预演，实际停工、缺料或贡赋先扣导致的后续生产变化仍以结算为准。
