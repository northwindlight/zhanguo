# 地图生成模块

`native:map-generation` 2.1.0 提供 `map:generation.cell(seed, size, x, y, terrain=None)`，返回不可变 `MapCell`：位置、命名空间地形、资源容量。按 [正式发行版模板](../README.md) 声明接口与算法数值；纯算法无玩家工具、结算阶段和持久状态。

`algorithm.py` 从原地图算法移入，参数由本模块维护；同一版本内相同种子、尺寸和地形生成结果一致。中文算法内部名称在公开边界转换为 `native:plain / forest / hill / mountain / desert` 和资源 ID。每世界的派生缓存不保存，不改变领土物化状态。

2.0.0 增加 `native:high-mountain`（高山）与 `native:ocean`（海洋）。整圈最外缘由
不可通行、不可占领的地形覆盖，内部山脊与海岸由连续低频场生成起伏；所有海洋连通外缘，
可用陆地保留单个四连通分量，避免出生国家位于无法到达的孤岛。
2.1.0 修正外缘过直：尺寸至少16的地图采用二维扭曲的大陆轮廓，形成海湾、圆弧与不齐的山肩，
海洋覆盖整个图幅最外圈，高山限制在靠近陆地的峰脊；深处外角改为海洋，避免雪峰被矩形图幅切齐。
这类地图不再使用会把曲线削成一圈直线的20%屏障上限，可用陆地比例随轮廓与种子变化。
小地图保留紧凑封边预算；所有尺寸仍以封边、海陆连通为先。
原五类地形配额只分配剩余可用陆地，各自的条件资源档位保留；两种屏障资源容量为零。
地名生成仍使用1.2.2的不放回词库，生成器缓存不保存。出生布点由发行版场景选择最近的完整陆地十字，
不会为出生点打穿高山或填海。本次仅这两类新地形，河流、渡口与跨海机制另行设计。
模块和发行版版本已提高，旧版本存档按既有依赖规则拒绝混载，不自动迁移。

2026-10-16 按用户要求扩大木资源覆盖：仅将平原、丘陵、山地、沙漠的部分零木档权重移至1木，森林必有木及各地形2木以上档位保留。地形算法、其他资源、初始库存与林场产量均沿用原规则。概率与人类侧核验见 [地图生成与资源分布](../../../docs/design/地图生成与资源分布.md)，不向局内模型注入资源先验。参数变更提升模块版本，按严格依赖校验使用新档。

随后按用户要求将沙漠有木比例由30%调低至10%（9%为1木、1%为2木），其余地形不变。1.2.1供后续新档采用，已运行的1.2.0对局继续使用原分布。

只换发行版成员即可替换地图机制，领土模块不导入具体算法。固定地图提供者替换与确定性查询由 `tests.test_world_domains` 验收；宿主在物化前配置领土尺寸和种子。

1.2.2改用整池不放回指派地名：保留原有98个前缀、82个后缀，8036个组合按种子及尺寸的稳定哈希排序，再按y、x扫描序依次分配。只有整个词库耗尽才启用数字后缀；哈希相同时按名字排序，保证跨进程确定性。地名与反查仍由地图派生，当前运行中的旧版本对局不改名。
