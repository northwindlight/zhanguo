# 规则纲要

由已加载 Mod 提供规则内容；结算顺序由阶段依赖自动生成。

## 一、一局游戏

**第一条　适用。** 本规则适用于国家玩家。人类、LLM及规则AI使用相同的世界规则、命令权限和信息边界。观察者权限不属于玩家权限。

**第二条　术语。**

| 术语 | 定义 |
|---|---|
| 世界回合 | 全部现存国家各完成一次行动阶段，并完成一次统一结算 |
| 国家行动阶段 | 一国在本轮中提交命令的期间；各国轮流进行，先手按世界回合轮转 |
| 外交实体 | 独立国家或联盟；联盟成员不另作为外交实体 |
| 地块归属 | 地块的国家所有者；无所有者的地块为无主地 |
| 核心归属 | 领土归还规则使用的归属标记；不等于当前所有者 |
| 国祚 | 一国拥有的已落成市政厅；在建市政厅不计入 |
| 已提交 | 命令已登记，预定效果尚未生效 |
| 已生效 | 命令的实际结果已经写入世界状态 |

**第三条　收尾。** `end_turn`仅结束本国行动阶段。全部国家完成行动后，方进行世界结算。一次模型请求可以包含多条命令；模型请求上限不等于命令条数上限。

**第五条　开局投递。** 进入下一世界回合时，先递增回合号，再依次处理到期信件、馈赠、地图和间谍任务，随后开始国家行动。

**第六条　时间边界。** 休战记录须注明起止回合。标为“至第N回合（含）”的休战，在第N回合仍禁止宣战，下一回合解除。任务送达、投票截止及贷款到期均须注明对应回合与阶段。

**第七条　地块。** 玩家坐标从 0 开始计数。地块以坐标或唯一地名引用（地名由地图决定，全图唯一、不随归属变化）。资源点决定采集建筑上限，不等于国家库存。标准开局如下；剧本或政体另有初始配置的，从其配置。

**第八条　取得领土。** 调动不改变地块归属。夺取无敌且可占领的地块，立即进驻并取得归属；夺取有敌地块，先进入交战，胜出后判定归属。建筑随地块归属转移；不存在拆毁建筑命令。

**第九条　占领索取。** 归属候选须为仍在场、未下令撤退且与格上其他存活势力没有交战关系的进攻方。候选按进入战斗的索取顺序接管；先入场方无存活且不撤退的军队时，顺延至下一候选。和平驻军不因驻留获得领土。

**第十条　存亡看市政厅。** 在亡国阶段，一国没有任何已落成市政厅即亡国。此前夺回或取得已落成市政厅的，不亡国；本轮新建但尚未落成的市政厅不能阻止亡国。停电不改变已落成市政厅的国祚资格。

**第十一条　亡国清理。** 亡国者军队解散；剩余领地成为无主地，原建筑保留，原核心主张作废。清除其在局状态，保留终局重建所需的长期记忆、回合小结、阶段归档及政体身份。亡国事实公开。

## 二、经济与能源

**第十二条　国家账户。** 金、粮、木、矿、油、装备和补给归国家统一管理。电力按国家结算，不形成库存。

**第十三条　生产。** 采集建筑按已落成数量产出。电厂先消耗燃料发电。全国电力不足额定需求时，工厂、市政厅和兵营停摆；电厂、采集建筑和军屯不因此停摆。工厂产出受电力与实际投料共同限制。

## 三、建筑

**第十四条　建造。** 仅能在自有地块建造。提交成功即扣金和木材，登记在建并占用建筑位。建造条件按已落成与在建合计核验；工程院折扣只认本格已落成工程院，且不作用于工程院自身。

**第十五条　生效。** 本轮动工项目在建筑落成阶段生效，不参与此前的生产、战斗或亡国判定。城堡每次升级分别支付费用并占用建筑位。采集建筑数量不得超过本地对应资源点。

**第十六条　造价。** 金价依次乘地形建设修正、工程院折扣和政体修正；各步向下取整。木材用量不受上述金价修正影响。表中金价为标准政体、无工程院的平原基准价。

## 四、军队与战斗

**第十七条　军队标识。** 番号在本国独立递增，不因阵亡或遣散回收。军队位置、地块归属、交战身份、行动资格及待撤离状态分别记录。

**第十八条　征召。** 正规军须在自有已落成兵营征召；民兵须在自有已落成军屯征召。资源与本轮产能不足时不能征召。新军立即生成并参加本轮补给，征召当回合不得主动调动、进攻或撤退。

**第十九条　民兵编制。** 军屯提供全国民兵编制及本格免供名额，两者分别核验。超编阻止继续征召，不强制遣散已有军队。驻自家军屯格的民兵按稳定军队顺序使用该格免供名额；离格、超出名额或军屯不属本国时，照常吃补给。

**第二十条　移动规则。** 地图采用八邻域。斜步与正交步均按一步计费；不设禁止切角条件。每步成本取出发格与到达格中的较高值，路径累计不得超过该军移动力。

**第二十一条　行动额度。** 调动、进攻和撤退共享本轮行动额度；一次跨格行动消耗该额度。移动力决定一次行动的距离，不增加行动次数。已在目标格的原地进攻不耗跨格额度，但不解除新兵当回合禁止行动的限制。

**第二十二条　调动。** `move`用于行军、驻留、驻防或增援，不取得领土。可进入自有、同联盟或允许通行的无主地；不得以调动进入敌国或中立国领土。无主地有交战敌军时须使用进攻。已在交战中的军队不得以调动脱战。

**第二十三条　进攻。** `attack`争夺目标地块控制权。进攻路径遵守移动力、地形及通行限制。多军命令须整批校验；校验失败不得让部分军先行。野地有非敌非盟势力正在战斗时不得插入；盟方或敌方在战斗时，按各方敌对关系参战。

**第二十四条　撤退。** `retreat`仅供交战军队脱战，固定退至相邻合法格，不按兵种移动力扩距。合法格为自有地、同联盟地或没有交战敌军的无主地。提交后军队仍在原战场，参加本轮结算；存活后才撤离。目标失效时改撤其他合法邻格；没有替代格则留在原地。

**第二十五条　失败。** 因视野外目标的隐藏通行墙导致调动或进攻失败，消耗相关军队本轮行动额度；可见目标撞墙不消耗。仅因距离或路径不可达失败，不适用盲探处罚。回执须分别报告位置是否改变、额度是否消耗及命令状态。

**第二十六条　遣散。** `disband`移除本国选定军队，不返还费用或资源，自本轮起不再消耗补给。交战军队及正在受攻击的守军不得遣散；民兵被遣散后释放全国编制名额。遣散不改变地块归属或国祚。

**第二十七条　强制遣返。** 退盟、断盟或停战后，非法滞留军队在遣返阶段按兵种速度逐回合趋向本国或同联盟合法地。途中可经过中立地；不取得所经地块。强制遣返不是主动撤退命令。

**第二十八条　补给。** 设需供给军队的总需求为D、库存为C、表列断粮扣血上限为K。实际扣补给为min(D,C)，缺口为max(D−C,零)。无缺口不扣血；有缺口时，各需供给军队扣血max(一，向下取整(K×缺口÷D))。免供民兵不分摊断粮伤害。饿毙军在战斗前移除。

**第二十九条　回血。** 国家本轮无补给缺口、军队所在格未交战且军队未满血时，方可回血。正规军逐支扣装备，付不起则该军不回血；民兵回血不扣装备。

**第三十条　输出。** 每交战格每轮，每个有敌人的势力各掷骰一次，全部势力同时出手。输出基数为各参战军攻击之和，与剩余HP无关；撤退军先扣输出比例。低血量不削减攻击，军队阵亡才移除其输出。

**第三十一条　分配。** 一方输出先均分给其敌对势力，再按目标方减伤计算受伤总额。格主及未主动参战而被攻击的和平驻军享受地形减伤；城堡减伤仅属于格主。其他进攻方不享受当地防御。野人仅攻击主动与其交战的进攻方。

**第三十二条　伤害。** 撤退军逐军按输出保留比例向下取整，最低为一，再合计攻击基数。骰子修正后的输出向下取整，最低为一；均分敌对势力并乘目标承伤比例后，按最近整数舍入，半整数取偶数，最低为一。地形与城堡承伤比例相乘后向下取整为百分数，不相加。逐军撤退承伤减免向下取整。

**第三十三条　均摊。** 同方受伤按军队人数均摊，余数按军队登记顺序分配；重载保持该顺序。致死军吃不完的伤害转嫁存活军。若该方含有撤退承伤减免军，则先均摊、再按各军承伤比例扣血，不转嫁溢出或减免部分。

**第三十四条　战果。** 移除阵亡者后，按索取顺序判归属。双方全灭不产生占领者；原地块归属不变。守军全撤或覆灭且存在有效围攻候选时，候选接管，无须再次进攻。

## 五、外交

**第三十五条　提交与生效。** 国家间外交在行动阶段提交，在规定的回合末阶段处理。命令结果须为已提交、已生效、失败或取消之一；待执行请求不得显示为正式条约或战线。

**第三十六条　外交主体。** 宣战、议和、休战、保障和共同防御以外交实体为主体。对联盟成员的外交目标解释为该联盟。写信、馈赠、地图分享及间谍仍由具体国家执行。

**第三十七条　关系。**

| 关系 | 权利与义务 |
|---|---|
| 中立 | 不得入境，不得攻击 |
| 交战 | 可按军事规则进攻；调动仍不得进入敌方领土 |
| 同联盟 | 互通领土、共享视野、不得互攻；同战线核心地按归还规则处理 |
| 共同防御 | 任一签约实体被宣战，另一方承担参战义务；不附带通行或共享视野 |
| 保障独立 | 保障方承担被保障实体遭宣战时的参战义务；被保障方无对等义务 |

**第三十八条　宣战与传导。** 独立实体宣战无需对方同意。被宣战实体的直接保障方和共同防御伙伴自动参战；援军自身条约不继续传导。联盟整体计作一个实体，被攻击时全盟同侧参战。

**第三十九条　名单。** 参战名单在宣战生效时确定，后续推进、反击或夺地不重新触发条约。休战阻止宣战及把签约方拖入战争的自动参战；休战义务优先于保障和共同防御，并通知相关方。

**第四十条　战线。** 进攻与防御各有主导者，义务参战者为跟随方。目标与同阵营既有战线相匹配时，按既有战线规则并入，不建立重复战争。联盟成员不得分列同一战线两侧。

**第四十一条　议和。** 各侧仅由主导实体的代表提出或接受议和；联盟代表须经投票。跟随方不得单独议和。议和包括白和、付款或索款；接受时核验付款能力。议和生效后整条战线终止、参战军解除交战，并按实际占有重算核心。

**第四十二条　冻结。** 战争期间不得缔结或解除保障、共同防御，不得立盟、入盟、退盟或解散联盟。开战使战前未通过的缔约、入盟投票及立盟提议作废；宣战与议和议案不因此作废。

**第四十三条　强制休战。** 亡国触发全部现有国家战争终止，并为现存外交实体两两设置强制休战；无关战线亦终止。在途外交事项，包括求和及全部投票，取消并通知当事人。休战只禁止宣战及受其阻止的自动参战，不禁止和平缔约。

**第四十四条　和约归属。** 联盟和约属于联盟，移交或继承盟主不改变和约。成员个人和约在盟内暂停，退出或联盟解散后按原截止回合恢复；已过期的不恢复。新增和约只能延长有效截止，不得缩短。成员个人保障和共同防御在入盟时作废，不随退盟恢复。

**第四十五条　视野。** 可见地块由本实体领地、相邻一圈及本实体瞭望塔覆盖范围组成。联盟成员共享视野。可见不等于可达，可达不等于可占领；玩家可向视野外下令，但承担军事命令的盲探规则。

**第四十六条　建筑与军情。** 自有地块公开完整资源、建筑及在建情况；可见他国地块仅公开城堡和市政厅，不公开其余建筑和资源。可见无主废墟公开遗留建筑。可见军队与未知军队不得混为同一统计；看见的市政厅不代表对方全部国祚。

**第四十七条　事件。** 事件写入时确定知情国家，后来获得视野不补发旧事件。正式条约、宣战、议和、联盟变化及亡国公开；信件、情报、提议与表决过程只对有权当事人可见。当前状态只陈述事实，不把历史判断或策略解释写成规则。

**第四十八条　通信。** 信件、馈赠及地图在发出后的下一回合开局处理。馈赠发送方扣出物资，收方存活则到账，收方亡国且发送方存活则退回。送达或失败均须留存结果并通知当事人，不因双方亡国而静默丢弃。地图为单向发送，保存发出时快照，不自动要求对方回图。

**第四十九条　间谍与报表。** 间谍在到期回合取得目标当时的经济、外交、建筑及地图情报；军情仅给兵种数量，不给军队位置、HP或番号。目标已亡国则任务失败。经济报表摘要仅公告本国；别国明细须购买。购买报表不是获取当前实时状态。

## 六、联盟与核心领土

**第五十条　核心领土。** 新占无主地成为占领国核心。夺取现存国家领土不立即改写原核心。战争结束按参与国实际持有重算核心；同联盟、同战线的成员夺回其他成员核心时，自动归还地块，驻军位置不变。

**第五十一条　联盟成立。** 发起人指定联盟名及创始成员，全体接受后成立；任一拒绝则不成立。名称须非空、全局唯一且不得含空格；长度见参数表。发起人为盟主。国家不得同时加入多个联盟。

**第五十二条　联盟权限。** 盟主代表联盟对外，不能自行绕过投票。成员可提出对外议案。盟主可改名、移交盟主及解散联盟，但不得直接退盟。盟主亡国由最早加入的存活成员继承；仅余一成员时联盟解散。任一成员交战时，全盟禁止退盟与解散。

**第五十三条　表决时间。** 发起回合登记议案，其下一世界回合为投票回合。成员仅在投票回合的本国行动阶段表态；该回合全部行动结束后，在世界结算的首阶段统一计票。发起回合不计正式票；任何票数均不得提前结束正常表决。

**第五十四条　票数。** 现成员各一票，申请人不参与其入盟表决。计票前可在本国行动阶段改票；未投算弃权。赞成数严格大于反对数即通过，否则不通过。盟主反对仅计一张反对票，不具有否决权。

**第五十五条　结果。** 投票的通过、未通过、失效和取消须通知全部盟内外当事人。结果通知不含票数；票数属于商议信息，仅在规定的发起人回执中给出。通过仅确定表决结果，不立即执行效果。议案按内容进入对应阶段：宣战、议和、缔约及入盟在本轮外交阶段执行；其他议题须由其规则指定阶段。执行时重新核验对应动作条件；不满足则失败并通知当事人，不得重复执行。

**第五十六条　改名。** 联盟改名须同步其条约、和约、议案及待执行请求中的实体引用，不改变其既有关系。

## 七、市场

**第五十七条　交易。** 金为货币，不能作为市场商品。买卖即时改变现金、库存及商品市价。成交额按价格路径均价和价差计算；不足支付整笔时不自动缩单。市场成交不计入世界生产或消耗流量。

**第五十八条　结算金额。** 同起始报价、同方向、同总数量且无其他交易插入时，同回合拆单与整单应有相同精确总额。整数金以累计精确金额向下取整，零头保留并进入存档。跨回合交易受价格回归和其他交易影响，不保证相同总额。

**第五十九条　价格。** 有产有耗时，缺口比为（消耗−产出）÷（消耗＋产出）；仅有单边流量时采用表列单边比；两者均无时为零。均衡价由基准价及缺口比计算并限幅；市价在市场阶段向均衡价回归。世界流量包括生产、投料、燃料、建设、征兵和军队实际耗料，不包括市场交换。

**第六十条　空转。** 本国同回合同商品双向成交计为空转，重叠量为买量与卖量较小者。空转为成交记录，不取消交易；跨回合不按同轮空转处理。

## 八、经济报表

**第六十三条　报表口径。** GDP为结报回合的生产增加值：产出价值与金收入之和，减中间投料与燃料价值。军费为本轮实际吃补给的价值；两者不是整期累计。资产为期末建筑重置价值，投资与贸易为期内累计。报表仅按期生成，不允许手动补造历史报表。

**第六十四条　来源。** 指标须注明报表期、采样时点及计价口径；GDP和局内资产按相应市价，终局四维展示按其独立口径。GDP减军费不是实际国库收支。没有有效上期基数时不报告增长率。

## 十二、终局结算

**第六十八条　终止与胜负。** 仅余一国或达到回合上限时结束对局。终止原因、剧本胜负和测评排名分别记录；自写国策或信件中的胜利宣称不构成判定。测评按累计总消费排序，即建造、征兵及军队补给的已记账价值；买卖、馈赠与存货不计分。

**第六十九条　结算厅。** 全体参赛国家列入名单，包括亡国者。各国使用自己的原始回放及保留归档、长期记忆重建上下文；缺少可用模型配置者可列成绩但不发言。
