# 外交模块

`native:diplomacy` 2.3.1 按 [正式发行版模板](../README.md) 装配。`Diplomacy` 拥有 `Alliance / Pact / War / Offer / Vote / Command`、休战期限与编号。条约实体是 `nation/<国家ID>` 或 `bloc/<联盟ID>`；联盟 ID 与展示名分离，改名、换盟主保留条约身份。

工具覆盖保障、共同防御提案/接受/拒绝/退出、建盟/入盟/离盟/解散/改名/转让、宣战、议和/接受/拒绝、投票及查询；面板 `diplomacy`。提交动作先校验并预留手续费，同一待结算命令去重，外交挂点稳定排序并重验，失败退款。接受提案只表示进入后续流程，回执明确区分提案、投票和实际生效。

入盟的政治代价直接写入创盟、入盟、接受邀请的工具说明，并可用 `player_rules(入盟/退盟/宣战/求和)` 查询：联盟统一外交表决；个人保障与共同防御双向涉及的条约全部作废，退盟不恢复；任一成员交战锁住全盟退盟/解散。退出后攻击原盟国仍面对其整个联盟，原个人保障作废不能绕过联盟防守。军队与经济仍由各国自行经营。胜利条件归当前发行版挂载的剧本程序，不由外交模块判定。

联盟在 T 发起表决，只在 T+1 行动期投票并在该期结算最前统一计票；发起人没有默认赞成票，可改票或用 null 显式弃权；结束回合未投票自动反对，显式 null 弃权保留，赞成多于反对通过，盟主也是普通一票。联盟内部议案及否决/作废通知只发给联盟选民，未生效的宣战不会自动预警目标国；真正宣战生效时才公告。已递交的入盟申请被否决会答复申请方外交实体；已收到的正式条约或和平邀约在本方否决后，由本方代表在外交阶段向对方正式拒绝并关闭邀约。双方实体收到最终答复，内部票单仍限本方选民。开票前只显示自己的选票，其他国家的票向、是否已投和累计票数全部隐藏；查询与投票回执遵守同一规则。回合末开票后向全部选民公开各国记名选票、赞成/反对/弃权数量及结果，联盟外国家不收到内部票单。外交信件允许拉票和承诺；通过的议案仍需外交阶段执行校验。战时冻结成员和条约变动；入盟清除个人条约。宣战只沿原防守实体的直接保障和共同防御传导一层，不递归串联。

和平金额通过资源原子批次转账，失败不修改外交状态。休战在 period < until 时有效，到期当期可宣战；重复延长取最大值；本期生效的和平在战斗前脱战、更新核心并启动遣返。亡国由生命周期接口触发全局停战、待条约失效与默认 10 周期休战。

`cycle.start` 计票，`relations` 结算。只调用国家、周期、资源和建筑的窄接口。保存待命令、预留费用、投票与近期结果，滚出十期的结果经 Session 归档；恢复校验实体与计数器。默认费用、名字上限、亡国休战由清单声明，政策禁用通过运行时作用域。验收见 `tests.test_world_domains`。

宿主可用 seed_pact(kind, source, target) 初始化独立国家的 guarantee 或 defense 条约；验证国家、和平与政策许可，不收费、不注册玩家工具。八国剧本通过此入口设置开局保障。

投票按计票时的现成员统计；通过后仍走外交阶段，按执行时的现任盟主代表原联盟执行，联盟解散则作废，不转为原发起人的个人动作。同期不同入盟申请各有议案。盟主须先转让或解散，不能直接退盟；成员少于两国自动解散。既有战线的同阵营援军并入原战线，跟随方不能另行议和；义务仅一跳，避免重复拉入已交战实体，并清除跨阵营冲突条约。

休战沿用 G12 的到期口径：`period >= until` 即到期，宣战门控、面板和清理保持一致。


## 附庸与特殊宗主联盟

`propose_vassalage(target)` 由宗主邀请，`submit_vassalage(target)` 由附庸主动称臣，普通关系均须另一方 `accept_proposal`。普通附庸逐项上交实际生产15%，自行经营与指挥军队，但没有独立外交权或联盟表决权；宗主与其普通附庸组成一个外交实体，宗主代表处理战争、条约和议和。普通附庸只能内部通信，不能自行对外赠礼、通信、换图或谍报。宗主没有联盟时可以带普通附庸加入或创建联盟；只有宗主是正式盟员，普通附庸随外交实体参战但不能投票。八国剧本中宗主加入周天下时，原附庸关系全部移交周；原宗主与原附庸都成为周的直接特殊附庸，各交10%、享有正常盟友权力，不保留双层宗主结构。周天下成员后续取得的附庸也直接归周。附庸关系禁止成环，任何附庸都不能再保有附庸。普通宗主被灭国或成为别国普通附庸时，原附庸在回合结算释放、恢复独立外交并停止上贡；八国周天下特效按上述规则移交给周。

宗主可在和平时 `release_vassal(target)` 释放；普通附庸不能和平自行退出，只能 `independence_war()` 发动真实战争，停止上贡、脱离宗主原战线、恢复外交权并与宗主实体交战，原战线其他参与者继续作战。原个人休战不抹消独立战争入口，宗主有效防守条约仍按正常宣战规则传导。可以用 `offer_peace(kind="submit")` 本国称臣，或 `kind="subjugate"` 要求对方称臣，gold须为0；其他战线须已结束，不形成循环隶属。联盟依正常表决；称臣代表在和平生效后退出原联盟，其他盟友不随之成为附庸。

剧本可经 `configure_subject_alliance(overlord, bloc, name, tribute_percent, found_fee, auto_accept, forbid_subjection, lock_chief)` 配置特殊宗主联盟。特殊附庸保留普通盟友全部权力，包括入盟表决和和平退盟；关系随退盟、解散、转让盟主及宗主灭亡同步清理。自动建盟费由宗主在成功结算时支付，失败不扣，资源操作与关系一起原子提交。周的身份、10%贡率、首次100金、不可称臣、盟主权锁定和胜利目标由独立八国剧本 Mod 提供，不是外交默认规则。

所有附庸/联盟关系变更在全体国家行动结束后的 relations 挂点生效；行动期只提交和预验。先议和、退出、变更关系，再处理独立战争，最后普通宣战。宣战按此时真实实体与休战重新校验，因此同回合先入盟再被宣战会由实际全盟防守，成为普通附庸的国家也不能执行先前提交的独立外交命令。

上贡按每国每期各类资源的全国实际总产出计算并从生产中先扣，所有可储存金币、粮、木、矿、油、装备和补给适用，总产出乘贡率后向下取整，不足1不收，余数不跨期累计，不对每座建筑单独取整；余量供后续生产链使用，收到的贡品在全体生产结束后到账，不能再用于本期生产或重复抽成。库存、交易、赠礼、贷款、利息和电力不计贡；停工无贡。外交在生产后结算，新关系从下一期生产生效。生产/GDP保持毛产出，贡赋单列转移收支，不进入消费或贸易；看海净变化包含贡赋。

存档新增附庸与特殊联盟策略，严格版本依赖需新档，不迁移真实存档。离线验收见 `tests.test_vassalage`。

## 外交目标与回应权限

保障、共同防御及解除、宣战、求和的 `target` 同时支持国家键、联盟 id、`bloc/联盟键`、`nation/国家键`，在领域层统一解析，工具与直接 API 一致。实体目标在结算时定位当前代表；联盟解散则失败并退回预留费用，不把旧盟主当成独立目标。称臣、释放附庸、移交盟主仍指定具体国家。

邀约视图包含 `response_actor`、`can_accept`、`can_reject` 和 `vote_ids`。和平只能由受邀战争代表直接回应；普通盟员只读和约并通过内部投票表态，等待代表处理的邀约不列为该成员的待办。
