# 外交模块

`native:diplomacy` 2.0.0 按 [正式发行版模板](../README.md) 装配。`Diplomacy` 拥有 `Alliance / Pact / War / Offer / Vote / Command`、休战期限与编号。条约实体是 `nation/<国家ID>` 或 `bloc/<联盟ID>`；联盟 ID 与展示名分离，改名、换盟主保留条约身份。

工具覆盖保障、共同防御提案/接受/拒绝/退出、建盟/入盟/离盟/解散/改名/转让、宣战、议和/接受/拒绝、投票及查询；面板 `diplomacy`。提交动作先校验并预留手续费，同一待结算命令去重，外交挂点稳定排序并重验，失败退款。接受提案只表示进入后续流程，回执明确区分提案、投票和实际生效。

联盟表决在发起后的下一周期统一计票；未投票为弃权，赞成多于反对通过，盟主也是普通一票。成员与相关国家收到结果，其他国家不获得私人表决通知。战时冻结成员和条约变动；入盟清除个人条约。宣战只沿原防守实体的直接保障和共同防御传导一层，不递归串联。

和平金额通过资源原子批次转账，失败不修改外交状态。休战期限含截止周期，重复延长取最大值；本期生效的和平在战斗前脱战、更新核心并启动遣返。亡国由生命周期接口触发全局停战、待条约失效与默认 10 周期休战。

`cycle.start` 计票，`relations` 结算。只调用国家、周期、资源和建筑的窄接口。完整保存待命令、预留费用、投票与历史结果；恢复校验实体与计数器。默认费用、名字上限、亡国休战由清单声明，政策禁用通过运行时作用域。验收见 `tests.test_world_domains`。
