# 独立央行模块

`native:bank` 1.1.0 拥有 `bank` 对象，提供 `economy:bank`。发行包通过 `Members` 加载模块，不存在 `on / enabled / world_bank` 开关或启用动作。政策在本模块 `mod.toml` 的 `[Bank]` 声明；更换规则实现时替换模块。

## 合同

- `credit_limit(owner)`：最近已关闭周期 GDP × 5，截断取整且最低为 0；尚无 GDP 时为 0，GDP 部分未估值时只取已知价值保守授信，未定价资源仍在报表中单列。
- `borrow(owner, fee=0)`：同时一笔贷款，借满额度，期限 5 周期。本金立即到账；显式传入的外交手续费先检查已有现金，不允许借来的本金掩盖手续费不足。native 玩家贷款工具读取外交费和外交中心减免；独立经济发行包无外交域时费用为 0。
- `set_rate(rate)`：模块接口，利率限制在声明的区间，默认 [-0.5, 0.5]；不向玩家开放央行利率控制工具。
- `settle(period)`：连续周期结算，正现金按存款利率截断取整；负现金不计存款利息。贷款按当期存款利率 + 0.02 复利，四舍五入为整数，到期一次扣款，可形成负现金。每次结算仅计算在世国家（无国家域时为资源账户）；亡国账户债务保持原值、不再复利或扣款。先计算全部候选账户，再提交原子现金批次。
- `buy_report(buyer, target, turn=None)`：20 金购买对方已发布报表，缺省最新，turn 指定期末周期，重复购买重复收费，每个买方保留最近 10 份不可变快照。未发布、自购、未知账户或现金不足时拒绝且不扣款。
- `position(owner)`：自己的现金、授信、贷款、负债和已购买报表。`liabilities / snapshot / to_save / restore` 提供模块协作与持久化接口；跨模块必须声明实际方法。

`position`另提供只读`repayment_schedule`：按当前贷款利率和正式逐期取整函数预估到期周期及扣款，供联合预算使用；之后央行调息会改变结果。查询不改变贷款，未增加存档字段或修改还款规则。

贷款本金、存款利息、贷款计息、还款及手续费记录在独立 `FinanceEntry`，本金、存款利息和债务利息不计入生产 GDP 或消费；实际借款手续费记入行政消费。贷款利息更新应付债务而不提前扣现金。流水的 `cash / liability_delta` 分别记录现金与负债变化。

现金扣款使用资源域独立授权的 `native:bank-cash.adjust(currency, changes)`。只接受 `Gold` 或其具体子类，不给普通资源放开负库存，也不改变市场和军队消费余额校验。

## 发行包与替换

完整独立入口是 [economic_system](../../economic_system/mod.toml)。发行包声明银行结算在报表前，央行阶段自己声明 `Before = ["native:economy.reports"]`；不满足关系时引擎拒绝装配。央行通过阶段上下文传递当前负债，报表计算 `net_assets = total_assets - liabilities`。

不加载央行时，从包清单移除本模块、`bank` 必需状态和银行挂点；经济报表、查询、建筑与市场仍能加载，不出现银行能力和三个银行工具。这里是包组合，不是配置开关。

[fixed_credit_bank](../../examples/fixed_credit_bank/mod.toml) 演示另一套银行：替换 `Members` 中的央行模块，授信变成固定 7 金；能力、状态、工具与报表阶段合同相同。存档严格匹配模块与政策，不支持旧银行存档直接热换规则。

显式 JSON 存档保存政策、利率、周期、贷款、金融流水及购买快照。恢复验证贷款时钟、现金/负债方向、金融流水与贷款余额、购买付款凭据及原始已发布报表；所有校验完成后再替换银行状态。模块 `After` 声明资源、经济先恢复，支持读入空世界后继续结算。

验收：`.venv/bin/python -m unittest tests.test_bank_objects`。不读取真实游戏存档，不依赖旧国家、外交或世界入口。
