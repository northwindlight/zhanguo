# 战略手册

**争天下，先夺取决定天下走势的主动权。**

这本手册讲盘面：谁是主要对手、该扶谁打谁、什么时候干预、怎样把经济变成力量、怎样让别人按你的需要行动。[经济学手册](经济学手册.md)讲资本与生产，[战争手册](战争手册.md)讲战场与军队，[游戏说明书](游戏说明书.md)讲操作和机制。

战略要连续回答三个问题：**沿现在的路线走下去，谁会成为最后的赢家？我现在能改变谁的选择？这一回合做什么，能把未来推向对我有利的一边？**

## 一、先看天下归谁，再看眼前打谁

**真正的对手，是正在取得决定性优势的那一方。** 它今天对你客气、愿意贸易、没有在边境驻军，都改变不了它明天统一天下时必须吞下你的事实。

把各国的经济、产能、军队、扩张速度和政治关系放到同一张盘面上。当前最强者与增长最快者，决定了你最急迫的战略任务。再往前推一场战争：它吃掉下一个国家后，会多出多少完工产业、征兵基地和进攻方向？你到那时能拉来谁、拿什么抗衡？

**强弱按整个外交实体比较。** 联盟、宗主及其附庸都要合起来看。盯着其中一个中等成员，漏掉它背后的整组国家，就是把一场多国战争误判成单挑。再把这份总量转成实际力量：谁能到场，谁掌握通路，谁愿意承担主攻，谁能持续提供军需。

朋友也要列入长期竞争的盘面，同时把先后次序排清楚。当前霸主正在吞人，就集中力量阻止它取得压倒性优势；此时拆散自己的制衡伙伴，会替霸主先清掉障碍。

**你和霸主之间的那个国家，是你最便宜的防线。** 它活着，对手要花兵、花补给、花时间才能前进；它灭亡，对手获得土地和产业，你还要独自接下变得更强的对手。维持缓冲国的生存，本身就是收益。

**本国已经领先，就在其他国家组织合纵之前继续拉开差距。** 集中力量迅速解决一个对手，安排部队接收产业；同时给其余国家一个保持中立的现实利益，用扩张范围、条约和共同目标分开它们。把每次胜利转成下一轮动员，把尚未形成的围攻拆成逐个解决的战争。

## 二、坐山观虎斗，会养出超级大虎

**两强交战，不会自动两败俱伤。** 快速取胜的一方可以保存主力、接收产业，借下一段休战继续建设。你眼里的消耗战，可能只是它眼里的一次低成本扩张。

因此，看见别国交战，先比较三件事：谁更可能赢，胜者能接收什么，你能用同样的时间增长多少。自己吞掉一个小国，赶不上霸主吞掉一个大国带来的优势增长，这场“趁机扩张”就是在输掉未来。

**霸主正在获得决定性战果，就主动改变这场战争。** 干预有多种力度：

- 给守方补给、装备、资金和地图，让它多撑几回合，把速胜拖成持久战。
- 促成共同防御、联盟或宗属关系，把下一次宣战变成多国战争。
- 联络另一强国，给它进攻者后方的情报与共同获利的目标，推动第二战场。
- 抢占通路、关键产业和即将失守的战略节点，让胜者拿不到完整战果。
- 直接进攻围攻者的后方，逼它回兵，替被围者解除压力。

**围魏救赵，救的是均势。** 援助带来的回报可以是对手分兵、战线延长、缓冲国存活，以及你多出来的建设期。把这些收益算进去，就有理由先付出资源、先作出承诺、先推动局面。

中立也要产生结果。利用双方牵制建成产业、占住通路、完成动员，再把这些增长变成下一阶段的行动。等到胜者腾出手才开始找盟友，政治窗口已经被你花掉了。

## 三、外交的任务，是改变别人的选择

**让攻击你变贵，让帮助你有利，让对手忙于别处。** 外交围绕这三个目标展开。

给另一国一个值得行动的局面：共同敌人正在变强，它有机会取得哪块产业、哪条通路，你能提供什么情报、牵制、贡赋或战后安排。把利益和动作说清楚，主动发信、回应邀约、组织条约与战争。

外交通常要有人先出手。先提供一份有用的地图，先承诺一段牵制，先接受一个能改变参战结构的提议，都能推动对方跟进。**对方被牵制、对手多一个敌人，就是已经发生的战略回报。**

把外交工具用到它擅长的位置：

| 手段 | 要改变的局面 |
| --- | --- |
| 独立保障 | 让攻击受保护国的一方必须面对保障人的直接防守义务，抬高开战成本 |
| 共同防御 | 把双方各自的防守变成共同利益，迫使进攻者考虑第二个对手 |
| 联盟 | 合并外交力量，共享视野与通路，用共同表决组织多国行动 |
| 称臣 | 把本国纳入宗主的外交实体，把孤立弱国的战争改造成面对整个宗主实体的战争 |
| 礼物、地图和情报 | 直接延长伙伴的抵抗时间，引导第三方发现值得进攻的目标 |
| 议和 | 结束低收益战线，释放主力，换取赔款、时间或新的政治安排 |

**抢在敌人宣战之前完成政治布局。** 保障和共同防御响应受保护方遭到宣战；宗属与联盟改变参与战争的实体。已有战争的战线在宣战时确定，向现有战线引入新力量，要推动新的合法宣战。把通信、回应、表决和正式生效排进时间表，让外交先于敌军抵达。

信件、条约和组织战争都占用资源。为外交留出经费，就像为下一轮战斗留出补给。外交花出去的钱，可以省下整场孤立无援的战争。

## 四、弱国要主动造局，称臣也是武器

**越弱，越要让强国四面受敌。** 弱国手里还有地理位置、通路、情报、产业和政治归属；把这些筹码交给合适的对象，就能借到本国养不起的力量。

两国正在夹击你，就找有能力改变这场战争的第三国。向它说明：保住你，可以挡住谁的扩张；接纳你，可以取得什么前沿位置；你能替它牵制谁、供给什么。把自己变成它经营霸权的一部分，让你的存亡进入它的利益计算。

**称臣可以直接改写开战对象。** 在进攻者宣战前，向能够制衡它的宗主提出称臣并推动接受；关系生效后，攻击你就要面对整个宗主外交实体。原来两国围攻一个弱国的便宜仗，可以变成它们必须考虑的大国对抗。这个结构变化，本身就值得付出贡赋。

普通附庸仍经营本国土地、产业和军队，以持续贡赋和独立外交权换取宗主实体的力量。把争取到的时间投入生产、军力和国祚支点，积累重新掌握主动权的实力。往后争取宗主和平释放，或组织独立战争，靠的是这段时间里真正长出来的力量。

对宗主而言，接纳附庸同样是主动扩张：取得贡赋、前沿位置与战略纵深，迫使竞争者重新选择战争对象。把附庸经营成能供给、能驻防、能牵制的支点，宗主的优势才能持续扩大。

**弱国的近期胜利，是让强国赢得更慢、付得更多，同时让自己长得更快。** 当两边的力量对比改变，弱国就有了下一步的选择。

## 五、结盟要组织力量，盟主要经营多数

**联盟把分散的国家组织成一股能改变战争结果的力量。** 共享视野、领土通行、整体参战，可以把本来互不相干的军队放到同一战场，把单挑打不过的对手变成多方围攻的目标。

组织联盟，先找共同敌人，再分配具体任务：谁在正面钉住主力，谁绕后，谁提供军需，谁接收哪片产业。伙伴越清楚自己能得到什么，就越容易把纸面的盟约兑现成军队。

盟主也是一票。用贡献、战果、共同利益和分配方案争取多数，才能让联盟表决转成统一的战争方向。争取盟主地位，是争取组织与协调的中心；组织能力要落实到每个成员愿意执行的任务上。

入盟会使涉及本国的原个人保障和共同防御作废，对外重大行动改由联盟表决。提前重组条约，把现有伙伴带进新的合作结构，让合并后的力量真正大于原来的分散力量。

联盟任一成员交战时，退盟与解散锁定。把调整阵营、转让盟主和重新组合的政治动作放在和平窗口完成。局势变化后，重新围绕主要对手组织伙伴，继续争取主导权。

周天下另有政治收益：周可以通过特殊联盟争取天下秩序，成员取得臣属保全；诸侯要把本国兼并争胜、阶段性依附和终局保全分别作为明确选择。目标改变时，把新的利益与行动一起说清楚。

## 六、经济增长要变成下一轮优势

**能持续增长的经济，才能支撑持续扩张的军队；能取得新产业的军队，才能打开下一轮增长。** 把这两个循环接起来，国家才会越打越强。

发展窗口里，优先建设能持续创造剩余的产业；战争窗口逼近时，把产能、库存和兵力集中到能改写局面的行动上。经济规模与动员规模要相互追赶：生产扩张后及时形成可投入的军力，战争得地后及时组织建设与接收。

**电网、工业、原料和军需，要作为一套能力扩张。** 多出的电力要接上工厂，多出的工厂要接上原料，多出的军队要接上补给。长期空转的电力、缺料的工厂、断粮的军队，都说明投资没有形成完整力量。

军需优先要服务于具体战争。长期把全部收入变成口粮，却没有新增产能与战果，就是让军队吃掉下一轮扩张的本钱。让军队去取得值得占领的产业，或释放一部分常耗，把资本重新送回增长。

**抓住市场的稀缺，形成自己的经济长处。** 各国都扩军，粮食、矿石和补给的需求会抬升；各国都卖装备，装备外销的利润就会被压低。把紧缺商品变成利润来源，把关键军需自产变成动员底盘，利用贸易换取本国稀缺的投入。依据资源禀赋和战争位置选择产业，让自己的增长领先于竞争者。

贷款用来提前取得优势。借款后要多出一批会生产的资产，或多出一场能够兑现的战果；还款以后，这些资产和战果仍然归你。把到期扣款与战争、外交、原料采购的窗口排在一起，保住决定性几回合里的行动能力。

财富要转成选择权：能买原料，能完成动员，能支付外交，能救一个缓冲国，能在对手失误时立刻出手。**国库、产线和军队共同决定你能做多大的事。**

## 七、夺地要接上建设，吞并要抢下产业

**空地给你建设位置，完工产业给你更快的力量增长。** 把地块的资源、现有建筑、通路和军事位置一起比较，选择能尽快转成收益的目标。

一块新地有三种主要价值：能开发出稀缺资源，能承接赚钱的产业，或能改变进攻和防守的通路。拿地之后接上建设、驻防或下一步推进，让占领立刻进入国家的增长与战争计划。

战争中优先争夺可以改变后续力量对比的目标：市政厅、完整产业区、关键能源、征兵基地和出入口。夺到完工产业，再组织原料与守备，就能迅速接上后续产出，比从零建设更快形成优势。

**灭国后立刻接收战果。** 敌国失去全部已落成市政厅会灭亡，剩余土地转为无主。预先安排接收部队，抢占遗留建筑与关键资源，把暂时打开的空间变成自己的资产、通路和纵深。

把这一仗的接收速度，与第三国的扩张速度一起算。你辛苦打垮一个国家，却让别人先占走它的产业，就是把战争利润送给旁观者。

## 八、战争要迅速改变局面

**战果要体现在国祚、产业、通路和政治地位上。** 把敌人主力钉住、夺取其唯一市政厅，可以比消灭全部敌军更快结束一场战争；切断关键产业，可以比正面攻城更快迫使对手让步。

开战就选择结束战争的路径：夺取全部市政厅、取得关键产业、逼出赔款或臣服，或完成一次让对手必须回防的牵制。把每一步推进与最终战果连起来，让主力始终朝着能够结束问题的方向用力。

**僵持会把你的军队变成第三国的机会。** 你在一条战线上不断补兵，别人就有时间增长、换边、进攻你的后方。长期围困也在付这个代价：兵被钉住，产业接收延后，天下的其他力量继续变化。

给战争一个主动改变局面的期限。正面迟迟打不开，就换轴绕后；产业打击已经逼出让步，就议和释放主力；更大的对手开始吞人，就把兵与外交转向新的主要矛盾。**用已经取得的成果结束旧问题，再把力量投入收益更大的方向。**

把本国战争与别国的战争放到同一张时间表。你必须在对手完成征服、回满兵血、重新集结之前，取得足以改变力量对比的成果。

## 九、集中形成拳头，机动决定打在哪里

**集中关键产业，分设国祚支点，把主力集中到决定性的战场。** 工业与能源组成守得住的产业簇，市政厅与征兵基地支撑持续作战，再用机动兵力连接这些支点。

能源关系到全国工业。夺取足以使敌国发电低于需求的能源节点，可以让它的耗电工业、市政厅和兵营整体停摆。围绕关键能源配置产业与守备，利用电力余量继续扩大有效产能，形成可以承受战场变化的生产体系。

**资产集中，就把对手钉在你的坚固核心前；资产分散，就主动出门逼它回防。** 敌人绕开主力抢产业时，去打它的落单分队、进军通路和后方，迫使它为自己的损失调整部署。

机动的收益，是每次都把更多力量送到更少的敌人面前。多路部队在同一回合抵达同一目标，以局部优势迅速夺地、歼兵，再转向下一处。骑兵的速度用于抢位置、形成侧击、穿过空隙和威胁后方，让敌人来不及把总兵力变成当地优势。

唯一市政厅就是敌人最直接的战略目标。用守军、第二座市政厅、征兵基地和通路，把国祚支撑起来；主力获得的行动自由，来自这些支点替它争取的时间。

**让对手分兵守很多地方，让自己的主力每次只打一个关键地方。** 防守与进攻都围绕这个力量分配展开。

## 十、让情报带来下一步动作

**情报用来选择目标、抓住时机、调动伙伴。** 经济报表找出谁在增长、谁正在透支；谍报找出产业和动员规模；视野、地图与通信找出军队、通路和可以利用的空隙。

为下一项决定购买最有用的情报。准备干预，就弄清谁正在取得优势、谁能成为伙伴；准备突击，就探明关键通路和市政厅；准备扩大工业，就掌握稀缺投入与可承接的市场。

把侦察、集结、通信和试探并行推进。先占一个能扩大视野的节点，先向潜在伙伴送出真实有用的信息，先用一支偏师迫使对手暴露部署。**主动行动本身也能制造情报。**

用日期与来源组织事实，把尚未看见的部分转成要试探的方向。依据新回执不断更新路线，持续增加自己能作出的选择。

## 十一、让国策推动局势，让执行兑现方向

**国策要选主要矛盾，分清先做什么、暂时放下什么。** 当前最重要的目标可能是阻止霸主速胜、取得一段发展窗口、建立宗属保护、抢下完整产业，或结束一条消耗主力的旧战线。把有限的钱、材料、兵和外交集中到这个目标上。

把战略写成能接续的行动：这一期改变哪件事，由哪些建设、军队和外交来完成，取得成果后接着做什么。让规划落到执行，让每一期执行又为下一步创造条件。

费用、投料、报价、路径和具体时点交给执行层落实。遇到一个操作障碍，就换合法的实现路径继续推进；当执行揭示出新的战争对象、力量对比或时间窗口时，重新选择战略。

**局势变了，就主动改国策。** 已经投入的钱和过去的承诺，要转成经验与现有资源，新的主要矛盾由现在的盘面决定。说明改变方向能取得什么，再把新的优先级兑现成行动。

复盘抓住因果：哪一步真正拉开了实力差距，哪次外交改变了参战结构，哪段等待给了对手决定性收益。把有效做法接着做，把失败的路径迅速换掉。

## 十二、四种局面，四种主动选择

### 霸主正在吞邻国，自己也有弱邻可打

先推演两场战争的相对结果。若霸主会得到压倒性的产业和兵力优势，就把救活缓冲国、引入第二战场和扩大本国产能放到前面。向被围者送军需，向第三国递情报，利用牵制窗口完成动员，再争夺真正能扭转均势的战果。

### 两个邻国压境，本国单独挡不住

立刻寻找能够制衡它们的宗主或联盟。把本国的前沿位置、贡赋和牵制价值组成一个可接受的方案，主动请求保障、入盟或称臣。推动政治关系在敌人宣战前生效，把对方的一场便宜战争改成必须重新考虑的大国战争。

### 电力充裕、工业不足，军需却靠高价进口

把闲置电力变成工厂，把工厂所需的原料与现金周转接上，再把新增军需变成可持续投入的军队。围绕世界短缺形成自己的产业优势，用建设获得更强的动员能力，而后用军队打开下一轮建设空间。

### 主力陷在长期战线，第三国开始连胜

迅速收束旧战线：换轴取得一个能兑现的战果，或议和释放主力。同步组织伙伴、援助被攻击者、威胁新霸主的后方，把军队从旧问题转到决定天下走势的新问题上。

## 十三、孙子兵法：把谋略落到盘面

| 原文 | 在本局中的用法 |
| --- | --- |
| 「上兵伐谋，其次伐交，其次伐兵，其下攻城。」 | 用保障、联盟、宗属和第三方行动，使对手的征服计划变贵、变慢、变成多线战争，再争取最有价值的战场成果。 |
| 「不战而屈人之兵，善之善者也。」 | 用政治结构、力量集中与产业打击迫使对手改变目标，取得土地、时间或臣服。 |
| 「善战者，致人而不致于人。」 | 主动制造对手必须回应的威胁，决定它的军队往哪里去。 |
| 「攻其无备，出其不意。」 | 利用视野空隙、机动速度和政治时机，直取关键产业与市政厅。 |
| 「我专为一，敌分为十，是以十攻其一也。」 | 主力集中突破关键点，用偏师、伙伴和多条威胁迫使敌人分兵。 |
| 「兵贵胜，不贵久。」 | 让战争尽快取得可兑现的成果，释放主力，把新产业投入下一轮增长。 |
| 「知彼知己，百战不殆。」 | 用本国能力、敌人的增长与部署、伙伴的利益和行动窗口，共同决定下一步。 |
| 「无恃其不来，恃吾有以待也。」 | 主动经营守备、国祚支点、伙伴关系和动员能力，让对手每一次进攻都付出代价。 |

**每回合都要让主要对手更难完成目标，让自己多一个决定局面的手段。**
