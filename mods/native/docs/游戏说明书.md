# 战国 · 游戏说明书

战国的玩家是治理国家的 AI，人类主要负责观察。看一局游戏，可以从三个问题入手：这个国家靠什么养活自己，军队准备到哪里去，它对其他国家究竟知道多少？

这本说明书讲当前默认 **native** 玩法。先读“国土与存亡”和“一个回合”，就能跟上大部分战报；需要算账或理解外交时，再查后面的表格。八国剧本和可选议会另有专节。

## 国土与存亡

普通国家从五格十字形领土和中心的一座市政厅起家，初始物资由配置决定。中心格是平原，其余土地保留生成的地形和资源。八国剧本指定各国的大致方位；出生点遇到自然屏障时，会寻找附近能放下完整开局的陆地。

**市政厅是国祚。** 国家可以拥有多座市政厅；结算检查时，一座已落成的市政厅也不剩，就会亡国。首都失守不一定亡国，其他市政厅仍能延续国家；反过来，即使还占着几十块地，没有市政厅也保不住国祚。

在建市政厅来不及挽救当期亡国，因为亡国检查先于施工完成。亡国后军队清除，剩余土地变为无主地，建筑作为废墟保留；相关战线停战，并建立默认十回合的强制休战。

### 土地怎样拿到手

无主陆地通常有一支静止的野人守军，100 HP、攻击 50，不会主动扩张或增援，死后不会重生。夺地需要进攻；仅仅把军队移动过去不会改变归属。没有守军阻挡时可以立即占领，有守军则进入交战，等结算裁决。

占领后获得该格的建设空间和现存建筑。地块的历史核心与当前归属分别保留，当前能否建设、驻防和生产以归属为准。

地图坐标从 **0** 开始：`x` 向右、`y` 向下，`(3, 11)` 表示第 3 列、第 11 行。相邻包括横、竖和斜向八格。

### 地形

| 地形 | 守方地形减伤 | 建设金币加价 | 骑兵每步代价 |
| --- | ---: | ---: | ---: |
| 平原 | 0% | 0% | 1 |
| 森林 | 10% | 15% | 2 |
| 丘陵 | 25% | 25% | 1 |
| 山地 | 50% | 50% | 2 |
| 沙漠 | -10%，即多受伤害 | 40% | 1 |
| 高山、海洋 | 不发生战斗 | 不可建设 | 不可通行 |

步兵和民兵在可通行地形的每步代价都是 1。高山与海洋没有资源和野人，不能占领，也不能从它们封住的夹角穿过。普通山地可以通行；地图边缘由高山与海洋封闭。

## 一个回合

各国依次行动。轮到本国时，玩家查看局势、制定或更新国策，再决定交易、建设、征兵、调兵和外交，AI 最后提交回合小结；真人直接结束本国行动。全部国家行动结束后，世界才统一结算。

动作有不同的生效时刻，读回执时需要分清：

| 动作 | 当时发生什么 | 还要等什么 |
| --- | --- | --- |
| 建造 | 扣材料、占建筑位、开始施工 | 回合末落成，下回合开始生产 |
| 买卖 | 实际交货并结算金额 | 市场在回合末更新下一期报价 |
| 征兵 | 新军立即出现 | 新兵本回合不能行动，但当期要补给 |
| 移动 | 军队到达合法目标 | 不会因此取得土地 |
| 进攻有守军的地块 | 进入交战 | 回合末打一轮，可能持续多回合 |
| 撤退 | 提交撤离申请、占用行动 | 当期仍参战，幸存后才撤走 |
| 外交 | 预留费用、提交命令或回应 | 外交阶段重验；联盟事项可能还须表决 |

### 回合末按什么顺序发生

下面将相邻的同类事项合并，便于读战报：

| 顺序 | 发生的事 |
| --- | --- |
| 1 | 联盟到期表决计票。 |
| 2 | 采集、燃料发电、电网与工业生产；按现有附庸关系扣贡，生产结束后派发贡品。 |
| 3 | 外交关系生效或失败退款，通信发出；普通宣战最后处理。 |
| 4 | 军队消耗补给，符合条件的伤兵恢复。 |
| 5 | 战斗掷骰、同时承伤，裁决占领；随后处理幸存军队撤退和弃城。 |
| 6 | 检查亡国、强制和平与军队遣返。 |
| 7 | 市场更新基准库存和下期开盘报价。 |
| 8 | 本回合施工完成。 |
| 9 | 银行结息、贷款到期扣款，记录经济报表。 |
| 10 | 发布事件、送达到期通信，进入下一回合并检查剧本终局。 |

因此，本期生产能供应本期军队；本期刚开工的工厂不能。新生效的和平能阻止随后战斗，新开工的市政厅却赶不上此前的亡国检查。战斗后才脱离战场的伤兵，要到下回合才有机会恢复。

## 视野与情报

玩家能看到本国和同盟土地周围一格，已落成的瞭望塔将附近视野扩展到半径 4 格。观察者的全图不会提供给玩家。

看得见一块外国土地，也不等于知道它的一切。普通视野只公开已落成的**市政厅和城堡**，其他建筑、资源容量和国家库存仍然保密。可见敌军也只是当前视野内的军队，不能据此把全国未知兵力算成零。

| 情报来源 | 能了解什么 | 时效与限制 |
| --- | --- | --- |
| 当前视野 | 地形、归属、可见军队和公开建筑 | 覆盖范围随领土、联盟与瞭望塔变化 |
| 经济报表 | 已公布期间的经济、资产和负债 | 每十期公布，购买别国报表每次 20 金；不提供当前部署 |
| 间谍 | 目标库存、兵种数量、建筑、已知地图和外交等 | 费用 100 金，三回合后返回；不含军队位置与逐支 HP |
| 购买地图 | 地图商在最近完整回合边界公开的该国土地及邻接无主地测绘 | 基础 20 金加每格 2 金，同一版本只能买一次；只增加历史知识，不提供实时视野 |
| 共享地图 | 发出时对方看到的地块 | 是带日期的快照，不是永久共享视野 |
| 信件 | 对方愿意告诉你的内容 | 可以谈判、劝说，也可能错误或欺骗 |

报表要看覆盖期，地图和谍报要看采样日期。历史事件按发生时的权限记录，后来开图不会让当时看不见的旧战报凭空出现。

普通信件下一回合送达。基础费 20 金，同盟间 10 金；每座外交中心减 5 金，最低基础费 5 金。前 20 字不加字数费，之后每 10 字加 1 金，不足 10 字也按一份计。送礼和共享地图也需要正式派发，同盟间免基础费用；物资送到后才归对方。

## 资源与建设

### 全国一本账

| 资源 | 主要用途 |
| --- | --- |
| 黄金 | 建造、交易、民兵征召、通信和外交费用 |
| 粮食 | 征兵、制造补给 |
| 木头 | 建造、木材能源厂燃料 |
| 矿石 | 制造补给和装备 |
| 石油 | 制造装备、石油能源厂燃料 |
| 装备 | 征召正规军、恢复正规伤兵 |
| 补给 | 维持军队；粮食不能直接代替补给 |
| 电力 | 全国即时供应，不储存、不买卖 |

除电力外，物资归国家库存统一管理，不需要运输队把本国材料逐格搬运。生产出来的商品不会默认卖掉；想换成金币，可以手动出售，也可以设置自动交易。

### 建筑位与资源位

普通地块有 20 个建筑位，在建建筑也占位，城堡每一级各占一位。每格每回合只能开工一次；不同地块可以同时开工。

采集建筑还受本格资源位限制。例如“木头×3”允许最多三座林场；农场与军屯都占用耕地资源位，军屯本身不产粮。工厂、电厂等主要受建筑位限制。

有些建筑要求该格已经使用足够多的建筑位：兵营至少 3 位，工程院 4 位，外交中心 5 位，新市政厅 6 位。这里数的是已有建筑，包含在建项，与这块地最多能容纳多少建筑不同。

### 建筑一览

下表是普通政体在平原、没有工程院折扣时的基础造价。地形只增加金币成本，木材不变；同格已落成的工程院使后续建造金币费用减少 25%。特殊政体可以另有修正。

| 建筑 | 基础造价 | 每回合用途或效果 |
| --- | --- | --- |
| 林场 | 20 金、15 木 | 产 1 木，占木头资源位 |
| 农场 | 20 金、15 木 | 产 1 粮，占耕地资源位 |
| 矿场 | 30 金、15 木 | 产 1 矿，占矿石资源位 |
| 石油厂 | 60 金、20 木 | 产 1 油，占石油资源位 |
| 黄金矿场 | 85 金、25 木 | 产 10 金，占黄金资源位 |
| 木材能源厂 | 60 金、30 木 | 烧 1 木，发 2 电 |
| 石油能源厂 | 120 金、30 木 | 烧 1 油，发 8 电 |
| 补给厂 | 90 金、25 木 | 2 粮＋1 矿＋1 电 → 2 补给 |
| 装备厂 | 105 金、25 木 | 1 矿＋1 油＋1 电 → 2 装备 |
| 兵营 | 175 金、40 木 | 耗 1 电，该格每座兵营每期可征 1 支正规军 |
| 市政厅 | 250 金、80 木 | 耗 1 电；每期产金＝5＋同格其他建筑数；维持国祚 |
| 瞭望塔 | 60 金、30 木 | 提供半径 4 格视野 |
| 外交中心 | 200 金、60 木 | 降低相关外交、通信费用；每格限 1 座，全国自行建造限 1 座 |
| 工程院 | 150 金、60 木 | 同格后续建造金币费用减 25%，每格限 1 座 |
| 军屯 | 110 金、30 木 | 占耕地资源位；增加 2 支全国民兵编制，该格每期可征 1 支民兵，每格限 1 座 |
| 城堡 | 一级 50 金、20 木 | 每级给格主增加 10% 城堡减伤，最高五级 |

市政厅每格限一座。城堡二至五级每次升级的金币费用依次为 100、200、400、800 金，每级另需 20 木。

例如平原上一座市政厅旁有五个其他已落成建筑，电网正常时它产出 `5＋5＝10` 金。新增建筑既有自己的作用，也会增加该格的厅金收入。

### 撤销施工与拆除

本国建筑可以按实例编号拆除。**尚未完工时返还当时实际支付材料的 50%，已经完工后拆除不返还材料**，不是按今天的基础造价重新计算。例如实际支付 57 金、20 木，撤销返还 28.5 金、10 木；15 木的一半为 7.5 木。

撤销后本格本回合的施工额度仍已用尽，下回合才能再次动工；其他地块的额度不受影响。施工取消后不会再落成或生产，经济报表只计未退回的一半材料为本次建设损耗。城堡从最高一级开始拆；拆除最后一座市政厅可能在结算时导致亡国。

桌面版点地块建筑或建设面板的“管理”入口操作，确认窗口提前显示返还金额。模型用 `building_sites` 查看本国建筑实例编号，再调用 `demolish(id=编号)`；真人与模型使用同一条领域 API。

### 电网与开工

每回合先采集，再消耗燃料发电，随后供应耗电建筑。木头只有建材与燃料用途，不是补给厂、装备厂的直接原料。

**全国发电不足额定用电时，耗电建筑全部停摆。** 工厂不生产、市政厅不产金币、兵营不能正常征兵。采集建筑、电厂和军屯不因缺电停摆；市政厅停产也不会因此消失或直接导致亡国。

电厂必须买好或产出燃料，工厂必须有完整配方。仓库有矿不代表能造装备，还要有油和电。新建建筑回合末才落成，从下一回合开始参与生产。

## 市场与银行

### 商品不会凭空补货

六种商品共用一个有限库存市场。开局库存为：粮 1920、木 1920、矿 1280、油 960、装备 640、补给 960。买入减少市场库存，卖出补回库存；没有外部商人定期送货，也没有自动消化积压的需求。

国家自己生产、消耗、赠送资源不会直接改变市场库存。买单超过现有库存会整单拒绝，不会只交一部分。

价格由**实际库存与基准库存**共同决定。净买入、净卖出会让基准库存逐期变化，因此价格与世界各国长期的采购和销售有关。同回合各国看到同一公开中间价，成交还要考虑价差和订单量。

买价在中间价上加 5%，卖价减 5%；大单还会扫过更深的市场库存，均价更不利。同账户同方向的累计成交深度也会计入，拆单不能绕开冲击成本。金币零头跨交易累计结算。查看市场时可参考买卖 50 单位的试算，成交以本次回执的实际金额为准。

这意味着一座工厂的利润会随行情改变。装备卖得贵时可能赚钱，矿和油一起涨价后也可能亏损；仓库有货、账上有钱和长期有收益，是三件不同的事。

### 即时与自动交易

玩家市场提供 `+1 / +10 / +50 / +100 / +500` 买入和 `−1 / −10 / −50 / −100 / −500` 卖出按钮，每个按钮显示整单金币，悬停显示整单均价。报价包括价差、累计成交深度、滑点及取整，缺货或余额不足的按钮变暗；点击后以实际回执成交。

自动交易默认关闭，按商品设置库存区间：低于购买目标时补货，高于出售保留量时卖出。购买目标不得高于出售保留量；可以只启用一个方向。另可设置每回合最多买卖多少、至少保留多少金币、最高购买均价和最低出售均价。

**本国成功结束行动后、世界统一结算前执行一次，先卖盈余，再买短缺**。因此本次自动购买可供接下来的生产和补给使用；本次生产得到的盈余要等本国下次结束行动时出售。不会在设置时立即成交，也不会反复盯盘或在每个生产阶段插队。

自动买卖使用与手动相同的有限库存和计价规则。资金、商品或价格限制不足以满足整笔目标时，尽量成交合法的整数数量；不能借贷或凭空补货。界面和市场查询显示最近一次实际结果，设置及本期执行标记随存档保存；可暂停或删除规则，已有成交不能撤销。

模型通过 `economy(action="auto_trade", resource="food", buy_below=50, sell_above=200, buy_limit=10, sell_limit=50)` 设置，`query(panel="market")` 查本国设置和结果；`enabled=false` 暂停，`economy(action="remove_auto_trade", resource="food")` 删除。脚本和规则 AI 对应调用 `economy:queries.auto_trade / remove_auto_trade`。

### 贷款与利息

银行默认存款利率为 0%，贷款利率比存款利率高 2 个百分点。观察者可以在 -50% 至 50% 之间调整存款利率，贷款随之变化。

普通贷款有四条关键规则：

1. 授信取最近一个已结算回合 GDP 的已估值部分，乘以 5 后向下取整；开局尚无 GDP 时没有授信。
2. 一次借满额度，同时最多一笔，期限五回合，借款手续费另计。
3. 每期复利增加应付债务，到期统一扣款；现金不足仍会扣，国库可以因此变为负数。
4. 借来的钱增加现金，也增加负债，不计作生产收入或 GDP。

### 怎样读经济报表

本国报表免费，每十期发布，列出覆盖期、GDP、建设、征兵、军需、进出口、资产、负债和增长率。别国已经公布的报表可花 20 金购买，重复购买仍收费。

**GDP 是产出价值减生产投入价值。** 它不能当作每期金币收入。军需折价是已消耗补给和装备的价值，也不会在材料之外再扣一笔同额金币。贡赋、借款与利息另列，避免把转移和融资重复当成生产。

## 军队与战争

### 三种军队

| 兵种 | 每支征召费用 | 满血 HP | 基础攻击 | 每期补给 | 移动力 |
| --- | --- | ---: | ---: | ---: | ---: |
| 步兵 | 10 粮、5 装备 | 100 | 50 | 1 | 1 |
| 骑兵 | 12 粮、12 装备 | 100 | 50 | 2 | 2 |
| 民兵 | 50 金、5 粮 | 80 | 25 | 1，可免供 | 1 |

正规军在本国已落成且可用的兵营征召；同格兵营的每期额度相加。民兵在军屯征召，另受全国军屯总数×2 的编制上限约束。每期能征多少，与全国最多保有多少，是两种限制。

新兵当期不能移动、进攻或撤退，但会参加当期补给。材料和征召额度不足时，批量征召可能缩减为实际可征数量，应看回执中的新兵名单。

### 行军、进攻与行动次数

每支军队每回合的一次跨格行动，由移动、进攻和撤退共用。移动力决定这一次能走多远，不增加行动次数。斜向也算一步，每步消耗取出发格与到达格中较高的地形代价。

例如骑兵移动力为 2，在平原可以一次走两格；进入或离开森林、山地的一步就要消耗 2 点。步兵移动力为 1，每期走一格。

移动用于调动，不夺地；进攻用于占领或交战。攻击外国土地前，战争必须已经正式生效。本国与盟国土地可以通行，无主地按守军和交战情况判断；中立国不能当作免费通道。交战中的军队不能用普通移动直接脱战。

原地进攻不消耗跨格额度，但新兵当期禁行动仍然有效。军队面板会区分是否已行动、是否新征、是否交战和是否待撤。

多军调动、进攻、撤退和遣散先整批校验，任一军队不合法则全批不执行。视野外盲推撞上隐藏障碍时，可能实际失败并消耗行动；回执会说明位置是否变化、额度是否已用。

### 补给和伤兵恢复

补给全国统一扣取，伤兵与满血部队都按一支计算，新兵和交战军也计入需求。本国民兵驻在自家军屯格时，在该格军屯提供的两个名额内免补给；正规军、超名额民兵或离开军屯的民兵照常消耗。

补给不足时，所有需供部队共同分摊断粮损失；免供民兵不分摊。每支损失为 `向下取整（35×缺口÷总需求）`，有缺口时至少损失 1 HP。完全断供每支损失 35 HP，饿死的军队在战斗前移除。

恢复需要全国当期补给满足，且军队所在格没有交战。每支每期最多恢复 30 HP；民兵不耗装备，正规军由现有装备提供总恢复量，每件装备对应 30 HP。合格正规伤兵平均分配，满血后的剩余额度再分配，按总实际恢复量向上取整扣装备。

例如两支正规军各缺 15 HP，一件装备就能把两支都补满。若只有一件装备、两支都缺 30 HP，则各恢复 15 HP。

军需面板会逐支列出需求、免供、断粮损失与预计恢复。它按查询时库存预演，不提前扣资源，也不把后续生产和采购当成已经发生。

### 一轮战斗怎样计算

有敌人的各方在每格每回合各掷一次六面骰，随后**同时造成伤害**。骰面 1 至 6 的输出修正依次为 -25%、-15%、-5%、+5%、+15%、+25%。

基础输出是参战军队的攻击力之和。伤兵只要活着就保留该兵种的基础攻击，不按剩余 HP 比例打折；阵亡后才移除。面对多个敌方时，输出分给各敌方。

守方享受地形减伤，格主另享城堡减伤，两者相乘。例如丘陵 25% 减伤、二级城堡 20% 减伤，守军承伤比例为 `75%×80%＝60%`。进攻军站进目标格，不会因此得到同样的防御待遇。

同方军队平分承伤，某支军吃不完的致死伤害会继续分给存活军。伤害和 HP 可以是小数。守军被清除或全部撤离后，才按实际战果裁决占领；双方全灭不会凭空产生胜者。

因此，军队数量只是判断的一部分。兵种、HP、到场时间、地形、城堡、补给和骰子都影响结果，全国总兵力不能直接替代当前战场投入。

### 撤退与遣散

正在交战或受攻击、本期尚未行动且不是新兵的军队，可以申请退到相邻合法格。撤退军本期输出降低 80%；守方撤退只承受分配伤害的 50%，攻方撤退承受全部分配伤害。

提交后仍在原地打本期这一轮，活下来才撤走。目标格失效时寻找其他合法邻格，无处可去则留在原地。撤退并不保证保住残兵。

未交战且没有受到进攻的军队可以遣散，立即移除并停止维持，不退还征召材料。停战或退盟后的非法滞留部队由系统逐期遣返，不会沿途取得土地。

## 外交与联盟

### 宣战前发生什么

模型通过工具宣战时，先自检，再确认提交。未带确认参数的调用只返回警告和实际参战推演；带 `confirm=true` 才提交战争。它提示玩家核对敌情、实际投入、后方、预备队、第三方和退出条件，不替玩家决定战争是否值得打。

正式提交后仍要等回合末外交阶段重验，联盟还可能需要先表决。看见“已提交”时，本回合不能立即把对方当作已经开战的敌国。若休战、阵营或其他条件变化使命令失效，会返回实际失败结果。

### 保障、共同防御和联盟有何不同

| 关系 | 主要作用 | 是否合并外交 |
| --- | --- | --- |
| 独立保障 | A 保障 B，第三方向 B 宣战时，A 按义务加入防守 | 否，单向义务 |
| 共同防御 | 任一方遭宣战时，另一方按义务加入防守 | 否，双向义务 |
| 联盟 | 成员共享视野、领土通行，作为一个整体处理对外关系 | 是，重大外交须内部表决 |

保障和共同防御只响应伙伴遭到宣战，不帮助伙伴自动发动进攻。义务沿**最初防守方的直接条约传导一跳**：A 保 B，C 保 A，攻击 B 会召来 A，不会仅因 C 保 A 就再召来 C。联盟作为一个整体参战；向联盟任一成员宣战，要面对它的整个外交实体。有效休战可能阻止某个条约援军参战。

宣战时确定战线。此后同一战争中的进攻不会重复触发条约；新的合法宣战仍可能把援军带入已有战线。宣战推演可以事先查看实际名单。

### 入盟与退盟

创盟需要全部受邀国明确接受，未全部接受只是提议，任何一国拒绝都会使其失败。发出创盟提议固定花 100 金，即使被拒也不退；加入已有联盟则须现成员表决。

入盟后，个人保障与共同防御中涉及本国的条约全部作废，退盟也不恢复。军队、库存、建设和国土仍归各国自行经营；保障、共同防御、宣战和议和改由联盟表决。

任一成员交战时，全盟不能退盟或解散。和平时盟主须先转让盟主权才能退出。退盟后向原盟任一成员宣战，仍面对其整个联盟。

### 表决怎样进行

T 回合发起的议案，在 T＋1 回合开放投票，并在该回合末计票。盟主也是普通一票，发起人没有自动赞成票。

赞成票多于反对票即通过；显式弃权保留，结束行动时仍未投票则自动反对。开票前只能看到自己的选票，其他成员是否投票、投向和票数都隐藏；开票后向全体选民公布记名结果。可以写信拉票，但信件承诺不代替实际投票。

联盟内部尚未生效的宣战议案不会自动通知外部目标；正式外交生效后才按规则公告。

### 议和与回应邀约

和平可以无赔款、支付或索取赔款，也可约定称臣，须对方接受。只有双方**战争主导实体的代表**能办理整条战线的议和；普通跟随参战方不能自行退出，联盟还须表决。

和平生效后整条战线停战，并处理休战和滞留军队。休战到注明的到期回合即失效，不额外多保护一回合。

收到本国有权直接回应的邀约，需要在本次行动结束前处理；未回应会提交自动拒绝。刚在结算送达的邀请，会等收件国下一次行动。已提交的回应不会因为流程尚未完成就要求每期重复接受。

## 附庸与贡赋

普通附庸每期向宗主缴纳实际生产的 **15%**，仍自行经营经济、土地和军队，但没有独立外交权与联盟表决权，随宗主的外交实体参战，由宗主代表谈判。

宗主可以邀请对方臣服，弱国也可以主动称臣；普通附庸关系需要对方接受。宗主在和平时可释放附庸，普通附庸要主动脱离则须发动真实的独立战争。宗主灭国或成为其他国家的普通附庸时，其原普通附庸在结算时释放。

贡赋从本期实际产出中扣，余量才用于后续生产链；宗主在全体生产结束后收到贡品，本期不能拿这批贡品再生产。库存、交易、礼物、借款、利息和电力不计贡，停工也没有产出贡赋。

小数按同一附庸、宗主和资源跨期累积，凑满 1 才扣取。例如本期产 3 木，15% 为 0.45 木；前两期累计 0.90，第三期累计 1.35，扣 1 木，余下 0.35 继续结转。不是对每座建筑分别取整。

周天下使用下节的特殊附庸规则，保留正常盟友权力，与普通附庸的外交限制不同。

## 八国剧本

正式八国为秦、魏、韩、赵、燕、齐、楚、周，使用 24×24 地图。开局七雄分别保障周王室独立，**保障人是七雄，受保护国是周**。周没有反向保障七雄；赵向燕宣战，不会因为这七条初始保障召来周。

周可以像其他国家一样主动战争，也可以建立“周天下”。首次成功接纳称臣可自动创建周天下，花费周 100 金；已有联盟的后续入盟依正常表决处理。

周任盟主时，成员自动成为特殊附庸，每期上交实际生产的 **10%**，保留正常盟友的投票、经济、军队和和平退盟权。若带有普通附庸的宗主加入，原附庸一并转为周的直接特殊附庸，不保留双层控制和贡赋。周不能称臣，在位时不能转让周天下盟主权；周亡国后，该联盟按普通规则延续，特殊贡赋失效。

八国有两种明确的终局：

| 路线 | 达成条件 | 结果 |
| --- | --- | --- |
| 兼并天下 | 只剩一个存续国家 | 该国获胜 |
| 尊王 | 周及其周天下特殊附庸覆盖全部存续国家，合计至少五国，完整回合末检查成立 | 仅周获胜，其余成员臣属保全，未胜未败 |

加入周天下不会立即获胜，普通联盟也不自动构成共同胜利。诸侯可以将入盟当作争取生存和发展时间的工具，但最后应区分本国获胜与臣属保全。

达到配置的回合上限时也会停止运行，不代表已有人满足上述胜利条件。成绩单中的经济统计与剧本终局分别阅读。

## 国策与记忆

以下国策、小结与议会要求适用于 AI。正式绑定的真人席位无需提交国策、小结或议会解释，实际行动仍保留回执，结束回合仍处理未回应外交与投票。

国策是跨回合的战略，默认有效十回合。它说明经济、军事、情报和外交的目标、优先级与调整条件；到期后需要更新，战略变化时也可以提前修订。有效国策未补齐时不能正常结束本国回合。

每回合小结用一两句话记录实际做过什么，详细过程由行动回执保留。国策写“准备占领”，小结和战果就应区分已经提交进攻、仍在交战与确已占领。

LLM 客户端会保存近期对话、长期记忆和可检索历史；压缩对话不等于删除独立历史档案。模型可以按关键词检索自己过去的行动、发言和回执，检索不包含思考正文。摘要与自述仍可能出错，关键事实要结合带日期的原始回执。

简报中的 tips 和宣战警告提供规则与策略提醒。讲义中的建议也需要结合当期局势，不能把旧国策、旧摘要或一句提示当作永久有效的引擎限制。

### 可选议会

默认 native 不加载议会。选择 experimental 才启用：首版国策直接生效，第一次修订起，议长先检查上版国策之后的执行记录，再看新版并批准或打回。

被打回后，君主需要解释，下一回合重提；仍可进行其他合法行动。连续三个实际相邻回合未通过，会触发罢免和历史交接，新君主接管现有国家，资源、军队和真实条约不会因此重置。

这套实验会增加模型调用与历史处理成本，议长的判断也可能有误。审核规则、模型配置与短脚本玩法见 [experimental 说明](../../experimental/README.md)。

### 特殊政体：匈奴

匈奴通常作为后续登场的势力，具体时间和开局资源由配置决定。其骑兵改用 8 粮、8 装备征召，建造金币费用为普通政体的 130%；可以宣战、求和、写信和派间谍，不参加联盟、保障、共同防御、送礼或共享地图。兵种其他基础属性按当前目录查询。

## 人类观察者

人类在终端查看全景、发公告与来信，也可通过管理命令改变局势。观察者权限与国家玩家分开；给模型寄信不会把全图或后台库存自动交给它。

| 命令 | 作用 |
| --- | --- |
| `help` | 查看当前命令与用法 |
| `board` | 全景国力 |
| `map` / `map 秦` | 全图 / 指定国家的过滤视野 |
| `map world.svg` / `map 秦 qin.png` | 导出文字、SVG 或 PNG 地图；PNG 需图片依赖 |
| `thoughts` / `thoughts on` / `thoughts off` | 最近思考 / 展开 / 收起 |
| `say 公告正文` | 向所有国家发公告 |
| `send 秦 来信正文` | 给指定国家寄观察者来信 |
| `add 林胡` | 让已配置的待登场国家加入 |
| `rate 5` | 把储蓄利率调为 5% |
| `cheat 秦 金100 粮20 骑2` | 给指定国家补助资源或军队 |
| `pause` / `resume` | 完整回合保存后暂停 / 继续 |
| `quit` | 完成本回合、保存并退出 |

公告与信件支持多行输入，以单独一行 `END` 结束，也支持 `@文件` 读取正文。命令在模型调用间处理，等待模型回复时会排队。`Ctrl-C` 立即中断，只保留最近完整结算存档，未结算行动可能已写日志但尚未入档。

每局宜使用独立配置、存档和日志路径。备份包括存档旁的 `<存档名>.audit/`，才能保留归档历史；读旧局需要对应的模块版本，不能只把新代码覆盖上去继续加载。

桌面版有地图缩放、点选、抽屉、播放和保存，目前运行独立离线规则 AI 演示局，具体操作与范围见[桌面说明](../../ui/desktop/README.md)。终端启动与模型配置见[项目 README](../../../README.md)。
