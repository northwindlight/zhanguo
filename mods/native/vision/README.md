# 视野模块

`native:vision` 1.0.0 是 [正式发行版](../README.md) 的无状态查询模块，提供 `Vision.visible / tiles`，工具和面板 `view`；查询不物化地图。

本国及同盟土地周围一格可见，已落成哨塔通过建筑效果扩展视野。可见他国土地只公开已落成城堡和市政厅；其他建筑、资源容量与库存保密。同盟共享可见范围，但不因此公开伙伴的完整经济信息。

依赖领土、外交及建筑公共事实，无独立存档或结算挂点。历史事件可见范围由情报域在发生时快照，不能用当前视野回溯。验收覆盖同盟、哨塔、外国建筑和资源过滤，见 `tests.test_world_domains`。
