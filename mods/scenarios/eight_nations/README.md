# 八国轻量剧本 Mod

`scenario:eight-nations` 继承 `ScenarioMod`，无自有持久化状态。发行版 Members 加载 `mod.toml`，`Distribution.Scenarios.eight_nations.Mod` 挂载，用户配置 `scenario: "eight_nations"` 才绑定钩子。

- `on_start` 幂等地安装周的特殊宗主联盟配置：身份 `scenario:zhou`、周天下、10%生产贡赋、自动接受首次称臣、首次建盟费100金。此钩子不扣钱，不赠物资。
- `on_new_game` 在新局全部初始国家登场后建立七雄各自保障周的条约，保障人是七雄、受保护国是周；通用 CLI 和创建器一致，续档、重新绑定及后续登场不会重建已撤销的保障。
- 通用外交负责在回合末执行已配置效果；周为盟主的盟友自动为特殊附庸，保留普通盟友权力。首次称臣自动创建周天下并扣周100金，后续入盟保留表决，不再收建盟费。
- 宗主加入周天下时，原附庸一并移交周，全部成为周的直接10%附庸并取得盟友权力；原宗主失去旧附庸的贡赋与控制，不保留双层结构。
- 周不能成为附庸；周在位时周天下盟主权不可移交。周灭国后按普通联盟规则继任盟主，盟友关系保留，但贡赋和附庸自动移交全部失效。
- `on_settlement` 在完整周期末检查周及特殊附庸覆盖所有存续国家且至少5国，或唯一存续国家兼并胜利；全覆盖即判仅周获胜，其他成员臣属保全（未胜未败，不列入主胜或次胜），不添加缴贡等待期。
- 所有世界读写都经声明的领域接口，胜利只经注入的 `trigger_victory`。资源、外交关系由其所有者存档，Mod不持有跨会话world引用。

手摆初始地图由 `scenarios/eight_nations.py` 配置；初始保障归本剧本的 `on_new_game`，不依赖操作者使用专用创建器。八国专属规则均在本目录，通用引擎和外交模块不识别周的国家键。

朝贡按每国每期各类资源的全国实际总产出乘贡率，小数按附庸、宗主及资源跨期累计，累计额向下取整扣取，余数继续结转。
