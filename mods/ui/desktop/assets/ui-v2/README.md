# GUI 补绘素材

本目录 SVG 为战国项目原创，使用仓库 MPL-2.0。采用整数像素网格，透明背景；Godot 直接导入，不依赖外部图片服务。

| 文件 | 原始尺寸 | 用途／锚点 |
| --- | --- | --- |
| market.svg | 64×48 | 市政厅旁唯一集市，脚点 (32,44)，视觉设施，不增加规则建筑 |
| road.svg | 8×8 | 已验证道路网的小格，中心 (4,4) |
| war-arrow.svg | 16×16 | 朝右的进攻箭头，中心 (8,8)，随方向旋转、使用进攻方国色 |
| letter.svg | 20×16 | 实际送达信件，中心 (10,8) |
| bird-up.svg / bird-down.svg | 16×8 | 同一鸟群的扑翼姿态，中心 (8,4) |

补绘资源图标也置于本目录；新增文件须保留 SVG 母版并在实际地图缩放中检查。
