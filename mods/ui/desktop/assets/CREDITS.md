# Mini World assets

Source: https://merchant-shade.itch.io/16x16-mini-world-sprites

Authors: Shade and octoshrimpy. Author download `MiniWorldSprites.zip`,
published 2022-12-24, downloaded 2026-10-23. The author page's Asset license field
was verified as **Creative Commons Zero v1.0 Universal** on that date.
https://creativecommons.org/publicdomain/zero/1.0/

Only the generic asset sheets in `manifest.json` are redistributed here,
unmodified. The manifest records original paths and SHA-256 hashes. No named
fictional character assets, customization pack or third-party expansions are used.

Grass and nature use 16×16 source regions. Swordsman uses a static 16×16 idle
frame; knight uses the four 32×32 frames in row 0 for idle only. No walking,
attack, injury or death animation is claimed by this first implementation.
Mountains and hills are drawn in code. Building icons are generic visual proxies;
the inspector lists every actual kind and level, including unknown content IDs.
The troop count is the actual number of surviving rule units in a tile, not
the number of illustrated soldiers or their combined HP.

The initial `--sample terrain` batch reused the unmodified tree and house
sheets. Its 6x8 scale figures, farmland, mineral outcrops and terrain shading
were drawn in project code. These
are provisional synthetic visuals, not a claim of complete character art.

Stage A, second batch (2026-10-23): three more unmodified sheets were selected
from the same author archive: `Nature/PineTrees.png`, `Nature/Rocks.png` and
`Buildings/Wood/CaveV2.png`. Their local names and SHA-256 hashes are in the
manifest. The author page and its CC0 license field were checked again on
2026-10-23. Green pine cell (1,0), gray rock row 0 and mineshaft cell (0,0) are used by the
terrain sample; no new character/IP sheets are included.

`generated/mountain-outcrop-v1.png` was generated using the built-in image_gen
tool on 2026-10-23 for this project. It is a prototype terrain sprite with real
alpha transparency. Its complete prompt is `generated/mountain-outcrop-v1.prompt.txt`;
its hash, dimensions and provenance are in `generated/manifest.json`.
This generated image is separate from the author's Mini World assets and is
not presented as part of that pack or as an asset covered by its CC0 statement.

`generated/agy-mountain-source-v1.jpg` was generated by the existing local
Antigravity gateway on 2026-10-23 (route requested `gemini-3.1-flash-image`).
It returned a JPEG with a painted checkerboard, not alpha transparency.
The built-in image_gen tool then extracted the background to create
`generated/agy-mountain-cutout-v1.png`, preserving the design for a prototype
second mountain silhouette. This is a generated derivative, not a byte-exact
pixel extraction. Both prompts, original JPEG, transparent derivative and
their provenance/hashes are kept under `generated/`. It is also separate
from the Mini World author's assets and license statement.
