## 接入约定

- 沿用现有深绿面板、米金边框、木色和统一世界色板；军令蓝、红作为语义色补充。
- SVG 用整数坐标和离散轮廓，不依赖滤镜、渐变、外部图片或脚本。PNG 最近邻采样，优先按原尺寸或整数倍显示。
- 按钮和面板使用九宫格拉伸，边距 4px；正文由游戏字体渲染，图标和底板没有内嵌中文。整页 SVG 的中文只用于设计预览，使用系统 Noto Sans CJK SC，不是游戏字体选型变更。
- 军令圆圈表示一个逻辑地块，按地块居中铺设。实线与虚线只是显示语义，目标与军队子集必须从玩家已知事实计算。
- `range-move-*` 保持蓝色空心，`range-attack-*` 保持红色准星；不能因国色染色而丢失命令区别。
- `army-own` 是迷雾上方的己方位置标记，仍由点地块打开驻军面板；不能加回点击军队选中的操作。
- `army-last-seen` 只用于曾合法见过的部队，必须附最后发现日期。普通地图报告不含军队位置，不得凭报告中的总兵数生成标记。
- 地图图标、道具不自带“购买成功”或“已送达”语义；以正式动作结果和收件事实决定何时显示。
- 原尺寸 16×16 的边缘图放在**已知格内侧**，`north=1/east=2/south=4/west=8` 表示对应相邻格为未知。未知格始终使用不透明底纹，不能拿半透明过渡替代未知遮罩。
- `fog-memory` 是透明度约 62% 的深色覆盖纹理；去饱和需另由绘制层完成。其下只渲染保存的历史建筑和地形，不运行人物、烟气、施工、水面与生产动画。
- 未知遮罩下不建立秘密地形、建筑、军队等可被点选或镜头自动聚焦的对象。遮罩纹理不是信息权限机制。
- 整页示意图复用现有 `unified-v1` 的地表色、树木和建筑 SVG，暗区无居民图形，候选虚线覆盖暗区及未知区。布局比例为屏幕样板，不改变 256×256 地区或现有建筑世界尺度。

## 重建与验证

仓库根目录运行：

```bash
.venv/bin/python scripts/build_human_ui_art.py
```

依赖 Pillow 和系统 librsvg/Cairo，或可选 CairoSVG。复用现有 `build_unified_art.Rasterizer`，不联网，不导入游戏，不读取存档或 API 设置。

SVG 绘图定义保存在生成脚本；调整导出 SVG 时需同步定义，重建只覆盖本素材目录及对应设计预览目录。

[validation.json](validation.json) 记录 XML、自包含、像素透明度、未知底纹不透明、历史覆盖半透明及图集逐像素读回结果。0 号边缘故意留空。按钮、图标、范围圈与边缘的透明度只取 0/255，历史覆盖层除外。
