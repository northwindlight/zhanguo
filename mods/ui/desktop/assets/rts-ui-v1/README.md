# 建设与征兵界面 SVG

2026-10-27 补绘，沿用本仓库 MPL-2.0。运行时由 Godot 导入 SVG，不需要在线服务。
母版与 SHA-256 见 manifest.json；可用 `python scripts/build_rts_ui_art.py` 确定性重建。

城堡与林场画布为 48×56，脚底锚点 (24,48)。城堡使用石墙、雉堞和主堡；
林场使用木屋、原木堆和树木，分别替换原来复用的兵营／房屋。
四种厂区为 64×64、锚点 (32,56)、烟囱 (50,6)，由原有原创 factory SVG 延伸；
屋顶色、木材／石油／补给／装备标志和发电闪电区分用途。
资源图标为 24×24，未知扩展资源使用中性箱子，文字仍取实际资源名称。

RtsArt.cs 将这些素材同时用于地图建筑、建设候选与本格库存；兵种卡直接截取
现有小人图集并使用本国军服颜色。普通建筑显示数量与施工状态，仅城堡显示等级。
Windows 包的“美术预览/建设征兵SVG”附同一套母版，方便讨论和修改。
