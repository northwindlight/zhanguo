# 旧版地图人物与建筑素材

当前默认地图使用 [unified-v1](../unified-v1/README.md) 的原创统一图集。
本目录保留此前图片、提示词、来源与帧表，方便追溯；以下是旧版接法，
向这里放入旧格式图片不会自动替换新图集。


已接入六张真实透明建筑 PNG：`townhall`、`farm`、`mine`、`oilwell`、`factory`、`barracks`。
由本次内置 image_gen 生成，原图保留；Godot 导入尺寸上限 128px，地图内按建筑脚印等比缩放。
每张完整提示词在同名 `.prompt.txt`，来源、尺寸、alpha 和 SHA-256 在 `generated-buildings.json`。
这些图是游戏原型美术，不属于 Mini World 作者的原始贴图。

另已接入原 Mini World 包的 17 张未修改人物表：剑兵、矛兵、斧兵、骑兵各四种配色，
以及农民。逐文件来源路径与 SHA-256 见 `mini-world-characters.json`；原包 CC0 说明见上级 `CREDITS.md`。
`mini-*` 按各自原包布局读取：清单分别声明待机、行走、攻击/工作的四方向行号与帧数，
不假定所有人物共用行列。步兵与居民每格16×16，骑兵32×32（显示为24像素）。
剑兵攻击4帧、斧兵攻击6帧、农民工作3帧；骑兵按每方向三行读取。
矛兵攻击区使用不规则格子，暂用完整身体帧配合程序突刺，避免切出半个人或空帧。
居民额外通过代码改变衣色、发型、头巾和携带物，野人保留粗布与棍矛外观。
同一类步兵允许剑、矛、斧外观混编，骑兵用完整人马；外观差异不代表新增规则兵种。

下列自定义人物表与两种树图仍可添加；自定义人物表优先，未提供时使用原包动作表。
启动器会先执行导入；人物帧格由 `manifest.json` 的 `sheets` 定义。

## 统一规格（所有素材）

- 视角：正交高角度俯视、略见正面，与现有 16×16 房舍同方向；不用等距菱形底座。
- 画法：粗像素、有限色板、左上光源、边缘干净；**服装主体保持素色/浅灰**，
  程序会轻量混合国家颜色，衣服画成大红大紫会看不清国别。
- 背景：PNG 真 alpha 透明；不画棋盘格、地面方块、阴影底、文字、边框。
- 每张图一个对象一个方向；左右朝向用两行帧分别画，不要镜像同一行。

## Gemini 提示词模板（可直接改词复用）

人物（以步兵为例，其余同格式）：

```text
为一款小比例2D大战略游戏绘制角色精灵表，16×16逻辑像素每格，共4行6列，
画布96×64。第0行：士兵朝右行走完整6帧循环；第1行：同一士兵朝左行走6帧
（单独绘制，不是镜像）；第2行：朝右持矛突刺/劈砍6帧；第3行：朝左攻击6帧。
士兵穿素灰束腰外衣与金属头盔，持木矛和圆木盾，脚底贴每格下边缘居中，
身高约12像素。粗像素、有限色板、左上光源、轮廓清楚。整张PNG背景真实透明，
不要棋盘格、地面、阴影底、文字或界面元素。
```

建筑（以市政厅为例）：

```text
为一款小比例2D大战略游戏绘制一栋市政厅素材，显示尺寸约64×64像素。
高角度俯视、略见正面，非等距视角、无菱形底座。石基座加木构二层大屋，
屋顶正脊带小旗杆，门口两级台阶。粗像素、有限色板、左上光源，与16×16
木屋同一画法。只画一栋建筑，完整轮廓，四周透明留空，PNG真透明输出；
不要人物、地面方块、烟雾、文字或照片质感。
```

放入文件后运行 `python desktop.py`（或 `--sample terrain`）直接查看缩放效果；
不合适删除文件即回到代码绘制版本。
