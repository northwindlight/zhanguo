# v14 联合经济规划

v14作为新局可选候选，默认仍为v13；`rule_ai=v13`或`v11plus`仍可显式选择，旧档按原策略续跑。v14用SciPy／HiGHS求解跨期混合整数规划，把建设、交易、库存、电力和军需放在同一个预算模型内，不再按建筑逐项评分、买材料、遇到首个缺口就结束投资。

求解器固定单线程，桌面宿主同时限制BLAS线程，减少Windows与渲染进程争抢CPU。源码环境先在项目虚拟环境中安装`requirements.txt`。Windows便携包内置NumPy／SciPy和相应许可证，不依赖系统Python；v11plus、v13和LLM协议本身仍不要求求解器。

## 规划如何工作

- 每次行动用绑定玩家的正式`planning`、目录、账户整单报价、库存、军需与银行信息建模，不读取观察者全图或其他客户端策略。
- 同时决定未来4期各地开工、买卖、燃料／原料储备、自动生产、电网和征募；已知贷款到期会延长窗口纳入还款（原生贷款最长5期）。资源逐阶段守恒；施工与征募发生在生产之前，新建筑下期才生产。每格额度、共享资源位、预付队列占位和工程院落成后的正式折扣一起受约束。
- 生产遵守采集、发电、工业、市政厅的顺序，同类设施聚合后仍必须最大化自动运行，不能虚构逐厂关机。缺电时全网耗电建筑停摆，燃料不足不会凭空产生电力。
- 补给按全国需求与可用库存的最小值自动扣取，整数装备恢复也必须实际消耗；断粮时停止恢复。模型不能通过“选择少吃／少回血”留下并不存在的库存。
- 先最小化服务短缺，本期优先于全部未来预测短缺（权重由未来短缺上界推导），再满足扩军排程需求（持久化绝对期限，避免随滚动窗口无限推迟；新增军需须在实际可运行净产出的30%以内），最后最大化折现的期末现金、库存与产能延续价值。军事控制器仍沿用原分组、寻路和战斗逻辑；经济求解统一核算征兵、设施和后续补给，避免先征兵再挤占建设预算。
- 当前整单成本及期末批量清算用正式报价的分段线性保守近似，包含金币尾差边界；同资源当期买卖互斥。未来买卖价取现价与公开净流量预测区间的保守端，不将预测涨价当作已实现利润；外国净交易、固定军事需求及延续价值仍是预测假设，不是已知未来。
- 每层最多8个搜索节点、5秒，经济层目标为2%相对间隙，触及预算时实际间隙可能更大。保存目标、界、间隙、各层状态和独立可行性检查结果；只有所有层真正证明最优时才标为最优。节点用尽的可行解仍可执行，没有可行解则不交易，不退回旧贪心策略。

只提交本期方案。提交前再次核对正式报价、完整资金／材料和行动预算，再依次执行出售、购买、建设与征募。长规划没有可行整数解时，在同一模型冻结新投资和扩军，求解一期运营；诊断明确标记`operations_only`并保留失败信息，不冒称完成长期优化。意外回执失败时停止余下提交，下次行动重算；已经生效的动作不伪装成可回滚事务。下一期重新读取现实状态，上一期的后续计划不直接执行。节点预算用于限制搜索规模，5秒上限防止单个困难问题阻塞界面；触及时间上限时不同机器可能取得不同的可行方案，不保证跨算力逐动作重放。

## 模型的实际边界

- 这是有限时域滚动规划；1%每期折现、公开价格路径和末期产能延续是目标假设，不声称完整博弈或无限时域最大复利。
- 未来市场以公开净流量预测，不能提前知道其他国家选择；未将本次所有新产能对长期价格的非线性反作用精确嵌入MILP。因此收益必须用实际结算对照，不能把模型目标当真实利润。
- 只预测持有土地和既有军队需求，不预测征服、死亡和战后恢复；外交变化、市场自动委托等外部动作可能改变计划。已知贡赋、到期债务和当前恢复需求进入预算，不猜测外国未来来贡。
- 不取消人工预付队列。待建地块保守地不再安排新投资，待征单位按未来全部生成预留补给；队列具体落成时点仍由正式规则处理。
- 沿用v13的持久经营偏好标识和公开市场记忆；当前只使用其中预测长度和交易规模参数，没有保留v13全部逐项偏好加权。旧存档不会被重标成v14。v14另保存`recruit_due`这一绝对扩军期限，v13状态格式不变。

`economy.run(ledger,state,manage_military=False)`提供经济职责入口，不写国策、不调兵、不外交、不借新贷款、不结束回合。本次尚未接真人经济托管开关或GUI预算面板。

## 验证

```bash
python3 -m unittest tests.test_rule_v14 tests.test_rule_market tests.test_rule_strategy -q
python3 experiments/rule_market/run.py --versions v13 v14 --seeds 73 --turns 20 --economy-only --out archive/previews/v14/joint-20.json
```

小模型先与完全枚举对照，再核对预测与引擎正式结算的电网、工厂共享原料、跨期折扣、贡赋小数和银行还款。基准统计实际投入／产出，按开局固定中间价计算生产净值，同时列行动失败、计划拒交、停电、军需和求解间隙。

净产出不含建设、征兵、军需与交易成本，不是全口径利润或胜率。八国统计均为整局合计。此前顺序v14原型已被替代，其样本提升不能作为本模型的成绩。数学结构见[联合规划设计](../../docs/design/v14联合经济规划.md)。
