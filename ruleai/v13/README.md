# v13 市场策略

v13 沿用 v11plus 的军事分组与战斗判断，重新实现经济规划。新局 `client=rule` 默认使用 v13；`rule_ai=v11plus` 保留旧策略用于对照。

每个国家开局随机选择一种经营偏好，保存在客户端状态中，续档不会重抽。默认抽签种子由本局地图种子与国家 ID 派生，延迟登场与续档也可复现。可选 `rule_seed` 固定本国抽签种子，或用 `rule_strategy` 显式指定。不同国家使用相同 `rule_seed` 会抽到同一偏好；做可重复实验时应给各国不同种子。

| rule_strategy | 偏好 | 原料目标储备 | 再采购阈值 |
| --- | --- | --- | --- |
| balanced | 平衡自产、出口与现金 | 3 期 | 低于约 1 期 |
| integrated | 更长投资期，优先补本国生产链 | 4 期 | 低于约 2 期 |
| merchant | 偏重出口、较快周转 | 2 期 | 低于约 1 期 |
| buffer | 较大库存、缓慢出售，批次补货 | 6 期 | 低于约 3 期 |
| liquid | 更高现金储备，偏重金币收入 | 2 期 | 低于约 1 期 |

缺省 `rule_strategy=random`。这是随机经营偏好，不保证一次八国抽签中五种偏好全部出现，也不把其他玩家视为必定同策略。

```json
{"id":"scenario:qin","name":"秦","client":"rule","rule_ai":"v13","rule_strategy":"random","rule_seed":7301}
```

市场模型只消费玩家公开的库存、基准库存、双边报价和大单试算。相邻快照的库存差扣掉本国实际交易，用于估计其他参与者的净订单；近期订单逐步衰减，避免把一次性清仓或建设采购永久外推。投资同时评估通常情景与其他参与者跟随增产的压力情景。每建成一项投资计划立即重新评分，计入它对既有出口收益和原料价格的影响。

没有读取其他客户端的偏好、隐藏库存或建筑。跟随增产是压力假设，不是已知的敌国意图。模型从公开整单试算估计价格曲率，库存基准漂移从历史观测估计；它不是市场引擎的精确复制，替换计价规则、突发战争或策略切换后仍可能预测失准。

运营预算统一包含木电燃料、油电燃料、工厂原料、军需、维修装备和现金。建材在出售前按本期合法施工位置预留；已有兵营的征兵材料也保留，同期售出的资源不再买回。买入使用 `economy:queries.trade_quote` 的本账户整单报价，包含累计成交深度和金币零头；不存在的市场库存不能当可采购材料。先验算整套配方再买入，较大储备买不起时降为一期开工材料，再降为军需，不逐项耗尽现金追逐无法开工的配方。

电厂按完整装机容量、安装费和持续燃料成本比较。功率刚好用完时允许为后续合法用电建筑扩容，不等实际停电才行动；在建厂的后续燃料也不作为多余库存卖掉。

亏损工业不主动高价补料；游戏没有逐厂开关，共享原料或已有库存仍可能让它实际开工。材料完全不可得或资金不足时，策略仍可能缺料或停电，不承诺永不缺料，也不修改市场库存、回补规则或建筑结算。

v13 保存独立的策略偏好、市场观测、上期本国成交和军事目标。不能把 v11plus 的状态解释成 v13；加载时显式改版本会拒绝。未指定版本时按存档记录恢复旧客户端。新增只读整单报价提升了经济查询模块版本，依赖清单不同的整局仍遵循引擎的严格拒绝加载规则，不自动迁移真实存档。

验收与重复实验见 [市场回归实验](../../experiments/rule_market/README.md)。
